# Insight Out 커버 이미지 프롬프트 라이브러리 (나노바나나 실사풍)

목적: 콘텐츠 카드·리포트에 쓸 **실사풍 에디토리얼 커버**를 David가 나노바나나(Gemini 2.5 Flash Image)로 생성하기 위한 프롬프트 모음. 폴백 체인(원본 썸네일 → **이 이미지 풀** → BrandedCover)에서 "이미지 못 가져온" 카드를 채운다. ④ 문서(추상 버전)의 스타일을 **실사풍**으로 대체.

키워드 그룹 slug는 실제 `keyword_groups.kind`와 일치(그대로 스토리지 폴더명으로 사용).

---

## 0. 공통 규칙 (모든 이미지)

- **규격**: 16:9, 1600×900(또는 1200×675), webp, ~200KB. 카드 `aspect-[16/9]`와 일치.
- **수량**: 키마다 **5~8장** 변형(세트감 유지, §변형축만 변경).
- **스토리지 규약**(어드민 업로드 시 참고): `topic-covers` 버킷 →
  `group/{kind}/{n}.webp`(예: `group/ai_tech/1.webp`), `entity/{slug}/{n}.webp`, `category/{name}/{n}.webp`, `report/{type}/{n}.webp`.
- **네거티브(반드시 배제)**: 텍스트·글자, 실제 로고·상표, 읽히는 브랜드명, **식별 가능한 실제 인물·실제 특정 건물**, 워터마크.

### 공통 스타일 접미사 (모든 프롬프트 끝에 붙임)
```
Photorealistic editorial photograph, cinematic soft lighting, shallow depth of field, deep navy and charcoal tones with a single restrained magenta accent (#DB0078), premium corporate tech-media aesthetic, 16:9 wide composition with clean empty negative space in the lower-left third, muted cohesive color grade, high detail 4k, no text, no logos, no brand names, no identifiable real people, no identifiable real buildings.
```

### 나노바나나 팁
- 자연어 서술형이 잘 먹힘(아래 프롬프트 = 장면 서술 + 공통 접미사).
- 세트 일관성: 첫 장을 마음에 들게 뽑은 뒤 "same lighting and color grade, different composition" 식으로 변형 요청.
- 인물이 필요하면 **얼굴 안 보이게**(뒤/실루엣/손·기기 클로즈업).

## F. 진행 방식
1. David: 위 프롬프트로 키별 5~8장 생성 → 16:9 webp로 저장(키별 폴더 구분).
2. Opus: 셀렉터 지시서(어드민 업로드/배정 UI + 렌더 셀렉터 + `topic_cover_images` 테이블·`topic-covers` 버킷) 작성.
3. Sonnet 구현 → 어드민에서 이미지 업로드·엔티티 배정 → 카드/리포트에 자동 노출.

> 우선순위 팁: **자주 뜨는 그룹부터** — `ai_tech`, `aidc`, `telecom_b2b`, `bigtech`, `it_trend`, `esg`, `mobility` + 카테고리 4종 + `report/strategy`. 나머지 그룹·엔티티는 이후 보강.
