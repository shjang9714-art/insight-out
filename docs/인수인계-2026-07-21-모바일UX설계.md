## 4. v4에 반영된 설계 결정 (David 확정 사항)

1. **스플래시**: 전구 점화 애니메이션 확정 — `.io-login` 라벤더/골드 그라디언트 위에 실제 브랜드 에셋(`public/brand/login-bulb-scene.png`)이 어둡게 등장 → 1.2초에 플래시와 함께 점화 → 광류 orb가 곡선을 따라 전구로 모여듦(웹 BulbScene의 animateMotion 연출 + globals.css의 ioGlowPulse/ioTwinkle 키프레임 동일 이식). 3.4초 후 자동 전환(탭 스킵 가능).
2. **로그인**: 스플래시 뒤에는 **로고·전구 없이 클린 로그인 박스만** (David 확정). 카드 내용은 실제 LoginCard.tsx 그대로: 이메일(name@lguplus.co.kr placeholder + 사내 계정 안내)·비밀번호 → OTP 복구 플로우(6자리 자동 검증, 10:00 타이머, 재전송) → 하단 "관리자는 Google로 로그인".
3. **모든 화면은 모바일 특화 + 기능 최적화 전환 구조** (David 지시). 미학이 아니라 기능이 전환 패턴을 결정:
   - **미니플레이어**: 모닝브리핑 ▶ 재생 시 하단 고정 플레이어 등장, **탭 이동에도 지속** (출근길 오디오 = 모바일 킬러 유스케이스)
   - **바텀시트 상세**: 신호·기업 탭 시 페이지 이동 없이 시트로 — 시사점 → 논조 추이 차트 → 근거 콘텐츠 → 액션(추적 토글/보고서로/공유). 컨텍스트 유지가 목적.
   - **풀스크린 질문 오버레이**: 중앙 검색 FAB → 렌즈별 추천 질문 칩(경쟁사/규제/기회/내 서비스) → 출처 pill 달린 AI 답변 카드 → "보고서로 보내기" (AlphaSense식 생성형 검색 지향)
   - 탭 전환은 즉시 크로스페이드(스택 없음), 상세는 시트, 전역 진입은 오버레이 — 3단 전환 문법.
4. **탭 구성**: **홈 · 이슈 · 검색(중앙 FAB) · 기업 · 보고서**. 근거: 사용자IA-재구성(2026-06-22)의 목표 IA(홈·이슈·기업·콘텐츠·보고서 + 검색 1급)를 모바일 5슬롯에 배치. 마이 → 우상단 아바타. 콘텐츠 라이브러리 → 검색 안 필터로("출처는 축이 아니라 원재료" 원칙). ※ 마스터플랜(6-19)의 "홈·이슈·검색·보고서·마이"와 다른 부분 — **기업(미팅 전 5분 브리핑)을 1급으로 올린 것은 이 레인의 제안**이며 David 이의 없이 진행됨. 최종 확정은 필요 시 재논의.
5. **홈 구조**: "오늘 알아야 할 한 가지" 한 문장 히어로(잡스 페르소나: "위젯이 아니라 답") + 신호 3개(시사점 한 줄 + 근거 수) + 개인화 토글(전체↔내 서비스) + 모닝브리핑 카드 + 워치리스트 피드.
6. **보고서 탭**: 모바일은 읽기·공유 전용(진행률 표시), 워크벤치(조립·AI 다듬기)는 데스크톱 안내.

## 5. 디자인 토큰 (실제 코드 추출 — 하드코딩 아님)

- 출처: `src/app/globals.css` — brand-600 **#E6007E**(다크 #FF4FA8), brand-solid-hover #c5006b, insight-teal-strong **#0F6E56**(아이브로우 전용), 헤딩 네이비 #0f244d, slate 뉴트럴, positive/negative/risk 시맨틱.
- `.io-login` 배경 그라디언트·ioGlowPulse·ioTwinkle 키프레임은 globals.css 값 그대로 이식.
- 폰트 Pretendard(동적 서브셋). 디자인 가이드 원칙 준수: flat 카드·얇은 보더·그림자 지양·마젠타는 CTA/핵심 강조에만·WCAG AA.
- 전구 에셋: `public/brand/login-bulb-scene.png`(1820×1290)를 세로 크롭 480px JPEG(22KB)로 다운스케일해 data URL 인라인. 작업 파생물: 컨테이너 `/home/claude/work/bulb-splash.b64`, `bulb-wide.b64` (세션 종료 시 소멸 — 원본에서 재생성 가능).
