## 2. 구현 (AdminContentManager.tsx만 수정)

### 2-1. import 추가
```ts
import MarkdownEditor from '@/components/admin/MarkdownEditor'
import { stripMarkdown, cleanBodyText, htmlToPlainText } from '@/lib/contents/clean-body'
```

### 2-2. EditState + openEdit
- `EditState`에 `bodyMarkdown: string` 추가.
- `openEdit` select에 `body_markdown` 추가.
- 초기값: 마크다운 에디터는 **기존 마크다운이 있으면 그걸, 없으면 body_original을 읽기 좋은 평문으로 변환**해 시드한다(크롤 HTML을 그대로 보여주지 않기 위해):
  ```ts
  bodyMarkdown: (data.body_markdown ?? '') ||
                cleanBodyText(htmlToPlainText(data.body_original ?? '')),
  ```
  `bodyOriginal`은 더 이상 편집 UI에서 쓰지 않으므로 EditState에서 제거해도 되나, 회귀 최소화를 위해 **필드는 남기되 저장 시 사용 안 함**(아래 2-4). (제거할 경우 참조 전수 정리.)

### 2-3. 본문 UI 교체(1146–1164)
"본문 (원문)" 평문 textarea 블록을 `MarkdownEditor`로 교체:
```tsx
<div className="flex flex-col gap-1.5">
  <Label>본문 <span className="text-xs font-normal text-muted-foreground">(마크다운·선택)</span></Label>
  <MarkdownEditor
    value={edit.bodyMarkdown}
    onChange={(v) => setEdit((p) => p && { ...p, bodyMarkdown: v })}
    placeholder="본문을 입력·편집하세요. 툴바로 서식을 넣을 수 있어요."
  />
  <p className="text-xs text-muted-foreground">
    서식(마크다운)은 상세 화면에 그대로 반영됩니다. 검색·요약에는 서식을 제거한 본문이 사용됩니다.
  </p>
</div>
```

### 2-4. handleEditSave — body_markdown + body_original 동기 기록
`body_original: edit.bodyOriginal.trim() || null` 부분을 교체:
```ts
const md = edit.bodyMarkdown.trim()
// 상세 렌더용 마크다운 원본 + 검색·스니펫용 평문(동기)
body_markdown: md || null,
body_original: md ? (stripMarkdown(md).trim() || null) : null,
```
- 로컬 `contents` 병합(≈405)도 동일 값 반영(있다면).
- **42703 graceful**(212와 동일): update가 `42703`(컬럼 없음)로 실패하면 `body_markdown` 키를 빼고 재시도 — SQL은 이미 적용됐지만 방어적으로 유지. (구현이 복잡하면, 컬럼 적용이 확인됐으므로 생략 가능 — 단 그 경우 주석으로 명시.)

## 3. 회귀 가드
- **크롤/평문 콘텐츠 편집**: body_markdown이 없던 콘텐츠를 열면 에디터에 평문이 시드되고, 저장 시 body_markdown 생성 + body_original 동기. 이후 상세는 마크다운 렌더.
- **미편집 콘텐츠**: 편집모달을 안 여는 콘텐츠는 불변(상세는 기존대로 body_original 평문 렌더).
- **빈 본문 저장**: md 비면 body_markdown·body_original 모두 null → 상세는 빈 본문 처리(기존과 동일).
- **검색·스니펫**: body_original이 stripMarkdown 평문으로 동기되어 깨지지 않음.
- 상세 렌더 경로(`ReportMarkdown`, raw HTML 미렌더=안전) 재사용 — XSS 안전.
- 편집모달의 다른 필드(제목·요약·카테고리·소스·발행일·썸네일)·저장 로직 불변.
