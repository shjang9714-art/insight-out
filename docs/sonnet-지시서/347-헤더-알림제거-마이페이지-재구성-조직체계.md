## 배경 (David)

1. **헤더의 알림·"오늘 업데이트 N건"이 의미가 없다.** 알림 뱃지가 세는 건 그냥 최근 수집된 *콘텐츠* 개수다. 매일 수십 건씩 들어오니 숫자가 늘 떠 있고, 눌러도 "최근 콘텐츠 목록"이라 알림이라 부를 것이 못 된다. 알림을 살린다면 콘텐츠가 아니라 **리포트 발행 같은 이벤트**여야 한다.
2. **마이페이지가 다른 화면과 성격이 다른데 같은 레이아웃을 쓴다.** 설정 패널인데 목록 화면처럼 좌측 정렬이고, 탭(설정/북마크/아카이브)이 나뉘어 있어 오히려 오가기 번거롭다. **로그아웃 버튼이 아예 없다.**
3. **"기본 보기"(렌즈) 설정은 쓰이지 않는다.** 화면에서 언제든 바꿀 수 있는 값이라 설정 화면에 둘 이유가 없다.
4. **조직 입력이 자유 텍스트다.** 실제로는 전원 **Ent 부문** 소속이고, 그 아래 그룹은 4개(부문직속·사업혁신그룹·고객그룹·AI사업그룹)로 고정이다. 부문 6종 드롭다운 + 팀 자유입력은 실제 조직과 맞지 않는다.

## 설계 결정 (Opus)

1. **알림·오늘 업데이트는 "숨김"이 아니라 제거.** 관련 상태·쿼리·`localStorage` 읽음 처리·바깥클릭 핸들러까지 전부 걷어낸다. 죽은 코드를 남기면 다음 사람이 "왜 안 보이지"를 다시 파야 한다. 이벤트 기반 알림은 필요해지면 새로 설계한다.
2. **마이페이지 = 중앙 정렬 설정 패널.** 폭은 다른 화면(`max-w-screen-xl`)까지 늘리지 **않는다** — 입력 폼이 1200px로 늘어지면 조작이 불편하다. `mx-auto max-w-3xl` 유지. 탭은 제거하고 한 화면 스크롤.
3. **조직은 코드 상수로, DB는 그대로.** `department` enum(6종)을 바꾸려면 마이그레이션이 필요한데 얻는 게 없다. 신규 저장만 enum 값 **`'Enterprise사업부문'`(화면 표기는 "Ent 부문")으로 서버에서 고정**하고, `team`(text)은 드롭다운으로 **입력 범위만 좁힌다**. SQL 0줄.
4. **부문은 클라이언트 입력을 신뢰하지 않는다.** 서버 액션에서 `FIXED_DEPARTMENT`로 덮어쓴다. 클라이언트가 임의 enum 값을 보내도 무시된다.

### D. 조직 체계 — `src/lib/org.ts`(신규)

```ts
export const FIXED_DEPARTMENT: Department = 'Enterprise사업부문'  // DB enum 값
export const DEPARTMENT_DISPLAY_LABEL = 'Ent 부문'                 // 화면 표기
export const ORG_GROUPS = ['부문직속', '사업혁신그룹', '고객그룹', 'AI사업그룹'] as const
export type OrgGroup = typeof ORG_GROUPS[number]
export function isOrgGroup(value: string): value is OrgGroup
```

**적용 — 마이페이지 `SettingsTab.tsx`**
| 필드 | 변경 |
|---|---|
| 부문 | `Select`(6종) → **읽기 전용 `Input`**, 값 `DEPARTMENT_DISPLAY_LABEL`, `bg-muted` |

**적용 — 온보딩 `Step1Profile.tsx`**
- 팀 자유입력 → 동일한 그룹 `Select`. 라벨 옆에 `Ent 부문` 보조 표기.
- 검증: `if (!isOrgGroup(form.team)) next.team = '그룹을 선택해주세요.'`

**적용 — 서버 액션**

## 회귀 / 주의

- **`Department` 타입·DB enum·`schema.sql`은 건드리지 않는다.** 어드민 사용자 관리(`UserManager.tsx`)는 기존 6종을 계속 표시한다 — 과거 데이터가 남아 있으므로 정상이다.
- `saveDefaultLens`·`users.default_lens`는 **삭제 금지**(UI만 제거).
- 헤더에서 `getKstTodayStartIso` import를 지울 때 다른 사용처가 없는지 확인.
- 로그아웃 후 이동 경로는 `/login`(341 비밀번호 로그인 전환 기준).
- 검증: `npx tsc --noEmit` · ESLint · `check-prefetch` · `npm run build` · 육안(헤더에 벨·업데이트 건수 없음 / 마이페이지 중앙 정렬·탭 없음·로그아웃 동작 / 온보딩 그룹 드롭다운 / 기존 사용자가 그룹 선택 후 저장되는지).
