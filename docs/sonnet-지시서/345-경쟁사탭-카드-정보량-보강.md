## 배경 (David)

344로 톤은 맞았지만 카드가 **너무 마른** 상태가 됐다.

1. **경쟁사 최근 뉴스** — 기사 제목이 1줄 말줄임(`line-clamp-1`)이라 `"챗GPT 반값에 이용하세요"...KT, 구독 상품 휴대폰 결…` 에서 끊긴다. 무슨 기사인지 식별이 안 된다. 2줄까지는 써도 무방하다.
2. **경쟁사 주간리포트** — 카드에 제목(요약) 한 줄뿐이라 클릭을 유도하기 어렵다. 상세 페이지에 있는 내용 일부를 카드에서 미리 보여줘야 한다.

## 설계 결정 (Opus)

1. **기사 제목은 항상 2줄.** 1줄짜리 제목도 **2줄 높이를 점유**하게 해서 카드 간 행/열이 어긋나지 않게 한다(`line-clamp-2` + `min-h`). 높이가 들쭉날쭉하면 343에서 잡은 스캔 리듬이 다시 깨진다.
2. **주간리포트 카드에 `sections` 요약을 노출.** 상세 페이지의 사업영역별 핵심 동향(`moves`)이 가장 실질적인 내용이므로, 상위 2개를 카드에 싣는다.
3. **카드 안에서 배지를 또 쓰지 않는다.** 섹션 위기/기회는 **색 점**으로만 표기 — 배지를 반복하면 상단 종합 판정 배지가 묻힌다(343의 "강조는 예외만" 원칙).
4. **데이터 계약 최소 확장.** `CompetitorWeeklyCardRow`에 `sections`만 추가(테이블·SQL 변경 없음).

## 작업

### A. 기사 제목 2줄 고정 — `CompetitorNewsGroups.tsx`

```
- line-clamp-1 / leading-snug
+ line-clamp-2 / leading-[1.35] / min-h-[2.7em]
```
- `<ul>` 간격 `space-y-0.5` → `space-y-1`
- 행 hover 영역: `px-1 py-1 -mx-1`(제목이 카드 패딩에 붙지 않게)
- 날짜는 우측 상단 고정(`items-start` 유지) — 2줄이 되어도 첫 줄에 맞춰 정렬된다.

### B. 주간리포트 카드 요약 — `CompetitorWeeklyCard.tsx` + `query.ts`

**`src/lib/competitor-weekly/query.ts`**
- `CompetitorWeeklyCardRow`에 `sections: CompetitorWeeklySection[]` 추가
- `CARD_COLUMNS`에 `sections` 추가

**카드 구조** (제목 아래 삽입)

- 제목 `line-clamp-3` → **`line-clamp-2`**(요약 블록 자리 확보)
- 섹션 점 색: `위기 → bg-negative` / `기회 → bg-positive` / `관망 → bg-muted-foreground/40` (`CompetitorWeeklyTimeline`과 동일 토큰)
- `moves`는 `cleanNarrative` 통과
- `sections`가 없거나 빈 배열이어도 안전하게 렌더(`(sections ?? []).slice(0, 2)`)

## 회귀 / 주의

- `min-h-[2.7em]`은 `leading-[1.35]` 기준 2줄 높이다. 폰트 크기·행간을 바꾸면 이 값도 같이 바꿔야 한다.
- 주간리포트 카드는 `<Link>` 하나로 감싸져 있다. 섹션 요약 안에 별도 링크를 넣지 말 것(중첩 링크).
- `sections`는 JSONB — 카드 목록 12건까지 함께 가져오므로 payload가 커진다. 목록 limit을 크게 늘릴 일이 생기면 `moves`만 잘라 오는 뷰를 고려.
- 검증: `npx tsc --noEmit` · ESLint · `npm run build` · `?view=competitor`(2줄 제목·행 정렬)와 `?view=trend`(섹션 요약) 육안.
