## 0. 한 줄 · 원인
`경쟁사 주간 브리핑 생성 > ②분석`의 **"① 프롬프트+데이터 복사"** 버튼이 `await fetch(...)` **후** `navigator.clipboard.writeText(...)`를 호출한다. fetch(네트워크 왕복)로 **transient user activation이 만료**돼 clipboard write가 `NotAllowedError`("The request is not allowed by the user agent or the platform...")를 던지고, 폴백이 없어 그대로 에러 노출된다. → **복사가 안 되니 붙여넣기·분석 워크플로 전체가 막힘.**

## 1. 대상 (동일 패턴 2곳)
- `src/components/admin/AdminCompetitorWeeklyAnalyze.tsx` — `handleCopyContext`(L45~61): `await fetch('/api/admin/competitor-weekly/analysis?week=...')` → `await navigator.clipboard.writeText(data.prompt)`. **주 대상(스크린샷).**
- `src/components/admin/AdminKeywordRiseAnalyze.tsx` — `handleCopy`류(L52~53): 동일하게 fetch 후 `navigator.clipboard.writeText(prompt)`. **같은 결함 → 함께 수정.**
- (참고: `McpTokenBoard.tsx:115`는 fetch 없이 즉시 write라 무해 — 손대지 않음.)

## 2. 구현 (두 컴포넌트 동일 패턴 적용)
핵심 원칙: **fetch로 프롬프트를 먼저 state에 담고, 복사는 (a)사용자 클릭에 직접 붙은 동기 write + (b)항상 보이는 textarea 수동복사 폴백**으로 분리. clipboard 실패를 에러가 아니라 폴백 안내로 처리.

### 2.1 AdminCompetitorWeeklyAnalyze.tsx
1. state 추가: `const [contextPrompt, setContextPrompt] = useState('')`.
2. `handleCopyContext` → **로드 + 베스트에포트 복사**로 변경:
   - fetch 성공 후 `setContextPrompt(data.prompt ?? '')`, `setContextInfo(...)`.
   - 그다음 clipboard는 **try/catch로 감싸 best-effort**: 성공 시 `setCopied(true)`, 실패 시 **에러로 던지지 말고** copied=false 유지(아래 textarea로 수동 복사 가능하므로). `setError`에 DOMException 원문 넣지 말 것.
3. **프롬프트 textarea(폴백) 추가**: `contextPrompt`가 있으면 readonly `<textarea>`(mono, rows≈6)로 항상 렌더 + 그 옆 **"복사" 버튼**을 별도로 둔다. 이 버튼 onClick은 **await 선행 없이** 곧바로 `copyText(contextPrompt)` 호출(사용자 제스처 유지 → 성공률↑).
4. 공용 복사 헬퍼(파일 내 or `@/lib/utils`): 
```ts
async function copyText(text: string): Promise<boolean> {
  try {
    if (navigator.clipboard?.writeText) { await navigator.clipboard.writeText(text); return true }
  } catch { /* fall through */ }
  try { // 레거시 폴백
    const ta = document.createElement('textarea'); ta.value = text; ta.style.position='fixed'; ta.style.opacity='0'
    document.body.appendChild(ta); ta.select(); const ok = document.execCommand('copy'); document.body.removeChild(ta); return ok
  } catch { return false }
}
```
5. 안내 문구: 자동 복사 실패 시 "자동 복사가 차단됐어요 — 아래 상자에서 직접 복사하세요"(에러 톤 아님, muted).

### 2.2 AdminKeywordRiseAnalyze.tsx
- 동일 리팩터: fetch로 prompt를 state에 담고, textarea 폴백 + 동기 복사 버튼 + `copyText` 헬퍼 재사용. 기존 `if (!navigator.clipboard) throw` 식 하드 에러 제거(폴백으로 대체).

### 2.3 (권장) 헬퍼 공용화
- `copyText`를 `src/lib/utils.ts`(또는 `src/lib/clipboard.ts` 신규)에 두고 두 컴포넌트에서 import. 중복 정의 지양.

## 3. 회귀 가드 / 검증
- fetch 이후 곧바로 await write 하는 코드 **제거**(핵심). 복사 버튼 onClick은 동기 진입(직전 await 없음).
- clipboard 실패가 **에러 박스로 노출되지 않음**(폴백 textarea로 흡수). DOMException 원문 미노출.
- 두 컴포넌트 모두 프롬프트 textarea 항상 제공 → 권한/컨텍스트 무관하게 수동 복사 가능.
- `tsc`/`lint`/`build` 통과. SQL·env·의존성 0.
