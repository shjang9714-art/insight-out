## 0. 한 줄
모바일에 **하단 고정 탭바**(홈·이슈·검색FAB·기업·보고서)를 넣는다. 데스크톱은 기존 상단 헤더 유지. **콘텐츠는 하단에서 빼되 접근 경로(드로어)는 유지.**

---

## 1. 착수 전 확인 (직접 확인 2026-07-22)

- `DashboardShell`: 상단 `DashboardHeader` + `main` + **모바일 햄버거 → 왼쪽 드로어**(하단 탭바 없음).
- 현재 `NAV_TABS`(DashboardHeader): **홈 · AI 인사이트(`/dashboard/issues`) · 기업동향(`/dashboard/entities`) · 콘텐츠(`/dashboard/contents`) · 리포트(`/dashboard/reports`)**
- 5슬롯 라우트 전부 실재: `/dashboard`·`issues`·`search`·`entities`·`reports`.
- `FloatingBriefingMini`: `fixed bottom-6 right-6 z-50`(우하단 미니 브리핑) — **하단 탭바와 겹친다. 탭바 위로 올려야.**

### 1.1 🔴 5슬롯 매핑 (IA 근거)
| 슬롯 | 라우트 | 현재 NAV_TABS | 비고 |
|---|---|---|---|
| 홈 | `/dashboard` | 홈 | 그대로 |
| 이슈 | `/dashboard/issues` | AI 인사이트 | 라벨 `AI 인사이트` 유지(앱 일관성) |
| **검색(중앙 FAB)** | `/dashboard/search` | **없음** | IA §77 상시 1급 → **신규 슬롯** |
| 기업 | `/dashboard/entities` | 기업동향 | 라벨 유지 |
| 보고서 | `/dashboard/reports` | 리포트 | 라벨 유지 |
| ~~콘텐츠~~ | `/dashboard/contents` | 콘텐츠 | **하단에서 제외**(IA §10: 검색 필터로). **드로어에 유지.** |

→ **콘텐츠를 검색으로 교체.** 콘텐츠는 하단 탭에서 빠지지만 **햄버거 드로어에는 그대로** 둔다(접근 경로 보장).

## 2. 구현

### 2.1 신규 `src/components/dashboard/MobileBottomNav.tsx` (클라이언트)
- **`md:hidden`** — 모바일 뷰포트에서만. `fixed bottom-0 inset-x-0 z-40`, 하단 고정.
- 5슬롯: 홈 · AI 인사이트 · **[검색 중앙 FAB]** · 기업동향 · 리포트.
  - 검색은 **중앙에 도드라진 원형 FAB**(브랜드 마젠타, 프로토타입 §3). 클릭 → `/dashboard/search` 로 이동.
    - ⚠️ 프로토타입의 **풀스크린 질문 오버레이는 M-5**. 이번엔 **라우트 이동**으로 충분.
  - 나머지 4개: 아이콘 + 라벨, 활성 표시(`isTabActive` 재사용).
- 각 항목 아이콘: `NAV_TABS` 에 icon 이 리포트만 있으니, 홈/이슈/기업/검색 아이콘을 lucide 에서 지정(예: Home·Layers·Building2·Search). **기존 import 우선, 최소 추가.**
- `prefetch-ok`(개수 고정·이동 잦음) 주석.

### 2.2 `DashboardShell` 통합
- `<MobileBottomNav />` 를 `main` 뒤에 마운트.
- **`main` 하단 패딩**: 탭바 높이만큼(`pb-16 md:pb-0` 류) — 콘텐츠가 탭바에 가리지 않게.
- **데스크톱(`md:` 이상) 무변경.** 상단 헤더·드로어 로직 그대로.
- 모바일 햄버거 드로어는 **유지**(콘텐츠·마이 등 하단에 없는 메뉴 접근). 단, 하단 탭바가 생겼으니 드로어는 "더보기" 성격.

### 2.3 `FloatingBriefingMini` 탭바 위로
- 현재 `bottom-6`. 모바일에서 하단 탭바(약 `h-16`)와 겹치므로 **모바일에서 `bottom` 을 탭바 높이만큼 올린다**(`bottom-[calc(4rem+0.75rem)] md:bottom-6` 류).
- ⚠️ 미니 브리핑 **로직 무수정**, 위치 클래스만.

### 2.4 하지 말 것
- **데스크톱 상단 헤더·네비 무변경.**
- `NAV_TABS`(데스크톱 상단용) 자체는 **건드리지 않는다** — 하단 탭바는 별도 구성(콘텐츠 제외·검색 추가). 상단은 기존 5탭 유지.
- 콘텐츠를 **드로어에서 지우지 않는다**(접근 경로).
- 검색 풀스크린 오버레이·바텀시트·미니플레이어 Context 는 **이 슬라이스 아님**(M-3~M-5).
- 인증·데이터·라우트 로직 무수정.

## 3. 회귀 가드
1. **모바일**: 하단에 5슬롯 탭바(홈·이슈·검색FAB·기업·보고서), 중앙 검색이 도드라진 FAB.
2. 각 탭 → 해당 라우트 이동, 활성 표시 정확.
3. 검색 FAB → `/dashboard/search`.
4. **본문이 탭바에 안 가린다**(하단 패딩).
5. `FloatingBriefingMini` 가 탭바 **위**에 뜬다(안 겹침).
6. 햄버거 드로어에 **콘텐츠·마이 등 유지**(접근 경로).
7. **데스크톱**: 상단 헤더·5탭이 지금과 완전히 동일, 하단 탭바 **안 뜸**.
8. 콘텐츠 상세·이슈 등 기존 화면 정상.
