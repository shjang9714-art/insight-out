## 1. 현행 진단 (검증된 코드 사실)

### 1.1 필터 바에 지금 몇 개가 있나
`src/app/dashboard/contents/page.tsx`
```
카테고리 탭 (뉴스·유튜브·웹인사이트·리서치)
사업 드롭다운 · 출처 드롭다운 · 기간

   발행순/수집순 토글                                ← :556  297 대상
   일별 보기 토글                                    ← :584  297 대상
   카드/목록 토글                                    ← :597  297 대상
```

**컨트롤이 8종이다.** 오픈 전 화면에 이건 많다.

### 1.2 스펙의 전제 확인
- **발행순이 이미 기본값**이다(`:227` `?? 'published'`). 수집순은 **선택지일 뿐** 기본이 아니다.
- **리포트 카테고리는 항상 수집순으로 강제**된다(`:243` `isReportCategory`). → 그 화면에서는 토글이 이미 숨겨진다(`:556` 주석).
- `groupByDay` 기본 **off**(`:252`), `카드/목록`도 상태로 관리된다.

### 1.3 ⚠️ 지금이 뺄 수 있는 유일한 시점이다
**오픈 전이라 아무도 안 쓴다.** 사용 데이터가 없으니 "누가 쓰는지"를 측정할 방법도 없다.

> **선택지를 안 줬다가 나중에 주는 건 쉽다. 줬다가 뺏는 건 어렵다.**
> 오픈 후에는 *"내가 쓰던 버튼이 없어졌다"* 가 된다. **지금 정리한다.**

## 3. 구현

### 3-1. 제거 — 토글 3종

| 토글 | 처리 |
|---|---|
| **발행순 / 수집순** (`:556`) | **제거.** 발행순으로 **고정**한다(이미 기본값) |
| **일별 보기** (`:584`) | **제거.** **일별 그룹으로 고정**한다(David 지시) |
| **카드 / 목록** (`:597`) | **제거.** **카드로 고정**한다 |

⚠️ **`sortByCollected` 로직 자체는 남긴다** — **리포트 카테고리가 그걸 쓴다**(`:243` `isReportCategory`). 리포트는 발행일이 의미 없어 수집일로 정렬한다. **UI 토글만 없애고 내부 분기는 유지할 것.**

⚠️ **`?sort=collected` URL 파라미터는 계속 받아들일 것**(북마크·공유 링크 보호). UI만 없앤다.

### 3-2. 일별 그룹 **고정**

`groupByDay`를 **항상 true**로. `groupByKstDay()`(`:126`)가 이미 있다 — **새로 만들지 말 것.**

```
2026년 7월 12일 (일)
  [카드] [카드] [카드]

2026년 7월 11일 (토)
  [카드] [카드]
```
- **날짜 헤더가 스크롤 시 sticky면 좋다**(있으면 좋음, 필수 아님).
- 무한 스크롤/페이지네이션과 **그룹 경계가 어긋나지 않게** 할 것 — 페이지를 더 불러왔을 때 **같은 날짜 그룹에 이어 붙어야** 한다. 새 그룹이 중복 생성되면 안 된다.

### 3-3. 필터 바 재배치

토글 3개가 빠진 자리를 정리한다.
```
[뉴스] [유튜브] [웹인사이트] [리서치]              ← 카테고리(L2 탭)
─────────────────────────────────────────────
[내 업무 ▾]  [🔴 위기] [🟢 기회]  |  사업 ▾  출처 ▾  기간 ▾
```
- **렌즈(309)와 위기/기회(313)를 왼쪽**에 — 이게 개인화·신호다.
- **사업/출처/기간은 오른쪽**에 — 이건 좁히기다.
- 활성 필터 칩은 그대로 유지.

## 4. 회귀 가드

- ⛔ **`sortByCollected` 내부 분기를 지우지 말 것** — 리포트가 쓴다(`isReportCategory`).
- ⛔ **`?sort=collected` URL 파라미터를 계속 받을 것** — 기존 북마크가 깨지면 안 된다. **UI만 없앤다.**
- **`groupByKstDay()`를 재사용할 것.** 새 그룹핑 로직 금지.
- ⭐ **페이지를 더 불러왔을 때 같은 날짜 그룹에 이어 붙어야 한다.** 그룹이 중복되면 실패다.
- **309(렌즈)·313(위기/기회) 필터가 그대로 동작해야 한다.** 방금 만든 것이다.
- 카테고리·사업·출처·기간 필터 **불변**.
- 무한 스크롤/페이지네이션 **불변**.

## 5. 검증 (Sonnet)

- `npx tsc --noEmit` 0 / `npx eslint` 0 / `npm run build`.
- 토글 3개가 **사라졌는지**. 필터 바가 정리됐는지.
- **항상 일별 그룹**으로 보이는지. 날짜 헤더가 맞는지(KST).
- ⭐ **2~3페이지 더 불러왔을 때 날짜 그룹이 중복되지 않고 이어 붙는지.** (이게 이 슬라이스의 핵심 검증이다.)
- **리포트 카테고리**가 여전히 수집일 기준으로 정렬·표시되는지.
- **`?sort=collected` 링크를 직접 열어도** 동작하는지(UI는 없어도).
- 렌즈·위기/기회 필터가 그대로 되는지.
