# 지시서 267 — 수집 본문 푸터 위젯(구독·반응·추천) 제거: cleanBodyText 정제 강화

> David 요청: 콘텐츠 수집 시 본문 뒤에 붙는 불필요한 푸터(구독/좋아요·슬퍼요·화나요 N개/이런 구독물도 추천합니다/지금 뜨는 뉴스 등)를 없앤다.

목표: 기사 본문에 딸려오는 **사이트 푸터·구독·반응·추천 위젯 텍스트**를 정제 단계에서 제거한다. `@extractus/article-extractor`가 못 걸러낸 꼬리를 `cleanBodyText`에서 잘라낸다.

핵심 이점: `cleanBodyText`는 **수집 저장(news-site 어댑터)과 표시(`full-body.ensureFullBody`) 양쪽에서 실행**된다 → 이 함수만 보강하면 **신규·기존 콘텐츠 모두 즉시** 정리된다(기존 본문 재백필 불필요).

대상 파일: `src/lib/contents/clean-body.ts` (단일).

---

## 1. 문제 예시 (실제 수집본 꼬리 — 제거 대상)
```
… 본문 마지막 문장.
Tech& >
구독
이런 구독물도 추천합니다!
부동산 빨간펜
구독
광화문에서
구독
인터뷰
구독
좋아요
0개
슬퍼요
0개
화나요
0개
지금 뜨는 뉴스
```
→ "본문 마지막 문장."까지만 남기고 이하 전부 제거.

## 2. 구현 (`clean-body.ts`)

### 2-1. 푸터 절단(tail truncation) — 신규
- **강한 푸터 시작 마커**(sentinel)를 만나면 그 지점부터 끝까지 잘라낸다. 마커는 기사 본문에 자연 등장하지 않는 고신뢰 문구·구조만 사용:
  - `이런 구독물도 추천합니다`
  - `지금 뜨는 뉴스`
  - **반응 위젯 블록**: `좋아요` `슬퍼요` `화나요` `후속기사 원해요` 중 하나가 **단독 라인**으로 나오고 인접(±1 라인)에 `\d+개`가 오는 패턴 → 그 첫 라인부터 절단.
  - 저작권/재배포: `무단전재`, `재배포 금지`, `ⓒ`, `Copyright ⓒ` (라인 시작)
- **가드**: 절단 후 남은 본문이 120자 미만이거나 원본의 30% 미만이면 절단 취소(오절단 방지 — 기존 length 가드와 동일 사상). 마커가 본문 초반(예: 앞 40%)에서만 발견되면 절단하지 않음(신뢰도 낮음 → 라인필터에 위임).
- 여러 마커 중 **가장 이른 유효 지점**에서 절단.

### 2-2. 라인 단위 boilerplate 확장 — 기존 `BOILERPLATE_PATTERNS`/`isJunkLine` 보강
절단 위쪽에 흩어진 잔여 위젯 라인도 제거하도록 단독 라인 패턴 추가(정확 일치, ≤ 짧은 라인만):
- `^(구독|좋아요|슬퍼요|화나요|후속기사 원해요|쏠쏠정보|굿아이디어)$`
- `^\d+개$` (반응 카운트)
- `^이런 구독물도 추천합니다!?$`, `^지금 뜨는 뉴스$`
- `^Tech&\s*>?$` 류의 섹션 브레드크럼(짧은 라인·`>` 포함) — 과도 제거 위험 있으니 **정확 매칭**으로 한정.
> `부동산 빨간펜`·`광화문에서`·`인터뷰` 같은 **칼럼명**은 하드코딩하지 말 것(기사 제목과 충돌 위험). 이들은 2-1 절단으로 함께 제거되므로 개별 패턴 불필요.

### 2-3. 적용 순서
`cleanBodyText`: 정규화 → **2-1 푸터 절단** → 라인 필터(2-2 포함) → 조인. 기존 최종 length 가드(`cleaned < 120 || < original*0.25` → original 반환) 유지.

## 3. 회귀 가드
- 정상 본문 오절단 금지 — 2-1 가드(남은 길이/위치) 준수. 마커가 애매하면 절단하지 않고 라인필터에만 맡긴다.
- `htmlToPlainText`·`stripMarkdown` 변경 없음.
- RSS 경로(news-site)·풀본문 경로(full-body) 모두 자동 반영(공유 함수).
- 영어 기사·짧은 스니펫 영향 최소(마커 대부분 한글 고정 문구).
- 기존 저장 본문은 표시 시 재정제되어 정리됨 — **DB 마이그레이션·백필 불필요**. (단, 이미 생성된 요약/임베딩은 구본문 기반 — 필요 시 요약 재생성은 별건, 이번 범위 아님.)

## 4. 검증 (Sonnet)
- `npx tsc --noEmit` 0 / `npx eslint` 0 / `npm run build`.
- **단위 케이스**: §1 예시 문자열 입력 → "본문 마지막 문장."까지만 남고 꼬리 전부 제거되는지(간단 테스트/스크립트로 확인).
- 반응 위젯만 있는 꼬리, 저작권 문구 꼬리, 추천 구독물 꼬리 각각 절단 확인.
- 정상 기사(푸터 없음) 그대로 보존 확인(오절단 0).
- 실제 상세 화면(문제 기사 URL)에서 꼬리 사라짐 육안 확인.

## 5. 후속(선택)
- extractor 단계에서 사이트별 셀렉터로 본문만 추출(네이버/매경 등)하면 더 근본적 — 필요 시 별건.
- 구본문 기반 요약을 새 정제본으로 재생성하는 어드민 백필 — 원하면 별도 지시.

SQL 없음. 이 지시서는 `clean-body.ts` 정제 강화(푸터 절단 + 위젯 라인 제거).
