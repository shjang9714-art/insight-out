## 작업

### 1. 키워드 클러스터 버블맵 (목업 부활) — 카드그리드 대체(토글 유지)
- 현 keyword 뷰의 "엔티티별 시그널 요약" 카드 그리드를 **버블 클러스터 맵**으로 대체하되, **뷰 토글(버블/카드)** 제공(기본 **버블**). 카드 그리드는 토글로 남긴다.
- **신규 컴포넌트** `src/components/analysis/KeywordClusterMap.tsx`(client). **새 의존성 금지 — 기존 `react-force-graph-2d` 재사용**(KnowledgeGraph 패턴): 노드=`classifiedKeywords`, **링크 없음** + `forceCollide` + 약한 charge로 **뭉치되 안 겹치는 클러스터**. 중앙에 최상위(관련문서 최다) 크게.
  - `val` = 관련문서수(√스케일), **색 = bucket**(tag-buckets, 기술=blue/기업=violet/시장=teal/정책=amber). canvas라 **hex 예외**(AGENTS.md §1-9).
  - **상승 표식은 색이 아니라 배지·외곽선**(▲%·NEW)을 버블 위 canvas 오버레이로(351-A 원칙 일관).
  - 노드 클릭 → `keywords/{name}`(351-B). 초기 안정화는 354 패턴(force 적용 게이트 + `zoomToFit`) 참고해 **첫 화면부터 펼쳐지게**.
  - 상단에 뷰 토글(전체/카드/버블) — 목업의 전체·개념도·트렌드맵 중 **전체(버블)·카드** 2종으로 축약(개념도/트렌드맵은 후속).
- 성능: 노드 상한(예: 상위 40~60개)·라벨 겹침 완화(작은 노드는 라벨 생략).

### 2. 오늘의 주요 변화 — 3 요약 카드 (결정론, LLM 금지)
- 4지표 스트립 아래에 **3카드**. `classifiedKeywords`에서 **규칙 기반 파생**(비용 0, LLM 안 씀):
  - 카드①: **가장 급상승한 축** — 최대 changePct 상위 키워드/버킷(예: "AI 인프라 관련 관심이 급증했어요 · 전일 대비 +N%").
  - 카드②: **신규 유입** — isNew 다수 버킷(예: "기업 AX 도입 흐름 확산 · 신규 N개 진입").
  - 카드③: **버킷 하이라이트** — 정책/시장 등 특정 버킷 상승(예: "정책·고용 이슈 주목 · 언급 +N%").
  - 각 카드: 버킷 아이콘 + 제목 + 한 줄 근거 + `→` 링크(대표 키워드 `keywords/{name}`). 데이터 부족 시 카드 수 축소(graceful).
- 문구는 **템플릿**(수치·키워드만 주입) — 과장·창작 금지.

### 3. 급상승 랭킹 행에 7일 추이 스파크라인
- 랭킹 Top 10 각 행 우측에 **미니 스파크라인**(축·격자 없음). 데이터 = `getKeywordDailyCounts(name, 7)`(351-B) — **랭킹에 실제 표시되는 상위 N개만** 서버에서 조회(비용 가드, N≤10). recharts 미니 LineChart 또는 경량 SVG.
- AiInsightsView(server)에서 랭킹 확정 후 해당 키워드들의 7일 시리즈를 함께 내려보내 AiInsightBoard가 렌더. 시리즈 없으면 스파크라인 생략(폴백).

## 회귀 / 주의
- 4지표 스트립·급상승 랭킹 탭(급상승/신규/관심지속) 기존 동작 유지.
- 버블맵은 canvas hex 예외, 그 외 색은 토큰(하드룰 9). 새 npm 패키지 금지(react-force-graph-2d·recharts 재사용).
- 스파크라인 데이터는 **상위 N개만**(온디맨드 남발 금지). 서버 컴포넌트/클라이언트 경계 유지(맵·스파크라인은 클라이언트).
- 주요 변화 카드 문구는 결정론 템플릿(LLM·외부호출 금지).
- `prefetch={false}`, 한글 키워드 URL 인코딩.
- 검증: `tsc`·ESLint·`check-prefetch`·`npm run build`·육안(버블맵 첫 화면 펼침·색=유형·상승 배지·클릭 이동 / 주요변화 3카드 / 랭킹 스파크라인 / 카드↔버블 토글). 완료보고 커밋 해시.
