대상: `src/app/dashboard/page.tsx` (단일). SQL 없음. 저위험.

## 1. 변경
- `src/app/dashboard/page.tsx`에서 **`<PersonalizationNudge />` 렌더 제거**(현재 32행 부근)와 **미사용이 되는 import 제거**(6행 `import PersonalizationNudge from '@/components/dashboard/PersonalizationNudge'`).
- 배너가 있던 자리의 상하 여백(간격) 어색하면 인접 요소 간격만 소폭 정리(선택, 다른 변경 없음).

## 2. 처리 범위
- 컴포넌트 파일(`PersonalizationNudge.tsx`·`PersonalizationNudgeBanner.tsx`)은 **삭제하지 않고 남겨둔다**(다른 곳 재사용/추후 복원 대비, 미사용 import만 정리). 원하면 후속에서 정리.
- 홈(대시보드) 외 다른 화면에는 이 배너가 렌더되지 않음(사용처는 dashboard/page.tsx 한 곳) — 회귀 위험 낮음.

## 3. 회귀 가드
- 홈 나머지 섹션(피드·인사이트 등) 불변.
- eslint no-unused-vars 대비 import 제거 필수.
- 배너 제거로 인한 레이아웃 깨짐 없음 확인.

## 4. 검증 (Sonnet)
- `npx tsc --noEmit` 0 / `npx eslint` 0 / `npm run build`.
