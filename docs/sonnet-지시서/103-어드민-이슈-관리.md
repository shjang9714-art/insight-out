## 배경 (David)

이슈(101)는 Claude 큐레이션 루틴이 SQL INSERT 로 채운다. 하지만 **발행·수정·match_keywords 조정·수동 배정**을 매번 SQL 핸드오프로 하면 느리다. 어드민 UI로 **이슈를 직접 관리**하게 해 큐레이션 루프를 매끄럽게. (100 엔티티 사전과 짝.)

## 설계 결정 (Opus)

1. **CRUD = 클라이언트 supabase + admin RLS**(EntityManager 동일). 신규 SQL·엔드포인트 불필요(101 정책으로 충분).
2. **수동 배정/해제 = issue_contents 직접 insert/delete**(source='admin').
3. **"키워드로 재배정"** = issue.match_keywords 로 published 콘텐츠 ILIKE 매칭 → issue_contents 일괄 insert(클라, 캡·dedup). match_keywords 수정 후 기존 콘텐츠 반영용.
4. **노출 = 관리 › AI·처리 그룹**(AI 인사이트 인근). 1차 계위 변경 없음.

## 작업

### A. IssueManager 컴포넌트 — `src/components/admin/IssueManager.tsx` (신규, `'use client'`)
EntityManager(100) 구조 미러(클라 supabase, 폼 state, 목록, 칩, 로딩/에러 한국어).

- **목록·필터**: `issues` select(id·title·summary·status·match_keywords·created_at) `order created_at desc`(또는 updated_at). 상태 필터(전체/draft/published/archived). 제목 검색(ilike). 각 행: 상태 배지·title·match_keywords 개수·**배정 콘텐츠 수**(issue_contents count — 행별 또는 일괄 집계)·액션(수정·콘텐츠·삭제).
- **생성/수정 폼**: title, summary(textarea), status(셀렉트 draft/published/archived), **match_keywords(칩 입력**, KeywordGroupManager/ReportUploadForm 패턴). 저장: insert/update(.eq id).
- **삭제**: `issues.delete().eq('id', ...)`(issue_contents cascade) + confirm.
- **배정 콘텐츠 수 표시**: 이슈 행에 issue_contents count(읽기 전용). 수동 개별 배정/해제 UI는 **두지 않는다**(자동배정+재배정으로 충분 — David 결정 B).
- **"키워드로 재배정" 버튼**(이슈별 액션 — 행 또는 수정 폼에서 독립 실행): 그 이슈 match_keywords 로 `contents` published 조회(`title.ilike` OR `summary_ko.ilike`, 각 키워드, 합집합, limit 예 300) → `issue_contents.upsert(rows, { onConflict:'issue_id,content_id', ignoreDuplicates:true })`. 결과 "N건 배정" 안내. (match_keywords 수정 후 기존 콘텐츠 반영.)

> ⚠️ **결정 B(슬림)**: 이미 구현된 풀버전(A)에서 **수동 콘텐츠 검색·추가(handleManualAssign)·개별 해제(handleUnassign)·콘텐츠 검색 패널**을 제거한다. "키워드로 재배정"(handleRematch)은 유지하되 assign 패널 의존을 풀어 **이슈별 독립 실행**으로 옮긴다. 배정 수 표시는 유지.

## 회귀 / 주의
- **신규 SQL 없음** — 101 admin RLS 로 CRUD. 101 SQL 미적용이면 목록 빈/에러(graceful 안내).
- match_keywords 는 **자동배정(크롤)·재배정 둘 다의 입력** — 변별력 있게(짧은 단어 오탐). 저장 후 "재배정"으로 기존 콘텐츠 반영 안내.

- 수동 배정 source='admin', 자동 'rule', 큐레이션 'claude' — 구분 유지(분석용).
- CRUD 는 클라+RLS(서버 엔드포인트·service_role 금지 #8). 어드민 세션만(미들웨어 가드).
- `any` 금지·UI 한국어(#1)·색 토큰(#9)·shadcn 재사용·lucide만.
