# 지시서 447 — 경쟁사 최근 뉴스, 주요기업 상세 하위 통합 (최소안)

> Opus · 2026-07-26 · 개선검토 [9c]. SQL 0·의존성 0. 브랜치 `agent/447-company-news-section`.
> 전제: 446(주요기업 주간)이 insights/[id] 를 이미 수정 → **446 머지 후 최신 main에서 분기**(같은 파일). Sonnet 안전 머지.

## 목표 (최소안)
주요기업 카드 상세(`/dashboard/insights/[id]`, scope='company')에 **"이 회사 최근 뉴스" 섹션**을 추가 — 경쟁사 최근 뉴스를 회사 단위로 상세 하위에 통합. (회사 허브 신설·경쟁사 탭 흡수 = 완전안은 별건.)

## 구현 (`src/app/dashboard/insights/[id]/page.tsx` + 헬퍼)
- scope='company'일 때만:
  1. `curated_companies`에서 `name = card.topic`인 행의 `aliases` 조회(없으면 aliases=[]).
  2. 최근 기사: `contents` `status='published'`, 최근 N일(기본 30), **name+aliases 매칭**(`generateCompanyInsightCards`와 동일 orClause: `title.ilike.%term%`/`summary_ko.ilike.%term%`, term은 `%_\` 이스케이프), `order('collected_at', desc)`, `limit 10`.
  3. **중복 제외**: 카드의 citations/source_content_ids(이미 근거로 표시된 것)는 뉴스 섹션에서 제외.
  4. 렌더: "이 회사 최근 뉴스" 섹션(제목 · 매체 · 날짜 → `/dashboard/contents/[id]` 링크). 근거 자료 섹션 아래(또는 시사점 뒤 적절 위치). 0건이면 섹션 숨김.
- orClause 빌더는 generate.ts 로직 재사용 위해 **작은 공용 헬퍼**(예: `src/lib/insight/company-match.ts` `buildCompanyMatchOr(name, aliases)`)로 추출 후 양쪽 사용(중복 지양) — 부담되면 페이지 내 복제 허용.

## 회귀 가드
- scope='industry' 카드엔 섹션 미표시. curated_companies 미가용/빈 결과 graceful(섹션 숨김). SQL 0·의존성 0.
- 446이 이미 바꾼 searchParams(`?week=`) 구조 보존(충돌 없이 병합). tsc/lint/build 통과.
- 운영철학: 조회 실패 시 섹션만 숨김(페이지 무중단).

company 카드 상세에 회사 최근 뉴스 표시(근거와 중복 제외), industry는 미표시. name+aliases 매칭 동작.
