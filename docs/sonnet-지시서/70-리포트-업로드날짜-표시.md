## 배경
업로드 리포트(카테고리 `리포트`, 통칭 리서치)는 발행일(`published_at`)이 업로드 시 보통 비어 있어 카드에 "날짜 없음"으로 뜨거나 정렬이 부정확하다. **업로드 시각(`collected_at`, insert 시 DB default now())**으로 표시·정렬한다. (뉴스/웹인사이트/유튜브는 기존대로 published_at 유지.)

### 설계 결정(David)
- **리포트 카테고리는 표시 날짜 = collected_at**(업로드 날짜). 그 외 카테고리는 published_at 유지.
- AI보고서도 동일하게 collected_at 권장(생성·업로드 시각이 의미) — 적용.

## 작업

### 1. 피드 쿼리·타입에 collected_at 추가
- `page.tsx` contents select 에 **`collected_at`** 추가. `ContentItem` 에 `collected_at: string` 추가.

### 2. 표시 날짜 헬퍼 (카테고리별)
- 헬퍼: `displayDate(item) = (item.category === '리포트' || item.category === 'AI보고서') ? item.collected_at : (item.published_at ?? item.collected_at)`.
- 카드/행에 넘기는 날짜 prop(현 `publishedAt={item.published_at}`)을 **`displayDate(item)`** 로 교체. (ContentListCard·ContentRow·card/list 양쪽.)
- 상세(`[id]/page.tsx`)의 날짜 표시도 동일 규칙 적용(리포트면 collected_at).

### 3. 정렬 — 리포트 탭에서 업로드순
- 현재 피드는 `published_at desc`(nulls last) 전역 정렬. **카테고리 필터가 `리포트`(또는 AI보고서)일 때는 `collected_at desc` 로 정렬**.
  - 쿼리 빌드에서 `category === '리포트'/'AI보고서'` 분기: `.order('collected_at', { ascending: false })`, 그 외 기존 `.order('published_at', { ascending: false, nullsFirst: false })`.
- 전체(카테고리 미선택) 보기는 기존 published_at 정렬 유지(리포트는 published_at null → 뒤로; 표시 날짜만 collected_at). 전역 혼합 정렬 변경은 범위 밖(후속).

### 4. (확인) 라벨
- 카드의 날짜 라벨이 "발행일" 같은 문구를 쓰면 리포트에선 어색할 수 있음 — 공용 표시면 그대로 두되, 리포트 전용 라벨 분기는 선택(과하면 생략). 날짜 값만 collected_at 이면 충분.

## 회귀 / 주의
- DB 무변경. 뉴스/웹인사이트/유튜브 날짜·정렬 불변.
- collected_at 은 항상 not null(insert default) → 리포트 "날짜 없음" 사라짐.
- 어드민 편집 모달(지시서 59)의 published_at 편집은 유지(운영자가 실제 발행일 기록 가능) — 표시 규칙과 무관.
- 전체 보기에서 리포트가 published_at null 이라 하단 정렬되는 건 이번 범위 밖(혼합 정렬은 coalesce RPC/뷰 필요, 후속).
- UI 한국어(#1), 토큰 색상(#9).
