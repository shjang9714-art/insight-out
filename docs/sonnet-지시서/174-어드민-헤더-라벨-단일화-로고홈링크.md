## 3. 구현

### 3-1. nav 단일 소스 조회 헬퍼 (`lib/admin/nav.ts`)
플랫 조회 추가:
```ts
export function findAdminNavItem(pathname: string): AdminNavItem | null {
  const all = [...ADMIN_NAV_GROUPS.flatMap(g => g.items), ...ADMIN_NAV_BOTTOM.items]
  // 정확 일치 우선, 없으면 startsWith(가장 긴 href) 매칭
  const exact = all.find(i => i.href === pathname)
  if (exact) return exact
  return all
    .filter(i => i.href !== '/admin' && pathname.startsWith(i.href))
    .sort((a, b) => b.href.length - a.href.length)[0] ?? null
}
```
→ **라벨·설명의 유일한 출처 = `ADMIN_NAV_GROUPS`.** 페이지 제목은 여기서만 온다.

### 3-2. `AdminPageHeader` 공용 컴포넌트 (신규, 클라)
`src/components/admin/ui/AdminPageHeader.tsx`:
- `usePathname()` → `findAdminNavItem` 로 `label`·`description` 파생.
- 레이아웃: 좌측 제목(`h1`, 아이콘 옵션=nav icon)+설명, 우측 `actions` 슬롯.
- props: `actions?: React.ReactNode`, `titleOverride?`/`descriptionOverride?`(예외용, 기본은 nav).
```tsx
'use client'
import { usePathname } from 'next/navigation'
import { findAdminNavItem } from '@/lib/admin/nav'

export default function AdminPageHeader({ actions }: { actions?: React.ReactNode }) {
  const item = findAdminNavItem(usePathname())
  const Icon = item?.icon
  return (
    <div className="mb-6 flex items-start justify-between gap-4">
      <div className="min-w-0">
        <div className="flex items-center gap-2">
          {Icon && <Icon className="h-5 w-5 shrink-0 text-brand-600" />}
          <h1 className="text-2xl font-bold text-foreground">{item?.label ?? '어드민'}</h1>
        </div>
        {item?.description && <p className="mt-1 text-sm text-muted-foreground">{item.description}</p>}
      </div>
      {actions && <div className="shrink-0">{actions}</div>}
    </div>
  )
}
```

### 3-3. 전 15개 페이지 적용
- 각 `src/app/admin/*/page.tsx`(+ 필요 시 매니저)의 기존 `<h1>+<p>`(및 `space-y-6` 래퍼 편차)를 **`<AdminPageHeader />`** 로 교체.
- 페이지 우측 주요 액션(예: insights 상태 드롭다운·생성 버튼, entities/issues/sources/keywords/keyword-groups의 "추가" 등)은 **`actions` 슬롯으로 이동**(위치 통일). 액션이 매니저 내부에 있으면 매니저 상단 액션을 헤더로 올리거나, 최소한 헤더는 공용으로 교체하고 액션은 기존 위치 유지(과개편 방지 — 라벨 통일이 우선).
- 결과: **모든 페이지 H1 = 사이드바 라벨**(단일 소스). 부조화 6건 자동 해소.

### 3-4. nav 설명(description) 보정(선택)
- 라벨을 짧게 통일하면서 잃는 맥락은 `description`이 담당. 일부 페이지는 nav의 description이 비어있을 수 있으니(대부분 있음) 확인. 예: /admin description "수집·검토·참여 현황 한눈에" 유지. (David 화면의 "콘텐츠 수집 현황과 운영 기능을 한곳에서" 문구를 쓰려면 nav description을 그 문구로 바꾸면 사이드바 툴팁/헤더 동시 반영.)

### 3-5. 로고 홈링크 (`AdminSidebar.tsx`)
- 상단 로고 영역(로고 아이콘 + "Insight Out" + "어드민" 배지)을 `<Link href="/admin">` 으로 감싼다(클릭 시 어드민 홈=대시보드로 이동). hover 시 미세 강조. 배지("어드민")는 링크 안/밖 무관하나 접근성 라벨 유지.
