## 배경
지금 `/admin/upload` 는 **파일 → 리포트**를 만드는 폼이다. 운영자가 RSS 로 안 잡히는 글(웹 기사·블로그 본문)을 **텍스트로 붙여넣어** 콘텐츠로 등록할 길이 없다. 둘 다 "수동으로 콘텐츠 추가"라는 같은 작업이므로, `/admin/upload` 를 **"콘텐츠 추가"**로 확장하고 **탭 2개**(`파일 업로드` = 기존 / `텍스트 붙여넣기` = 신규)로 묶는다. 네비 슬롯·UX를 재사용한다.

### 설계 결정(David)
- `/admin/upload` 를 **"콘텐츠 추가"**로 확장 + **탭 2개**: `파일 업로드`(기존 `ReportUploadForm` 그대로) / `텍스트 붙여넣기`(신규).
- 붙여넣기 폼은 `contents` 에 행을 직접 추가한다(파일 없음, `file_path=null`).

## 붙여넣기 폼이 저장하는 값 (contents 행)
| 컬럼 | 값 |
|---|---|
| `category` | 기본 `'웹인사이트'`, 선택 가능(`웹인사이트` / `뉴스` / `리포트`) — deprecated enum(`오피니언`·`가트너`·`KRG` 등) 노출 금지 |
| `title` | **필수** |
| `body_original` | 붙여넣은 텍스트 (서버에서 **HTML 정리** 후 저장 — 아래 §4) |
| `original_url` | 원문 링크(선택) |
| `summary_ko` | 직접 입력, **비우면 서버에서 LLM 자동 요약**(`summarizeKo`) |
| `author` | 발행처/저자(선택) |
| `published_at` | 발행일(선택, date) |
| `source_id` | 출처(선택) — `category`→`source_type` 매핑으로 필터 |
| `file_path` | `null` |
| `original_language` | `'ko'` |
| `status` | `'published'` |
| 서비스 태그 | `content_services` |
| 키워드 | `keywords` 조회/생성 → `content_keywords` |

## 작업

### 1. 네비·페이지 헤더 라벨 변경
- `src/app/admin/layout.tsx` `NAV_ITEMS`: `{ href: '/admin/upload', label: '리포트 업로드' }` → **`label: '콘텐츠 추가'`** (href 유지).
- `src/app/admin/upload/page.tsx`: `metadata.title` → `'콘텐츠 추가 | 어드민 | Insight Out'`, 설명·`<h1>`·안내문을 "콘텐츠 추가"로. `<ReportUploadForm />` 자리에 **`<ContentAddTabs />`** 렌더.

### 2. 탭 래퍼 — `src/components/admin/ContentAddTabs.tsx` (신규, `'use client'`)
- 단순 세그먼트 토글(버튼 2개, `useState<'file'|'paste'>('file')`). **shadcn tabs/Radix 추가 금지**(미설치, 작은 폼 useState 원칙 — AGENTS §11).
- 선택에 따라 `<ReportUploadForm />`(file) 또는 `<TextPasteForm />`(paste) 렌더. 토글 스타일은 브랜드 토큰(`bg-brand-600 text-white` 활성 / `bg-card` 비활성), `cn()` 사용.

### 3. 붙여넣기 폼 — `src/components/admin/TextPasteForm.tsx` (신규, `'use client'`)
- `ReportUploadForm` 의 **서비스 태그·키워드 칩 입력·요약 textarea·출처 Select** UX를 그대로 가져와 재사용(코드 복사 OK, 중복 허용).
- 필드: 카테고리 Select(기본 `웹인사이트`) · 제목(필수) · **본문 textarea(필수, `rows≥10`)** · 원문 링크(선택) · 요약(선택, "비우면 AI가 자동 요약합니다" 안내) · 저자/발행처(선택) · 발행일 date(선택) · 출처 Select(선택) · 서비스 태그 · 키워드.
- 출처 로딩: 선택 카테고리에 맞는 `source_type` 만 조회 — `웹인사이트→web_insight`, `뉴스→news_site`, `리포트→report_publisher`. 카테고리 변경 시 재조회, `source_id` 초기화.
- 검증: 제목·본문 필수. 제출은 **클라이언트 insert 가 아니라** `POST /api/admin/paste` 호출(요약·HTML정리가 서버 전용이므로). 성공 시 `ReportUploadForm` 과 동일한 "등록 완료" 화면 + "계속 추가" 버튼.

### 4. 서버 라우트 — `src/app/api/admin/paste/route.ts` (신규)
- `src/app/api/admin/upload/route.ts` 의 **관리자 게이트 패턴 동일**(쿠키 서버 클라이언트 + `users.role==='admin'` 확인, 비관리자 403). **service_role 불필요**(스토리지 없음) — insert 는 쿠키 기반 서버 클라이언트로 수행해 **RLS(admin) 적용**.
- 흐름:
  1. body 파싱: `{ category, title, bodyText, originalUrl, summary, author, publishedAt, sourceId, serviceIds[], keywords[] }`. `title`·`bodyText` 빈값이면 400(한국어).
  2. **HTML 정리**: `bodyText` 에서 `<script>`/`<style>` 블록 제거 → 태그 제거 → 기본 엔티티 디코드(`&amp; &lt; &gt; &quot; &#39; &nbsp;`) → 3줄+ 공백을 2줄로 collapse → trim. (신규 의존성 추가 금지, 정규식 기반 헬퍼.)
  3. `summary` 비었으면 `await summarizeKo(title, cleanBody)`(best-effort, null 허용 — 실패 시 `summary_ko=null`).
  4. `contents` insert(위 표) → `id` 반환. `content_services`(serviceIds) → `content_keywords`(키워드 ilike 조회/없으면 생성, `ReportUploadForm` 로직 동일) 삽입.
  5. `original_url` **부분 유니크 인덱스 위반**(이미 등록된 URL) catch → 409 `'이미 등록된 원문 URL 입니다.'`. 그 외 실패는 한국어 메시지 + 콘솔 영문 로그.
  6. 성공 `{ id }` 반환.

## 회귀 / 주의
- DB 무변경. 기존 `ReportUploadForm`·`/api/admin/upload`(파일 업로드) 동작 불변 — 탭으로 감싸기만.
- deprecated 카테고리(`오피니언`·`가트너`·`KRG`·`뉴스레터`) Select 에 노출 금지.
- `original_url` 은 null 허용(부분 유니크) — 링크 없이도 등록 가능.
- LLM 요약은 키 미등록/한도소진 시 null → 폼은 정상 등록(요약 없음). 자동요약 실패가 등록 실패가 되면 안 됨.
- UI 텍스트 한국어(#1), 색상은 토큰/`brand`(#9), `'use client'` 는 폼·탭 leaf 에만(#12), `cookies()` await(Next.js 16).
