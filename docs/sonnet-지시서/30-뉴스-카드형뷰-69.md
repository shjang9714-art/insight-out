## 배경

`RecentFeed.tsx`는 `divide-y`로 텍스트 리스트를 그린다. 썸네일이 없어 정보 밀도/스캔성이 떨어짐. `contents.thumbnail_url`이 스키마에 존재하므로 카드(썸네일+배지+제목+요약+출처+시간)로 전환한다.

## 1. 신규 `src/components/dashboard/ContentCard.tsx` (재사용 카드)

- props:
  ```ts
  interface ContentCardProps {
    id: string
    title: string
    summaryKo: string | null
    category: ContentCategory
    sourceName: string | null
    publishedAt: string | null
    thumbnailUrl: string | null
    href?: string | null   // 없으면 비링크(유튜브 등 상세 없는 항목)
  }
  ```
- 레이아웃(세로 카드):
  - 상단 **썸네일 영역**(`aspect-[16/9]`, `rounded-t-2xl`, `next/image` `fill` + `object-cover`). `thumbnailUrl` 없으면 **카테고리색 그라데이션 폴백**(`CATEGORY_COLOR` 톤) + 카테고리 라벨 워터마크. `next/image` 외부 도메인은 `next.config.ts`의 `images.remotePatterns` 확인 필요 — 미설정 도메인이면 `<img>` 폴백 또는 `unoptimized` 처리(빌드 에러 방지).
  - 본문(`p-4`): 카테고리 배지 + 출처 배지(기존 `CATEGORY_COLOR` 맵 재사용) → 제목(`line-clamp-2 font-medium`) → 요약(`line-clamp-2 text-muted-foreground`) → 하단 메타(출처 · `timeAgo`).
  - 카드 컨테이너: `group rounded-2xl border border-border bg-card overflow-hidden transition hover:shadow-md hover:border-brand-200`. 제목 `group-hover:text-brand-600`.
  - `href` 있으면 카드 전체를 `<Link>`, 없으면 `<div>`(유튜브). `next/image` 도메인 이슈 회피용 폴백 포함.
- `CATEGORY_COLOR`/`timeAgo`/`CONTENT_CATEGORY_LABEL` 등은 RecentFeed에서 공용 위치로 빼거나 ContentCard 내부에 복제(최소 결합). 기존 색 맵 유지.

## 2. `RecentFeed.tsx` 카드 그리드로 교체

- 쿼리 `select`에 **`thumbnail_url` 추가**(`'id, title, summary_ko, category, published_at, thumbnail_url, sources(name)'`). `FeedItem`에 `thumbnail_url: string | null` 추가.
- `.limit(5)` → **`.limit(6)`**(2·3열 그리드 정렬용).
- 렌더: `divide-y` 리스트 제거 → `<div className="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3">` 안에 `ContentCard` 매핑.
- 유튜브 항목: `href={null}`(기존처럼 상세 미연결) 또는 원문 링크가 있으면 그쪽. 기존 분기 유지.
- 스켈레톤: 카드형 스켈레톤(썸네일 블록+텍스트 라인 2~3개)으로 교체, `grid` 동일.
- 빈 상태 문구 유지. 카드 컨테이너 외곽(`rounded-2xl border bg-card`)·헤더("최근 피드"/"전체 보기")는 유지하되 색은 토큰화.

## 3. (권장) 전체 목록 `contents/page.tsx`도 카드 적용

- "전체 보기" 대상 목록 페이지도 동일 `ContentCard` 그리드로 통일(전면 교체 취지). 페이지네이션/필터 로직은 그대로 두고 표시만 카드 그리드로. 작업량 크면 본 라운드는 RecentFeed 우선, contents/page.tsx는 보고에 "후속"으로 표기 가능.

## 4. 점검

- 썸네일 있는/없는(폴백) 항목 모두 정상. `next/image` 도메인 미허용으로 인한 빌드/런타임 에러 없음.
- 반응형(1/2/3열) — 지시서 11(#33) 반응형 기조 유지, 모바일 1열.
- 라이트/다크(지시서 29) 카드 대비.
