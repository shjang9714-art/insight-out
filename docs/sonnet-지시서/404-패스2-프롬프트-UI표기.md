## 0. 착수 전 확인 결과 — **이미 구현돼 있다. UI 문구만 고친다.**

디렉터 요청은 "프롬프트까지 같이 복사해서 어느 LLM에 붙여도 되게". **확인 결과 이미 그렇게 동작한다.**

`GET /api/admin/competitor-weekly/analysis` 가 복사용 `prompt` 를 이렇게 만든다(`analysis/route.ts`):
```
frameSpec (FRAME_SPEC 역할·규칙 6개 + 출력 JSON 스키마 + LGU_CONTEXT)   ← 프롬프트
+ [주간] 날짜
+ [사건 목록] JSON                                                        ← 데이터
```
- `FRAME_SPEC`(`frame-spec.ts`)은 **역할·작성규칙·완전한 출력 스키마·"JSON 외 붙이지 마라"** 까지 담은 완결 프롬프트다. POST 검증 스키마와 정확히 일치한다.
- 파일 주석: *"이 문자열이 곧 프롬프트다. 유료 API 붙이면 이 스펙을 system 프롬프트로 그대로 쓴다."*
- **즉 프롬프트+스키마+데이터가 이미 한 덩이로 클립보드에 복사된다. Claude·GPT 어디든 붙일 수 있다.**

**그런데 화면 문구가 이 사실을 감춘다:**
| 위치 | 현재 문구 | 문제 |
|---|---|---|
| 제목 | `패스② · Claude 수동` | Claude 전용처럼 보인다 |
| 안내문 | `컨텍스트를 복사 → Claude에 붙여넣기` | Claude 특정 + "컨텍스트"(데이터)만 복사되는 인상 |
| 복사 버튼 | `① 분석 컨텍스트 복사` | "프롬프트"라는 말이 없어 데이터만 복사되는 것처럼 보인다 |
| 결과 라벨 | `② Claude 분석 결과` | Claude 전용처럼 보인다 |

→ **백로그 §5.4 "데이터만 복사된다"는 플래너 추정 오류였다.** 실제 복사물엔 프롬프트가 맨 위에 있다. 이번 슬라이스는 **UI 문구만** 실제 동작에 맞춘다.

## 1. 변경 — `AdminCompetitorWeeklyAnalyze.tsx` 문자열만

로직·상태·API·핸들러 **일절 무수정.** 아래 4개 문자열만 교체한다.

| 위치 | 현재 | 변경 |
|---|---|---|
| 제목(`<h2>`) | `경쟁사 주간 브리핑 분석 (패스② · Claude 수동)` | `경쟁사 주간 브리핑 분석 (패스② · LLM 수동 분석)` |
| 안내문(`<p>`) | `사실 추출(생성)이 끝난 주에 대해 컨텍스트를 복사 → Claude에 붙여넣기 → 결과 JSON을 다시 붙여넣으면 근거 검증 후 저장됩니다. 근거가 없는 문장은 저장되지 않습니다.` | `사실 추출(생성)이 끝난 주에 대해 **프롬프트+데이터를 복사** → 원하는 LLM(Claude·GPT 등)에 붙여넣기 → 결과 JSON을 다시 붙여넣으면 근거 검증 후 저장됩니다. **복사 버튼에 지시문·출력 형식·사건 데이터가 모두 담깁니다.** 근거가 없는 문장은 저장되지 않습니다.` |
| 복사 버튼 | `① 분석 컨텍스트 복사` | `① 프롬프트+데이터 복사` |
| 결과 라벨(`<label>`) | `② Claude 분석 결과 — 객체 { summary, overall_impact, areas: [...] }` | `② LLM 분석 결과 — 객체 { summary, overall_impact, areas: [...] }` |

- `복사됨` 토글 문구는 그대로.
- `contextInfo` 표시(`영역 N개 · 사건 N건`)는 그대로 — 데이터 규모 정보라 유용하다.
- 다른 컴포넌트·라우트·상수 **무수정.**
