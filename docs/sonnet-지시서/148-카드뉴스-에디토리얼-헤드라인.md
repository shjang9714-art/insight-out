## 0. 한 줄

인사이트 카드 헤드라인은 지금 "핵심 동향 1줄"(분석가 톤)이고 어드민·카드뉴스가 같은 값을 쓴다. **카드뉴스(큰 글자)용 에디토리얼 카피**를 분리 필드 `card_headline` 로 추가한다. 생성 시 LLM이 `headline`(분석가)과 `card_headline`(에디토리얼)을 동시 산출, 카드뉴스는 `card_headline ?? headline`. 어드민 목록·기존 동작은 무변경. 키/컬럼 없으면 graceful 폴백(회귀 0).

## 1. 현행 진단 (검증된 코드 사실)

- `src/lib/insight/generate.ts` — `SYSTEM_PROMPT`(L49, 산업)·`COMPANY_SYSTEM_PROMPT`(L236, 회사) 둘 다 `{"headline","implication","citations"}` JSON 산출. **`parseLlmOutput`(L63)·`LlmOutput`(L19) 타입은 두 함수 공유.** upsert payload는 각 함수 인라인(산업 L185~199 / 회사 L339~355).
- `src/components/analysis/NewsCardSlider.tsx` — 카드뉴스 슬라이더(140), `s.headline` 을 `text-2xl/3xl font-bold` 로 렌더(L152). 슬라이드는 `AiInsightsView` 에서 `insightSlides`(industry `cards`)로 빌드, `headline: card.headline`.
- `src/components/analysis/InsightCardNewsList.tsx:58` — 인사이트 카드뉴스 뷰(133) 큰 헤드라인 `{card.headline}`.
- `src/lib/types.ts:285` `InsightCard` 인터페이스(headline L291).

## 2. DB / SQL 핸드오프 (먼저 푸시)

## 3. 구현

### 3-1. `src/lib/insight/generate.ts`

**(a) 출력 타입** — `LlmOutput`(L19)에 추가:
```ts
interface LlmOutput {
  headline: string
  card_headline: string   // 에디토리얼 카피(큰 글자 카드뉴스용)
  implication: string
  citations: { content_id: string; quote: string }[]
}
```

**(b) 파서** `parseLlmOutput`(L63) — card_headline 추출, 없으면 headline 폴백:
```ts
const card_headline =
  typeof obj.card_headline === 'string' && obj.card_headline.trim()
    ? (obj.card_headline as string).trim()
    : (obj.headline as string)
return { headline: obj.headline as string, card_headline, implication: ..., citations }
```

**(c) 프롬프트** — 두 시스템 프롬프트 JSON 스키마에 `card_headline` 추가 + 가이드. 예시(산업 `SYSTEM_PROMPT`):
```
... headline(핵심 동향 1줄, 분석가 톤) ...
추가로 card_headline: 카드뉴스 큰 글자용 **에디토리얼 헤드라인**. 짧고 강렬하게(공백 포함 20자 내외), 단 사실 기반 — 과장·낚시·물음표 금지, 핵심 주체와 동향은 유지.
JSON만 출력: {"headline":"","card_headline":"","implication":"","citations":[{"content_id":"","quote":""}]}
```
`COMPANY_SYSTEM_PROMPT`(L236~239)도 동일하게 card_headline 항목·스키마 추가(기업 동향 톤).

**(d) upsert — 42703 graceful 헬퍼** (두 함수 공유). 파일 상단(엔진 함수 위)에 추가:
```ts
async function upsertInsightCard(
  adminClient: SupabaseClient,
  payload: Record<string, unknown>,
): Promise<{ error: { message: string } | null }> {
  const first = await adminClient
    .from('insight_cards')
    .upsert(payload, { onConflict: 'period_start,scope,topic' })
  // card_headline 컬럼 미적용(42703) → 제거 후 재시도(생성 무중단)
  if (first.error && (first.error as { code?: string }).code === '42703' && 'card_headline' in payload) {
    const rest = { ...payload }
    delete rest.card_headline
    const retry = await adminClient
      .from('insight_cards')
      .upsert(rest, { onConflict: 'period_start,scope,topic' })
    return { error: retry.error }
  }
  return { error: first.error }
}
```
- 산업 upsert(L183~199): payload에 `card_headline: parsed.card_headline` 추가 후 `await upsertInsightCard(adminClient, { ...payload })` 로 교체. `upsertError` 변수는 `(await upsertInsightCard(...)).error` 로 받음.
- 회사 upsert(L339~355): 동일하게 `card_headline: parsed.card_headline` 추가 + 헬퍼 경유.

### 3-3. `src/components/analysis/AiInsightsView.tsx` — card_headline 보강(읽기 graceful)

산업/회사 카드 select는 **건드리지 않는다**(42703로 전체 뷰가 깨지지 않도록). 대신 `companyCards` 산출 직후, 가드된 보강 쿼리로 card_headline을 카드 객체에 병합:

```ts
// card_headline 보강 (148, SQL 미적용 시 graceful skip)
const allInsightIds = [...cards, ...companyCards].map(c => c.id)
if (allInsightIds.length > 0) {
  const { data: chData, error: chErr } = await supabase
    .from('insight_cards')
    .select('id, card_headline')
    .in('id', allInsightIds)
  if (!chErr && chData) {
    const chMap = new Map(
      (chData as { id: string; card_headline: string | null }[]).map(r => [r.id, r.card_headline])
    )
    for (const c of [...cards, ...companyCards]) {
      const ch = chMap.get(c.id)
      if (ch) c.card_headline = ch
    }
  }
}
```
(컬럼 없으면 `chErr.code==='42703'` → skip, 카드뉴스는 headline 폴백 = 회귀 0.)

**슬라이드 헤드라인** — `insightSlides`(약 L333) `headline: card.headline` → `headline: card.card_headline ?? card.headline`. `matchNames`에도 `card.card_headline` 포함(렌즈 하이라이트 유지, 선택).

## 4. 회귀 가드 / 비기능 요건

- SQL 미적용 → 쓰기 42703 폴백(생성 무중단)·읽기 skip → 카드뉴스 headline 폴백. **회귀 0.**

- 기존 발행 카드(card_headline NULL) → 야간 재생성(145 cron) 시 자동 채워짐. 그 전엔 headline 폴백.
