## 배경 (David 피드백 2026-06-22)

지식그래프가 **① 동그라미가 다 붙어 있어 헷갈림**(노드 겹침) **② 연결선(고리)이 안 보임**(흐릿) **③ 왜 연결됐는지 화면이 안 알려줌**(호버해야 잠깐 뜸) **④ 노드를 눌러도 관련 기사가 안 나옴**(클릭=확장이라 직관과 어긋남). → 가독성 + "연결의 이유" + "클릭하면 기사"를 갖춘 도구로.

핵심 재정의: **클릭 = 그 주제 선택 → 옆에 관련 기사·연결 이유 패널.** 확장(이웃 더 보기)은 **명시적 버튼**으로 분리.

---

## A. 가독성 — 겹침 해소 + 연결선 또렷
- **노드 겹침 방지**: ForceGraph2D d3 force 조정 — charge 반발 강화(예 strength −200~−400), **link distance 키우기**(예 60~90), **collision 반경**(노드 반지름+여백) 추가. `d3VelocityDecay`·`cooldownTicks` 조정으로 안정 배치. (ref의 `d3Force('charge')/('link')` 또는 props로.)
- **연결선 또렷하게**: `LINK_COLOR` 불투명도 ↑(rgba 0.35 → 0.6 수준), 기본 두께 하한 ↑. 선택/하이라이트 시 더 진하게. (canvas hex 예외 유지.)
- 노드 라벨 가독(겹칠 때 흐림 처리 or 충돌 회피)·중심/확장/미확장 시각 구분(136)은 유지.

## B. 노드 클릭 → 선택 + 관련 기사 패널 (핵심)
- **클릭 동작 변경**: 노드 클릭 = **선택**(재중심·확장 아님). 우측(또는 하단) **선택 패널** 열림:
  - 엔티티 요약(이름·유형·경쟁사·언급수) + **"상세 보기 →"**(`/dashboard/entities/{id}`).
  - **관련 기사 목록**(`content_entities`→`contents` 최근 ~8건, 제목 링크 `/dashboard/contents/{id}` + 일자). = "이 주제를 누르면 관련 기사가 나온다"(David 요구 ④).
  - **함께 등장한 주제(이웃)** 칩 — 누르면 그 주제로 선택 이동. = 연결의 맥락.
  - **"이웃 펼치기"** 버튼(명시적) → 기존 ego-expand(누적 확장) 실행. (클릭=확장 제거, 확장은 버튼으로.)
- 빈/RPC 미적용 시 graceful 안내.

## C. 연결선(엣지) 클릭/선택 → 왜 연결됐는지 (David 요구 ③)
- 엣지 클릭(또는 호버 유지) → **"A와 B는 기사 N건에서 함께 등장"** + `entity_pair_contents`로 그 **공동 기사 목록**(제목 링크). 기존 호버 툴팁을 **선택 시 고정**되는 패널로 격상(스쳐 지나가지 않게).
- 엣지에 weight 라벨(함께 등장 건수)을 옅게 상시 표기 검토(과하지 않게).

## D. 안내·온보딩 (비전문 사용자)
- 그래프 상단/빈 상태에 한 줄 설명: *"점=기업·기술·인물, 선=함께 뉴스에 등장한 관계. 점을 누르면 관련 기사가 보여요."*
- 하단 힌트 문구를 새 동작에 맞게 갱신(노드=선택/기사, 버튼=이웃 펼치기, 선=연결 이유).
