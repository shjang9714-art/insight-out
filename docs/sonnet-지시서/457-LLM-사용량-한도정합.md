# 지시서 457 — LLM 사용량 한도 정합(키개수 반영) + 초과 상태 표시

**SQL 0 · env 0 · 의존성 0.** 브랜치 `agent/457-llm-usage-limit`.

## 배경
어드민 두 화면이 **서로 다른 사용률**을 보여준다.
- `LlmManager.tsx:214` — `usagePct = tokens_used / monthly_token_limit * 100` → **키개수 곱 누락**. Gemini가 100% 초과로 보이는데 실제로는 여유가 있다.
- `AdminOpsSignals`(대시보드) — `admin/page.tsx:257`에서 `× keyCount`를 반영해 넘긴다.

라우팅의 실효 한도(유일한 정본)는 `llm/index.ts:179` `(s?.limit ?? 1_000_000) * getProviderKeyCount(provider)` 다.
⇒ 매일 보는 화면이 잘못된 값을 띄우고 있어 **운영 판단을 오도한다**(448·449 관측을 이 화면으로 판정하는 중).

## 근본 원인 — 같은 공식이 3곳에 복제됨
`(monthly_token_limit ?? 1_000_000) * keyCount` 가 이미 세 군데에 흩어져 있고, `LlmManager` 는 아예 빠져 있다.
- `src/lib/llm/index.ts:179` (라우팅 **정본** · hot path)
- `src/app/admin/page.tsx:257`
- `src/lib/ops/daily-brief.ts:52`

## 변경

### 1. 공식 공용화 (재발 방지의 본체)
**신규 `src/lib/llm/token-limit.ts`**
```
export const DEFAULT_MONTHLY_TOKEN_LIMIT = 1_000_000
export function effectiveTokenLimit(settingLimit: number | null | undefined, keyCount: number): number
```
위 3곳이 **전부 이 함수를 호출**하도록 교체한다. 복제 잔존 0.
⚠️ `llm/index.ts`는 **라우팅 hot path** — 값·분기 동작이 **완전히 동일**해야 한다(리팩터만, 동작 변경 0).

### 2. API 응답 확장
`GET /api/admin/llm` (`src/app/api/admin/llm/route.ts`) 응답의 provider별 항목에 **`keyCount`** 와 **`effectiveTokenLimit`** 추가.
`getProviderKeyCount`는 `server-only`(env 파싱)라 **반드시 이 라우트에서 계산**한다. 클라이언트에서 키 개수를 추정하지 말 것. 키 값 자체는 절대 응답에 넣지 않는다(개수만).

### 3. LlmManager 표시 수정
- `usagePct`를 **`effectiveTokenLimit` 기준**으로 계산. 진행바 임계(90/70)는 그대로.
- 문구를 오해 없게: `월 한도 1,000,000 × 2키 = 2,000,000 중 50%` 형태로 **곱셈 근거를 드러낸다**(지금은 곱이 안 보여서 사용자가 계산을 못 믿는다).
- `keyCount = 0`(미설정)이면 한도 0 → % 대신 **"키 미설정"** 표기(0으로 나누지 말 것).

### 4. 초과 상태 배지
- `usage >= effectiveTokenLimit` → **"차단(폴백 전환)"** — 서비스가 멈추는 게 아니라 다음 provider로 넘어간다는 뜻이 전달되어야 한다.
- `enabled === false` → **"비활성"**
- 기존 `StatusBadge`·`Tone`(`positive|risk|negative|neutral|info`) 사용. 신규 톤 정의 금지.

### 5. 범위에서 제외 — 쿨다운 배지 (하지 말 것)
개선검토(2026-07-26)에 "쿨다운 배지"가 적혀 있으나 **현 구조에서 구현 불가**다.
`cooldownUntil`은 `llm/index.ts`의 **모듈 스코프 `Map`** 으로 warm 인스턴스별 메모리다(콜드스타트 시 리셋). 다른 요청·인스턴스에서 조회할 방법이 없다.
표시하려면 DB 기록이 필요하고 그건 **SQL 동반 별건**이다. 이 지시서에서는 **넣지 않는다.** 억지로 추정값을 그리지 말 것.
