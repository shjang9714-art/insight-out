## 파트 A — #65 아카이브 담기 팝업을 Radix Dialog로
현재 `ArchiveButton` 은 absolute 드롭다운 → 하단으로 빠지고 스크롤 불가·클릭 과다.
- 트리거 클릭 시 **중앙 정렬 Radix Dialog**(shadcn `Dialog`, 없으면 추가)로 전환.
- 내부: 아카이브 목록을 **스크롤 영역**(max-h + overflow-y-auto)으로, 각 항목 **원클릭 담기/해제 토글**(현재 "담기" 후 닫힘 없이 즉시 반영), "새 아카이브 만들기"는 같은 다이얼로그 안 인라인.
- 모바일에서도 화면 안에 들어오게(중앙·반응형). ESC·바깥클릭·닫기 버튼. 기존 저장 로직(archive_items insert/삭제)·RLS 유지.

## 파트 B — #66(1) 사이드패널에 아카이브 표시·갱신
현재 Sidebar 는 아카이브 *콘텐츠 항목*만 8개 표시 + mount 1회 로드(담은 직후 미갱신).
- **아카이브 폴더(이름) 목록**을 사이드패널에 표시(본인 RLS): `archives` 조회 → 이름 + 항목수(또는 최근 항목 일부). mypage로 링크.
- (또는 폴더 + 그 안 항목 트리) — 과하면 폴더 목록 + 개수만.
- **갱신**: 담기/삭제 후 사이드패널이 반영되도록 — 라우트 이동 시 재조회되게 하거나, 간단한 refetch 트리거(과설계 금지, mount 재조회로 충분하면 그대로 + 빈/로딩/에러 처리).
- 빈 상태("아직 아카이브가 없습니다") 명확히.

## 파트 C — #66(2) 메일 발송 실패 진단·수정
**진단(확정)**: `from: RESEND_FROM_EMAIL ?? 'onboarding@resend.dev'` — Resend는 **도메인 미인증 시 계정 소유자 본인 주소로만 발송 허용** → 다른 수신자 403 실패.
- **코드**: `send-archive/route.ts` 에서 Resend `sendError` 의 **실제 사유를 사용자 메시지에 반영**(현재 일괄 "이메일 발송에 실패했습니다"). 예: 도메인/수신자 제한이면 "발송 도메인이 아직 인증되지 않아 외부 수신자에게 보낼 수 없습니다(관리자 설정 필요)" 같은 한국어 안내. 상태코드·사유 로깅 유지.
- (선택) `RESEND_FROM_EMAIL` 미설정 시 시작 로그 경고.
- **수희 핸드오프(보고에 명시, 코드 아님)**: **Resend 도메인 인증**(resend.com/domains) 후 `RESEND_FROM_EMAIL` 을 그 인증 도메인 주소(예 `noreply@<인증도메인>`)로 Vercel env 설정 → 그래야 임의 수신자 발송 가능. 미인증 동안은 소유자 본인 주소만 성공.
