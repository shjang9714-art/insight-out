## 0. 한 줄

콘텐츠 테이블의 "관리" 열을 **오른쪽에 고정**해 가로 스크롤과 무관하게 보기·노출/숨김·수정·삭제가 항상 보이게 하고, 어드민 `--destructive` 토큰을 **차분한 무드 레드**로 재정의 + "비우기" 버튼의 생 `red-*` 을 토큰으로 교체해 빨강을 톤다운한다.

## 1. 현행 진단 (검증된 코드 사실)

### 1-A. 관리 열 짤림
- `AdminContentManager.tsx`: 테이블은 `table-fixed`(:1031)에 **명시 width = 선택(40) + 관리(300) + 리사이즈 6열 기본합(320+96+140+130+80+150=916) = 1256px**(:1032~1035). 어드민 본문 폭보다 넓어 `overflow-x-auto`(:1029) **가로 스크롤 상시** 발생.
- 관리 열(`MANAGE_COL_WIDTH = 300`, :79)은 **맨 오른쪽 col**(:1042). 셀 내부 버튼 4개: 보기(:1181) + 노출|숨김(:1187~1207) + 수정(:1208~1215) + 삭제(destructive, :1216~, 아이콘). 스크롤이 오른쪽 끝까지 안 가면 수정/삭제가 카드 밖으로 밀려 잘림. → **열 폭 문제가 아니라 "오른쪽 열이 스크롤에 가려지는" 구조**.

### 1-B. 강렬한 빨강
- 사용량 바(`AdminOpsSignals.tsx` UsageBar): `pct>=100 ? 'bg-destructive'` + `text-destructive`(:33,37). 삭제 버튼(테이블 행): `variant="destructive"`(:1217).
- `--destructive` 는 **어드민 스코프에 재정의 없음** → 전역 `:root --destructive: oklch(0.577 0.245 27.325)`(globals.css:98, 고채도 강렬 레드)를 라이트·다크 모두 그대로 사용(어드민 다크는 data-admin-theme라 `.dark`(167)도 안 탐).
- "수집 기사 비우기/유튜브 비우기" 버튼: 생 Tailwind `border-red-200 text-red-600 hover:border-red-400 hover:bg-red-50`(:772,785) — 토큰 미사용이라 더 쨍함.

## 2. 구현

### 2-A. 관리 열 오른쪽 고정 — `AdminContentManager.tsx`

1. **폭 확대**: `MANAGE_COL_WIDTH = 300 → 340`(:79). 4버튼(글자 크기 '크게'까지) 여유. 테이블 width 계산(:1033)은 상수 참조라 자동 반영.
2. **헤더 셀**(:1110) `<th className="px-4 py-3 text-right">관리</th>` →
   `className="sticky right-0 z-20 bg-muted px-4 py-3 text-right"` + 왼쪽 구분선.
3. **본문 액션 셀**(:1179) `<td className="px-4 py-3">` →
   `className="sticky right-0 z-10 bg-card px-4 py-3"` + 왼쪽 구분선.
4. **왼쪽 구분선**: `border-collapse`(:1031) 환경에서 sticky 셀의 자체 border 가 안 그려질 수 있으니 **box-shadow inset 로 구분선**을 준다(항상 페인트):
   `style={{ boxShadow: 'inset 1px 0 0 0 var(--border)' }}` 또는 임의 속성 클래스 `[box-shadow:inset_1px_0_0_0_var(--border)]`. (th·td 동일.)
   - border-collapse 로 sticky 배경이 불안하면 대안: 테이블을 `border-separate border-spacing-0` 로 바꾸고 행 구분선은 기존 `tbody tr { border-bottom }`(globals :324) 유지 — **단 이 전환은 회귀 위험이 있어 box-shadow 우선, 정 안 되면 채택**.
5. **불투명 배경 필수**: 고정 셀 아래로 다른 열이 지나가므로 th=`bg-muted`(헤더색)·td=`bg-card`(행 배경)로 가림. **행 hover 틴트**(globals `tbody tr:hover{background:accent}`)는 고정 td의 `bg-card`에 가려 이 셀만 hover 색이 안 뜸 — 허용(원하면 후속으로 `tr:hover` 시 고정 td 배경도 accent 로).
6. 선택(체크) 열(왼쪽)은 고정 대상 아님. z-index: 헤더 고정 셀 z-20 > 본문 고정 셀 z-10(스크롤 시 헤더가 위).

### 2-B. 빨강 톤다운

1. **어드민 `--destructive` 재정의**(globals.css) — 차분한 무드 레드:
   - `.admin-scope { … }`(:357 블록, `--negative` 인근 :377)에 추가:
     `--destructive: #C4564C;` (라이트 — 저채도 벽돌 레드)
   - `.admin-scope[data-admin-theme="dark"] { … }`(:394 블록, :414 인근)에 추가:
     `--destructive: #DD8079;` (다크 — 다크 배경서 읽히는 부드러운 살몬 레드)
   - `--color-destructive: var(--destructive)`(@theme :29)가 참조하므로 `bg-destructive`·`text-destructive`·destructive 버튼 variant 전부 자동 톤다운. (값은 육안 후 미세조정 가능 — 의도=강렬↓, 위험 신호는 유지.)
2. **"비우기" 버튼 토큰화**(`AdminContentManager.tsx` :772, :785 두 곳):
   `border-red-200 text-red-600 hover:border-red-400 hover:bg-red-50`
   → `border-destructive/40 text-destructive hover:border-destructive/60 hover:bg-destructive/10`
   (bordered 룩 유지 + 톤다운된 destructive 토큰 공유. `text-red-600` 같은 생 유틸 제거 → 203 대비 규칙과도 정합.)
3. 사용량 바(UsageBar)·테이블 삭제 버튼은 **코드 변경 없이** 토큰 재정의로 톤다운(확인만).

## 3. 회귀 가드 / 비기능 요건

- **어드민 한정**: `--destructive` 재정의는 `.admin-scope`/`[data-admin-theme="dark"]` 스코프에만 → 공개 :root·`.dark` 무변경(사용자 화면 빨강 무영향).
- sticky 전환은 순수 표시 — 데이터·정렬·선택·리사이즈(200 훅) 로직 무변경. 리사이즈 대상은 여전히 6열(관리 고정 유지).
- 가로 스크롤 시 관리 열 항상 노출, 왼쪽 구분선/그림자로 스크롤 경계 인지.
- 신규 hex 는 `--destructive` 2값뿐(토큰). 컴포넌트는 `*-destructive` 토큰 클래스 사용(Rule 9 정합). SQL·npm 0.
- 203 폰트 축소·대비 유지, 빨강 삭제 버튼은 톤다운되되 **여전히 빨강(위험 신호 식별 가능)**.
