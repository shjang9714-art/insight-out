## 3. 구현

### 3-1. `src/components/feed/FeedSlot.tsx` — 폴백 서버 페치 + 주입

RecommendedFeed 분기(status !== 'new')에서만 폴백 페치(온보딩 분기는 불필요). FeedItem 형태로:

```ts
import { isB2BRelevant } from '@/lib/feed-blocklist'
import { dedupSimilarItems } from '@/lib/feed-dedup'

const FALLBACK_SELECT =
  'id, title, summary_ko, body_original, category, published_at, thumbnail_url, sources(name), matched_groups, matched_keywords'

// ... status !== 'new' 경로에서:
const { data: fbRaw } = await supabase
  .from('contents')
  .select(FALLBACK_SELECT)
  .eq('status', 'published')
  .neq('category', '유튜브')
  .order('importance_score', { ascending: false })
  .order('collected_at', { ascending: false })
  .limit(18)

const fbFiltered = ((fbRaw ?? []) as unknown as FeedItem[])
  .filter(c => isB2BRelevant(c.title, c.summary_ko))
const fallbackItems = dedupSimilarItems(fbFiltered).slice(0, 6)
```
`FeedItem` 타입은 RecommendedFeed의 것과 동일(필요 시 FeedSlot 내 로컬 인터페이스 또는 export 재사용). `fallbackItems`를 `<RecommendedFeed fallbackItems={fallbackItems} ... />`로 전달.

### 3-2. `src/components/feed/RecommendedFeed.tsx` — 빈 분기 폴백 렌더

props 확장:
```ts
interface RecommendedFeedProps {
  ...
  fallbackItems?: FeedItem[]
}
```
구조분해 기본값 `fallbackItems = []`.

빈 분기(177~180) 교체:
```tsx
) : sections.length === 0 ? (
  fallbackItems.length > 0 ? (
    <div>
      <h3 className="mb-2 text-xs font-medium text-muted-foreground">요즘 주목할 콘텐츠</h3>
      <div className="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3">
        {fallbackItems.map((item) => (
          <ContentCard
            key={item.id}
            id={item.id}
            title={item.title}
            summaryKo={toExcerpt(item.summary_ko, item.body_original)}
            category={item.category}
            sourceName={item.sources?.name ?? null}
            publishedAt={item.published_at}
            thumbnailUrl={null}
            href={item.category === '유튜브' ? null : undefined}
            keywords={tagsOf2(item.matched_groups ?? [], item.matched_keywords ?? [], item.category)}
          />
        ))}
      </div>
      <p className="mt-3 text-center text-xs text-muted-foreground">
        관심사를 설정하면 더 잘 맞는 추천을 받을 수 있어요.
      </p>
    </div>
  ) : (
    <p className="py-8 text-center text-xs text-muted-foreground">
      추천할 콘텐츠가 아직 없습니다
    </p>
  )
) : (
  // ... 기존 정상 렌더(무변경)
)}
```

- 카드 렌더는 기존 섹션과 동일 패턴(ContentCard·toExcerpt·tagsOf2) 재사용.
- 폴백도 0이면(코퍼스 자체가 빔) 기존 빈 메시지 유지.
- 헤더 제목(`맞춤 추천 피드`/`지금 화제…`)·관심사 버튼은 그대로 — 폴백 시에도 헤더는 유지돼 "관심사 설정하기"로 유도.

## 4. 회귀 가드 / 비기능 요건

- 피드가 비지 않으면(정상) 폴백 미사용 — **정상 경로 완전 무변경, 회귀 0.**
- 폴백 페치는 status='new'(온보딩) 경로엔 없음(불필요한 쿼리 회피).
- 폴백도 0(코퍼스 빔) → 기존 빈 메시지.
- B2B 필터·dedup 재사용으로 무관/중복 콘텐츠 차단.
- SQL·신규 의존성 0. 하드코딩 hex 0(기존 토큰/컴포넌트).
