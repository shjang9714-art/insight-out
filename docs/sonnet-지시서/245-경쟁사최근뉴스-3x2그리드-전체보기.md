# 지시서 245 — 경쟁사 최근 뉴스 3×2 그리드 + 전체보기 페이지

목표: 경쟁사 최근 뉴스(242)의 그룹 내 레이아웃을 **가로 스크롤 → 3열×2행(최대 6개) 그리드**로 바꾸고, **"전체보기"**로 **전체 경쟁사 최근 뉴스 전용 화면**(모든 그룹·전 경쟁사, 제한 없음)으로 이동한다.

David 요청(라이브 피드백): 각 그룹 3×2로 6개쯤 보여주고, 전체보기로 확장하면 전체 화면으로 넘어가게.

범위: `entities/page.tsx` competitor 뷰(요약, 6-cap) + **신규 전체 페이지** + 공유 컴포넌트 추출. SQL 없음.

> ⚠️ 별개(데이터): 현재 카카오엔터프라이즈·KT 등이 "기타 경쟁사"로 몰림 — 224 competitor_group 백필이 이름과 안 맞음. **어드민 EntityManager에서 competitor_group 지정** 또는 백필 이름 확장 필요(이 지시서 밖). 레이아웃은 그룹이 채워지면 진가 발휘.

---

## 1. 현행 진단 (검증된 코드 사실)
- 242로 competitor 뷰: 그룹 박스(통신/클라우드·플랫폼/빅테크/기타 경쟁사) + 그룹 내 **회사 카드 가로 스크롤**(`flex overflow-x-auto`, 카드 `flex-none w-[288px]`). 각 회사 카드=이름+위기/기회/관망 칩+기사(최대5, 날짜)+더보기.
- 그룹 순서·데이터(`competitorGroups`, 42703 graceful)는 242에서 구축됨 — **재사용**.

## 2. 구현

### 2-1. 공유 컴포넌트 추출 `CompetitorNewsGroups`(신규)
- 242의 그룹 박스 + 회사 카드 렌더를 **컴포넌트로 추출**(props: `groups: CompGroupBucket[]`, `capPerGroup?: number`, `showSeeAll?: boolean`, `seeAllHref?: string`). 요약/전체 페이지가 공유해 중복 제거.
- 데이터 타입(`CompGroupBucket`·`CompResult`)은 공유 모듈로 이동하거나 export.

### 2-2. 요약 뷰 (기업동향 관심기업 탭 = `entities/page.tsx` competitor)
- 그룹 내부: **가로 스크롤 → 그리드** `grid grid-cols-2 lg:grid-cols-3 gap-3`. 그룹당 **최대 6개**(3×2) 회사 카드만(`capPerGroup=6`).
- 그룹 헤더에 총 사수·건수 유지. 그룹이 6개사 초과면 카드 그리드 아래 또는 헤더에 그룹 카운트 노출.
- **상단 "전체보기 →"**(기간 캡션 우측 정렬) → `href="/dashboard/entities/competitor-news"`. (그룹별 초과 시 그룹 헤더에도 "전체보기" 선택적)

### 2-3. 전체 페이지 (신규 `dashboard/entities/competitor-news/page.tsx`)
- 제목/헤더: "경쟁사 최근 뉴스" + 기간 캡션 + 범례. 뒤로가기(기업동향) 링크.
- 242와 **동일 데이터 조회**(competitor 뷰 로직 재사용 — 회사 조회·competitor_group·lgu_impact·기사 매칭·그룹핑, 42703 graceful). limit는 넉넉히(회사당 기사 상한만, 회사 수 cap 없음).
- `<CompetitorNewsGroups groups={...} />` **제한 없이**(capPerGroup 없음) 전 그룹·전 경쟁사·전 카드. 각 회사 카드 기사도 더 많이(예: 최대 8) 노출.
- 미들웨어 인증 게이트 안(로그인 필요) — 기존 dashboard 하위라 자동.

### 2-4. 데이터 조회 공유(선택)
- competitor 데이터 조립 로직(회사→그룹→기사→dist)을 `lib/entities/competitor-news.ts` 같은 서버 헬퍼로 추출해 요약·전체 페이지가 공유(중복·불일치 방지). 요약은 `capPerGroup` 적용만 다름.

## 3. 회귀 가드
- 위기/기회 칩·기간·날짜·그룹박스(242) 로직 **불변** — 배치만 그리드로.
- 42703 graceful(competitor_group·lgu_impact) 유지.
- 전체 페이지는 신규 라우트 — 기존 뷰 영향 없음.
- 요약 6-cap은 표시만 제한(데이터·정렬 동일). 회사<6이면 그대로.
- 관심기업/동향분석 탭 무영향.
- (225와 같은 `entities/page.tsx` 수정 — 225 커밋 후 진행 권장, 충돌 방지.)
