> 전제: **지시서 19 머지 후**(translate 레이어·`translation_usage` 존재). 방식(David 확정): **키는 env(수희)로만 관리, DB에 비밀 미저장.** 어드민은 상태·사용량·on/off만.
> ⚠️ 작업 전 `AGENTS.md` + `src/lib/translate/index.ts`·`providers/*`·`src/app/api/admin/upload/route.ts`(admin 인증 패턴)·`src/app/admin/page.tsx`(홈 카드) 를 읽을 것.

## 핵심 보안 규칙
- **API 키 값은 절대 client/DB로 보내지 않음.** 어드민에 노출하는 건 "키 있음/없음(boolean)"·사용량(숫자)·enabled(boolean)뿐. 키 자체는 env 에만.

## 1. enabled 플래그 스키마 (Codex 가 SQL → 수희 실행)
`supabase/2026-06-06-번역설정.sql`(멱등) — **비밀 아님**(on/off 플래그만):
```sql
create table if not exists public.translation_settings (
  provider text primary key,
  enabled boolean not null default true,
  updated_at timestamptz not null default now()
);
alter table public.translation_settings enable row level security;
revoke all on table public.translation_settings from anon, authenticated;
grant select, insert, update on table public.translation_settings to service_role;
insert into public.translation_settings(provider, enabled) values ('deepl',true),('papago',true),('google',true)
  on conflict (provider) do nothing;
```

## 2. 번역 레이어에 enabled 반영
- `translateToKorean` 프로바이더 루프에서 **enabled 체크 추가**: `translation_settings` 조회(usage 조회와 함께, admin) → `enabled=false` 인 프로바이더는 skip. 조건 = `isConfigured() && enabled && (used+len ≤ limit)`. 조회 실패 시 기본 enabled=true(번역 막지 않음).

## 3. 상태 API (server route, admin 인증)
`src/app/api/admin/translation-status/route.ts`:
- **GET**: admin 인증(upload 라우트 패턴). 응답 = 프로바이더 배열 `[{ name, configured, enabled, used, limit, remaining }]`.
  - `configured` = **서버에서 env 키 존재 여부만** 판정(`provider.isConfigured()`), 키 값 미포함.
  - `used` = 이번 달(KST) `translation_usage`, `limit` = `provider.monthlyCharLimit`, `enabled` = `translation_settings`.
- **POST**: admin 인증. body `{ provider, enabled }` → `translation_settings` upsert(admin). 키 입력 기능 없음.
- `runtime='nodejs'`, `dynamic='force-dynamic'`.

## 4. 어드민 페이지
- `/admin` 홈에 **"번역 상태"** 카드 추가.
- `/admin/translation`(또는 settings 하위): 프로바이더별 행 — 이름 · **연결 상태**(configured ●초록/○회색 + "키 미설정"이면 안내) · **이번 달 사용량 바**(used/limit, % + remaining) · **enabled 토글**(→ POST). 차분한 토큰(AGENTS §9), 한국어, 로딩·에러.
- (선택) "키는 Vercel 환경변수로 관리됩니다" 안내 문구 + 어떤 env 이름인지(`DEEPL_API_KEY` 등) 표기 — 값은 안 보임.
