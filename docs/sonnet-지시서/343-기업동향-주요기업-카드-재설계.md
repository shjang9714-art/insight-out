## 배경 (David)

`/dashboard/entities?view=watchlist` — 산업군 컨테이너 안에 기업 카드가 들어간 2중 박스 구조. 실사용에서 다음이 문제로 드러났다.

1. **위계 없음** — 산업군 박스와 기업 카드가 둘 다 흰 배경·회색 테두리·라운드. 어느 쪽이 상위인지 시각적으로 구분 불가. 화면에 선이 6겹(산업군 외곽선 / 헤더 하단선 / 카드 외곽선 / 카드 내부 점선 / 태그 배경 / 중요도 배경)으로 겹쳐 낡은 어드민 UI처럼 보임.
2. **시선이 머물 지점 없음** — 회사명 ≈ 중요도 ≈ 태그 ≈ 제목 ≈ 기사 목록이 전부 비슷한 크기·명도. 정작 "어떤 기업에 무슨 일이 났는가"보다 태그가 먼저 눈에 들어옴.
3. **핑크 남용** — 카드마다 핑크 태그 3~4개. 브랜드 컬러가 강조색이 아니라 기본색이 되어, 진짜 중요한 항목을 강조할 수단이 사라짐. `#해시태그` 표기도 전략 인텔리전스보다 SNS 큐레이션 인상.
4. **하단 기사 영역 저품질** — 점선 + 회색 이탤릭 인용구. 가독성 낮고, 기사 제목인지 인용문인지 불명확하며, 카드마다 길이가 달라 리듬이 깨짐.
5. **카드 수에 대응 못 함** — 3열 고정 그리드라 그룹에 카드가 1개면(예: 빅테크 그룹의 OpenAI) 우측 2칸이 통째로 빈 채 남음. 콘텐츠보다 컨테이너가 먼저 결정된 느낌.

## 설계 결정 (Opus)

1. **시각 표면을 3단계 → 1단계로.** `페이지 배경 → 산업군(섹션 제목) → 기업(카드)`. 산업군은 박스가 아니라 **제목 + 여백**으로만 구분한다. 카드가 화면에서 유일하게 떠 있는 표면이다.
2. **제목이 카드의 최강 시각 요소.** 회사명은 보조(회색 13px), 헤드라인이 17px/700. 태그는 제목 아래로 내린다.
3. **중요도는 예외만 강조.** `computeImportance`가 `high`일 때만 `● 중요`. mid/low는 **표시하지 않는다**(전 카드 "중요도 중간" 노출은 정보량 0).
4. **핑크 절제.** 태그는 최대 2개 + `+N`, 그중 **첫 번째만** 핑크. `#` 기호 제거.
5. **기사 인용구 제거 → `관련 기사 N건`으로 축약.** 기사 목록은 카드 클릭 후 상세(`/dashboard/insights/{id}`)에서 본다. (선택지 검토 결과 David 결정: 대표 기사 제목 노출 없이 건수만.)
6. **`implication`(LG U+ 시사점)을 요약문에서 분리해 전용 블록으로.** 이 화면의 정체성(경쟁사 동향이 아니라 *우리에게 무슨 의미인가*)이 카드에서 즉시 읽혀야 한다.
7. **그리드는 3열 고정.** ~~카드 수별 분기~~ → 카드 폭·높이는 그룹마다 동일해야 한다(스캔 리듬). 카드 1~2개인 그룹의 빈 칸은 허용. 자세한 근거는 작업 D 참고.
8. **데이터 계약은 그대로.** `MajorGroupBucket`·`MajorCompanyCard`에 필드를 추가하지 않는다. 섹션 서브텍스트는 대표 회사명으로 **런타임 조립**(별도 description 컬럼 만들지 말 것).

### B. 카드 — 세로형(`CompanyCard`)

정보 노출 순서: **① 기업 → ② 헤드라인 → ③ LG U+ 시사점 → ④ 태그 → ⑤ 기사 수·기간**

```tsx
<Link className="group flex flex-col gap-3 rounded-xl border bg-card p-5 transition-all
                 hover:border-brand-200 hover:shadow-[0_2px_12px_-4px_rgb(0_0_0/0.10)]">
```
- `isGold`(=importance high)면 기존 `io-gold-glow border-transparent` 유지, 아니면 `border-border`.
- `href`는 기존 그대로 `${getCardDetailHref(card)}?origin=entities&view=watchlist`.
- **`flex-1` 스페이서**를 시사점 블록과 태그 사이에 넣어, 카드 높이가 달라도 푸터가 바닥에 정렬되게 한다(리듬 유지).

| # | 요소 | 사양 |
|---|---|---|
| ① | 기업 심볼 | `size-7 rounded-lg bg-muted` + `text-[11px] font-bold text-muted-foreground`. **중립 회색 고정** — 브랜드 로고 색 사용 금지(화면 다시 복잡해짐) |
| ① | 이니셜 규칙 | 영문 시작 → 앞 알파벳 최대 2자 대문자(`KT`, `SK`, `LG`, `OP`). 한글 시작 → 첫 글자 1자(`삼`, `네`). `SK브로드밴드`/`SK텔레콤` 충돌은 허용(회사명이 바로 옆에 있음) |
| ① | 심볼 생략 | **이니셜 == 회사명 전체**(예: `KT`)면 `CompanySymbol`이 `null` 반환. 안 그러면 `KT KT`로 같은 글자가 두 번 나온다 |
| ① | 회사명 | `text-[13px] font-semibold text-muted-foreground truncate` — **보조 정보로 강등** |
| ① | 중요도 | `high`만: `● 중요` (`size-1.5 rounded-full bg-brand-600` + `text-[11px] font-semibold text-brand-600`). mid/low는 `null` |
| ② | 헤드라인 | `text-[17px] font-bold leading-[1.35] line-clamp-2`, `group-hover:text-brand-600`. 소스는 `card_headline ?? headline` |
| ③ | 시사점 | `rounded-lg bg-brand-50/60 px-3.5 py-3 dark:bg-brand-950/20` — **카드 안에 또 다른 테두리 금지**. 라벨 `LG U+ 시사점` `text-[11px] font-semibold text-brand-700`, 본문 `text-[13px] leading-relaxed text-foreground/75 line-clamp-3` |
| ④ | 태그 | `#` 제거. 최대 2개 + `+N`. 1번째 `bg-brand-50 text-brand-700`, 2번째 `bg-muted text-muted-foreground`, `+N`은 `text-muted-foreground/70`. `rounded-md`(pill 아님) |
| ⑤ | 푸터 | `text-[11px] text-muted-foreground/70` 한 줄. 좌 `관련 기사 {n}건`(n = `citations.length || source_content_ids.length`, 0이면 `관련 기사 준비 중`), 우 `6.29–7.5`(en dash, `tabular-nums`) |

**제거 대상:** 점선 구분선(`border-dashed`), 이탤릭 인용구 `<ul>`, `중요도 중간/낮음` 배지, `#` 해시 기호.

### C. 텍스트 정제 — `cleanNarrative`

`stripLlmArtifacts`에 더해 **`①②③…` 열거 기호 제거** + 연속 공백 축약. 헤드라인·시사점 렌더 직전에 통과시킨다. (번호는 보고서 본문엔 맞지만 카드 요약에서는 시선을 방해.) 저장 데이터는 건드리지 않는다 — 렌더 단계 정제만.

### D. 그리드 — 3열 고정

`grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3` — **카드 수와 무관하게 동일**.

> 초안(v1)에서는 카드 1개 → 가로형 피처드, 2개 → 절반 폭 2열로 분기했으나, 실렌더 확인 후 **되돌림**(David 결정 2026-07-14). 그룹마다 카드 폭·높이가 달라지면 페이지 전체의 스캔 리듬이 깨지고, 폭이 늘어난 예외 카드가 빈 칸보다 더 눈에 거슬린다. 카드가 1~2개인 그룹은 **우측 칸을 그대로 비워 둔다.**
> `FeaturedCompanyCard`·`count` 분기 코드는 존재하지 않아야 한다.
