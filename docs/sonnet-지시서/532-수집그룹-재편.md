## 작업

### 1) 콘텐츠 추가 → 콘텐츠 화면의 팝업

- `/admin/contents` 화면 헤더 우측에 "콘텐츠 추가" 버튼을 놓고, 누르면 다이얼로그에서
  기존 `ContentAddTabs` 를 그대로 띄운다.
- **패턴은 531 의 `AdminRequestsDialog` 를 그대로 따른다** — `'use client'`,
  `next/dynamic` 지연 로드, 열렸을 때만 본문 렌더.
- `src/app/admin/upload/page.tsx` 는 리다이렉트 스텁으로 바꾼다.
  전례: `src/app/admin/keyword-groups/page.tsx` (524).
  갈 곳이 쿼리가 아니라 팝업이므로 `/admin/contents` 로 보낸다.
- `nav.ts` 수집 그룹에서 `콘텐츠 추가` 항목 제거.

### 2) 수집 규칙 → 소스 관리 탭으로 흡수

소스 관리 최종 탭: **소스 목록 / 수집 설정 / 제외 규칙 / 데이터 보강 재처리 / AI 보강**
(뒤 네 개는 각각 현재 `CrawlRulesHub` 3탭 + 아래 4)에서 옮겨오는 AI 보강)

⚠️ **여기가 이번 지시서에서 유일하게 위험한 지점이다.**
`src/app/admin/sources/page.tsx` 는 **서버 컴포넌트**로 `job_runs`(`cron:crawl-seeds`)와
`search_seeds` 를 조회한다. 탭으로 합치면서 이 조회가 **다른 탭에서도 매번 도는 일이 없도록**
`KeywordsHub` 의 `taxonomyPanel` 슬롯 패턴을 그대로 쓴다 —
페이지에서 `searchParams.tab` 을 보고 활성 탭일 때만 서버 패널을 만들어 슬롯으로 넘긴다.

- `src/app/admin/crawl-settings/page.tsx` 는 리다이렉트 스텁으로
  (`/admin/sources?tab=crawl-settings`).
- 기존 스텁 `/admin/exclusion-rules` · `/admin/enrich` 의 목적지도 새 경로로 갱신한다.
  **이 둘을 빠뜨리면 딥링크가 사라진 화면으로 간다.**
- `AdminTabShell` 에 531 이 추가한 `resetParamKeys` 를 쓴다. 탭들이 쓰는 쿼리 키를
  실제로 확인해서 넣을 것(추측 금지).
- `nav.ts` 수집 그룹에서 `수집 규칙` 항목 제거, `소스 관리` description 갱신.

### 3) 사전·분류 → "키워드", 분류·카테고리 탭 제거

- `nav.ts`: 라벨 `사전·분류` → **`키워드`**. href(`/admin/keywords`)는 그대로.
- `KeywordsHub` 에서 `taxonomy` 탭 제거.
- `src/app/admin/keywords/page.tsx` 의 `TaxonomyPanel` 분기·슬롯 제거.
- `src/app/admin/taxonomy/page.tsx` 스텁은 `/admin/keywords` 로(탭 쿼리 없이).
- **죽은 코드 정리** — `TaxonomyPanel.tsx` 삭제. 그리고
  `src/components/dashboard/CategoryGrid.tsx` 는 **소비처가 0건**(실측: import 0,
  참조는 주석 2곳뿐)이므로 함께 삭제한다. Sonnet 보고에 매번 따라붙던
  `CategoryGrid.tsx:57` eslint 경고도 이것으로 사라진다.
  ⚠️ `src/lib/categories.ts` 의 `CATEGORY_DEFS` 는 **다른 곳에서 쓰이므로 남긴다.**
  삭제 전 `CategoryGrid` 와 `CATEGORY_DEFS` 각각의 참조를 다시 grep 해 확인할 것.

### 4) 엔티티 사전 → "관계지도 사전", 어드민 관계지도 → "관계 그래프"

- `KeywordsHub` 탭 라벨 `엔티티 사전` → **`관계지도 사전`**. 탭 value(`entities`)는 그대로.
- `nav.ts` 기업동향 그룹 `/admin/relations` 라벨 `관계지도` → **`관계 그래프`**,
  description 도 그에 맞게. 경로는 그대로.
- `src/app/admin/relations/page.tsx` 의 `metadata.title` 도 맞춘다.
- 서비스(사용자) 화면의 "관계지도" 명칭은 **건드리지 않는다.**

### 5) AI 보강을 AI 리포트에서 떼어낸다

`ReportsHub` 의 `ai-jobs` 탭(논조·위기기회·유튜브요약·요약백필·신호분류 실행 패널)은
리포트가 아니라 **콘텐츠 보강**이다. 2)에서 만든 소스 관리 허브의 마지막 탭으로 옮긴다.

- `ReportsHub` 탭 목록에서 `ai-jobs` 제거. 발행 콘텐츠 / 리포트 생성 / 프롬프트 3탭.
- `src/app/admin/ai-jobs/page.tsx` 스텁 목적지를 `/admin/sources?tab=ai-jobs` 로 갱신.
- 패널 컴포넌트 자체는 이동만 하고 **로직 수정 금지.**

- 프롬프트 DB 이관 — 533 의 선행 과제다
