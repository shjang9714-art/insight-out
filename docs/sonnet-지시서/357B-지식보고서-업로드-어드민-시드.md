# 지시서 357-B — 지식보고서(NotebookLM 산출물) 업로드 + 어드민 + 시드

> 대상: 구현 에이전트 · **신규 SQL 있음**(content_category '지식보고서' 추가) · 선행: 357-A(리포트 메뉴·지식보고서 탭 자리)
> ⚠️ 읽을 것: `src/components/admin/ReportUploadForm.tsx`(Storage 서명URL 업로드 패턴) · `src/components/contents/PdfViewer.tsx`·`src/lib/contents/pdf-cover.ts`(표지) · `src/lib/extract/pdf.ts`(본문) · `src/app/dashboard/reports/page.tsx`(리포트 목록·`?view=knowledge`) · `supabase/schema.sql`(contents·file_path) · `AGENTS.md`

## 설계 결정 (재사용 최대화)
- **지식보고서 = `contents(category='지식보고서')` + `file_path`(Supabase Storage)**. 업로드·PdfViewer·요약(summary_ko)·검색·북마크·키워드 인프라를 **그대로 재사용**(외부 리포트가 contents인 것과 일관). 신규 테이블 없음.
- 성격: 내부 보유 NotebookLM 산출물(PDF/PPTX). `is_official=false`·출처=내부. 사용자에겐 리포트 메뉴 `지식보고서` 탭에 노출.

## §0. 신규 SQL (수희 핸드오프)
`docs/sql-handoff/357B-knowledge-report-category.sql`:
- `alter type content_category add value if not exists '지식보고서';`
- 미적용(42P01/enum 없음) 시 업로드·목록 graceful 안내.

## 작업

### 1. 어드민 업로드 — `/admin/knowledge-reports`(신규) 또는 기존 업로드 화면 확장
- `ReportUploadForm` 패턴 재사용: 파일 선택 → 서명URL 발급 → `uploadToSignedUrl`(Storage) → `contents` insert(category='지식보고서', title, summary_ko, file_path, status).
- 입력: **제목·요약(선택)·키워드(선택)**. 파일: PDF·PPTX 허용.
- 업로드 후 **표지 자동 추출**(PDF는 `pdf-cover.ts`, PPTX는 후술) + 선택적 본문 추출(`extract/pdf.ts`)로 summary 보조.
- verifyAdmin. 목록에서 편집·삭제(soft).

### 2. 목록·상세 (리포트 메뉴)
- `/dashboard/reports?view=knowledge` = `contents(category='지식보고서')` 목록. 외부 리포트와 동일 카드/리스트 렌더 재사용, 라벨 "지식보고서".
- 상세: PDF는 `PdfViewer` 인라인 + 요약. **PPTX는 인라인 뷰어 불가 → 다운로드 링크 + (가능 시)첫 슬라이드 표지**. (pptx→pdf 변환은 후속, 이번엔 다운로드 폴백.)

### 3. 시드 — 첨부 6종(어드민 업로드로 투입)
빌드 후 **어드민 업로드 UI로 아래 6개를 등록**(파일은 David 보유·49MB급이라 git 커밋 금지, Storage 업로드). 권장 한글 제목:
| 파일 | 제목(권장) | 유형 |
|---|---|---|
| The_AI_Sovereignty_War.pptx | AI 주권 전쟁 | PPTX |
| The_Invisible_Fortress.pdf | 보이지 않는 요새 | PDF |
| Securing_the_Digital_Office.pdf | 디지털 오피스 보안 | PDF |

| Modern_Threat_Detection_Architecture.pdf | 현대적 위협 탐지 아키텍처 | PDF |
- 요약은 업로드 시 수기 입력 또는 본문 추출 보조. 키워드는 보안·AI·B2B 계열 태깅 권장.

## 회귀 / 주의
- **파일 바이너리 git 커밋 금지** — 전부 Supabase Storage.
- Storage 버킷·용량·MIME(PDF·PPTX) 허용 확인. 대용량(≈18MB) 업로드 타임아웃 여유.
- 42P01/enum 미적용·키 없음 graceful. `content_category` 렌더 라벨(CONTENT_CATEGORY_LABEL)에 '지식보고서' 추가.
- PPTX 인라인 뷰어 없음 → 다운로드 폴백 명확히.
- 검증: `tsc`·ESLint·`check-prefetch`·`build` + (SQL 적용 후) 어드민에서 PDF 1개 업로드→리포트 지식보고서 탭 노출·PdfViewer·PPTX 다운로드 폴백. 완료보고 커밋 해시.
