> 범위: **플레이어 UI 재설계(아이팟 나노) + briefings 최신 공개분 연동 + 오디오 유무 상태 처리.** TTS·Storage 적재는 #50·#52(별도), 여기선 **읽어서 재생만**.

## 배경
- 기존 `MorningBriefingPlayer` 는 플로팅 다크 미니플레이어 + **색 하드코딩(`#E6007E`·`#1A1A4E` 등)** + `audioUrl` prop 만 받음(DB 미연동).
- 목표: **아이팟 나노 감성**(실버 바디 + 클릭휠 원형 컨트롤, 모바일 우선)으로 재설계하고 `briefings` 최신 공개분을 직접 읽어 재생.

## 파트 A — 데이터 연동
- `'use client'` 컴포넌트에서 Supabase 로 **최신 공개 브리핑** 조회:
  ```ts
  supabase.from('briefings')
    .select('id, briefing_date, title, script, audio_url, audio_duration_seconds')
    .in('status', ['published','archived'])
    .order('briefing_date', { ascending: false })
    .limit(1).maybeSingle()
  ```
- 상태: `briefing | null`, 로딩. 없으면 "오늘 브리핑이 아직 없습니다" 빈 상태.
- 시드 row(audio_url = null) 로 **오디오 없는 상태**가 우선 보이는 게 정상.

## 파트 B — 아이팟 나노 UI (실버 바디 + 클릭휠)
- **실버 바디**: 금속 느낌 카드(둥근 모서리, 미세 그라데이션/보더). 실버는 브랜드색이 아니므로 중립 회색 톤은 커스텀 가능하나, **강조(재생 버튼·진행)는 `--color-brand-*` 변수**로. `#E6007E` 등 하드코딩 금지.
- **상단 디스플레이 영역**: 날짜(`briefing_date`, ko-KR) + 제목(`title`) + 스크립트 미리보기(접힘/펼침, 스크롤). 재생 중 진행 시간/총 길이 표시.
- **클릭휠(원형 컨트롤)**:
  - 중앙 버튼 = **재생/일시정지**.
  - 휠 링 = **원형 진행 표시**(현재 위치 progress). 가능하면 링 좌/우 탭으로 ±10초 seek(과하면 생략).
  - 모바일 우선: 손가락 타깃 충분히 크게(최소 44px), 데스크톱에서도 동일 비율.
- 다크모드: 주변 카드·텍스트는 시맨틱 토큰. 실버 바디는 양 모드에서 대비 확보(완전 흰/검 배경에서도 읽히게).

## 파트 C — 재생 동작
- `audio_url` 있으면: `new Audio(audio_url)`(기존 패턴), `timeupdate` 로 progress·현재시간, `loadedmetadata`/`audio_duration_seconds` 로 총 길이, `ended` 로 정지. 재생/일시정지 토글.
- `audio_url` 없으면: 클릭휠 중앙 비활성 + "오디오 생성 전 · 스크립트만 제공" 안내. **스크립트 텍스트는 그대로 노출**(읽을 수 있게).
- 정리: 언마운트 시 `pause()`·해제.

## 파트 D — 배치
- `RightRail.tsx` 의 `BriefingPlaceholder` 를 **이 플레이어로 교체**(홈 우측 레일 "오늘의 브리핑" 자리). 컴포넌트는 ~280px 폭에 맞게.
- 같은 컴포넌트를 #53 아카이브 페이지에서 재사용할 수 있도록 **props 로 briefing 주입도 가능**하게 설계(기본은 자체 최신 조회, `briefing` prop 주면 그걸 사용). 재사용성 확보.
- 기존 플로팅 트리거 방식은 폐기(레이아웃에서 이미 제거됨). 파일은 재설계로 대체.
