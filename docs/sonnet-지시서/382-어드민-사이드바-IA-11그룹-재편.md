## 1. 현행 진단 (확인된 코드 사실)

- 사이드바 데이터는 `src/lib/admin/nav.ts`의 `export const ADMIN_NAV_GROUPS: AdminNavGroup[]` 단일 진실. 현재 **8그룹**(운영센터·수집·크롤링·콘텐츠 관리·AI 운영·인사이트·리서치·발행·구독·사용자·분석·시스템 설정).
- 타입(같은 파일): `AdminNavItem { href, label, description, icon: LucideIcon, disabled?, badge? }`, `AdminNavGroup { group, items }`.
- 렌더러 `src/components/admin/AdminSidebar.tsx`:
  - `disabled: true` 항목은 클릭 불가 `<span>`으로 렌더되며 `item.badge`를 표시한다(151–165행). **이미 지원 — 수정 불필요.**
  - `/admin/requests` 배지(openRequestCount, 181–185행), `/admin/daily-insights` 배지(dailyInsightReviewCount, 186–190행)는 각 href 문자열에 하드코딩. **두 href를 S1에서 유지하므로 배지 로직 무수정.**
  - 활성표시 `isActive`는 정확일치 또는 `startsWith(href + '/')`. disabled 항목은 이 분기를 타지 않음.
- `findAdminNavItem(pathname)`(nav.ts 하단)은 `AdminPageHeader.tsx`에서 페이지 제목·아이콘 조회에 사용. **null 안전**(`item?.label ?? '어드민'`, 19행) — nav에서 빠진 라우트는 제네릭 '어드민' 제목으로 폴백(하드 실패 아님).
- 아이콘: `lucide-react@1.16.0`. 신규 사용 아이콘 `AlertTriangle·BarChart3·Building2·Landmark·Globe·Video·FolderTree·UserCheck`는 **존재 확인됨**. `Youtube`는 이 버전에 **없음** → 유튜브는 `Video` 사용.
- 디스크에 있으나 nav에 없는 고아 라우트: `/admin/content-data`, `/admin/raw`(이번 슬라이스 범위 아님, 그대로 둠).

### 1.1 S1 설계 원칙 (홀 없는 전환)
최종안은 여러 현행 화면을 **통합/분화**하지만, 그 통합·분화 화면은 아직 없다. S1은 **골격만** 세우므로:
- **현행 화면이 있는 항목** → 그 라우트로 연결(최종 라벨 또는 현행 라벨).
- **아직 없는 신규 화면** → `disabled: true` + `badge: '준비중'`(기업공시는 `'도입 예정'`).
- **나중 슬라이스에서 흡수/이동될 현행 화면**(이슈 관리·일일 핵심 Insight·소스 관리·프롬프트 콘솔 등) → **사이드바에서 제거하지 않고** 해당 그룹에 유지하고 `description`에 흡수 예정 슬라이스를 명시. → **운영 접근 상실(사일런트 홀) 방지.**

```ts
export function findAdminNavItem(pathname: string): AdminNavItem | null {
  const all = ADMIN_NAV_GROUPS.flatMap(g => g.items)
  const exact = all.find(i => i.href === pathname)
  if (exact) return exact
  return all
    .filter(i => i.href !== '/admin' && pathname.startsWith(i.href))
    .sort((a, b) => b.href.length - a.href.length)[0] ?? null
}
```

> `AdminSidebar.tsx` 143행 주석 `8그룹 평탄화(지시서 278)`은 선택적으로 `11그룹(지시서 382)`으로 갱신해도 되고, 안 해도 기능 무관.

## 4. 회귀 가드 (건드리면 안 되는 것 / 경계)

1. **`AdminSidebar.tsx`는 수정하지 않는다.** disabled 렌더(151–165)와 두 배지 로직(181–190)이 이미 현재 href를 참조하므로 그대로 동작한다. 특히 `/admin/requests`(운영 게시판)와 `/admin/daily-insights`(일일 핵심 Insight) href를 **바꾸지 말 것** — 배지가 사라진다.
2. **`findAdminNavItem` 로직·시그니처 유지.** `AdminPageHeader`가 null 폴백을 하므로 nav에 없는 라우트도 하드 실패하지 않는다. 단, 이번 nav에는 현행 라우트를 모두 남겨두었으므로 제목 유실은 없다.
3. **disabled 항목 href는 실제 이동하지 않는다**(span 렌더). `/admin/content?type=...` 등 쿼리스트링·미존재 라우트를 넣어도 안전. 단 **React key 유일성**을 위해 href는 서로 겹치지 않게(위 안은 모두 유일).
4. **아이콘 import는 위 목록과 정확히 일치**시킨다. 기존 29개는 전부 계속 사용되고, 신규 8개(AlertTriangle·BarChart3·Building2·Landmark·Globe·Video·FolderTree·UserCheck)만 추가. **사용하지 않는 import를 남기지 말 것**(lint `no-unused-vars` 빌드 실패). `Youtube`는 이 버전에 없으니 쓰지 말 것.
5. **SQL·API·다른 컴포넌트 변경 금지.** 이 슬라이스는 nav.ts 한 파일이다.
6. 빈/경계: 그룹 순서는 위 배열 순서대로 렌더된다(최종안 트리 순서와 일치). 바꾸지 말 것.
