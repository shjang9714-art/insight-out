쿠키 세션이 아니라 서버-대-서버 토큰이므로 `publicPaths` 에 있는 것이 **맞다.**

⇒ **`/api/council/route.ts` 와 `publicPaths` 의 `/api/council` 항목은 그대로 둔다.**

### 1-5. 🟡 `VALID_VIEWS` 에 실험실 뷰 3개가 남아 있다

`src/app/dashboard/issues/page.tsx:15`


`headline`·`trending`·`issues` 는 실험실 전용인데 **URL 직접 입력이 통과**한다.

⚠️ **단순 제거하면 관리자 화면이 깨진다.** `isAdmin` 이면 실험실 탭줄이 노출되고
그 세 뷰를 실제로 쓴다. **비관리자에게만 차단**해야 한다.

## 2. 작업

### 2-1. COUNCIL 관리자 전용 복귀 (B-1 · E-B)

**네 지점을 모두 막는다. 하나라도 빠지면 우회가 남는다.**

1. **`middleware.ts`** — `/dashboard/lab` 분기 **바로 아래**에 같은 형태로 추가.
   ```ts
   if (pathname.startsWith('/dashboard/council') && gate.role !== 'admin') {
     return NextResponse.redirect(new URL('/dashboard', request.url))
   }
   ```
2. **`dashboard/council/page.tsx`** — 서버에서 role 을 **재검사**한다.
   middleware 를 신뢰하지 않는다(이 저장소에 middleware 가 죽은 코드로 방치된 사고
   전례가 파일 하단 주석에 남아 있다). 비관리자면 `notFound()` 또는 `/dashboard` 리다이렉트.
   **`/dashboard/lab` 페이지의 재검사 패턴을 그대로 따를 것.**
3. **`api/council/ticket/route.ts`** — `getUser()` 뒤에 **role 검사**를 추가한다.
   관리자가 아니면 `403`. 티켓을 발급하지 않는다.
4. **버튼 2곳** — `isAdmin` 일 때만 렌더한다.
   - `entities/[id]/page.tsx:462`
   - `contents/[id]/page.tsx:525` (지금의 `isLoggedIn` 조건을 **대체**)
   두 페이지에 `isAdmin` 판정이 없으면 서버에서 조회해 넘긴다.
   **판정 기준은 `users.role === 'admin'`** — `AiInsightsView.tsx:188` 과 같다.

### 2-2. 실험실 데이터 전송 차단 (B-2)

`AiInsightsView.tsx` 에서 **`isAdmin` 이 아니면 세 props 를 빈 배열로 넘긴다.**

⚠️ **먼저 확인할 것**: `insightGroups`·`trendingTopics`·`issueCards` 를
**실험실 뷰(`headline`·`trending`·`issues`) 밖에서도 쓰는 곳이 있는지** `AiInsightBoard.tsx`
에서 확인한다. **쓰는 곳이 있으면 그 값은 비우지 말고 그대로 두고, 무엇을 왜 남겼는지
보고할 것.** 서비스 화면을 깨뜨리는 것이 목적이 아니다.

⚠️ **쿼리 자체를 지우지 말 것.** 관리자에게는 그대로 필요하다.

### 2-3. `insights/[id]` scope 게이트 (B-3)

`scope='industry'` 카드는 **비관리자에게 `notFound()`**.
`scope='company'` 는 **지금처럼 통과**시킨다.

관리자 판정이 없으면 서버에서 조회한다. `:144`·`:212` 의 `scope === 'company'` 분기와
`backHref` 가 어긋나지 않는지 함께 확인한다.

### 2-4. 실험실 뷰 차단 (B-4)

비관리자가 `?view=headline|trending|issues` 로 들어오면 **`brief` 로 강등**한다.
관리자는 그대로 통과.

- `VALID_VIEWS` 를 **공개 3종(`brief`·`graph`·`keyword`)** 과
  **관리자 전용 3종(`headline`·`trending`·`issues`)** 으로 나눈다.
- 강등 판정은 **`isAdmin` 을 아는 곳**에서 한다(`AiInsightsView` 안이 자연스럽다).
  `issues/page.tsx` 에서 role 을 새로 조회해 왕복을 늘리지 말 것.
- URL 자체를 고쳐 쓰는 리다이렉트는 **하지 않는다**(범위 밖).
