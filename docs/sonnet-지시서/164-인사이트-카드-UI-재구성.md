## 3. 구현

### 3-1. `src/lib/insight/card-meta.ts` (신규, 순수 함수)
카드 메타 규칙 산출. 클라이언트/서버 공용 순수 함수.

```ts
export type Importance = 'high' | 'mid' | 'low'
export type Relevance  = 'high' | 'mid' | 'low' | null

// 중요도: 근거 수 기반(+선택적 최신성). citations 우선, 없으면 source_content_ids.
export function computeImportance(card: { citations: unknown[]; source_content_ids: string[] }): Importance {
  const n = (card.citations?.length || card.source_content_ids?.length) ?? 0
  if (n >= 5) return 'high'
  if (n >= 2) return 'mid'
  return 'low'
}

// 내 관련도: 렌즈/개인화(watchlist+serviceIds) 매칭 강도. activeLens 무관하게 항상 계산.
//  - 완전 매칭(watchlist/담당 키워드가 topic·headline에 포함) → high
//  - 부분(score>0) → mid / 없음 → low (미설정 사용자면 null = 미표시)
export function computeRelevance(score: number, matched: boolean, hasPersonalization: boolean): Relevance {
  if (!hasPersonalization) return null
  if (matched) return 'high'
  if (score > 0) return 'mid'
  return 'low'
}

// 선정 이유: 규칙 조합 문구(근거 N건 · 관심 키워드 일치 · 최근 생성)
export function buildSelectionReason(input: {
  evidenceCount: number; matched: boolean; generatedAt: string | null
}): string { /* 예: "근거 4건 · 관심 키워드 일치 · 최근 생성" */ }
```
- 임계값(5/2)은 가이드 — 라이브 분포 보고 미세조정 허용.
- 라벨: high=높음, mid=중간, low=낮음.

### 3-2. 그리드 카드 재구성 (`InsightCardsSectionClient.tsx` 228-322)
새 레이아웃(위→아래):

1. **상단 배지 행**: `[카테고리=topic]` `[중요도]` `[내 관련도]`
   - 카테고리: 중립 칩(`bg-muted text-muted-foreground` — 159/163 방향, 핑크 고정 해제).
   - 중요도: 위계만(높음=진한 foreground 배지, 중간=muted, 낮음=text-disabled). 상태색 아님(긍/부정과 혼동 금지).
   - 내 관련도: 개인화 강조라 **brand 허용**(높음=`bg-brand-600/10 text-brand-600`, 중간=옅게, 낮음/null=미표시). 기존 "관심 표시"를 이 배지로 대체.
2. **제목**: `card.card_headline ?? card.headline` (에디토리얼 우선).
3. **AI 요약(한 줄)**: `card_headline` 이 있어 제목과 다르면 `card.headline` 을 한 줄 요약으로 표기(라벨 "AI 요약"). 같으면 생략(중복 방지).
4. **시사점**: `card.implication` (기존 유지, 라벨 "시사점").
5. **선정 이유**: `buildSelectionReason(...)` 결과를 옅은 한 줄(라벨 "선정 이유", text-disabled/muted 톤).
6. **관련 키워드**: 우선 `topic` 칩. (※ 추가 키워드 칩은 contentMap 확장 필요 → 후속. 160/161 데이터 변경 없이 topic만.)
7. **액션 행**: `[자세히 보기]` → `/dashboard/topics/{encodeURIComponent(topic)}`(토픽 페이지 존재). **저장 아이콘은 후속**(저장 백엔드 없음 — 본 지시서 미구현, 빈 자리도 두지 않음).
   - 근거(citations) 블록은 "자세히 보기" 안으로 접거나 유지 — 본 지시서는 **유지**(기존 근거 리스트 그대로 카드 하단). 단 보고서 버튼 잔재 없음(159).

`matched` 테두리 강조(`border-brand-600/20`)는 내 관련도 high 와 일관되게 유지.

### 3-3. 에디토리얼 카드(`InsightCardNewsList.tsx`) 정합(경량)
큰 에디토리얼 카드의 형식은 유지하되, **카테고리/중요도/관련도 배지 톤을 그리드와 동일 규칙으로 정합**(핑크 고정 칩 → 중립, 관련도만 brand). 선정 이유는 공간상 선택(생략 가능). 과개편 금지.
