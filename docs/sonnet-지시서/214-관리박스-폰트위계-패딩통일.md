# 지시서 214 — 관리 박스 폰트 축소·정보 위계·패딩 통일

목표: 어드민 관리 카드/박스가 "홍보 페이지"가 아니라 "관리 콘솔"로 보이도록 정보 밀도를 높인다. 주요 수치를 한 단계 줄이고, 박스 패딩을 통일하고, 캡션 클래스 혼용을 정돈한다.

범위 결정(David): **수치 축소 + 패딩 통일**(전반 축소 아님). 캡션 11/12px 정리 포함.

## 2. 구현

### 2-1. globals.css — 대시보드 수치 축소 + 카드 제목 소폭 상향(위계)
`.admin-metric-dashboard`(215)·유닛(216)·미디어쿼리(230,237) 수정:
```css
/* 214 — 대시보드 KPI 수치 한 단계 축소(콘솔 밀도) */
.admin-scope .admin-metric-dashboard      { font-size: calc(24px * var(--admin-font-scale,1)); line-height: calc(32px * var(--admin-font-scale,1)); font-weight:700; }
.admin-scope .admin-metric-unit-dashboard { font-size: calc(14px * var(--admin-font-scale,1)); line-height: calc(22px * var(--admin-font-scale,1)); font-weight:600; }
/* @media ≤1439 */  .admin-scope .admin-metric-dashboard { font-size: calc(22px * ...); line-height: calc(30px * ...); }
/* @media ≤1023 */  .admin-scope .admin-metric-dashboard { font-size: calc(20px * ...); line-height: calc(28px * ...); }
```
정보 위계: 제목을 목표(15–16)로 살짝 올려 수치와의 대비를 만든다:
```css
.admin-scope .admin-card-title { font-size: calc(15px * var(--admin-font-scale,1)); line-height: calc(21px * var(--admin-font-scale,1)); font-weight:600; }
```
> `.admin-metric`(212, 38px)와 `.admin-metric-unit`(213)은 **다른 화면용이므로 변경 금지**.

### 2-2. 박스 패딩 p-5 통일
관리 박스(요약·상태·수치 카드) 패딩을 `p-5`로 통일:
- `src/app/admin/page.tsx` 28 `KPI_CARD`: `p-6` → `p-5`.
- `src/components/admin/AdminTodoBlock.tsx` 82: `p-4` → `p-5`.
- `src/components/admin/AdminOpsSignals.tsx` 86·124: `p-4` → `p-5`.
- 이미 p-5인 ContentHealth/Processing/DataReset: 변경 없음.
> 리스트형(`HomeSectionsSettings`의 `px-4 py-3` 항목)은 박스가 아니므로 제외.

### 2-3. 캡션 클래스 정돈
카드/박스 내부 설명·부가 텍스트를 `admin-caption`으로 통일:
- `AdminOpsSignals.tsx`: 박스 제목 `text-xs font-semibold ... uppercase` 유지(라벨 성격)하되, 설명/보조 텍스트 `text-xs text-muted-foreground` → `admin-caption text-muted-foreground`.
- `AdminContentHealth.tsx`: note `text-[11px] text-muted-foreground`(69) → `admin-caption text-muted-foreground`. 링크 버튼 `text-[11px]`(HealthRow)는 컨트롤이라 유지 가능(과밀 시 그대로 둠).

### 2-4. 같은 유형 박스 높이 균일
KPI 카드 그리드에 높이 정렬 부여:
- `src/app/admin/page.tsx` KPI 카드 컨테이너(grid)에서 카드가 `h-full`이 되도록 `KPI_CARD`에 `h-full` 추가(그리드 셀은 기본 stretch). 오늘 할 일 타일도 동일하게 `h-full` 확인.

## 3. 회귀 가드
- `--admin-font-scale` 조정이 여전히 모든 값에 반영(전부 `calc(px*var)` 유지).
- 반응형 3구간(≥1440 / 1024–1439 / ≤1023)에서 수치가 각각 24/22/20px로 단계 축소되는지.
- KPI/할 일/신호등 박스가 동일 패딩(p-5)·동일 높이로 정렬되는지.
- 다크/라이트 대비 유지(색 토큰 불변).
- `.admin-metric`(38px) 쓰는 다른 화면이 영향받지 않는지(grep로 사용처 확인).
- 캡션 클래스 교체 후 줄바꿈/색이 어색하지 않은지.
