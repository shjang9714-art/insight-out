# 지시서 243 — 경쟁사 동향분석 그룹박스 양식 통일

목표: **경쟁사 동향분석**(구 경쟁사(동향), trend 뷰)의 competitor_group 섹션을 **경쟁사 최근 뉴스(242)와 동일한 그룹 박스 양식**으로 꾸민다. 시각 일관성 — 통신/클라우드·플랫폼/빅테크가 각각 테두리 박스 + 헤더(그룹명·건수)로 감싸지고, 그 안에 헤드라인 insight_cards가 들어간다.

David 요청: "이런 양식(그룹박스)으로 경쟁사 동향도 레이아웃을 꾸미자."

범위: `InsightCardsSectionClient.tsx`에 **`boxed` 옵트인 프롭** 추가(+`InsightCardNewsList.tsx`) + `entities/page.tsx` trend 뷰에서 `boxed` 전달. **기존 다른 사용처(관심기업·AI인사이트 헤드라인) 무영향**(boxed 기본 false).

전제: 224(trend 뷰·label 그룹) 이미 배포. 이 지시서는 스타일 확장.

---

## 1. 현행 진단 (검증된 코드 사실)
- trend 뷰: `<InsightCardsSectionClient groups={trendGroups} .../>` — 각 그룹 `label=competitor_group`. 224에서 label 헤더(그룹명 · N건) 지원 추가됨.
- `InsightCardsSectionClient`는 view 토글(cardnews/analysis) → cardnews는 `InsightCardNewsList`, analysis는 자체 그리드. **둘 다 그룹 헤더를 평면(밑줄 없이 텍스트)으로** 렌더. 박스 컨테이너 아님.
- 242에서 경쟁사 최근 뉴스는 `rounded-2xl/18px border bg-card` 그룹 박스 + 헤더바(그룹명·N개사·N건) 양식 도입.

## 2. 구현

### 2-1. `InsightCardsSectionClient.tsx` — `boxed` 프롭
- `Props`에 `boxed?: boolean` 추가(기본 false). `InsightCardNewsList`에 그대로 전달.
- **analysis 뷰**: `boxed` 이면 각 그룹 `<div>`를 **박스로**: `rounded-2xl border border-border bg-card overflow-hidden` + 헤더 행을 박스 헤더 스타일(`px-5 py-3 border-b bg-gradient-to-b from-card to-muted/20`, 그룹명 `text-[15px] font-bold` + `N건` muted) + 카드 그리드는 박스 안쪽 `p-4/5`. `boxed` 아니면 기존 그대로.
- label 그룹일 때만 boxed가 의미 있음(기간 그룹엔 미적용 권장이나, 프롭으로만 제어 — trend만 전달).

### 2-2. `InsightCardNewsList.tsx` — `boxed` 반영(기본 뷰)
- Props에 `boxed?: boolean`. 각 `visibleGroups.map` 그룹을 `boxed`면 **박스 컨테이너**로 감싸고 헤더를 242 그룹박스 헤더 양식으로. 카드 목록은 박스 안쪽.
- `boxed` 아니면 기존(평면 헤더) 그대로 — 관심기업·AI인사이트 헤드라인 무영향.

### 2-3. `entities/page.tsx` trend 뷰
- `<InsightCardsSectionClient groups={trendGroups} contentMap={trendContentMap} bucketByTopic={trendBucketByTopic} boxed />` — `boxed` 추가만.

## 3. 회귀 가드
- **`boxed` 기본 false** → 관심기업(watchlist)·AI인사이트 헤드라인/키워드 등 **기존 사용처 렌더 완전 불변**.
- trend 뷰만 박스 양식. label 그룹(그룹명 헤더)은 224에서 이미 동작 → 박스 컨테이너만 덧입힘.
- 뷰 토글(cardnews/analysis) 양쪽에서 boxed 일관 적용.
- 다크모드 박스 대비·그라디언트 확인.

## 4. 검증 (Sonnet)
- `npx tsc --noEmit` 0, `npx eslint` 0, `npm run build`.
- 육안: 경쟁사 동향분석이 통신/클라우드·플랫폼/빅테크 **박스**로 감싸지고 헤더(그룹명·건수) + 안에 헤드라인 카드. 최근 뉴스(242)와 시각 일관.
- 관심기업·AI인사이트 헤드라인은 기존 그대로(회귀 없음).
