## 0. 한 줄
AI 리포트 생성 폼의 `주제(필수)` 를 **이슈를 고르면 그 제목으로 자동 채운다.** 비어 있을 때만. LLM 0.

---

## 1. 착수 전 확인 (직접 코드 확인 2026-07-22)

`ReportCreateForm.tsx`(142줄):
- `topic`(필수)·`title`(선택)·`selectedIssueIds: Set<string>` 상태 보유.
- 이슈 선택은 자식 `ReportSourcePicker` 가 담당 — **이슈 목록을 자체 조회**한다:
  ```ts
  // ReportSourcePicker.tsx
  const [issues, setIssues] = useState<IssueRow[]>([])   // {id, title, summary}
  .from('issues').select('id, title, summary')
  ```
- **문제**: 자식은 `onChangeIssueIds(ids)` 로 **id 만** 올린다. 부모는 title 을 모른다 → 주제를 채울 수 없다.

→ **자식이 "방금 고른 이슈의 title" 을 부모에 알려주면 된다.** 콜백 하나 추가.

---

## 2. 구현

### 2.1 `ReportSourcePicker.tsx` — 선택된 이슈 title 콜백 추가
- 새 optional prop: `onIssuePicked?: (issue: { id: string; title: string }) => void`
- 이슈 체크(선택 추가) 시점에 그 이슈의 `{id, title}` 로 `onIssuePicked` 를 호출한다. **선택 해제·콘텐츠 선택에는 호출하지 않는다.**
- ⚠️ 기존 `onChangeIssueIds` 동작은 **그대로.** 이 콜백은 부가 신호일 뿐, 선택 상태의 소스는 여전히 `selectedIssueIds`.

### 2.2 `ReportCreateForm.tsx` — 주제 자동 채움
```tsx
<ReportSourcePicker
  …
  onIssuePicked={(issue) => {
    if (!topic.trim()) setTopic(issue.title)   // ← 비어 있을 때만
  }}
/>
```
- **`topic` 이 비어 있을 때만 채운다.** 이미 입력했으면 덮어쓰지 않는다(디렉터 §4).
- 여러 이슈를 골라도 **처음 채운 값 유지**(두 번째부터는 `topic` 이 차 있어 안 덮음). "첫 번째 + 운영자 수정" 원칙과 합치.
- 채운 뒤 **수정 가능**(그냥 `setTopic` 이라 입력 자유).

### 2.3 하지 말 것
- `title`(제목 선택 필드)은 **건드리지 않는다.** `title` 은 비우면 서버가 topic 을 제목으로 쓴다(기존). 여기 자동값 넣지 말 것.
- 이슈 목록 조회를 부모로 옮기지 않는다(중복 조회 금지). 자식이 콜백만 올린다.
- 생성 API·프롬프트·검증 무수정.
- `ReportRow.tsx`(편집행)도 `ReportSourcePicker` 를 쓰지만(345행) **이번엔 건드리지 않는다.** 편집은 이미 주제가 있는 상태라 자동 채움이 무의미하다.

---

## 3. 회귀 가드
1. 이슈를 처음 고르면 **주제 칸이 그 이슈 제목으로 채워진다**(주제가 비었을 때).
2. 이미 주제를 입력한 뒤 이슈를 골라도 **주제가 바뀌지 않는다.**
3. 자동 채운 주제를 **손으로 고칠 수 있다.**
4. 이슈 **선택 해제**·콘텐츠 선택은 주제에 영향 없다.
5. `selectedIssueIds`·`selectedContentIds` 선택 상태·생성 요청이 기존과 동일하게 동작한다.
6. `ReportRow` 편집 폼은 변화 없다.
