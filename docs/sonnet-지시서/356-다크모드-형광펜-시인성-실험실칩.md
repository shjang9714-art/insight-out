## 1. 다크모드 형광펜 시인성 개선 (밑줄 형태 유지)

### 원인
`.dark`에서 `--brand-100`(#ffd6ef)·`--brand-200`(#ffaad9)이 **재정의 안 됨** → 라이트 연분홍 밴드가 다크에도 그대로. 밝은 본문글자(#F5F6F8) 아랫부분이 불투명 연분홍에 겹쳐 대비 저하(스샷). brand-600/700은 다크용으로 이미 더 밝게 재정의됨(형광펜만 누락).

### 조치 (라이트 무변경, 다크만)
- **밑줄(형광펜) 개념 유지** — 불투명 연분홍 밴드를 **반투명 brand 밴드**로 교체해 밝은 글자가 위에서 읽히게.
- 전역 brand-100/200을 바꾸면 다른 사용처에 파급되므로 **전용 하이라이트 변수** 도입(surgical):
  - `:root`: `--report-hl: var(--color-brand-100); --report-hl-strong: var(--color-brand-200);`(현행 동일)
  - `.dark`: `--report-hl: color-mix(in srgb, var(--color-brand-600) 34%, transparent); --report-hl-strong: color-mix(in srgb, var(--color-brand-600) 50%, transparent);`(밝은 핑크 반투명 → 다크 배경 대비 + 글자 가독)
  - `.io-report-body mark` 배경을 `linear-gradient(transparent 55%, var(--report-hl) 55%)`, h1~h4 mark는 `--report-hl-strong` 사용하도록 변수화. (밴드 시작을 58%→55%로 살짝 올려 밑줄 두께 확보.)
- 소제목(굵은 글자) 뒤 형광펜과 긴 본문 형광펜 **둘 다** 다크에서 읽히는지 확인. 값(34/50%)은 대비 보며 미세조정 가능.

## 2. 실험실 칩 — 아이콘 + 형상 도드라지게

현재 `DashboardHeader` L224: dashed 테두리 pill·10px·아이콘 없음 → 눈에 안 띔(David).
- **아이콘 추가**: lucide `FlaskConical`(실험실 플라스크) 를 라벨 앞에 (`h-3.5 w-3.5`). "실험실" 텍스트 유지.
- **형상 변경**(pill 탈피): dashed 테두리 대신 **은은한 brand 틴트 칩**으로 도드라지게 — 예: `rounded-md border border-brand-600/30 bg-brand-600/10 text-brand-700`(비활성)·활성(`pathname.startsWith('/dashboard/lab')`)은 `bg-brand-600/20 border-brand-600/50 text-brand-700`. 크기 살짝 키움(`text-[11px] px-2 py-1 gap-1`).
- 관리자 전용·`ml-auto` 우측 배치 유지. 하드룰 9(토큰만) 준수 — 위 brand 유틸리티는 토큰 기반이라 OK.
- 대안(문서에 남길 것): 완전 사각 배지/아웃라인 플라스크만 등도 가능하나, 상단 바 톤과 어울리는 **brand 틴트 + 플라스크 아이콘**을 기본으로 채택. 육안 확인 후 조정.
