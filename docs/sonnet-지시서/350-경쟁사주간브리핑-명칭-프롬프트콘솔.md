## 배경 (David)

1. "주간 리포트"라는 이름이 전략보고서와 헷갈린다 → **경쟁사 주간 브리핑**으로 통일. 상세 제호는 **경쟁사 동향 브리핑**.
2. 프롬프트를 쓰는 모든 AI를 **어드민 한 곳에서 편집·저장**하고, 저장 즉시(초안) 반영해 생성 결과로 검수할 수 있어야 한다.

## 설계 결정 (Opus)

1. **명칭은 UI 라벨만 바꾼다.** 테이블명(`competitor_weekly_reports`)·라우트(`/dashboard/entities?view=trend`)·컴포넌트명은 그대로 — 데이터·URL 호환. "리포트"라는 코드 식별자도 유지.
2. **프롬프트 = `llm_prompts` 단일 소스.** 이미 생성기들이 `loadPrompt(key)` → 코드 상수 폴백 패턴을 쓴다. 콘솔은 이 테이블의 CRUD일 뿐, 새 저장소를 만들지 않는다.
3. **카탈로그로 "편집 가능한 key"를 코드가 선언.** `PROMPT_CATALOG`가 key·label·group·설명·**폴백 상수**를 갖는다. 콘솔은 카탈로그 ∪ DB를 병합해 보여준다 → DB에 없으면 "코드 기본값"으로 표시.
4. **프레임 스펙을 DB로 승격.** 348에서 코드 상수(`FRAME_SPEC`/`LGU_CONTEXT`)로만 있던 패스② 프레임을 `competitor_weekly_frame`/`competitor_weekly_lgu_context` key로 콘솔에서 편집 가능하게. export 라우트가 DB 우선 로드 + 상수 폴백.
5. **"즉시 반영, 검수는 결과로."** 저장하면 다음 생성부터 적용. 별도 승인 단계 없음(어드민 전용이므로). 품질 검수는 생성 결과 미리보기·발행 게이트가 담당.

### B. 상세 제호 — `CompetitorWeeklyReport.tsx`

헤더에 **`경쟁사 동향 브리핑`** 제호(15px/700) + 주차 배지를 상단에 확실히. 그 아래 summary(24px). HTML 디자인·지면 톤은 유지. **이미지 배너는 넣지 않는다**(플랫 에디토리얼 톤 유지 — David와 합의). 향후 필요 시 슬롯만.

### C. 통합 프롬프트 콘솔 (신규)

- `src/lib/prompts/catalog.ts` — `PROMPT_CATALOG`. 각 항목: `key·label·group·description·fallback`. fallback은 각 생성기의 상수를 **import**(그래서 상수를 `export` 해야 함: `FACTS_SYSTEM_FALLBACK`·`COMPANY_SYSTEM_PROMPT`·`STRATEGY_SYSTEM_FALLBACK` + `FRAME_SPEC`·`LGU_CONTEXT`).
- `src/app/api/admin/prompts/route.ts` — `GET`(카탈로그 ∪ DB 병합, `saved`/`updatedAt` 포함) / `PATCH`(카탈로그에 있는 key만 upsert). admin 검증. 42P01 graceful.
- `src/components/admin/PromptConsole.tsx` — 그룹별 목록, key별 textarea, `변경됨`·`DB 저장됨`/`코드 기본값` 뱃지, 저장·`코드 기본값으로` 리셋.
- `src/app/admin/prompts/page.tsx` + `nav.ts` 에 `프롬프트 콘솔` 진입(기존 TODO 슬롯 채움).

### D. 프레임 DB 로드 — `api/admin/competitor-weekly/analysis/route.ts`

`GET` 이 `competitor_weekly_frame`/`competitor_weekly_lgu_context` 를 `llm_prompts` 에서 우선 로드(없으면 `FRAME_SPEC`/`LGU_CONTEXT`). → 콘솔에서 프레임을 고치면 다음 "분석 컨텍스트 복사"에 반영된다.

## 회귀 / 주의

- **테이블·라우트·컴포넌트명 무변경.** `competitor_weekly_reports`·`view=trend`·`CompetitorWeekly*` 그대로. 라벨만.
- 상수 `export` 전환 시 기존 내부 참조가 깨지지 않게(특히 `generate-strategy.ts`의 `FALLBACK_SYSTEM_PROMPT` → `STRATEGY_SYSTEM_FALLBACK` 리네임 후 `return` 문도 갱신).
- `catalog.ts`는 `server-only` — 클라이언트에서 import 금지. 콘솔은 API로만 접근.
- `PATCH`는 카탈로그에 없는 key를 거부(라우팅·모델설정 등 llm_prompts 외 값 보호).
- 하드룰 8: 콘솔은 `createAdminClient()`(service_role) 서버에서만. 클라이언트 노출 금지.
- 검증: `npx tsc --noEmit` · ESLint · `npm run build` · 육안(`/admin/prompts` 목록·저장 / 기업동향 탭 라벨 / 브리핑 상세 제호).
