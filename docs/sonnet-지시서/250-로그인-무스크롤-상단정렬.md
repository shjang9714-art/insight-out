# 지시서 250 — 로그인 무스크롤 상단 정렬 (전구 씬·카드 상향)

목표: 로그인 페이지의 **세로 스크롤을 제거**한다. 헤드라인(폰트)은 그대로 두고, **전구 애니메이션 씬 + 로그인 카드를 상단으로 올려** 100vh 안에 다 들어오게 한다.

David 요청: 폰트 제외 나머지(애니메이션·로그인 박스)를 상단으로, 스크롤 안 생기게.

범위: `src/app/login/page.tsx`(정렬·여백·씬 오프셋). 필요 시 `globals.css`(.io-login) 미세. 로그인 세션 워킹트리. 코드 로직·인증·248 구성 불변.

## 1. 현행 진단 (검증된 코드 사실)
- `main`: `min-h-screen ... items-center justify-center overflow-hidden ... py-8 lg:py-10`. → **세로 중앙정렬**. 콘텐츠가 100vh보다 크면 `min-h-screen`이 콘텐츠 높이로 늘어나 **body 스크롤** 발생(main의 overflow-hidden은 main 자기 박스 밖만 클립, 박스 자체는 콘텐츠로 커짐).
- 좌측 씬 래퍼: `mx-auto mt-4 ... lg:-mt-[28%] lg:-ml-[26%] lg:w-[153%]`. **BulbScene aspect-[1456/1087]** → 153% 폭이면 높이도 큼(스크롤 주범).
- 우측 카드: `max-w-[460px]`, Suspense fallback `h-[620px]`.

## 2. 구현 (스크롤 제거 = 상단 정렬 + 세로 축소)

### 2-1. `main` 상단 정렬 + 여백 축소
- `items-center` → **`items-start`**(콘텐츠를 위로).
- 세로 패딩 축소: `py-8 ... lg:py-10` → **`pt-4 pb-3 lg:pt-6 lg:pb-4`**(상단 여백 최소, 하단도 축소). 가로 패딩(px)은 유지.
- `overflow-hidden` 유지.

### 2-2. grid 상단 정렬
- 그리드 `items-center` → **`items-start`** — 좌/우 컬럼 모두 위로. (우측 카드도 상단에서 시작 → 상향)

### 2-3. 전구 씬 상향 + 세로 축소(스크롤 제거 핵심)
- 씬 래퍼: 위로 더 당기고 폭을 약간 줄여 **높이를 낮춘다**(aspect 고정이라 폭↓ = 높이↓):
  - `mt-4` → `mt-2`(모바일 상단 여백↓).
  - `lg:-mt-[28%]` → **`lg:-mt-[32%]`**(더 위로, 헤드라인과 더 겹침 — 텍스트 z-10이라 가독성 유지).
  - `lg:w-[153%]` → **`lg:w-[132%]`**, `lg:-ml-[26%]` → **`lg:-ml-[16%]`**(씬 축소로 세로 footprint↓, 전구·구슬은 이미지 feather라 비율 유지).
- 목표: 데스크톱에서 씬 하단이 카드 하단과 비슷한 높이에서 끝나 **컬럼 전체가 뷰포트 내**.

### 2-4. (필요 시) 카드 fallback 높이
- 실제 카드가 620보다 짧으면 fallback `h-[620px]`를 실측 높이(예: `h-[560px]`)로 맞춰 레이아웃 점프·과높이 방지(선택).

## 3. 하드 요구 (검증 기준)
- **다음 뷰포트에서 세로 스크롤 0**(브라우저 실측): **1280×800 · 1440×900 · 1536×864**. 씬(전구·오브·트윙클)·카드가 **잘림 없이** 다 보여야 함.
- 모바일(<lg): 세로 스택 유지, 가로 스크롤 0. 모바일은 자연 흐름이라 세로 스크롤 일부 허용(데스크톱 무스크롤이 핵심).
- 헤드라인·서브·설명(폰트)은 **위치·크기 불변**(David: 폰트 제외).

## 4. 튜닝 (Sonnet — 라이브)
- §2-3의 `-mt`·`w`·`-ml` 값은 **시작값**. 브라우저로 위 3개 뷰포트를 열어 **스크롤이 0이 될 때까지** 조정(씬을 더 올리거나 폭을 더 줄임). 씬이 과하게 작아지면 카드와 균형 깨지니 폭 120~140% 범위에서 균형.
- 씬을 올려도 카드(우측)가 길어 스크롤이 남으면, 카드 컬럼도 `items-start`로 상향된 상태에서 상단 여백만 더 축소.
