## 3. 구현 (`excerpt.ts` `tagsOf2`)

카테고리와 동일한 태그를 제외(대소문자·공백 무시), fallback(`[category]`) 제거:
```ts
export function tagsOf2(matchedGroups: string[], matchedKeywords: string[], category: string): string[] {
  const catLower = (category ?? '').trim().toLowerCase()
  const tags = [...new Set([...matchedGroups, ...matchedKeywords])]
    .filter(t => t.trim().toLowerCase() !== catLower)
  return tags.slice(0, 6)
}
```
- 카테고리 칩은 카드가 항상 별도 표시하므로, 태그가 0개면 해시태그 영역만 생략(카드는 `keywords.length > 0` 조건부 렌더 — 빈 영역 안 생김).
- (선택) 카테고리 라벨 표기가 enum과 다를 수 있는 경우 대비: `CONTENT_CATEGORY_LABEL[category]` 도 함께 비교하려면 excerpt.ts 에 라벨 비교를 추가할 수 있으나, 현행 케이스("리포트"="리포트")는 raw 비교로 충분. 라이브에서 다른 중복 발견 시 라벨 비교 추가.

## 4. 회귀 가드 / 비기능 요건

- 카테고리 칩은 유지(항상 1개). 해시태그에서 카테고리 중복만 제거.
- 태그 0개 카드: 해시태그 미표시(빈 칩/영역 없음).
- `tagsOf2` 를 쓰는 모든 카드(리스트·썸네일형·클러스터)에서 일관.
- 다른 태그(실제 키워드)는 그대로 노출. SQL/hex 0.
