## 0. 한 줄

**도메인/URL/제목 패턴 제외 규칙**을 어드민에서 관리하고, 크롤러가 이를 적용해 **자동 보류(hold=검토 대기+사유) 또는 미적재(reject)** 한다. 저품질 소스(186)·검수 화면에서 **"제외 규칙 추가" 원클릭**으로 재유입을 끊는다(반복 방지 루프).

## 1. 현행 진단 (검증된 코드 사실)

- 기존 제외(orchestrator 315-323, step 1): `isAdLike`(광고 패턴)·`isExcludedByGroups`(keyword_groups.exclude_patterns, **제목만**) → **reject(미적재)**. 사유 태깅 없음.
- **도메인/URL 단위 제외 없음**(제목만) → 특정 매체가 계속 저품질을 밀어도 도메인 차단 불가.
- 제외 패턴이 keyword_groups(분류 규칙)에 섞여 있어 **전용 관리면 없음**. 저품질 소스(186)에서 바로 제외하는 액션 없음.

## 2. DB / SQL (수희 핸드오프)

`docs/sql-handoff/190-exclusion_rules.sql` — `exclusion_rules`(rule_type: domain/url_pattern/title_pattern, value, action reject/hold, is_active, note, hit_count, created_by). **먼저 커밋·푸시해 수희 적용**(테이블 없으면 규칙 0·크롤 기존대로 graceful).

## 3. 구현

### 3-1. 크롤러 적용 (`orchestrator.ts` + `quality.ts`)
- 크롤 시작 시 `exclusion_rules`(is_active) 로드(1콜, keyword_groups 로드 옆).
- step 1 제외 판정 확장: 아이템의 **도메인(original_url host)·URL·제목**을 규칙과 대조:
  - `domain`: host 완전/서브도메인 일치 · `url_pattern`: URL 부분일치 · `title_pattern`: 제목 부분일치.
  - 매칭 규칙의 `action`:
    - `reject` → 기존처럼 미적재(counts.rejected++).
    - `hold` → 적재하되 status='pending' + `review_reason='excluded_rule'`(178 게이트와 합류, 라벨 "제외 규칙").
  - (선택) 매칭 시 `hit_count` 증가(배치/후속 — 매 아이템 update 부담이면 생략, 후속에서 집계).
- `quality.ts`에 순수 함수 `matchExclusion(item, rules)` → { action, ruleId } | null.
- 테이블 미적용(42P01)·규칙 0 → 기존 동작 유지(graceful).

### 3-2. review_reason 라벨(178 연계)
- `REVIEW_REASON_LABEL`에 `excluded_rule: '제외 규칙'` 추가(어드민 검토 대기 사유 표시).

### 3-3. 어드민 관리 UI — `/admin/exclusion-rules`(신규) 또는 소스 관리 섹션
- 규칙 목록: 종류·값·동작(reject/hold)·활성·비고·(hit_count). CRUD + 활성 토글.
- nav 시스템/수집 그룹에 항목 추가(또는 소스 관리 탭). AdminPageHeader·v2 스타일.
- API `/api/admin/exclusion-rules`(GET/POST/PATCH/DELETE, service_role, 42P01 graceful).

### 3-4. 검수 흐름 원클릭 "제외 추가"
- **186 소스 품질**(SourceManager): 저품질 소스 행에 **"도메인 제외" 버튼** → 그 소스 도메인으로 domain 규칙 생성(action 기본 hold, 확인 후).
- **어드민 콘텐츠 상세(184)**: "이 도메인 제외" / "이 제목 패턴 제외" 빠른 추가(선택).
- 생성은 위 API 재사용.

### 3-5. (범위 밖) 학습 제안
- 반려율·불량률 높은 도메인 자동 "제외 후보" 제안 — 후속(186 데이터 기반).

## 4. 회귀 가드 / 비기능 요건

- 테이블 미적용·규칙 0 → 크롤 기존 동작(회귀 0). 기존 isAdLike·keyword_groups 제외 유지(공존).
