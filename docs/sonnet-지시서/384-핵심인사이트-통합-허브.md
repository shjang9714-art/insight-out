## 1. 현행 진단 (확인된 코드 사실)

- **`/admin/insights/page.tsx`**: `'use client'` 페이지 **자체가** 인사이트 카드 컴포넌트(`export default function InsightsAdminPage()`). 내부에서 `AdminPageHeader`(actions=새로고침 버튼) + 생성 패널 2개 + 카드 목록 렌더. API: `GET/POST /api/admin/insights`, `PATCH/DELETE /api/admin/insights/[id]`. metadata export 없음(클라이언트라 불가).
- **`/admin/issues/page.tsx`**: 서버 페이지. `<AdminPageHeader/>` + `<IssueManager/>`(852줄). `IssueManager`는 **자체 AdminPageHeader 렌더 안 함**(grep 0), 내부에 자기 `AdminTabs`(레벨3, 695행) 보유. API: `/api/admin/issues/*`.
- **`/admin/daily-insights/page.tsx`**: 서버 페이지. `<AdminPageHeader/>` + `<DailyInsightsManager/>`(225줄, `'use client'`, **자체 헤더 없음**). API: `/api/admin/daily-insights`, `.../count`, `.../[id]`.
- **사이드바 배지**: `AdminSidebar.tsx` 186행 `item.href === '/admin/daily-insights' && dailyInsightReviewCount > 0` — 카운트는 `/api/admin/daily-insights/count`(34·38행). S1에서 일일핵심을 별도 nav 항목으로 둬 배지가 살아있었음.
- **nav.ts 인사이트 그룹**(지시서 382): `핵심인사이트`(/admin/insights) · `이슈 관리`(/admin/issues, icon `Radar`) · `일일 핵심 Insight`(/admin/daily-insights, icon `CalendarClock`) · `키워드분석`(disabled) · `관계지도`(disabled). **`Radar`(17행)·`CalendarClock`(28행)은 이 두 항목에서만 사용** → 항목 제거 시 미사용 import가 됨.
- `AdminTabShell`(S2): `tabs`·`defaultTab`·`renderContent(active)`·`aria-label` 등. URL `?tab=`. 헤더·브레드크럼 자동. `IssueManager`·`DailyInsightsManager`가 헤더리스라 탭에 바로 마운트 가능.

### 3.2 신규 `src/components/admin/InsightHub.tsx` — 허브(3탭)
```tsx
'use client'

import AdminTabShell from '@/components/admin/ui/AdminTabShell'
import InsightCardsManager from '@/components/admin/InsightCardsManager'
import IssueManager from '@/components/admin/IssueManager'
import DailyInsightsManager from '@/components/admin/DailyInsightsManager'

const TABS = [
  { value: 'card',  label: '인사이트 카드' },
  { value: 'issue', label: '이슈 관리' },
  { value: 'daily', label: '일일 핵심' },
]

export default function InsightHub() {
  return (
    <AdminTabShell
      tabs={TABS}
      defaultTab="card"
      aria-label="핵심인사이트 관리"
      renderContent={(tab) =>
        tab === 'card'
          ? <InsightCardsManager />
          : tab === 'issue'
            ? <div className="space-y-6"><IssueManager /></div>
            : <div className="space-y-6"><DailyInsightsManager /></div>
      }
    />
  )
}
```

## 4. 회귀 가드

1. **`IssueManager`·`DailyInsightsManager`·인사이트 API·`AdminTabShell`은 무변경.** 재사용만.
2. **`InsightCardsManager` 추출은 기계적**이어야 한다 — 함수명·헤더 블록·`AdminPageHeader` import 3가지 외에는 한 글자도 바꾸지 말 것. 상태/핸들러/카드 JSX/필터 로직 보존.
3. **nav.ts**: 인사이트 그룹만 수정 + `Radar`·`CalendarClock` import 삭제. **다른 10개 그룹·타입·헬퍼 변경 금지.** 그룹 수는 **11 유지**.
4. **AdminSidebar**: 186행 조건 문자열만 교체. `dailyInsightReviewCount` fetch(`/api/admin/daily-insights/count`)·`openRequestCount` 등 나머지 로직 무변경. `/admin/requests` 배지 유지.
5. **탭 중첩**: `IssueManager`가 내부 `AdminTabs`(레벨3)를 가진다 → 허브 레벨2 탭 안에 레벨3 탭이 보인다(정상, 스켈레톤 허용). 시각적으로만 확인.
6. **Suspense**: `insights/page.tsx`를 `<Suspense>`로 감쌌다(S2와 동일, `useSearchParams` 정적생성 대비).
7. 구 라우트 `/admin/issues`·`/admin/daily-insights`는 nav에서 빠져 `findAdminNavItem`이 null → 그 페이지의 `AdminPageHeader`가 '어드민' 제네릭 제목으로 뜬다(하드 실패 아님, 후속에서 리다이렉트). 이번 슬라이스에선 정상 동작만 확인.
