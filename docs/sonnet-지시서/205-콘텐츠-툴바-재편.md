## 0. 한 줄

콘텐츠 관리 상단을 이렇게 재편: **카테고리 탭을 최상단·크게(메뉴화)** → 필터 → 리스트. **처리 도구(풀본문·신호분류·URL정규화)는 리스트 우측 상단**으로 모으고, **풀본문은 클릭 시 기간 팝업**(프리셋+시작/종료일)으로 범위 선택. **선택 작업 바(노출/숨김)는 1개 이상 선택 시 리스트 상단에 sticky 등장**. 불필요 항목(범위 드롭다운·선택 해제·선택 풀본문·idle 바) 제거. 행 "관리" 열 순서를 **노출/숨김·보기·수정·삭제**로.

## 1. 현행 진단 (검증된 코드 사실)

- 상단 구조: 제목행+운영버튼(:722~833) → 카테고리 탭(:836~853) → 필터 그리드(:855~910) → 활성 필터 칩(:912~951) → **일괄 작업 바(:953~1010, 항상 렌더)** → 테이블(:1028~).
- **범위 드롭다운**(`backfillRange`, :186·:792~804 Select)은 **풀본문(handleEnrich)만** 사용(:546~549 from 계산). 신호분류(`?limit=10`)·URL정규화(`?limit=15`)는 범위 미사용.
- `handleEnrich`(:538): `from` 만 계산해 `/api/admin/body-backfill?limit=30&from=…` 반복 호출. **라우트는 `to`도 이미 지원**(route.ts:47 `?from&to`). → 프런트에서 `to`만 넘기면 종료일 됨.
- 일괄 작업 바(:953): "선택된 콘텐츠 없음/N건 선택" + 일괄 보이기(`handleBulkStatus('published')`) + 일괄 숨기기(`handleBulkStatus('rejected')`) + **선택 풀본문(`handleEnrichSelected`)** + **선택 해제**. `noSelection` 이어도 항상 렌더(높이 점프 방지 위해).
- 카테고리 탭(:837): `rounded-full border px-3.5 py-1.5 text-sm`, active=brand.
- 행 "관리" 셀(:1179~, 204에서 sticky 적용됨): 순서 보기 → 노출|숨김 → 수정 → 삭제.

## 2. 구현 (AdminContentManager.tsx 단일, 프런트)

### 2-1. 카테고리 탭 최상단 + 강조(메뉴화)
- 카테고리 탭 `<div>`(:836~853)를 **컴포넌트 최상단**(에러 배너 다음, 검토대기/필터보다 위)으로 이동.
- 크게: 예 `rounded-full px-5 py-2.5 text-[15px] font-medium` + active `bg-brand-600 text-white`, 비활성 `bg-card text-foreground border-border hover:bg-accent/50`. 탭 사이 gap 넉넉히(gap-2). "메뉴" 느낌이 나게 살짝 큰 히트영역.
- (선택) 탭 묶음 아래 옅은 구분선(border-b) 한 줄로 네비 영역임을 구분.

### 2-2. 처리 도구 → 리스트 우측 상단으로 이동
- 제목행의 운영버튼 블록(:764~833 중 206이 비우기 제거하고 남은 것 = 기간select+풀본문+신호+URL+결과칩)을 제거하고, **리스트 헤더 행**(테이블 바로 위 "총 N건 · N/N 페이지" 줄, :~1013 부근)의 **오른쪽**에 배치.
  - 좌: 총 건수·페이지(기존) + (원하면) 검토대기 배지.
  - 우: 처리 도구 3버튼 = **풀본문 채우기**(→ 기간 팝업, 2-3) · **신호 분류**(handleSignalClassify 그대로) · **원문 URL 정규화**(handleCanonicalize 그대로). 진행 중 "중단" 토글·결과 텍스트도 이 근처로 이동(작게, 우측 정렬).
- 범위 드롭다운(Select, :792~804)·`backfillRange` state는 **삭제**(기간 팝업이 대체).

### 2-3. 풀본문 "기간 팝업"
- 풀본문 버튼 클릭 → **Dialog**(기존 편집 모달과 동일 shadcn Dialog 사용) 오픈:
  - **프리셋 버튼**: 최근 7일 / 30일 / 90일 / 전체.
  - **직접 지정**: 시작일·종료일 `<input type="date">` 2개(달력). 프리셋 클릭 시 두 날짜 자동 채움(전체=비움).
  - 하단 "채우기 시작" 버튼 → 팝업 닫고 `handleEnrich({ from, to })` 실행.
- `handleEnrich` 시그니처를 `({ from, to }: { from: string | null; to: string | null })`로 변경, URL을 `/api/admin/body-backfill?limit=30${from?`&from=${from}`:''}${to?`&to=${to}`:''}` 로. (프리셋 계산은 팝업에서 from/to 산출.)
- 진행/중단/결과 표시는 기존 로직 유지(우상단 결과 텍스트).

### 2-4. 선택 작업 바 — sticky, 노출/숨김만, 조건부
- **1개 이상 선택 시에만 렌더**(`selectedIds.size > 0`). idle("선택된 콘텐츠 없음")·힌트문(BULK_SELECTION_HINT) 제거.
- **리스트 상단 sticky**: 테이블 래퍼 안(또는 바로 위)에 `sticky top-0 z-30` + 불투명 배경(`bg-accent`/`bg-card`)+하단 그림자/보더로, 스크롤 시 리스트 위에 고정.
- 내용: `${size}건 선택` + **노출**(`handleBulkStatus('published')`, 아이콘 Check, text-positive) + **숨김**(`handleBulkStatus('rejected')`, 아이콘 X). (색: 숨김은 204 destructive 톤/또는 muted, 생 `text-red-600` 금지 — 203/204 정합.)
- **제거**: "선택 풀본문 채우기" 버튼 + `handleEnrichSelected` + `isEnrichingSel` state (중복). "선택 해제" 버튼(체크박스로 해제 가능하니 불필요) — 단 선택 유지 UX 위해 바에 작은 "해제"는 남겨도 됨? → **David 지시대로 제거**. (전체 해제는 헤더 체크박스 토글로 가능.)

### 2-5. 행 "관리" 열 순서 변경(:1179~ 액션 셀)
- 순서를 **노출/숨김 → 보기 → 수정 → 삭제** 로: 현재 보기(:1181) 다음에 노출|숨김(:1187~1207)을 **앞으로** 옮겨 `[노출|숨김][보기][수정][삭제]`. (204 sticky/폭 유지, 버튼 스타일 동일.)

## 3. 회귀 가드 / 비기능 요건
- 백엔드·API·SQL·npm 무변경. body-backfill 는 기존 `from/to` 그대로.
- 필터·정렬·리사이즈(200)·선택 로직 유지. 선택 바 조건부 렌더로 높이 점프 나던 것은 sticky+등장/퇴장로 대체(레이아웃 안정).
- 신호분류·URL정규화 동작 불변(범위 미사용). 풀본문만 팝업 경유.
- 카테고리 탭 확대 후에도 줄바꿈·모바일 폭 정상. 203 폰트 축소·204 대비/빨강 톤 유지, 생 `red-*`·신규 hex 금지(토큰 사용).
- 비어드민 무영향(기존 게이트).

## 4. 검증 (Sonnet 자체)
1. `npx tsc --noEmit` 0 / `npx eslint` 0 / build.
2. 카테고리 탭이 최상단·크게, 메뉴처럼 보임. 전환 정상.
3. 풀본문 클릭 → 기간 팝업(프리셋+시작/종료일) → 선택 범위로 채우기 실행·진행·완료 표시. 신호분류·URL정규화는 우상단에서 그대로 동작.
4. 범위 드롭다운·idle 바 사라짐. 1개 이상 선택 시 리스트 상단에 노출/숨김 바 sticky 등장, 스크롤해도 고정. 전량/부분 선택·해제(헤더 체크박스) 정상.
5. 행 액션 순서 노출/숨김·보기·수정·삭제. 리사이즈·sticky 관리열(204) 유지.
6. 라이트·다크 스크린샷, 공개 화면 무영향.
