## 1. 데이터 (이미 존재)
- `sources` 컬럼: `id, name, type(source_type), url, rss_url, is_active, crawl_interval_minutes, last_crawled_at, "order", created_at, updated_at`.
- `source_type` enum: `news_site`(뉴스), `report_publisher`(리포트 발행처), `opinion_channel`(오피니언), `newsletter`(뉴스레터), `youtube_channel`(유튜브). **지금 크롤러가 처리하는 건 `news_site` 뿐**(나머지는 후속) — 폼엔 전부 노출하되 안내.
- RLS: `sources: admin 관리`(is_admin) → **로그인 admin 의 브라우저 client(`createClient()`) 로 CRUD 통과**(service_role 불필요). `/admin/*` 는 proxy.ts 가 이미 가드.

## 2. 할 일

### 2.1 `src/app/admin/sources/page.tsx` (신규, 서버 컴포넌트)
- `metadata`(제목 "소스 관리 | 어드민 | Insight Out") + 헤더(h1 "크롤링 소스 관리" + 설명) + `<SourceManager />`(클라이언트) 렌더. (`/admin/upload` 패턴 동일)

### 2.2 `src/components/admin/SourceManager.tsx` (신규, `'use client'`)
- `createClient()`(브라우저)로:
  - **목록 로드**: `sources` 전체 `order`·`name` 정렬 조회 → state. 표: 이름·유형(한글 라벨)·rss_url(말줄임)·활성(토글)·주기(분)·마지막 수집(KST, 없으면 "—")·작업(수정/삭제).
  - **추가**: 폼(이름*·유형 select·url·rss_url·주기(기본 720)·활성 기본 true) → `insert` → 목록 갱신.
  - **수정**: 행 인라인 또는 모달 편집 → `update ... eq('id')`.
  - **활성 토글**: `update is_active`.
  - **삭제**: 확인(window.confirm 또는 간단 확인 UI) 후 `delete ... eq('id')`. ⚠️ 안내: 삭제해도 기존 콘텐츠/로그는 보존됨(FK on delete set null) — 보통은 **삭제보다 비활성**을 권장하는 문구.
- 검증: 이름 필수. `news_site` 인데 `rss_url` 비면 경고(저장은 허용하되 "RSS 없으면 수집 안 됨" 안내). 에러는 한국어 메시지(AGENTS §11 패턴), 로딩/저장 상태 표시.
- mutation 후 목록 재조회 또는 낙관적 갱신. shadcn/ui(Button/Input/Select/Label) 사용.
