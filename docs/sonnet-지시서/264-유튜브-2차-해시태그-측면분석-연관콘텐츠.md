# 지시서 264 — 유튜브 2차 (해시태그 + 측면 분석 + 연관 콘텐츠)

목표: 유튜브 인앱 상세(252)를 심화한다. (1) 유튜브 라벨칩 옆에 **키워드(엔티티) 해시태그**, (2) 세로 영상의 **우측 빈 공간에 내용 분석/요약 패널**, (3) 하단에 **추천 기사·추천 유튜브 연관 콘텐츠**.

David 요청. 전제: 252(유튜브 인앱 상세·태깅) 배포됨.

범위: `contents/[id]/page.tsx`(유튜브 분기). SQL 없음. (자막 스크립트는 별도 수집 필요 → 후속.)

## 1. 현행 진단 (검증된 코드 사실)
- 252: 유튜브 상세 = 상단 배지(유튜브)+제목+메타 → youtube-nocookie iframe(aspect-video, 세로 영상은 좌우 검은 여백 큼) → 기존 관련기사 캐러셀(`getRelatedGrouped`/`getRelatedYoutube` + `FeedCarousel`)·관련 엔티티 칩 상속.
- 252 태깅: 유튜브 콘텐츠에 `matched_groups`·`content_entities` 부여(백필/신규자동).
- summary_ko: 유튜브가 요약 파이프라인을 타면 존재(확인 필요). 자막(transcript)은 미수집.

## 2. 구현 (유튜브 분기, `contents/[id]/page.tsx`)

### 2-1. 유튜브칩 옆 해시태그(엔티티)
- 상단 배지 행: `유튜브` 칩 옆에 **해시태그** 노출 — `matched_groups`(태그) + 연결 엔티티(content_entities) 상위 4~5개. 뉴스 카드 해시태그 톤과 통일. 각 해시태그 클릭 → `/dashboard/topics/{kw}`(모아보기, 실존).

### 2-2. 우측 분석 패널 (세로 영상 여백 활용)
- 유튜브 상세를 **2단 레이아웃**(데스크톱): 좌 = iframe 플레이어(세로 영상이면 폭 제한), 우 = **분석 패널**.
  - 세로 영상은 aspect가 세로라 좌우 여백이 큼 → 플레이어를 적정 폭(예: `max-w-[400px]`)으로 두고 우측에 패널.
- **분석 패널 내용**:
  - **주요 내용**: `summary_ko` 있으면 표시. 없거나 빈약하면 **LLM 분석**(제목+채널+설명 기반 3~5줄 "이 영상 핵심")을 온디맨드/생성 시 채움(요약 파이프라인 재사용, `llmComplete('summarize', …)`, 한글).
  - **관련 엔티티/키워드** 칩(기존 관련 엔티티 섹션을 여기로).
  - (후속) **번역 스크립트**: 자막 수집 붙이면 접힘 패널로. 지금은 자리만/생략.
- 모바일: 2단 → 세로 스택(플레이어 위, 분석 아래).

### 2-3. 하단 연관 콘텐츠 (추천 기사 + 추천 유튜브)
- 기존 `getRelatedGrouped`(뉴스/리서치/웹인사이트)·`getRelatedYoutube` 캐러셀이 유튜브 상세에도 렌더되는지 확인·보정.
- **추천 유튜브**(`getRelatedYoutube`)를 별도 캐러셀로 명시 노출("관련 영상"). 추천 기사(뉴스 등)도 함께.
- 매칭은 matched_keywords/엔티티 기반(252 태깅 덕에 유튜브도 매칭됨).

## 3. 회귀 가드
- 비유튜브 상세 불변(유튜브 분기만 심화).
- 태깅 안 된 유튜브(백필 전): 해시태그·연관 비어도 graceful(플레이어·요약은 표시).
- summary_ko 없으면 LLM 분석 폴백(실패 시 패널 최소 표시).
- 임베드 차단 영상: "YouTube에서 보기" 폴백(252) 유지.
