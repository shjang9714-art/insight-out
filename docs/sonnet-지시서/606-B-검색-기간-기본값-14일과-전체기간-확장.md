대상 = `src/lib/search/use-unified-search.ts` · `src/components/search/SearchResultsPanel.tsx`

★기본 검색은 반드시 14일 제한으로 나가야 한다(성능이 이번 지시서의 존재 이유다). "전체 기간에서

### ★놓치기 쉬운 사실 — `?? ` 는 null 을 못 통과시킨다

`opts?.sinceDays ?? SEARCH_DEFAULT_SINCE_DAYS` (:446)는 **`??`(nullish coalescing)** 를 쓴다.
`??`는 `null`도 `undefined`와 똑같이 "없음"으로 취급해 오른쪽 기본값으로 넘어간다.

그 말은, `SEARCH_DEFAULT_SINCE_DAYS`를 14로 바꾼 뒤 확장 버튼이 `{ sinceDays: null }`(전체
기간 = 무제한)을 넘겨도 **`null ?? 14` → `14`가 되어 확장이 동작하지 않는다.** 지금까지는
기본값이 `null`이라 이 버그가 드러나지 않았을 뿐이다.

**고쳐야 한다** — "옵션을 아예 안 줬다"(기본값 사용)와 "옵션으로 명시적 `null`을 줬다"(무제한)를
구분해야 한다. 예:

```ts
const sinceDays = opts && 'sinceDays' in opts ? opts.sinceDays! : SEARCH_DEFAULT_SINCE_DAYS
```

(정확한 형태는 판단해서 골라라 — 핵심은 `opts.sinceDays === null` 과 `opts` 자체가 없는 경우를
구분하는 것이다.)
