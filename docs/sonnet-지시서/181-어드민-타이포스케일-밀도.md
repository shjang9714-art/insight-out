## 3. 구현

### 3-1. 타이포 스케일 — `globals.css` `@layer components` (`.admin-scope` 한정)
David v2 확대판을 재사용 클래스로 정의(어드민 안에서만). 예:
```
.admin-scope .admin-page-title   { font-size:32px; line-height:40px; font-weight:700; }
.admin-scope .admin-page-desc    { font-size:16px; line-height:24px; font-weight:400; }
.admin-scope .admin-section-title{ font-size:20px; line-height:28px; font-weight:700; }
.admin-scope .admin-section-desc { font-size:15px; line-height:24px; font-weight:400; }
.admin-scope .admin-card-title   { font-size:15px; line-height:22px; font-weight:600; }
.admin-scope .admin-metric       { font-size:44px; line-height:54px; font-weight:700; }   /* 40~48 */
.admin-scope .admin-metric-unit  { font-size:26px; line-height:36px; font-weight:600; }
.admin-scope .admin-body         { font-size:16px; line-height:26px; font-weight:400; }
.admin-scope .admin-table-th     { font-size:15px; line-height:22px; font-weight:600; }
.admin-scope .admin-table-td     { font-size:15px; line-height:24px; font-weight:400; }
.admin-scope .admin-caption      { font-size:13px; line-height:20px; font-weight:400; }

.admin-scope .admin-btn-text     { font-size:15px; line-height:22px; font-weight:600; }
.admin-scope .admin-badge        { font-size:13px; line-height:20px; font-weight:600; }
```
- 반응형(옵션): `@media (max-width:1439px)` 에서 page-title 28~30·metric 36~42·body 15 로 축소. 좁은 화면 추가 축소. (미디어쿼리로 클래스 값 조정.)
- 폰트 패밀리는 기존 Pretendard 유지(변경 불필요).

### 3-2. 밀도 토큰/값
```

Card gap 16 · Card padding 20~24 · Card radius 14~16
```

### 3-3. 구조 크롬 적용(이번 슬라이스)
- **레이아웃**(`app/admin/layout.tsx`): 컨테이너 `px-4`→`px-8`(32), `py-8` 유지/조정, `max-w-7xl` 유지. (`.admin-scope`는 180에서.)
- **사이드바**(`AdminSidebar`): 로고 20 · "어드민" 배지 13 · 검색 15 · 그룹 라벨 `admin-sidebar-group`(13/600) · 메뉴 `admin-sidebar-menu`(16/500) · 아이콘 20 · row height 44~48 · width 280~300. 비활성 대비 상향(180 토큰 반영).
- **페이지 헤더**(`AdminPageHeader`, 174): 제목 `admin-page-title`(32) · 설명 `admin-page-desc`(16) · 하단 여백 28.
- **버튼/탭 높이**: 공용 Button height 40~44, 탭(ContentAddTabs 등) height 44, 텍스트 `admin-btn-text`(15~16). (색·variant는 175/183, 여기선 크기·높이.)
- **base body**: `.admin-scope { font-size:16px }` 로 미지정 텍스트 기본 상향(명시 사이즈 컴포넌트는 후속 적용에서 클래스로).

### 3-4. 범위 밖(후속에서 클래스 적용)
