# 지시서 213 — 어드민 테이블 한 줄 정리(말줄임·행 높이 균일)

목표: 어드민 테이블의 주요 텍스트를 기본 한 줄 표시로 통일해 행 높이를 일정하게 하고 스캔 효율을 높인다. 콘텐츠 관리 테이블을 기준으로 정리하고, `.admin-scope` **공유 CSS 규칙**으로 나머지 어드민 테이블도 기본 한 줄화한다. 단, 콘텐츠 요약·본문 미리보기처럼 **의도적으로 여러 줄을 보여주는 셀은 예외**로 둔다(최대 2줄 clamp 유지).

범위 결정(David): **콘텐츠 테이블 + 공유규칙**. 6개 테이블을 개별로 손보지 않고, 공유 규칙 + 예외 클래스로 일괄 적용.

## 1. 현행 진단 (검증된 코드 사실)

### 공유 테이블 컴포넌트 없음
어드민 테이블은 재사용 래퍼/셀 컴포넌트가 없고 각 매니저가 `<table>` 마크업을 직접 작성한다. 공통 규칙은 `globals.css`의 `.admin-scope` 스코프 스타일뿐.

### `src/app/globals.css` 기존 테이블 기본(333–351)
```css
.admin-scope table { font-size: calc(14px * var(--admin-font-scale, 1)); }
.admin-scope thead th { font-size: calc(13px * ...); font-weight:600; color:var(--muted-foreground); background:var(--muted); padding-top:.625rem; padding-bottom:.625rem; }
.admin-scope tbody td { padding-top:.875rem; padding-bottom:.875rem; }
.admin-scope tbody tr { border-bottom:1px solid var(--border); }
.admin-scope tbody tr:hover { background:var(--accent); }
```
→ **줄바꿈 제어 규칙(nowrap/ellipsis)은 없음.** 각 셀이 개별 클래스로 처리.

### 이미 한 줄/말줄임 처리된 곳
- **AdminContentManager** `src/components/admin/AdminContentManager.tsx` (표 742–954): 제목 `line-clamp-2 block`(851–857, **의도적 2줄**), 카테고리·소스·상태·본문·수집일 `truncate`(859–894), 관리열 sticky flex 아이콘 버튼(896–899). → 대체로 부합.
- **ExclusionRulesManager** (372–441): 다수 `whitespace-nowrap` + 값/비고 `max-w-* truncate`.
- **SourceManager** RSS URL `max-w-[200px] truncate`, 오류 `max-w-[160px] truncate`, 시각열 `whitespace-nowrap`.

### 줄바꿈이 실제로 발생하는(정리 대상) 셀
- **UserManager** `src/components/admin/UserManager.tsx` (256–351): 이메일·이름 등 전 셀이 truncate 없이 **wrap**.
- **CrawlLogsTable** `src/components/admin/CrawlLogsTable.tsx` (278–389): 소스명 셀 wrap(308–), 상태 셀 정상 흐름.
- **SourceManager** `src/components/admin/SourceManager.tsx`: 이름 셀 `px-4 py-3 font-medium` wrap.
- **IssueManager** `src/components/admin/IssueManager.tsx` (732–831): 제목 텍스트 truncate 없음(747).

### ⚠️ 예외로 반드시 보존할 "의도적 멀티라인" 셀
일괄 nowrap 적용 시 깨지면 안 되는 셀 — 아래는 예외 클래스로 opt-out 한다:
- AdminContentManager **제목** td: `line-clamp-2`(851) — 2줄 유지.
- IssueManager **제목+요약** td(745–749): 제목 + `line-clamp-1` 요약 서브행.
- CrawlLogsTable **오류** td(374–382): `max-w-[200px]` + `line-clamp-2`.
- SourceManager **품질(Quality)** td(1043–1063): `space-y-0.5` 다중 서브행(개수·배지·비율).

### 칩 현황(추가 작업 불필요)
- 상태/카테고리/역할 등은 이미 `StatusBadge`(`src/components/admin/ui/StatusBadge.tsx`) 또는 `rounded-full` pill로 인라인 표시 → 한 줄. 별도 칩화 불필요.

## 2. 구현

### 2-1. globals.css — 공유 규칙 추가(안전한 nowrap 기본 + 예외 클래스)
`.admin-scope tbody td` 블록(342 인근) 뒤에 추가:
```css
/* 213 — 어드민 테이블 기본 한 줄. 여러 줄이 필요한 셀은 td에 .admin-cell-wrap 로 예외 처리 */
.admin-scope tbody td { white-space: nowrap; }
.admin-scope tbody td.admin-cell-wrap { white-space: normal; }
```
근거: `white-space: nowrap`만으로 "행 높이 균일 + 한 줄 표시" 목표를 달성한다. 폭이 넓은 컬럼은 이미 `max-w-* truncate`가 있어 말줄임되고, 없는 컬럼은 한 줄 유지 + 컨테이너 가로 스크롤(각 표 `min-w-[...]` 존재)로 흡수된다. `max-width: 0` 류의 트릭은 table-auto 컬럼 폭을 무너뜨릴 위험이 있어 쓰지 않는다.

### 2-2. 예외 클래스 부여(멀티라인 보존)
아래 td에 `admin-cell-wrap` 클래스를 **추가**(기존 클래스 유지):
- `AdminContentManager.tsx` 제목 셀(851 인근, `line-clamp-2` 있는 td).
- `IssueManager.tsx` 제목 셀(745, 제목+요약 컨테이너 td).
- `CrawlLogsTable.tsx` 오류 셀(374, `max-w-[200px]` td).
- `SourceManager.tsx` 품질 셀(1043, `space-y-0.5` td).
- 그 외 `line-clamp-*`/다중 서브행을 쓰는 td가 있으면 동일하게 예외 부여(전 어드민 테이블 grep: `line-clamp` / `space-y` in `<td>`).

### 2-3. 콘텐츠 테이블 기준 마감(정리 대상 소폭 보강)
가로 스크롤 없이도 깔끔히 보이도록, 폭 지정이 없어 넘칠 수 있는 단문 컬럼에 말줄임 보강(선택적, 한 줄 원칙 강화):
- `UserManager.tsx` 이메일·이름 td: `max-w-[200px] truncate` + `title` 속성 추가.
- `SourceManager.tsx` 이름 td: `max-w-[220px] truncate` + `title` 속성.
- `IssueManager.tsx` 제목 텍스트(`font-medium` div, 747): 요약과 별개로 제목이 길면 `line-clamp-1`(제목 셀은 예외 클래스이므로 clamp 허용).

> 관리(액션) 열은 flex 아이콘 버튼이라 `nowrap` 영향 없음 — 변경 금지.

## 3. 회귀 가드
- **멀티라인 유지 확인**: 콘텐츠 제목(2줄), 이슈 제목+요약, 크롤 오류(2줄), 소스 품질(다중행)이 그대로 여러 줄로 보이는지.
- **액션 버튼 열**: 버튼이 줄바꿈되거나 잘리지 않는지(sticky 관리열 포함).
- **가로 스크롤**: 각 표의 `min-w-[...]` 컨테이너에서 넘칠 때 세로 줄바꿈 대신 가로 스크롤로 처리되는지.
- **폰트 스케일**: `--admin-font-scale` 조정 시에도 규칙 유효(스케일은 폰트만, nowrap 무관).
- **다크/라이트 양쪽** 렌더 확인.
- 다른 화면(공개 페이지)엔 영향 없어야 함 — 규칙이 `.admin-scope tbody td`로 스코프됨.
