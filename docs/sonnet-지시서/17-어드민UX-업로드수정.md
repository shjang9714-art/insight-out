> 작성: Opus(Cowork) · 대상: Claude Code(Sonnet) · 유형: 어드민 UX + 버그 수정 (작업계획서 미등재 → §5)
> ⚠️ 작업 전 `AGENTS.md` + `src/components/admin/SourceManager.tsx`·`src/app/admin/upload/page.tsx`·`src/components/admin/ReportUploadForm.tsx`·`src/lib/crawler/orchestrator.ts`(runCrawl) 를 읽을 것.
> 먼저 `npm install`(로컬에 `resend` 등 새 의존성 동기화) 후 시작.

## A. 소스 관리 — 유형 필터 (SourceManager)
- `/admin/sources` 표 **상단에 유형 필터 칩** 추가: `전체 / 뉴스(news_site) / 유튜브(youtube_channel) / 리포트(report_publisher) / 오피니언(opinion_channel) / 뉴스레터(newsletter)`.
- **다중 선택**(여러 칩 토글) 가능, "전체"는 필터 해제. 선택된 유형의 소스만 표에 표시(클라이언트 필터, 이미 로드한 목록에서 거름).
- 각 칩에 해당 유형 **개수** 표시(예: `뉴스 3`). 칩은 차분한 토글 스타일(AGENTS 토큰).

## B. "지금 수집" 버튼 (수동 트리거)
curl 없이 어드민에서 클릭으로 수집. CRON_SECRET 을 노출하지 않도록 **서버 라우트 경유**.

### B-1. `src/app/api/admin/crawl-now/route.ts` (신규)
- `POST`. **관리자 확인**(`/api/admin/upload` 패턴: 서버 client 로 `auth.getUser()` + `users.role==='admin'` 체크, 아니면 401/403).
- 통과 시 `import { runCrawl } from '@/lib/crawler/orchestrator'` → `const summary = await runCrawl()` → `Response.json(summary)`.
  - **당일분만**(backfill 옵션 없이) 호출 → 가볍게. (대량 소급은 기존 크론 라우트의 `?days` 로.)
- `export const runtime='nodejs'`, `dynamic='force-dynamic'`, `maxDuration=60`. CRON_SECRET 불필요(관리자 인증으로 대체).

### B-2. 버튼 UI (소스 관리 또는 크롤링 현황 상단)
- "지금 수집" 버튼 → `POST /api/admin/crawl-now` → 로딩 표시 → 결과 요약(예: "성공 N · 실패 M · 신규 K건") 토스트/문구. 실패해도 UI 안 깨지게.
- (권장 위치: `/admin/sources` 상단. 또는 `/admin/crawl-logs` 상단에 두고 누른 뒤 새로고침 안내.)

## C. 리포트 업로드 에러 수정 ("This page couldn't load")
- **재현 먼저**: `npm run dev` 후 `/admin/upload` 열어 실제 에러(터미널/브라우저 콘솔) 확인.
  - **재현되면** → 원인 수정(예: 런타임 throw, 잘못된 쿼리/컬럼, null 참조 등). `ReportUploadForm` 의 서비스 로드 `useEffect`·제출 핸들러 점검.
  - **재현 안 되면**(로컬 정상) → 프로덕션의 stale 청크였을 가능성 → 명백한 런타임 리스크만 정리하고 "재현 불가, 배포 후 재확인 필요"로 보고.
- 변경은 업로드 페이지/폼에 한정. 업로드 동작(서명 URL 발급·Storage 업로드·contents insert)은 유지.

## D. 건드리지 말 것
- 크롤러 수집 로직·dedup·태깅·스키마·RLS 변경 없음(B는 runCrawl 호출만).
- 소스/키워드 **데이터**는 변경하지 않음(admin 운영 영역).
