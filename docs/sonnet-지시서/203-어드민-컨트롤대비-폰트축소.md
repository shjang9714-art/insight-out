## 0. 한 줄

`.admin-scope`에 **기본 글자색**을 주고, outline·ghost·secondary 버튼과 select 트리거에 **평상시 글자색(`--foreground`)** 을 명시해 흰-on-흰을 없앤다. 동시에 `.admin-*` 타이포 스케일을 **한 단계 축소**(기본 16→15px 등). 201의 글자 크기 설정(작게/기본/크게)은 이 새 기본 위에서 그대로 동작.

## 1. 현행 진단 (검증된 코드 사실)

- **근본 원인 1 — 컨트롤 평상시 글자색 없음**: `src/components/ui/button.tsx` 의 variant 정의에서
  - `outline` = `"border-border bg-background hover:bg-muted hover:text-foreground …"` → **평상시 text-color 없음**(hover만 foreground).
  - `ghost` = `"hover:bg-muted hover:text-foreground …"` → 평상시 색 없음.
  - `secondary` = 색 있음(secondary-foreground)이나 스코프 토큰 확인 필요.
- **근본 원인 2 — `.admin-scope` 에 base `color` 없음**: `globals.css`(:202~204) `.admin-scope { font-size; font-family }` 뿐, `color` 미지정. → 위 무색 컨트롤들이 **주변에서 색을 상속**받는데 어드민 배경(흰 `--card`/회색 `--background`) 위에서 거의 안 읽히는 색으로 뜸. 라이트=연회색, 다크=어두운색 → 양쪽 다 안 보임.
- 기존 부분수정 존재: 185(:265~271 outline `bg:card`·select-trigger `bg:card`+border), 191(:278~304 input/placeholder/disabled 대비) — **배경·비활성은 고쳤지만 "활성 상태 글자색"은 미해결**.
- **영향 컨트롤**(콘텐츠 관리 상단): "기사 풀본문 채우기·신호 분류·원문 URL 정규화"(outline, 비활성 아님 = 191 disabled 규칙 대상 아님), 백필 기간 select("최근 30일"), 필터 select("전체 소스/상태/본문", "50건"), "열 너비 초기화"(ghost, `AdminContentManager.tsx`:1018). 어드민 전 화면 동일 패턴.
- **폰트**: `.admin-scope` 타이포 스케일(:205~222) + 반응형(:225~236). 201에서 전부 `calc(px * var(--admin-font-scale,1))` 로 전환됨(기본 1). 별개로 `.admin-scope table{font-size:15px}`(:311)·`thead th{14px}`(:313) 은 **스케일 변수 미적용 요소 규칙**(201 스케일 영향 밖).

## 2. 구현 (globas.css, 순수 CSS)

### 2-A. 컨트롤 대비 수정 (185/191 블록 인근, unlayered)

1. **`.admin-scope` 기본 글자색**(근본 수정 — 무색 상속 텍스트 안전망):
   ```css
   .admin-scope { color: var(--foreground); }
   ```
   (기존 `.admin-scope { font-size; font-family }` 선언에 `color` 한 줄 추가. 명시적 `text-*` 클래스는 특이도상 그대로 우선 → 회귀 없음, 오직 무색 텍스트만 읽히게.)

2. **버튼 outline/ghost/secondary 평상시 글자색**:
   ```css
   .admin-scope [data-slot="button"][data-variant="outline"],
   .admin-scope [data-slot="button"][data-variant="ghost"],
   .admin-scope [data-slot="button"][data-variant="secondary"] {
     color: var(--foreground);
   }
   ```
   (outline 은 185에서 이미 `bg:card`. ghost 는 투명 배경이라 card/muted 위 foreground 로 읽힘. hover 의 `text-foreground` 와 충돌 없음. **빨강 계열 커스텀 버튼**("수집 기사 비우기" 등 `text-red-600` 클래스)은 특이도/유틸로 유지 — 영향 없음.)

3. **select 트리거·값 글자색**:
   ```css
   .admin-scope [data-slot="select-trigger"] { color: var(--foreground); }
   .admin-scope [data-slot="select-value"]   { color: var(--foreground); }
   ```
   placeholder 표시(SelectValue placeholder)는 연한 게 맞으므로 `[data-placeholder]` 있으면 `var(--text-tertiary)` 유지(현행이 그러면 그대로).

4. **비활성 우선순위 유지**: 기존 disabled 규칙(:289~304, `color: var(--text-tertiary)`)이 위 신규 규칙보다 **뒤에 위치**하도록(동일 특이도 → 소스 순서 후자 승). 신규 규칙은 185 블록(265~271) 인근에 배치 → disabled(289~) 가 뒤 = OK. select-trigger disabled 는 `[data-disabled]` 로 특이도 더 높아 승.

### 2-B. 기본 폰트 한 단계 축소 (:205~236)

`.admin-*` 클래스 px 값을 아래 표로 하향(줄간격도 함께). **`calc(… * var(--admin-font-scale,1))` 곱셈 형태는 유지**, 안쪽 px만 교체:

| 클래스 | 현재 fs/lh | 신규 fs/lh |
|---|---|---|
| `.admin-scope` (base) | 16 | 15 |
| admin-page-title | 32 / 40 | 28 / 36 |
| admin-page-desc | 16 / 24 | 15 / 22 |
| admin-section-title | 20 / 28 | 18 / 26 |
| admin-section-desc | 15 / 24 | 14 / 22 |
| admin-card-title | 15 / 22 | 14 / 20 |
| admin-metric | 44 / 54 | 38 / 46 |
| admin-metric-unit | 26 / 36 | 22 / 30 |
| admin-metric-dashboard | 32 / 40 | 28 / 36 |
| admin-metric-unit-dashboard | 18 / 26 | 16 / 24 |
| admin-body | 16 / 26 | 15 / 24 |
| admin-table-th | 15 / 22 | 14 / 20 |
| admin-table-td | 15 / 24 | 14 / 22 |
| admin-caption | 13 / 20 | 12 / 18 |
| admin-sidebar-group | 13 / 20 | 12 / 18 |
| admin-sidebar-menu | 16 / 24 | 15 / 22 |
| admin-btn-text | 15 / 22 | 14 / 20 |
| admin-badge | 13 / 20 | 12 / 18 |

반응형 블록(:225~236)도 한 단계 하향(곱셈 유지):
- ≤1439: page-title 28→26 / 36→34, metric 36→32 / 44→40, metric-dashboard 28→26 / 36→34, body 15→14 / 24→22
- ≤1023: page-title 24→22 / 32→30, metric 32→28 / 40→36, metric-dashboard 24→22 / 32→30, section-title 18→17 / 26→24

요소 규칙(스케일 밖, :311~313)도 정합 위해 하향:
- `.admin-scope table { font-size: 15px → 14px }`
- `.admin-scope thead th { font-size: 14px → 13px }`
- (선택·권장) 이 두 규칙도 `calc(… * var(--admin-font-scale,1))` 로 감싸 201 글자 크기 설정에 반응하게(현재 표 텍스트가 설정에 안 따르는 갭 해소).

버튼 높이/폰트 오버라이드(:246~258, `font-size:15px`)도 표와 정합 위해 **15→14px** 하향(줄간격 22→20). 아이콘 사이즈 규칙은 무변경.

## 3. 회귀 가드 / 비기능 요건

- **순수 CSS**(globals.css 만). 컴포넌트·데이터·SQL·라우트·npm 무변경.
- **대비**: 라이트(흰/회색 배경)·다크(네이비 배경) 양쪽에서 문제 컨트롤 글자 AA 이상. `.admin-scope color` 추가는 무색 상속 텍스트만 교정, 명시 `text-*` 클래스는 특이도상 그대로(회귀 0).
- **빨강 삭제 버튼**("수집 기사 비우기/유튜브 비우기", `text-red-600`) 색 유지 확인.
- **폰트**: 축소 후에도 사이드바·테이블·툴바 레이아웃 안 깨짐. 201 글자 크기 "기본" = 새 축소 기준(작게=×0.92, 크게=×1.08 그 위에서 동작).
- **어드민 한정**: 모든 규칙 `.admin-scope` 스코프. 공개 :root·`.dark` 무변경 → 사용자 화면 무영향.
- 197 다크 대비·토큰 유지, 신규 hex 0(전부 기존 변수 참조).
