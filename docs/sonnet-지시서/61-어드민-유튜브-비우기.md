## 배경
유튜브 영상은 `youtube_videos`(별도 테이블)에 저장되는데 **어드민에 삭제 UI가 없다**(콘텐츠 관리=contents 전용, /dashboard/youtube·SourceManager 는 영상 삭제 불가). 채널 소스를 지워도 FK `ON DELETE SET NULL` 이라 영상은 남는다. 유튜브 소싱을 API 키워드 검색(지시서 60)으로 재설계하므로, **기존 무관 영상을 어드민에서 일괄 비우는 버튼**이 필요하다(David 요청). 콘텐츠 관리의 "수집 기사 비우기"와 동일 패턴.

## 작업

### 1. 삭제 API 라우트 `src/app/api/admin/youtube/purge/route.ts`
- `contents/purge/route.ts` 를 **그대로 미러**(verifyAdmin + createAdminClient, runtime/dynamic/maxDuration 동일).
- **GET** — 삭제 대상 건수 미리보기: `youtube_videos` 전체 count(`{ count: 'exact', head: true }`). → `{ count }`.
- **POST** — `youtube_videos` 전체 삭제: `admin.from('youtube_videos').delete({ count: 'exact' }).not('id', 'is', null)`(전 행 매칭). FK(bookmarks 등)는 schema cascade/set null 로 자동 정리. → `{ deleted: count }`.
- 오류 처리·로그 메시지 한국어, 콘텐츠 purge 와 동일 형식.

### 2. AdminContentManager 에 "유튜브 비우기" 버튼
- 기존 "수집 기사 비우기" 버튼 **옆에** 동일 스타일(outline, 빨강 계열)로 "유튜브 비우기" 추가.
- `handleYoutubePurge`(기존 `handlePurge` 미러): `/api/admin/youtube/purge` GET 건수 → 2단계 `window.confirm`("유튜브 영상 N건을 삭제합니다. 되돌릴 수 없습니다.") → POST → 결과 칩(`purgeResult` 재사용 또는 별도 상태)으로 "N건 삭제 완료".
- 콘텐츠 목록은 contents 라 유튜브 삭제와 무관 → 목록 새로고침 불필요(검토대기 카운트도 무관). 결과 칩만 갱신.
- 진행 중 상태(`isPurging` 류) 별도 변수로 두 버튼 독립 동작.

## 회귀 / 주의
- DB/RLS/스키마 무변경. 기존 "수집 기사 비우기"·콘텐츠 관리 기능 정상.
- 삭제는 admin 만(verifyAdmin + service_role 서버 라우트, 클라이언트 키 노출 금지 #8).
- `youtube_videos` 전량 삭제 — 되돌릴 수 없음. 2단계 확인 필수.
- 채널 소스 자체 삭제는 기존 SourceManager 로(별도). 이 버튼은 영상만 비움.
