# Sonnet 지시서 09 — 크롤링 현황 어드민 페이지 (#23)

> 작성: Opus(Cowork) · 대상: Claude Code(Sonnet) · Phase 2-C 용주 트랙 #23
> 목적: 매일 자동 수집(Vercel Cron)이 **깨졌는지 한눈에** 보는 어드민 페이지. `crawl_logs` 데이터는 이미 쌓임.
> ⚠️ 작업 전 `AGENTS.md`(Next.js 16 async cookies, 서버컴포넌트 기본, /admin 가드는 `proxy.ts`가 이미 처리) + 기존 `src/app/admin/upload/page.tsx`(어드민 페이지 패턴)·`src/app/dashboard/contents/[id]/page.tsx`(서버 supabase 조회 패턴) 를 읽을 것.

## 0. 목표 (한 줄)
`/admin/crawl-logs` 어드민 페이지에서 소스별·실행별 수집 로그(성공/부분/실패·건수·에러·시각)를 표로 보여준다.

## 1. 데이터 (이미 존재)
- 테이블 `crawl_logs` 컬럼: `id, source_id, status(success|partial|failed), fetched_count, inserted_count, duplicate_count, held_count, error_message, started_at, finished_at, created_at`.
- RLS: `crawl_logs: admin 조회`(`is_admin()`) — **로그인 admin 의 서버 client 로 조회하면 통과**(service_role 불필요).
- `/admin/*` 비관리자 접근은 `proxy.ts` 가 이미 차단 → 페이지에서 권한 재확인 불필요(타입 안전용 user null 체크 정도만).

## 2. 할 일

### 2.1 `src/app/admin/crawl-logs/page.tsx` (신규, 서버 컴포넌트)
- `export const dynamic = 'force-dynamic'`, `export const metadata`(제목 "크롤링 현황 | 어드민 | Insight Out").
- 서버 supabase client(쿠키 기반, `#15` 상세페이지 패턴 동일)로 조회:
  ```ts
  const { data: logs } = await supabase
    .from('crawl_logs')
    .select('id, status, fetched_count, inserted_count, duplicate_count, held_count, error_message, started_at, finished_at, created_at, sources(name)')
    .order('created_at', { ascending: false })
    .limit(100)
  ```
- **상단 요약 카드**: 가장 최근 실행분(같은 `created_at` 근처 배치 또는 최근 24h) 기준 — 총 소스 수, 성공/부분/실패 개수, 신규(inserted) 합계, 마지막 실행 시각. 간단히 `logs` 에서 집계.
- **표**: 컬럼 = 시각(created_at, KST 표기) · 소스명(sources.name, null이면 "—") · 상태(배지) · 가져옴(fetched_count) · 신규(inserted_count) · 중복(duplicate_count) · 보류(held_count) · 소요(finished-started 초) · 에러(error_message, 있으면 빨강 작은 글씨, 없으면 빈칸).
- **상태 배지**: `success`→녹(`bg-green-...`/의미토큰), `partial`→노랑, `failed`→빨강. 한국어 라벨(성공/부분/실패).
- **빈 상태**: 로그 없으면 "아직 수집 기록이 없습니다." (AGENTS §17.5 빈 상태 패턴).
- 한국어 UI, AGENTS §9 디자인 토큰, `/admin/upload` 와 톤 일치. 읽기 전용이라 **'use client' 불필요**(서버 컴포넌트).

### 2.2 어드민 내비 (있으면)
- `/admin` 에 레이아웃/내비가 있으면 "크롤링 현황" 링크 추가. 없으면 생략(페이지만).

### 2.3 건드리지 말 것
- 크롤러·스키마·RLS 변경 없음(읽기 전용 페이지).
- service_role 사용 금지(서버 client 로 RLS 통과).
