## 배경 (David)

이슈(101)·논조(96)가 깔렸지만 홈(추천피드·경쟁사 동향·KA 동향)에는 **이슈 신호가 없다**. David IA #1("매일 첫 화면 = 신호 대시보드")을 점진적으로 — 홈에 **급상승 이슈** 블록을 올려, 들어오자마자 "지금 뜨는 이슈"가 보이게 한다.

## 설계 결정 (Opus)

1. **101 활동 집계 로직을 공용 lib로 추출**(중복 제거): `computeIssueActivity` + KST 주경계 헬퍼를 `src/lib/issues/activity.ts` 로 옮겨 이슈 보드(101)와 홈 위젯이 공유.
2. **홈 위젯 = 급상승 상위 3~5 이슈**(보드의 정렬 그대로: 신규/급상승 우선). 컴팩트 카드, 클릭 → `/dashboard/issues/{id}`.
3. **신규 SQL 없음**·서버 컴포넌트·이슈 없으면 블록 자체 숨김(빈 홈 방지).

## 작업

### A. 공용 lib 추출 — `src/lib/issues/activity.ts` (신규)
- `src/app/dashboard/issues/page.tsx` 의 `computeIssueActivity`, `getKstTodayStartMs`, 관련 타입(`IssueRow`·`ActivityRow`·`IssueCard`)을 이 파일로 이동(export). 
- 활동 페치 헬퍼도 함수화 권장: `fetchIssueActivity(supabase): Promise<IssueCard[]>` — issues(published) 조회 + issue_contents(+contents collected_at·sentiment) 바운디드 페치 + `computeIssueActivity`.
- **101 보드는 이 lib를 import 하도록 리팩터**(동작 동일, 중복 제거). 회귀 주의.

### B. 홈 위젯 — `src/components/dashboard/IssueSignals.tsx` (신규, 서버)
- `fetchIssueActivity` 호출 → 상위 **5건**(급상승순). 0건이면 `null` 반환(섹션 숨김).
- 렌더: 섹션 헤더("급상승 이슈" + 아이콘 `Flame`/`TrendingUp`, "이번 주" 보조). 컴팩트 카드/행 그리드(CompetitorTrends 톤):
  - 이슈명 + 급상승 배지(▲%/신규, 91/보드 스타일) + 최근 7일 건수 + 논조 미니(긍/부).
  - 각 항목 `Link href={/dashboard/issues/{id}}`.
  - 하단 "이슈 전체 보기 →" `/dashboard/issues`.

### C. 홈 배치 — `src/app/dashboard/page.tsx`
- 새 `<section><IssueSignals /></section>` 추가. 위치: **추천 피드(FeedSlot) 아래, 경쟁사 동향 위**(또는 최상단 — 신호 우선이면 FeedSlot 위). 권장: FeedSlot 아래.
- IssueSignals 가 null 이면 섹션 미표시(이슈 시드 전 빈 블록 방지). Suspense 불필요(서버 직접 await) 또는 기존 패턴 따름.
