## 0. 한 줄

항상 펼쳐져 본메뉴 꼬리를 덮던 하단 "시스템" 그룹(운영게시판·사용자관리·테마토글)을 **접이식 단일 항목**으로 바꾼다. 기본 접힘 → 1행만 차지(본메뉴 안 가림), 클릭하면 하위 항목이 펼쳐진다. "시스템 설정(준비중)" 진입점을 추가한다.

## 1. 현행 진단 (검증된 코드 사실)

- `AdminSidebar.tsx`: `<aside sticky h-screen flex flex-col>` → 헤더 · 메뉴검색 · `<nav flex-1 overflow-y-auto>`(ADMIN_NAV_GROUPS 본메뉴) · **하단 시스템 그룹**(`ADMIN_NAV_BOTTOM`, :176~) = nav 밖 고정 블록으로 **항상 펼침**(운영게시판·사용자관리 + AdminThemeToggle).
- 하단 블록에 `shrink-0` 없음 → 뷰포트가 짧으면 본메뉴 마지막 항목(예: 카테고리 분류기준)을 시각적으로 덮음(슬라이드 4).
- `ADMIN_NAV_BOTTOM`(nav.ts): 운영게시판(`/admin/requests`, openRequestCount 배지)·사용자관리(`/admin/users`).
- `findAdminNavItem`은 BOTTOM 항목도 포함(헤더 라벨 조회).

## 2. 구현 (순수 UI — SQL·라우트 무변경)

### 2-1. nav.ts — 시스템 설정 진입점(준비중) 추가
- `ADMIN_NAV_BOTTOM.items`에 항목 추가:
  ```ts
  { href: '/admin/settings', label: '시스템 설정', description: '테마·폰트·화면 구성(준비중)', icon: Settings, disabled: true, badge: '준비중' }
  ```
  (`Settings` 아이콘 import. 실제 화면은 2차 — disabled라 이동 없음.)

### 2-2. AdminSidebar — 하단 시스템 그룹을 접이식으로
- 하단 블록을 **접이 컴포넌트**로 전환(`shrink-0` 부여로 겹침 원천 차단):
  - **헤더 버튼** "시스템" + 우측 Chevron(펼침 시 회전). 그룹 라벨 자리에 클릭 가능한 토글.
  - **기본 접힘**. 상태 `systemOpen`(useState). **자동 펼침**: 현재 pathname이 시스템 하위(`/admin/requests`·`/admin/users`·`/admin/settings`)면 초기 open=true(활성 항목 보이게). (선택) localStorage `io:admin-system-open` 유지.
  - **접힘 시 배지 버블업**: `openRequestCount > 0`이면 "시스템" 헤더 우측에 risk 배지 표시(펼치지 않아도 미처리 요청 인지). 펼치면 기존처럼 운영게시판 항목에도 배지.
  - **펼침 콘텐츠**: 운영게시판·사용자관리(기존 Link) + 시스템 설정(disabled 준비중, 비Link·opacity·`badge`) + 구분선 + `AdminThemeToggle`.
- disabled 항목 렌더: Link 대신 `div`, `cursor-default opacity-60`, 라벨 뒤 `준비중` 배지(admin-caption·중립 톤). (대시보드 "리서치 반영" 패턴 미러.)
- 접이 애니메이션은 과하지 않게(높이/opacity 트랜지션 or 단순 조건부 렌더). 197 다크 대비·`admin-sidebar-*` 타이포 유지.

### 2-3. 레이아웃 안정
- 하단 컨테이너 `shrink-0` + 접힘 기본으로 본메뉴 `flex-1` nav가 항상 온전히 스크롤·표시(가림 0). 접힘/펼침 어느 상태든 겹침 없음.

### 2-4. (범위 밖 → 2차)
- **시스템 설정 화면**(`/admin/settings`): 라이트/다크 토글 이관 + 전체·메뉴별 폰트 크기 + 홈 위젯 구성 + 디자인 색상. 199는 진입점(준비중)만.

## 3. 회귀 가드 / 비기능 요건

- 순수 UI(접이 토글). 라우트·데이터·SQL 무변경. 운영게시판·사용자관리 링크·배지 동작 유지.
- 접힘 기본 + `shrink-0` → 본메뉴 가림 0(어느 뷰포트 높이에서도). 활성 시스템 하위 페이지 진입 시 자동 펼침으로 현재 위치 표시.
- 테마 토글 위치·동작 유지(2차에 설정 화면으로 이관 예정). 어드민 한정, 사용자 화면 무영향.
- 신규 hex 0(197 토큰·기존 배지 톤 재사용). 신규 npm 의존 0.

## 4. 검증 (Sonnet 자체)

1. `npx tsc --noEmit` 0 / `npx eslint` 0 / build 통과
2. 사이드바 하단 "시스템"이 **기본 접힘 1행** → 본메뉴 마지막 항목까지 안 가림(짧은 뷰포트 스크린샷)
3. "시스템" 클릭 → 운영게시판·사용자관리·시스템 설정(준비중)·테마토글 펼침, 다시 클릭 접힘
4. `/admin/requests` 또는 `/admin/users` 진입 시 자동 펼침 + 활성 표시
5. 접힘 상태에서 미처리 요청 있으면 "시스템" 헤더에 배지
6. 시스템 설정은 disabled(이동 안 됨)·준비중 배지, 다크·라이트 스타일 정상, 신규 hex 0
