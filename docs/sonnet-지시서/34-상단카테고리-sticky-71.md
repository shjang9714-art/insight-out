## 배경 (현재 문제)

- `DashboardHeader` 는 `sticky top-0 z-20`(높이 `h-14` = 56px)로 이미 고정.
- 그 아래 상단 네비 div(`CategoryGrid`+`ServiceTabs`+`SearchBar`)는 **일반 흐름**이라 스크롤하면 사라짐 → 피드를 내리는 중 카테고리/서비스 전환을 하려면 매번 맨 위로 올라가야 함.
- `Sidebar` 는 `sticky top-14` 로 헤더 아래 고정되어 있음(z-index 명시 없음).

## 설계 의도 / 주의

- 상단 네비를 **`sticky top-14`** 로 헤더 바로 아래에 고정한다. z-index 는 헤더(`z-20`)보다 **낮게**(`z-10`) 두어 헤더가 위에 오게 한다. 단 본문 카드보다는 위여야 함.
- **높이 주의**: `CategoryGrid` 는 카드 그리드라 세로로 큼. 전체를 sticky 로 두면 화면을 많이 가림. → 아래 둘 중 **택1**, 기본은 (A):
  - **(A) 전체 바 sticky(기본)**: 상단 네비 박스에 `sticky top-14 z-10` + `bg-card` 불투명 배경(겹침 시 비침 방지) 적용. 가장 단순하고 이슈 요구(카테고리 고정)에 부합. CategoryGrid 가 너무 높으면 카드 패딩/세로 크기를 약간 축소 검토.
  - (B) 분리 sticky: 카테고리 그리드는 일반 흐름, **서비스 탭+검색 줄만** 별도 박스로 `sticky top-14` 고정. 화면을 덜 가림. 구현 시 두 박스로 분리.
- `Sidebar(sticky top-14)` 와 **top 기준이 같다** → 사이드바와 상단 네비가 같은 라인에서 시작하므로 레이아웃상 자연스러움. z-index 충돌 없는지 확인(사이드바 `z` 미지정이면 상단 네비 `z-10` 가 필요 시 위로).

## 작업

1. `layout.tsx` 상단 네비 박스 className 에 `sticky top-14 z-10` 추가. 반투명이면 겹침 시 글자가 비치므로 `bg-card`(불투명) 확인(현재 `bg-card` 사용 중 — 유지).
2. 헤더 `z-20` > 상단 네비 `z-10` > 본문 순서 보장. 모바일 드로어(`z-40`)·오버레이(`z-30`)보다 낮아야 하므로 `z-10` 적절.
3. 스크롤 시 헤더(56px) + 상단 네비가 겹치지 않고 순서대로 쌓이는지, 본문 첫 요소가 상단 네비에 가려지지 않는지(필요 시 `<main>` 상단 여백) 육안 확인.
4. `shouldHideTopNav` 가 true 인 경로(마이페이지·상세)에서는 상단 네비 자체가 없으므로 영향 없음 — 회귀만 확인.
