## 0. 한 줄

`/admin/settings`를 실제 화면으로 만들어, 어드민이 **글자 크기(밀도)·폰트·강조색·테마(라이트/다크)** 를 고르면 `.admin-scope` CSS 변수로 **즉시 적용 + localStorage 영속**된다. 서버·DB·사용자 화면 무영향.

## 1. 현행 진단 (검증된 코드 사실)

- **진입점**: `src/lib/admin/nav.ts` `ADMIN_NAV_BOTTOM.items` 에 `/admin/settings` 항목이 `disabled: true, badge: '준비중'` 로 존재(:180~187). 페이지 파일 없음.
- **테마 스코프**: `src/components/admin/AdminThemeScope.tsx` — `'use client'`, `localStorage('io:admin-theme')` 라이트/다크만 관리. `<div className="admin-scope ..." data-admin-theme={theme}>` 로 감쌈. `useAdminTheme()` 컨텍스트(`{ theme, toggle }`) 제공. **기본 라이트 즉시 렌더 후 마운트 시 저장값 반영**(다크 저장자만 짧게 깜빡임, 허용).
- **테마 토글 UI**: `src/components/admin/AdminThemeToggle.tsx` — `useAdminTheme()` 사용.
- **타이포 스케일**: `globals.css` `@layer components` 안 `.admin-scope .admin-*`(page-title 32px … caption 13px) **전부 고정 px**(:205~222) + 반응형 축소(@media :225~237). 밀도 조정 훅 없음.
- **색 토큰**: `.admin-scope { --color-brand-600:#DB0078; … }`(라이트 :334~) / `.admin-scope[data-admin-theme="dark"] { --color-brand-600:#E6007E; … }`(:371~). 폰트: `@theme --font-sans: var(--font-pretendard)`(:10). `.admin-scope { font-size:16px }`(:202~204).
- 즉 **어드민은 이미 `.admin-scope` + `data-admin-theme` 로 완전 격리**된 테마 레이어. 외관 커스터마이즈는 이 레이어에 CSS 변수 몇 개만 얹으면 됨(사용자 화면 :root 무영향).

## 2. 설계 원칙

- **적용 메커니즘 = CSS 변수 오버라이드 on `.admin-scope`** (인라인 style 또는 setProperty). 클래스 재작성 최소화.
- **저장 = localStorage**(테마와 동일 패턴). SSR 안전(초기 렌더는 기본값 → 마운트 후 저장값 적용, hydration mismatch 0).
- **기본값 = 현행 그대로**(아무 설정 안 하면 지금과 픽셀 동일). graceful.
- **어드민 한정**: 모든 변수는 `.admin-scope` 스코프에만. 공개 화면(:root) 절대 변경 금지(Rule 9 — 브랜드색은 변수로만).

## 3. 구현

### 3-1. 외관 상태를 스코프로 승격 — `AdminThemeScope` 확장

`AdminThemeScope.tsx` 를 테마 + **외관(appearance)** 통합 컨텍스트로 확장(파일명 유지 또는 `AdminAppearanceScope`로 개명은 자유, import 정리 조건).

- 관리 값(전부 localStorage, 각 키):
  - `io:admin-theme` — 'light' | 'dark' (**기존 유지**)
  - `io:admin-font-scale` — 'compact' | 'normal' | 'roomy' (기본 'normal')
  - `io:admin-font-family` — 'pretendard' | 'system' (기본 'pretendard')
  - `io:admin-accent` — 프리셋 id (기본 'pink' = 현행)
- 마운트 시 4개 저장값 로드(기존 테마 effect에 합침, try/catch).
- `.admin-scope` div 에 **인라인 style 로 CSS 변수 주입**(기본값이면 미설정=현행 유지):
  - `--admin-font-scale`: compact→`0.92` / normal→`1` / roomy→`1.08`
  - `--admin-font-family`: pretendard→미설정(=`var(--font-sans)`) / system→`system-ui, -apple-system, 'Segoe UI', sans-serif`
  - `--color-brand-600` / `--color-brand-700`: 선택 프리셋의 (라이트/다크 각) 쌍. **현재 data-admin-theme 값에 맞는 쌍**을 주입(테마 토글 시 재계산되도록 theme·accent 의존).
- 컨텍스트 확장: `{ theme, toggle, appearance, setFontScale, setFontFamily, setAccent, reset }` 노출 → 설정 폼이 **실시간 미리보기**(setter가 state+localStorage 동시 갱신).
- `useAdminTheme()` 시그니처 하위호환 유지(기존 `AdminThemeToggle` 안 깨지게 `theme`·`toggle` 그대로).

### 3-2. 폰트 스케일을 타이포 클래스에 연결 — `globals.css`

`@layer components` 의 `.admin-scope .admin-*` 폰트 크기를 **scale 변수 곱**으로 전환(기계적 편집, 기본 1이라 현행 동일):

- 예: `.admin-scope .admin-page-title { font-size: calc(32px * var(--admin-font-scale, 1)); line-height: calc(40px * var(--admin-font-scale, 1)); … }`
- 대상: page-title·page-desc·section-title·section-desc·card-title·metric·metric-unit·metric-dashboard·metric-unit-dashboard·body·table-th·table-td·caption·sidebar-group·sidebar-menu·btn-text·badge (:205~222 전부). `.admin-scope { font-size: calc(16px * var(--admin-font-scale,1)) }`.
- @media 축소 블록(:225~236)도 동일하게 `* var(--admin-font-scale,1)` 곱(선택이 반응형에서도 유효).
- 폰트 패밀리: `.admin-scope { font-family: var(--admin-font-family, var(--font-sans)); }` 한 줄 추가.
- **line-height 도 함께 스케일**(글자만 커지고 줄간격 안 늘면 겹침). 위처럼 calc.

### 3-3. 강조색 프리셋 — 코드 상수(신규 `src/lib/admin/appearance.ts` 등)

- `ACCENT_PRESETS`: id·label·라이트쌍(600/700)·다크쌍(600/700). 예:
  - `pink`(기본): light `#DB0078`/`#C00068`, dark `#E6007E`/`#FF2C9C` (**현행 값 그대로**)
  - `blue`: light `#2563EB`/`#1D4ED8`, dark `#3B82F6`/`#60A5FA`
  - `violet`: light `#7C3AED`/`#6D28D9`, dark `#8B5CF6`/`#A78BFA`
  - `emerald`: light `#059669`/`#047857`, dark `#10B981`/`#34D399`
  - (4~5개면 충분. WCAG 대비 확보한 값으로.)
- `FONT_SCALE_OPTIONS`(compact/normal/roomy label 한국어: "작게/기본/크게"), `FONT_FAMILY_OPTIONS`("프리텐다드(기본)/시스템 기본").

### 3-4. 설정 페이지 — `src/app/admin/settings/page.tsx`(서버 셸) + `AdminAppearanceSettings`(client)

- 서버 페이지: `AdminPageHeader`(findAdminNavItem 자동 제목) + 섹션들. 데이터 조회 없음.
- `AdminAppearanceSettings.tsx`(`'use client'`, `useAdminTheme()` 확장 컨텍스트 사용):
  - **테마**: 라이트/다크 세그먼트(기존 토글 로직 재사용) — 설정 화면에도 노출.
  - **글자 크기**: 작게/기본/크게 세그먼트(라디오). 선택 즉시 미리보기 반영.
  - **폰트**: 프리텐다드(기본)/시스템 기본 세그먼트.
  - **강조색**: 프리셋 스와치(원형 칩, 선택 표시). 클릭 즉시 반영.
  - **미리보기 카드**: 실제 `.admin-*` 클래스로 제목/본문/버튼(brand)/배지 샘플을 보여줘 선택 효과 즉시 확인.
  - **초기화 버튼**: `reset()` → 4개 키 삭제 + 기본값 복원.
  - 안내문(비전문 사용자용): "이 설정은 이 브라우저의 관리자 화면에만 적용됩니다. 방문자 화면과 다른 기기에는 영향이 없습니다." (memory: 일반 사용자 우선.)
- **하위 섹션 자리**: 페이지 하단에 "공개 홈 구성" 자리(지시서 202)를 위한 빈 섹션 헤더 + "준비중" 또는 202에서 채움. 201에서는 만들지 않아도 됨(202가 이어붙임).

## 4. 회귀 가드 / 비기능 요건

- **기본값 = 현행 픽셀 동일**: 아무것도 안 고르면 font-scale 1·pretendard·pink·기존 테마 → 지금과 완전 동일. 회귀 0.
- **어드민 한정**: 모든 CSS 변수 `.admin-scope` 스코프. 공개 :root·`.dark` 무변경 → 사용자 화면 100% 무영향(직접 확인).
- SSR: 초기 렌더 기본값 → 마운트 후 localStorage 반영(테마와 동일, hydration mismatch 0). localStorage 접근 try/catch.
- 신규 hex 는 `appearance.ts` 프리셋 상수에만(브랜드 변수 오버라이드용, Rule 9 — 컴포넌트에서 하드코딩 금지). 컴포넌트는 `bg-brand-600` 등 변수 클래스 유지.
- 다크에서 강조색 대비 확보(프리셋 다크쌍은 밝은 톤). 폰트 '크게' 에서도 사이드바·테이블 레이아웃 안 깨짐(육안).
- SQL·DB·API·라우트 신규 0. npm 의존 0.
