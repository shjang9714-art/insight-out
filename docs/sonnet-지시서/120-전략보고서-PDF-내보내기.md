## 배경 (David)

전략보고서 = IA 종착점. 118(워크벤치)·114(뷰어)에 이어 **내보내기**로 캡스톤을 닫는다. AGENTS §12 = "보고서 미리보기 → PDF/DOCX 다운로드". 1차는 **브라우저 인쇄→PDF 저장**(의존성 0, Vercel 안전). 서버 생성·Storage 적재(`ai_reports.file_path`)는 후속.

## 설계 결정 (Opus)

1. **인쇄 기반**: 상세 페이지에 "PDF로 내보내기" 버튼 → `window.print()`. 사용자가 브라우저 인쇄 대화상자에서 "PDF로 저장". 별도 라이브러리·라우트 불필요.
2. **셸 격리**: 인쇄 시 대시보드 헤더·사이드바·카테고리타일·플로팅미니·버튼/편집툴바가 안 나오게 `print:hidden`. 보고서 본문만 깨끗하게.
3. **인쇄 본문 보정**: 보고서 카드의 테두리/배경/그림자를 인쇄 시 제거, 텍스트는 가독 흑색. `print:` Tailwind variant 사용(globals.css 블랙리스트 selector 지양).
4. **근거 출처 포함**(§12 출처표기 필수): 인쇄물에도 근거 출처 섹션이 그대로 나오게(이미 페이지에 렌더됨 → `print:hidden` 안 붙이면 됨).

## 작업

### A. PrintButton — `src/components/reports/PrintButton.tsx` (신규, client)
```tsx
'use client'
import { Printer } from 'lucide-react'

export default function PrintButton() {
  return (
    <button
      onClick={() => window.print()}
      className="no-print inline-flex items-center gap-1.5 rounded-lg border border-border px-3 py-1.5 text-sm text-muted-foreground hover:border-brand-600/40 hover:text-brand-600 transition-colors"
    >
      <Printer className="h-3.5 w-3.5" />
      PDF로 내보내기
    </button>
  )
}
```
- `no-print` 클래스 + `print:hidden`(아래 globals 규칙). 둘 중 하나로 통일 — **`print:hidden` 권장**(Tailwind). 위 className의 `no-print`를 `print:hidden`으로 바꿔도 됨. 구현자 택1, 일관 유지.

### B. 상세 페이지 버튼 배치 — `src/app/dashboard/reports/[id]/page.tsx`
- 상단 제목 영역(뒤로가기 아래, 메타 옆)에 `<PrintButton />` 추가. 비소유자도 노출(읽기 전용 보고서도 인쇄 가능).
- 이미 있는 "뒤로가기" 링크·메타 줄에 `print:hidden` 부여(인쇄물에 네비 불필요).

### C. 셸 인쇄 숨김 — `src/app/dashboard/layout.tsx` (DashboardShell)
다음 요소 루트에 `print:hidden` 추가:
- `<DashboardHeader … />`
- 데스크톱 사이드바 래퍼(`<div className="hidden lg:block">`)
- 모바일 사이드바/오버레이 래퍼
- `<CategoryGrid … />`(타일)
- `<FloatingBriefingMini />`
또 콘텐츠 컨테이너의 좌우 패딩·그리드는 인쇄 시 단일 컬럼이 되도록 `print:block print:px-0` 등 최소 보정(레이아웃 깨지면 본문 컨테이너에 `print:max-w-none`).

### D. 본문 인쇄 보정 — `ReportEditor.tsx` & `[id]/page.tsx`
- ReportEditor의 "편집" 버튼·편집 모드 툴바 컨테이너에 `print:hidden`(편집 UI는 인쇄 제외). 렌더 뷰(`ReportMarkdown` 카드)는 인쇄 포함.
- 본문 카드(`rounded-xl border bg-card p-6`)에 `print:border-0 print:bg-white print:p-0 print:shadow-none` 추가(인쇄 여백·테두리 제거).
- (선택) `globals.css`에 인쇄 페이지 여백 한 줄: `@media print { @page { margin: 16mm } }`.
