## 2. 구현

### 2-1. L1 좌측 정렬
- `DashboardHeader.tsx` 컨테이너: `justify-center` → **`justify-start`**(좌측). `gap-10` → `gap-9`(36px) 정도로 살짝 조정(취향, 유지 가능).
- L1 그룹이 max-w-6xl 좌측에서 시작.

### 2-2. L2를 L1 그룹 중앙 아래로 (공유 폭 상수)
- L1·L2가 별개 컴포넌트이므로, **L1 그룹 폭과 동일한 폭을 공유**해 정렬한다:
  - 공유 상수 정의(예: `NAV_GROUP_WIDTH`를 `src/lib/nav` 또는 globals CSS 변수 `--nav-group-w`). L1 5개 항목(홈·AI 인사이트·기업동향·콘텐츠·전략보고서 @17px + gap-9)의 렌더 폭에 맞춘 고정값(대략 500~560px, 시각 QA로 미세조정).
  - **L1**: 항목들을 `--nav-group-w` 폭의 좌측 정렬 블록에 담기(또는 자연폭 그대로 좌측). 
  - **L2**: 페이지의 L2 컨테이너를 `max-w-6xl mx-auto` 안에서 **좌측 기준 + `width: var(--nav-group-w)` 블록**으로 감싸고 그 안에서 `justify-center`. → L2가 L1 그룹 중앙 아래에 옴.
- 대안(더 견고하나 큼): L2를 헤더로 이관해 L1과 한 flex-col 래퍼에 두면 정렬이 자동 — **범위 크므로 이번엔 공유 폭 상수 방식**. 시각 QA로 L1 중앙과 L2 중앙이 세로로 맞는지 확인.

### 2-3. 밑줄을 글자에 더 붙이기
- L1 항목: `py-3.5`(위아래 큰 패딩) → **하단 패딩 축소**(예 `pt-3 pb-1.5`)해서 `after:bottom-0` 밑줄이 글자 바로 아래(≈4~5px)에 오게.
- L2 항목: `py-2` → **`pt-2 pb-1`** 정도로 밑줄을 글자에 붙임.

### 2-4. L1↔L2 상하 간격 축소
- L2 행의 상단 여백(현재 페이지에서 L2 위 margin, 예 `mt-5`/20px)을 **`mt-2`~`mt-3`(8~12px)** 로 좁힘. (각 L2 렌더 위치의 상단 여백 조정 — AiInsightBoard·EntityTabs·contents 공통 지점, 또는 InsightViewTabs 래퍼 상단 여백.)

### 2-5. 유지
- 긴 풀폭 줄 없음, 짧은 활성 밑줄(L1 2px / L2 1.5px 중앙 틱), 무트 마젠타(`--brand-muted`), 폰트 17/15, Pretendard.
