## 배경 (페르소나 회의 결론)
홈 KPI가 4개 숫자뿐·종류별 분해·차트·드릴다운 없음. **현황판으로 교체**: 종류별 전체/당일, 검토 대기, 소스 현황, 참여(북마크), 리서치 반영을 **카드 + 차트**로 보고, **카드·차트 세그먼트를 누르면 raw 테이블**로 드릴다운.

### 결정(David)
- 차트: **Recharts**. · 오픈 수: **추적 코드 없음 → 1차는 북마크 참여로 대체, view 추적은 후속 지시서.** · raw 보기: **별도 raw 테이블 뷰 신설**(`/admin/raw`). · DB 무변경(집계는 바운디드 쿼리 + JS).

## 데이터 가능 여부(반드시 인지)
- ✅ 카테고리별 수, `collected_at` 일별, `status`(pending/published/rejected), `sources.is_active`/전체 — 실데이터.
- 🟡 **북마크 참여** = `contents.bookmark_count`(트리거 동기화) > 0 인 콘텐츠 수(`.gt('bookmark_count',0)` head count). "북마크된 콘텐츠" 카드.
- 🟡 **리서치 반영** = `ai_report_sources`(content_id not null) head count. AI보고서가 Phase 3라 **현재 0** 가능. 카드는 만들되 0 허용. RLS 에 admin SELECT 없으면(`ai_report_sources`) **선택 SQL 핸드오프**로 `create policy ... using public.is_admin()` 추가(데이터 0이라 급하지 않음 — 안 되면 카드값 `—` 표시).
- 🔴 **실제 오픈 수**: 미추적 → 이번 카드 제외(후속 지시서에서 view_count 증가 + 카드 추가).

## 작업

### 1. 패키지
- `npm install recharts`. AGENTS §18 "차트 라이브러리 = **Recharts** (결정 2026-06, 지시서 74)" 한 줄 기록.

### 2. 집계 — 서버에서 (`src/app/admin/page.tsx`, 서버 컴포넌트 유지)
기존 `metrics` 4개 블록을 아래 현황판 데이터로 확장. 모두 `Promise.all` 병렬. **카테고리 목록 상수**: `['뉴스','리포트','웹인사이트','유튜브','AI보고서']`(deprecated 제외).
- KPI head count: 총 콘텐츠 · 오늘 수집(`gte(collected_at, todayStart)`) · 검토 대기(`status='pending'`) · 활성 소스(`is_active=true`)·전체 소스 · 북마크된 콘텐츠(`gt('bookmark_count',0)`) · 리서치 반영(`ai_report_sources` content_id not null).
- 카테고리 분포(전체): 카테고리별 head count(5쿼리) → 도넛 + "총 콘텐츠" 카드 미니 분포.
- 오늘 카테고리 분포: 카테고리별 head count + `gte(collected_at, todayStart)`(5쿼리).
- 상태 분포: published/pending/rejected head count(3쿼리).
- **최근 14일 일별 추이**: `select category, collected_at from contents where collected_at >= (오늘-13일 KST 00:00)` → JS 로 `[{ date:'MM/DD', 뉴스, 리포트, 웹인사이트, 유튜브, AI보고서 }]` 14행 집계(빈 날 0 채움).
- **소스 기여 Top 10**: `select source_id, sources(name) from contents where collected_at >= (오늘-29일)` → JS group by source name → 상위 10.
- 위 두 바운디드 쿼리는 14/30일로 제한(대용량 안전). *대용량화 시 RPC/뷰로 이관 — 후속 메모.*

### 3. 현황판 UI — `src/app/admin/page.tsx`
페이지 구성(위→아래): **① KPI 카드 그리드 → ② 차트 그리드 → ③ (지시서 73의) 그룹 메뉴 카드**. ③은 73 결과 유지, 이번엔 ①②를 그 위에 추가하고 기존 "운영 현황 4카드"를 ①로 교체.
- **KPI 카드**(클릭 가능, `Link`): 각 카드 `/admin/raw?...` 로 연결.
  - 총 콘텐츠 → `/admin/raw` · 오늘 수집 → `?from=today` · 검토 대기 → `?status=pending` · 북마크된 콘텐츠 → `?bookmarked=1` · 활성 소스 → `/admin/sources` · 리서치 반영 → `/admin/raw?research=1`(없으면 비활성).
  - "총 콘텐츠"·"오늘 수집" 카드 하단에 종류별 미니 숫자(뉴스 n · 리포트 n …) 인라인.
  - 클릭 가능 카드엔 hover:brand 테두리(73 카드와 동일 토큰).

### 4. 차트 컴포넌트 — `src/components/admin/DashboardCharts.tsx` (신규, `'use client'`)
- props 로 서버 집계 JSON 받음(서버에서 직렬화 전달). **이 파일만 클라이언트**(페이지는 서버 유지 — #12).
- Recharts 4종: ①카테고리 분포 `PieChart`(도넛) ②최근 14일 `BarChart` 스택(카테고리별) ③소스 Top10 `BarChart`(가로) ④상태 분포 `PieChart` 또는 작은 `BarChart`.
- 각 차트는 `<Card>` 안. `ResponsiveContainer` 사용, 높이 240~280.
- **색**: 차트 카테고리용 **전용 팔레트 상수**(구분되는 중립 색조 — 브랜드 핑크 `#E6007E` 하드코딩 금지 #9). 브랜드 강조가 필요하면 CSS 변수 사용. 팔레트는 카테고리 키와 1:1 매핑 상수로.
- 도넛/바 **세그먼트 클릭 → 해당 raw 필터로 이동**: `onClick` 에서 `router.push('/admin/raw?category=' + encodeURIComponent(key))`(또는 status). `useRouter` from `next/navigation`.
- 라벨·툴팁 한국어, 숫자 `toLocaleString`.

### 5. raw 테이블 뷰 — `src/app/admin/raw/page.tsx` (신규, 서버 컴포넌트)
- `/admin/*` 는 미들웨어가 관리자 가드(중복 체크 금지 — AGENTS §7). 쿠키 서버 클라이언트로 조회.
- `searchParams`(Next.js 16: `await`) 파라미터: `category`, `status`, `from`(`today` → `gte(collected_at, todayStart)`), `bookmarked`(`gt('bookmark_count',0)`), `source`(source_id), `research`, `page`(기본 1, 50건/페이지).
- 쿼리: `contents` select(제목·category·status·source(name)·collected_at·published_at·view_count·bookmark_count·original_url) + 필터 적용 + `order('collected_at', desc)` + range 페이지네이션 + `count:'exact'`.
- 표: 한국어 헤더 raw 테이블(제목 링크는 `original_url` 있으면 새 탭, 없으면 텍스트), 카테고리·상태 배지, 날짜, 조회/북마크 수. 상단에 적용 필터 칩 + 총 N건 + 이전/다음 페이지 + "콘텐츠 관리에서 편집" 링크(`/admin/contents`).
- `research=1` 은 `ai_report_sources` 조인 필요 → 1차는 안내문("AI보고서 데이터 준비 중")만 표시 가능(데이터 0). 무리하면 생략.
- metadata: `title: 'Raw 데이터 | 어드민 | Insight Out'`.

## 회귀 / 주의
- 페이지(`page.tsx`)는 **서버 컴포넌트 유지**, 차트만 leaf 클라이언트(#12). 집계는 서버에서.
- 바운디드 쿼리(14/30일) 외 전수 스캔 금지. head count 는 `head:true`.
- 차트 색 브랜드 핑크 하드코딩 금지(#9) — 전용 팔레트.
- 지시서 73의 그룹 메뉴 카드 섹션은 **삭제하지 말고 현황판 아래 유지**.
- `searchParams`·`cookies()` await(Next.js 16). UI 한국어(#1).
- 북마크/리서치 카드는 데이터 0일 수 있음 → 0/`—` 깔끔히 표기(에러 아님).
