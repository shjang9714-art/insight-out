# PA01 커밋 지시 (Sonnet 세션에 복붙)

플래너 승인 완료. 아래대로 커밋·푸시한다.

---

```
[커밋 승인 — PA01]

브랜치 agent/PA01-newsletter-today 에서 커밋한다.

포함할 변경:
- src/app/api/newsletter/today/route.ts (신설)
- src/middleware.ts (publicPaths에 '/api/newsletter/today' 1행)

커밋 메시지:
---
feat: /api/newsletter/today REST — 발송된 뉴스레터를 팀즈로 (PA01)

Power Automate가 GET 한 번으로 오늘 발송된 뉴스레터(newsletter_issues.payload)를
받아 팀즈 카드로 게시하도록 읽기 전용 REST 엔드포인트를 신설한다.

- 인증: Authorization Bearer CRON_SECRET (cron/newsletter 패턴 복제)
- KST 오늘 sent_on·status='sent' issue 조회, ?date= 오버라이드
- payload.newsGroups[].cards[] → flat items(group/title/summary/insight/source/url)
- topTeaser?.headline → teaser(문자열|null)
- 미발송/구버전 payload → { sent:false, items:[] } 안전 반환
- 읽기 전용: newsletter_issues write 없음, contents 재조회·LLM 없음

middleware publicPaths에 '/api/newsletter/today' 등록 —
이게 없으면 세션 없는 요청이 /login으로 307 리다이렉트된다(원래 버그).

검증: tsc 0 / eslint 0 / build 성공 / 로컬 프로드 Supabase로
시크릿없음→401(307아님)·정답→200+실데이터·미래날짜→sent:false 확인.
---

푸시 후 origin/main으로 PR 또는 직접 머지(팀 관행대로).
merge 후: main 배포 확인 → /api/version 으로 커밋 SHA 확인.
```
