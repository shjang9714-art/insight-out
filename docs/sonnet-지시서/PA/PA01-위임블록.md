     (src/app/api/cron/newsletter/route.ts 패턴 복제)
   - 오늘(KST=now+9h) 발송 issue 조회:
     admin.from('newsletter_issues')
       .select('id, sent_on, subject, status, payload')
       .eq('sent_on', todayKST).eq('status','sent')
       .order('created_at',{ascending:false}).limit(1).maybeSingle()
     · ?date=YYYY-MM-DD 파라미터로 특정일 허용(없으면 오늘)
   - payload(PreparedNewsletterIssue) → flat items 로 변환:
     payload.newsGroups[].cards[] 순회 →
       { group:newsGroups[].label, title, summary:summaryKo??'', insight:insight??'',
         source:sourceName??'', url:originalUrl ?? detailUrl }
     · teaser = payload.topTeaser?.headline ?? null
   - 응답: { date, sent:boolean, subject, teaser, items:[...] }
   - 발송분 없으면 { date, sent:false, items:[] } (200)
   - payload 구조 없거나 비면 items:[] 안전 반환
   - 읽기 전용. newsletter_issues 에 쓰지 말 것. contents 재조회·LLM 금지.
