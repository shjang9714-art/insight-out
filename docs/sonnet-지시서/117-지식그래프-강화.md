## 배경 (David)

ego 그래프(116)를 "탐색 도구"답게 강화. 세 가지: ① 엣지 **최근성 가중**(오래된 동시언급 약화) ② 엣지 **호버 시 "함께 등장한 기사" 맥락** ③ **경쟁사 프리셋 중심** 버튼(빠른 진입). → 단순 관계도 → *지금·왜 연결됐나*까지 읽히게.

## 작업

### A. (선행) SQL — `docs/sql-handoff/117-graph-enrich.sql` (수희 선적용)
1. `entity_neighbors` 교체 — 가중치를 **최근 30일 동시언급 ×2** 합으로(반환 컬럼 동일 → 116 드롭인). 최근 관계가 두껍게.
2. `entity_pair_contents(a, b, limit)` 신규 — 두 엔티티가 함께 등장한 기사(title·collected_at). 엣지 호버용.
- `supabase/schema.sql` 두 함수 SSOT 반영(#6).

### B. 엣지 맥락 (호버) — `src/components/entities/KnowledgeGraph.tsx`
- `onLinkHover(link)` → link 있으면 **`supabase.rpc('entity_pair_contents', { p_a: centerId, p_b: 이웃id, p_limit: 5 })`** 호출(디바운스·결과 캐시 Map<이웃id, rows>).
- 작은 **툴팁/패널**: "함께 등장 N건" + 최근 기사 1~3개 제목(클릭 `/dashboard/contents/{id}`). 호버 해제 시 닫힘. (모바일은 노드/엣지 탭으로 대체 가능.)
- 엣지 두께는 weight(최근성 가중) 반영(기존 linkWidth 유지 — 값이 가중치라 자동).

### C. 경쟁사 프리셋 중심 — `KnowledgeGraph.tsx`(또는 상단바)
- 그래프 상단에 **프리셋 버튼 줄**: `entities` 중 **is_competitor** 인 것들(예: KT·SKT·삼성SDS) + (선택) mention 최상위 3~4개. 클릭 → `centerId` 그 엔티티로 설정(재중심).
- entities prop 에 is_competitor 포함(없으면 page 쿼리 select 에 추가). 경쟁사 버튼은 빨강 점 표시.
- 검색/선택(116)과 공존 — 프리셋은 빠른 진입 단축.

## 회귀 / 주의
- **신규 SQL(117) 선적용.** entity_neighbors 는 교체(드롭인, 컬럼 동일)·entity_pair_contents 신규. 미적용 시 호버 rpc 에러 → 툴팁 graceful 생략, 그래프 동작 유지.
- 호버 rpc 남발 방지: 디바운스(예 200ms) + 이웃별 캐시.
- 최근성 가중으로 weight 스케일 바뀜 — 노드/엣지 크기 정규화 점검(너무 얇/두껍지 않게).
- 데이터 의존(content_entities) 여전 — 얕으면 이웃·맥락 빈약(정상, graceful).
- 다크모드·색 토큰(#9)·UI 한국어(#1)·`any` 최소·client leaf.
- 116 ego 동작(재중심·history·미니패널) 회귀 없게.
