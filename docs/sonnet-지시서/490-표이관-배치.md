## A. 이관 규칙 (모든 파일 공통)

1. `<table>` 마크업 → `AdminTable` + `columns[]`. **셀 렌더 로직은 그대로 옮긴다.** 이 지시서에서 표시 내용을 바꾸지 마라.
2. **`state`를 명시적으로 넘긴다.** `rows.length === 0`으로 빈 상태를 추론하지 마라 — 조회 실패는 `state='error'`, 데이터 없음은 `state='empty'`.
   - 조회 실패 경로가 없는 화면(부모가 이미 처리)은 `'idle'`/`'empty'`만 써도 된다. **없는 오류 처리를 새로 만들지 마라.**
3. 직접 만든 `border-dashed` 빈 상태 → `AdminEmptyState`(`AdminTable`의 `empty*` props 경유).
4. **정렬은 기존에 있던 화면에만** 붙인다. 없던 화면에 새로 만들지 마라(범위 팽창).
5. 상한(`limit(N)`)이 있는 조회는 **`truncated`를 넘겨** 절단을 화면에 표기한다. 상한 값 자체는 이번에 바꾸지 마라.

## B. 페이지네이션 — 붙일 곳만 붙인다

전 화면에 페이징을 넣지 않는다. **행 수가 실제로 늘어나는 목록에만** 넣는다.

| 넣는다 | 근거 |
|---|---|
| `SourceManager` · `EntityManager` · `KeywordGroupManager` | 운영하며 계속 늘어난다 |
| `IssueManager` · `CrawlLogsTable` · `company-documents/page` | `limit`으로 이미 잘리고 있다 |
| `AdminContentManager` | 이미 `.range()` 사용 — **`useAdminTable`로 교체**해 URL 동기화를 얻는다 |

| 안 넣는다 | 근거 |
|---|---|
| `NewsletterHistory` · `taxonomy` · `SourceImportDialog` · `CompanyDocumentDartResolver` · `ExclusionRulesManager` · `RequestsBoard` · `CompanyDocumentSourceRegistry` · `SourceQualityManager` | 행 수가 구조적으로 제한적이거나 전량을 봐야 하는 화면 |

⚠️ `AdminContentManager`는 **자체 페이징 상태를 `useAdminTable`로 교체**하는 것이지 새로 만드는 게 아니다. 기존 필터 쿼리 키를 **바꾸지 마라**(북마크·링크가 깨진다).

## C. 선택(체크박스) — 이번에 확산하지 않는다

`AdminContentManager`의 기존 다중 선택을 `AdminTable`의 `selection` props로 **연결만** 한다. 다른 화면에 선택 기능을 **추가하지 마라** — 일괄 액션은 494 범위다.

## 범위 밖 / 금지

- ❌ 표시 내용·컬럼 구성·문구 변경. **순수 이관이다.**
- ❌ 없던 정렬·선택·필터 신설.
- ❌ `limit` 값 변경, 쿼리 로직 재작성.
- ❌ 기존 URL 쿼리 키 변경.
- ❌ 일괄 액션 구현(494) · SQL · 새 의존성.
- ❌ `AdminTable` 사용 중인 7곳 수정.
- ❌ `AdminTable` v2 props 시그니처 변경 — 부족하면 **중단하고 보고**하라.

## 검증

배치마다 아래를 돌린다.

1. 이관한 화면이 **이전과 같은 컬럼·같은 값**을 보여준다(스크린샷 전/후 비교).
2. 빈 상태가 `AdminEmptyState`로 렌더된다.
3. `limit`이 있던 화면에서 **절단 문구**가 보인다.
4. B 표의 "넣는다" 화면에서 페이지 이동·새로고침이 URL로 유지된다.
5. `AdminContentManager`의 **기존 필터 URL이 그대로 동작**하고 다중 선택·일괄 삭제가 이전처럼 동작한다.
6. `npm run lint` · `npx tsc --noEmit` · `npm run check:admin-auth` · `npm run build` 통과.

최종 보고 시 추가로:

7. `grep -rl "<table" src/components/admin src/app/admin` 결과가 **`ui/AdminTable.tsx` 하나만** 남는다.
