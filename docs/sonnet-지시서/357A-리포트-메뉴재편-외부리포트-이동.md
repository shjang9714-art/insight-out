> 대상: 구현 에이전트 · **신규 SQL 없음**(표기·라우팅만, 데이터 무이전)
> ⚠️ 읽을 것: `src/components/dashboard/DashboardHeader.tsx`(NAV_TABS·2레벨 탭) · `src/app/dashboard/contents/page.tsx`(리서치 탭) · `src/app/dashboard/reports/page.tsx`·`reports/[id]` · `src/components/analysis/InsightViewTabs.tsx`(2레벨 탭 패턴) · `src/lib/types.ts`(CONTENT_CATEGORY_LABEL) · `AGENTS.md`
> ⚠️ 로컬 diverge 주의: 상단 네비는 355-A가 건드렸을 수 있으니 **배포본(origin/main) 기준으로 재확인** 후 작업.

```
홈 · AI인사이트 · 기업동향 · 콘텐츠 · [리포트]
  콘텐츠  → 뉴스 · 유튜브 · 웹인사이트            (리서치 제거)
  리포트  → AI 리포트 · 외부 리포트 · 지식보고서   (2레벨 탭)
            ├ AI 리포트   = 현 전략보고서(ai_reports) — 표기만 개칭
            ├ 외부 리포트 = 현 콘텐츠-리서치(contents category '리서치') 이동
            └ 지식보고서  = 신규 탭(내용은 357-B에서. 이 지시서는 탭 자리+라우팅만)
```
- **경쟁사 주간 브리핑은 기업동향에 그대로 유지**(이동 안 함).

## 작업

### 1. 상단 메뉴 개칭
- `NAV_TABS`의 `전략보고서` 라벨 → **`리포트`**. 라우트는 `/dashboard/reports` 유지.

### 2. 리포트 하위 2레벨 탭 신설
- `/dashboard/reports`에 2레벨 탭(기업동향·콘텐츠가 쓰는 `InsightViewTabs` 패턴 재사용): **AI 리포트 / 외부 리포트 / 지식보고서**. `?view=ai|external|knowledge`(쿼리형, 기존 탭과 일관). 기본 `ai`.
  - `ai` = 현 reports 목록(ai_reports) 그대로.
  - `external` = **콘텐츠-리서치 목록을 여기서 렌더**(아래 3).
  - `knowledge` = 357-B 자리. 이 지시서에선 "준비 중" placeholder 또는 빈 목록(357-B가 채움).

### 3. 리서치 → 외부 리포트 이동
- `contents/page.tsx` 탭에서 **`리서치` 제거**(콘텐츠는 뉴스·유튜브·웹인사이트 3탭).
- 외부 리포트 탭은 **기존 리서치 목록 렌더를 재사용** — contents `category='리서치'` 조회·카드/리스트를 reports `?view=external`에서 표시(컴포넌트 재사용, 데이터 무이전). 표기 라벨만 "외부 리포트".
- **딥링크 리다이렉트 필수**: 기존 `/dashboard/contents?category=리서치` → `/dashboard/reports?view=external` 로 리다이렉트(연관기사·근거·북마크 링크 보호). proxy/미들웨어 또는 페이지단 redirect.

### 4. "AI 리포트" 표기 개칭
- 현 전략보고서 카드/헤더 문구·워드마크("INSIGHT REPORT"·"전략보고서 모음" 등)를 **AI 리포트** 톤으로. `ai_reports` 데이터·상세는 그대로.

## 회귀 / 주의
- **DB `content_category`는 안 건드림**(표시 레이어에서만 개칭). 메뉴 "리포트" ≠ category '리포트'(가트너·KRG) — 혼동 없게 라벨만.
- 리서치 이동으로 깨질 수 있는 내부 링크(연관기사·근거·검색 필터) 전수 점검 + 리다이렉트로 흡수.
- metadata title(`전략보고서 | Insight Out`)도 "리포트"로.
- `prefetch={false}`, 한글 URL 인코딩.
- 검증: `tsc`·ESLint·`check-prefetch`·`build`·육안(메뉴 리포트·3탭·외부리포트=리서치목록·리서치 딥링크 리다이렉트·콘텐츠 3탭). 완료보고 커밋 해시.
