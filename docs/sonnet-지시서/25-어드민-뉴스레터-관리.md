## 0. 목표
어드민이 `/admin/newsletter`에서 발송 설정(시각·요일·on/off·카드수·제목)을 관리하고, 미리보기·수동발송·발송 이력·오픈율을 확인한다.

## 1. 페이지 & 내비
- `src/app/admin/newsletter/page.tsx` 신규(서버 컴포넌트, service_role로 settings+최근 issues 조회).
- `src/components/admin/NewsletterManager.tsx` 신규(클라이언트 UI).
- `admin/layout.tsx` `NAV_ITEMS`에 `{ href:'/admin/newsletter', label:'뉴스레터' }` 추가.
- 라우트 보호는 `middleware.ts`(#34)가 이미 `role=admin` 가드 → 추가 불필요. 단 모든 mutation 서버 액션은 `requireAdmin()` 재검증.

## 2. 서버 액션 `src/app/admin/newsletter/actions.ts`
`users/actions.ts`의 `requireAdmin()` 패턴 복제. 모든 액션 첫 줄에서 admin 확인.
- `updateNewsletterSettings(input)` — `newsletter_settings`(id=1) update. 검증: `send_hour_kst` 0–23, `send_days` 1–7 subset(빈 배열 금지), `card_count` 1–10.
- `sendNewsletterNow()` — 지시서24의 `runNewsletterDispatch({ triggeredBy:'manual' })` 호출(멱등·요일 체크 건너뜀). 결과 반환.
- `getPreviewHtml()` — 현 설정 기준 선정 콘텐츠로 `buildNewsletterHtml` 생성해 HTML 문자열 반환(발송 없음, unsubscribeUrl은 더미/예시).

## 3. UI 구성 (NewsletterManager)
1. **발송 설정 카드**: on/off 토글, 시각(0–23시 select), 요일(월~일 멀티 토글 → ISO 배열), 카드 수(1–10), 제목 템플릿 input. 저장 버튼 → `updateNewsletterSettings`. 한국어 검증 메시지.
   - ⚠️ 시각 옆 안내: "현재 Hobby 플랜에선 일 1회(08:00 KST) 고정 발송됩니다. 시각 설정은 Pro 전환 후 적용." (설계서 §4 제약)
2. **미리보기**: 버튼 → `getPreviewHtml` → `<iframe srcDoc={html}>`로 렌더.
3. **수동 발송**: 버튼(확인 다이얼로그) → `sendNewsletterNow` → 결과 토스트(sent/failed/skipped).
4. **발송 이력**: `newsletter_issues` 최근 N개 표(발송일·제목·수신자수·status·trigger). 행 클릭 시 해당 issue의 `newsletter_recipients` 집계로 **오픈율**(opened/recipient_cnt) 표시.

## 4. 오픈율 — Resend Webhook (결정 1)
`src/app/api/webhooks/resend/route.ts` 신규.
- Resend 대시보드에서 webhook 등록(이벤트: `email.delivered`, `email.opened`, `email.bounced`) → 이 엔드포인트.
- **서명 검증**: Resend는 Svix 서명 사용. `svix` 라이브러리로 `RESEND_WEBHOOK_SECRET` 검증(없으면 401). (svix 미설치면 `npm i svix`.)
- 페이로드의 메시지 id로 `newsletter_recipients`(`resend_message_id` 매칭) 업데이트:
  - `email.delivered` → status='delivered', `delivered_at`.
  - `email.opened` → status='opened', `opened_at`(최초 1회만 set).
  - `email.bounced` → status='bounced', `error`.
- service_role로 update. `middleware.ts` `publicPaths`에 **`/api/webhooks/resend` 추가**(외부 호출, 비로그인).
- 신규 env: `RESEND_WEBHOOK_SECRET`(Vercel Production/Preview 스코프 등록 — 수희).
