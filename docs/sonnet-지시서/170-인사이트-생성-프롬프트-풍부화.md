## 3. 구현 — 프롬프트 튜닝 (`generate.ts`)

### 3-1. `card_headline` — 끌리되 사실 기반
현행 "과장·낚시·물음표 금지, 짧고 강렬(20자 내외)" 을 아래로 교체:
- **목표**: 밋밋한 요약 제목이 아니라, **읽고 싶게 만드는 에디토리얼 헤드라인.** 내부 도구지만 "안 끌리면 안 들어온다"(David).
- **허용(끌림 장치)**: 구체 수치·주체·변화폭을 앞세운 긴장감, 능동적 동사, 대비/전환 프레이밍. 길이 **공백 포함 24자 내외**(살짝 여유).
- **금지(정직성 가드)**: 허위·왜곡·근거 없는 단정·선정적 낚시. 사실에 없는 과장 금지. 물음표는 남용 금지(정말 효과적일 때만). — **호기심은 "구체성과 판돈"으로, 선정성으로가 아님.**
- **예시(가이드, 프롬프트에 2~3개 포함)**:
  - 밋밋 "AI 데이터센터 투자 확대" → 끌림 "AI 데이터센터, 전력이 발목 잡는다"(사실: 전력 병목이 기사에 있을 때만)
  - 밋밋 "삼성전자 반도체 동향" → 끌림 "삼성, 광주에 반도체 클러스터 건다"
  - (판돈·구체 주체·동사 살리되 기사 근거 내에서)

### 3-2. `implication`(시사점) — 2~3문장 구체화
- "1~2줄" → **"2~3문장, 구체적으로"**: ① 이 동향이 LG U+ B2B(엔터프라이즈/공공/AICC·AIDC 등)에 **왜 중요한지**, ② **기회 또는 리스크**를 명시, ③ 가능하면 **어떤 사업·행동과 연결**되는지. 일반론·한 줄 요약 금지.
- 여전히 사실 기반(기사 근거). 과설명·환각 금지 — 근거 밖 단정 금지.

### 3-3. `headline`(분석 한 줄) — 유지 또는 소폭
- 분석가 톤 1줄 유지(169 카드의 "핵심" 리드). 필요 시 "무슨 일이 일어났나"를 조금 더 분명히. 과확장 금지(card_headline·implication과 역할 구분).

### 3-4. 두 프롬프트 동기화
- `SYSTEM_PROMPT`(산업)·`COMPANY_SYSTEM_PROMPT`(기업) **양쪽 동일 원칙** 반영(기업 쪽은 경쟁/협력/위협 관점 유지).
- 출력 JSON 스키마 문구는 그대로(`{headline, card_headline, implication, citations}`). `parseLlmOutput` 무변경.

## 4. 회귀 가드 / 비기능 요건

- **스키마·DB·파서 무변경** — 프롬프트 텍스트만. 기존 카드 표시(169) 그대로, 내용만 상향.
- 정직성: 어그로 허용은 **사실 기반 한정**. 허위·과장·낚시 명시적 금지 문구 유지(수위만 조정 — "밋밋함 지양 + 왜곡 금지" 균형).
- LLM 미연결 시: 카드 생성은 원래도 LLM 필수 → 동작 변화 없음(규칙 폴백은 브리핑/이슈 별개).
- 기존 카드는 **다음 생성 cron(야간)부터** 새 톤 반영(소급 재생성은 범위 밖, 필요 시 어드민 재생성).
- 하드코딩 hex/신규 의존성 0.

## 5. 검증

1. `npx tsc --noEmit` 0 / `npx eslint` 0 (프롬프트는 문자열이라 타입 영향 적음 — 빌드 확인).
2. 프롬프트 문구 리뷰: card_headline 어그로+정직성 균형, implication 2~3문장 지시 반영, 두 프롬프트 동기화.
3. **(LLM 키 있을 때)** 샘플 토픽 1건 생성 → card_headline 끌림·사실성, implication 2~3문장 구체성 육안 확인. 키 없으면 이 단계는 후속(라이브)로.
4. 스키마/파서 무변경 확인(회귀 0).
