## 2. 구현 (파일 1개: `FloatingBriefingMini.tsx`)

### 2.1 빈-오디오일 때 중앙 버튼 = 스크립트 열기 (🚫 제거)
중앙 원형 휠의 재생 버튼을, **`hasAudio` 여부로 분기**한다.
- **`hasAudio` 참**: 지금 그대로(재생/일시정지 `togglePlay`).
- **`hasAudio` 거짓 & `briefing` 있음**: 버튼을 **"스크립트 보기" 동작**으로. `disabled` 를 걸지 않고(🚫 금지), `onClick={() => setScriptOpen(v => !v)}`, 아이콘을 `FileText`(lucide, 신규 import), `aria-label="스크립트 보기"`. 커서는 pointer.
  - 스타일: `cursor-not-allowed`·회색 죽은 버튼 대신 **활성 가능한 보조 톤**(예: `bg-zinc-900 text-brand-500` 또는 outline 느낌) — "누를 수 있는 것"으로 보이게.
- **`briefing` 없음/로딩**: 기존대로 비활성(이건 정당한 disabled).

### 2.2 안내 문구 전면화 — "오디오 준비 중 · 스크립트로 보기"
- LCD 영역의 문구(238행)를 **"오디오 준비 전 · 스크립트 제공" → "오디오 준비 중 · 스크립트로 보기"** 로 교체(413 §6 문구).
- 이 안내를 **눈에 띄게**: `text-zinc-500` 톤을 살짝 올리거나(예: `text-zinc-400`) 아이콘(FileText)과 함께. 과하지 않게, 그러나 "왜 재생이 안 되지"가 안 생기게.
- `briefingScript` 가 없을 때(스크립트조차 없음)의 문구도 확인: "오디오·스크립트 준비 중" 정도로 죽지 않게(현재는 아무것도 안 뜰 수 있음 — 확인 후 최소 한 줄).

### 2.3 진행 바 — 빈-오디오일 때 정리(선택, 저비용)
- 오디오 없을 때 `--:--` 진행 바가 떠 재생 가능처럼 오해될 수 있다. **`hasAudio` 거짓이면 진행 바를 숨기거나** 자리만 흐리게. 과하면 생략하고 §6 에 기록.

### 2.4 🔴 `togglePlay` Promise 처리(별 사안이지만 같은 파일이라 함께)
```ts
function togglePlay() {
  if (!audioRef.current) return
  if (playing) { audioRef.current.pause(); setPlaying(false); return }
  const p = audioRef.current.play()
  setPlaying(true); setPlaybackActive(true)
  if (p && typeof p.then === 'function') {
    p.catch(() => {
      // 재생 거부(자동재생 정책·네트워크 등) → 멈춘 UI 복구
      setPlaying(false)
      // setPlaybackActive 는 필요시 false 로(미니 바가 헛뜨지 않게)
    })
  }
}
```
- 실패 시 **UI 를 재생 상태로 남기지 않는다.** 미니 바(412, `playbackActive`)가 재생도 안 되는데 뜨지 않게 `catch` 에서 정리.
- ⚠️ 성공 경로·미니 바·`preload='none'`(391) **동작 무변경.** 실패 복구만 추가.

### 2.5 하지 말 것
- **오디오 조회·`preload='none'`·미니 바(412)·전역 지속·데스크톱 우하단 동작 무변경.** 배치·분기·문구·실패복구만.
- 없는 오디오를 억지로 만들거나 자동 재생 시도 금지.
- `briefing` 조회 로직·타입 무수정.
- 데스크톱/모바일 위치 클래스(411/412) 무너뜨리지 않기.

## 3. 회귀 가드
1. **오디오 있음**: 재생/일시정지 그대로, 진행 바·미니 바(412)·전역 지속 정상.
2. **오디오 없음 + 스크립트 있음**: 중앙 버튼이 **🚫 아님** — 누르면 스크립트가 펼쳐진다. "오디오 준비 중 · 스크립트로 보기" 문구가 보인다.
3. **오디오·스크립트 둘 다 없음**: 죽지 않고 최소 안내가 뜬다(빈 화면 아님).
4. **재생 실패**(거부): UI 가 재생 상태로 멈추지 않는다(`catch` 복구). 미니 바 헛뜸 없음.
5. `briefing` 없음/로딩: 기존 비활성·스켈레톤 그대로.
6. 데스크톱 우하단 카드·모바일 위치(411/412) 회귀 없음.
7. `preload='none'` 유지(391 회귀 금지).
