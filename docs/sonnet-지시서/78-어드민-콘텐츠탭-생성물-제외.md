## 배경
사용자 카드 콘텐츠 모델(설계 doc) = 수집(외부 시그널) / 생성(AI분석·전략보고서) / 개인(아카이브) 3평면. **생성물(AI분석·전략보고서)은 `content_category` enum·`contents` 테이블에 없다.** 그런데 어드민 콘텐츠 관리 카테고리 탭이 `CATEGORY_DEFS` 전체를 써서 `AI분석`·`전략보고서` 탭이 노출되고, 누르면 항상 빈 결과(75에서 `__none__` 가드로 에러만 막음). **수집 카테고리만 탭으로 남긴다.** (사용자 화면 카드는 이번 범위 밖 — 변경 없음.)

## 작업

### 1. `categories.ts` — 생성물 플래그
- `CategoryDef` 에 `generated?: boolean` 추가.
- `id: 'ai-analysis'`(AI분석)·`id: 'strategy'`(전략보고서) 두 def 에 `generated: true`.
- (선택) 헬퍼 `export const COLLECTED_CATEGORY_DEFS = CATEGORY_DEFS.filter(d => !d.generated)`.

### 2. `AdminContentManager.tsx` — 탭에서 생성물 제외
- `categoryTabs` 구성 시 `CATEGORY_DEFS` → **`!d.generated` 만**(또는 `COLLECTED_CATEGORY_DEFS`). 결과 탭: 전체 · 뉴스 · 리서치 · 웹인사이트 · 유튜브.
- 나머지(목록 필터 `toDbCategories`·소스타입 매핑·편집 모달 `EDIT_CATEGORY_OPTIONS`)는 75 그대로 — 변경 없음.

## 회귀 / 주의
- DB·enum 무변경. 사용자 `CategoryGrid`(카드 타일)는 **건드리지 않음**(여전히 CATEGORY_DEFS 전체 사용 — 사용자 화면은 이번 범위 밖).
