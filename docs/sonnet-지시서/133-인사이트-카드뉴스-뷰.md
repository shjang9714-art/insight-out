## 배경

현재 AI 인사이트 카드(`InsightCardsSectionClient`)는 **밀도 높은 "분석 카드"**(topic 배지 + headline + 시사점 + 근거 인용 목록 + 보고서 링크, 2열 그리드) — **정독용**으로는 좋으나 **훑어보기엔 무겁다.** David 결정: 인사이트는 "한입 정보" = **큰 글자 에디토리얼 카드뉴스**가 기본 시각화. 보고서는 깊이 필요할 때만 별도(인사이트→보고서 강제 X).

**원칙(브레이크)**: 기존 분석 카드 **파괴하지 않고** "카드뉴스" 뷰를 **토글로 추가**(분석 뷰는 대체 보존). **절제된 에디토리얼 톤** — 큰 타이포·여백·단일 액센트. **유아틱 금지**: 과장 모션·이모지·그라데이션·네온 금지. WCAG AA·디자인가이드(타입 스케일·lh 1.7·의미색 최소) 준수. 신규 데이터·SQL 없음. 렌즈(132) 그대로 적용.

데이터(insight_cards): `topic` · `headline`(not null) · `implication` · `citations`(jsonb: quote+content_id) · `source_content_ids` · `period_start/end` · `scope` · `status`.

## A. 뷰 토글

- `InsightCardsSectionClient`에 뷰 상태 추가: `const [view, setView] = useState<'cardnews'|'analysis'>(...)`, **localStorage `io:insight-view`**(기본 **`cardnews`**). 마운트 시 복원.
- 섹션 상단(렌즈 스위처 근처)에 작은 **세그먼트 토글 "카드뉴스 / 분석"**(기존 card/list 토글 톤·아이콘 재사용, 하드코딩색 금지).
- `analysis` → **기존 그리드 그대로**(현재 코드 보존·회귀 0). `cardnews` → B 렌더.
- **렌즈 필터/정렬/배지 로직(visibleGroups 계산)은 두 뷰 공유**(중복 금지) — 계산 결과를 받아 뷰만 분기.

## B. 카드뉴스 렌더 — `src/components/analysis/InsightCardNewsList.tsx` (신규)

기간 그룹 헤더(기존 `formatPeriod`·최신 배지)는 유지. 각 인사이트 = **큰 에디토리얼 카드를 1열 세로 스택**(훑어 내려보기). 카드 구조:

1. **키커(kicker)**: `topic · 기간`(작은 대문자 라벨, `text-[11px] uppercase tracking-wide text-muted-foreground`). + 우측 **"내 관련"** 배지(렌즈 매칭 시, 132 톤).
2. **헤드라인(주인공)**: `headline`을 **큰 글자**(`text-2xl sm:text-3xl font-bold leading-tight tracking-tight text-foreground`). 카드뉴스의 핵심.
3. **데크(시사점)**: `implication` 한 줄(`text-base text-muted-foreground leading-relaxed`, `line-clamp-2`). 없으면 생략.
4. **푸터(저채도·작게)**: 
   - **대표 근거 1건**: citations[0] 있으면 그 제목 링크(`/dashboard/contents/{content_id}`), 없으면 source_content_ids[0]. 
   - **"근거 N" 펼치기**: 버튼(`aria-expanded`) 클릭 시 나머지 인용/출처 목록 인라인 노출(기존 분석 카드의 근거 마크업 재사용). 기본 접힘.
   - **"보고서로 만들기"**: 보조 텍스트 링크(헤드라인 액션 아님 = 인사이트→보고서 강제 안 함). 기존 href 유지.
- **카드 컨테이너**: `rounded-2xl border bg-card p-6 sm:p-8`, 넉넉한 여백·세로 간격(`space-y-3`), 렌즈 매칭 시 `border-brand-600/20`. **단일 액센트(brand)만**, 카테고리 컬러·그라데이션·이모지 금지.
- **빈 상태**: 기존 문구 재사용(렌즈/전체 분기).

## C. 접근성·반응형
- 헤드라인은 `h3`(시맨틱), 근거 펼치기는 `<button>` + `aria-expanded`/`aria-controls`.
- 모바일: 카드 패딩·헤드라인 스케일 반응형(`text-2xl sm:text-3xl`), 1열 유지.
- 다크모드 토큰 정합(시맨틱 토큰만).
