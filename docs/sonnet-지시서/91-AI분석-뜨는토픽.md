## 배경 (David, 부록 3-1/트렌드)
AI 분석 ② = **이번 주 뜨는 토픽**. `matched_groups`(토픽)를 주 단위로 집계해 **직전 주 대비 급증**한 토픽을 보여줌(트렌드 감지). 정형 소스 diff(채용·가격 변화 알림)는 스냅샷 인프라 필요 → **후속**. v1 = 급증 토픽.

## 작업 — `dashboard/ai-analysis/page.tsx` 에 위젯 추가 (서버 집계)

### 1. 집계 데이터(바운디드, SQL 없음)
- 인사이트 카드 조회와 **병렬**로: `contents` published, `collected_at >= (오늘-13일 KST)`, select `matched_groups, collected_at`, limit 1000.
- JS 집계:
  - 이번 주 = 최근 7일(오늘-6일~오늘), 직전 주 = 그 이전 7일(오늘-13일~오늘-7일). KST 일 기준(74의 `+9h` 패턴 재사용).
  - 각 행의 `matched_groups` 펼쳐 그룹별 카운트를 두 윈도우로 누적: `cur[group]`, `prev[group]`.
  - 급증 점수: `delta = cur - prev`, `changePct = prev>0 ? Math.round((cur-prev)/prev*100) : (cur>0 ? null /*신규*/ : 0)`.
  - **상위 N(기본 6)**: `cur > 0` 인 그룹 중 (신규(prev=0)·증가) 우선, `changePct` desc(신규는 맨 위 묶음), 동률은 `cur` desc. 감소만 하는 토픽은 제외(또는 하단 1~2개만 "식는 토픽" 선택).

### 2. 위젯 렌더 (인사이트 카드 위/옆)
- 섹션 "이번 주 뜨는 토픽"(아이콘 `TrendingUp`). 컴팩트 목록:
  - 각 행: 토픽명 · `cur`건 · **▲{changePct}%**(증가, 초록) / **NEW**(신규, 강조) / 하락은 회색 ▼.
  - 토큰 색(#9), Recharts 불필요(텍스트/막대 미니로 충분 — 과하면 생략).
- 데이터 0이면 위젯 숨김(또는 "집계할 데이터가 부족합니다").
- (드릴다운) 토픽 클릭 → 토픽 타임라인은 ③/후속에서. v1은 표시 전용(또는 검색으로 임시 연결은 선택).

### 3. 배치/성능
- 14일·limit 1000 바운디드. matched_groups 만 select(가벼움). 인사이트 카드 쿼리와 `Promise.all`.

## 회귀 / 주의
- DB·SQL 무변경. 대용량화 시 집계 RPC/뷰 이관은 후속(74와 동일 메모).
- `matched_groups` 비어있는 콘텐츠는 집계 제외(기존 태깅 의존). 태깅 적으면 위젯도 빈약 — 데이터 채우면(86 재수집) 개선.
- KST 일 경계는 74 `+9h` 헬퍼 패턴과 일치시킬 것(불일치 금지).
- 서버 컴포넌트 유지. UI 한국어(#1)·토큰 색(#9)·lucide.
