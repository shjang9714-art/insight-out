# 지시서 235 — 내비 프리미엄(크리스프 도트, 밑줄 제거)

목표: 내비의 "탁한 마젠타 밑줄"을 없애고 **잉크 대비 + 활성 앞 작은 선명 브랜드 도트**로 프리미엄·모던 톤을 만든다(방향 C). 배치(L1 좌측 / L2 L1중앙 아래)·폰트(17/15)·간격은 233 유지.

범위(David 선택: C). 내비 활성 표현·색만 변경. SQL 없음.

---

## 1. 현행 진단 (233 반영 상태)
- **L1** `DashboardHeader.tsx`: 항목 `pt-3 pb-1.5 text-[17px] font-medium ... after:h-[2px]`, 활성 `text-foreground after:bg-brand-muted`(무트 마젠타 밑줄), 비활성 `text-muted-foreground after:bg-transparent hover:after:bg-border`. 컨테이너 `justify-start gap-9`.
- **L2** `InsightViewTabs.tsx`: 항목 `pt-2 pb-1 text-[15px] ... after:left-1/2 after:w-4 after:-translate-x-1/2 after:h-[1.5px]`, 활성 `text-foreground after:bg-brand-muted`(짧은 무트 밑줄), 비활성 `text-muted-foreground`.
- 브랜드 토큰: 선명 브랜드색 `brand-600`(로고색 계열) 존재. `--brand-muted`(#A83E63)는 "오늘 업데이트"(227)에도 쓰이므로 **토큰 자체는 유지**, 내비 밑줄 용도만 제거.

## 2. 구현

### 2-1. L1 (DashboardHeader nav 항목)
- **밑줄 제거**: `after:*` 관련 클래스(after:absolute/bottom-0/left-0/right-0/h-[2px]/bg-*) 전부 삭제.
- **리딩 도트 슬롯**(정렬 흔들림 방지): 각 항목을 `inline-flex items-center gap-2`로, 라벨 앞에 도트 span 항상 렌더:
  - 활성: `<span class="h-[5px] w-[5px] rounded-full bg-brand-600">`
  - 비활성: 같은 크기 `bg-transparent`(공간 유지).
- **색 대비**: 활성 `text-foreground font-medium`, 비활성 `text-muted-foreground`(더 밝게 원하면 `text-muted-foreground/70`). hover 시 `text-foreground`.
- **자간**: 컨테이너 또는 항목에 `tracking-[-0.01em]`(살짝 tight, 프리미엄).
- 패딩: 밑줄 없으니 `pt-3 pb-1.5` → 위아래 균형 `py-2.5` 정도로(취향, 라벨 세로 중앙).

### 2-2. L2 (InsightViewTabs 항목)
- **밑줄 제거**: `after:*` 전부 삭제.
- **리딩 도트 슬롯**: 라벨 앞 도트 span 항상 렌더 — 활성 `h-[4px] w-[4px] rounded-full bg-brand-600`, 비활성 `bg-transparent`.
- 활성 `text-foreground font-medium`, 비활성 `text-muted-foreground hover:text-foreground`. `tracking-[-0.01em]`.
- count 표시(콘텐츠 탭)는 유지하되, 활성 카운트 색을 `text-brand-muted` → `text-muted-foreground`(도트가 브랜드 포인트 담당, 카운트는 뉴트럴).

### 2-3. 유지
- L1 좌측(justify-start)·L2 L1중앙 아래(`w-[var(--nav-group-w)]` + `-mt-3`), 폰트 17/15, gap-9/gap-6, 유틸바·로고, `--brand-muted` 토큰(오늘 업데이트용).

## 3. 회귀 가드
- 리딩 도트 슬롯을 활성/비활성 모두 렌더(투명) → **활성 전환 시 가로 위치 흔들림 없음**.
- 활성 판정·전환·라우팅 동작 불변.
- 세 L2 섹션(AI인사이트·기업동향·콘텐츠) 동일 적용.
- 라이트/다크 모두: `brand-600` 도트가 양쪽에서 선명하게 보이는지(다크에서 너무 튀면 밝기 미세조정). 잉크(text-foreground) vs 비활성(text-muted-foreground) 대비 확인.
- 콘텐츠 카운트 정상.
