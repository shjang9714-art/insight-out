## 배경 (David)

112의 "상위 60노드 한꺼번에" 전역 그래프는 (1) 데이터 얕으면 노드·엣지가 안 떠 비어 보이고, (2) 떠도 헤어볼이라 해석 불가. David 제안 = **하나의 키워드/엔티티를 중심에 두고 그 관계도만** 그리기 → 더 직관적·강건·"인사이트 따라가기".

## 설계 결정 (Opus, David 승인)

- 그래프 = **ego 네트워크**: 중심 엔티티 1개 + 공기출현 이웃(상위 N) + 중심↔이웃 엣지. (전역 그래프 폐기.)
- **검색/선택**으로 중심 지정, **이웃 클릭 → 그 노드로 재중심**(탐색). 빈 검색 시 기본 중심 = mention 최상위 엔티티.
- 이웃 = `entity_neighbors` RPC(min_weight 1 — 얕은 데이터에서도). 온디맨드(중심 바뀔 때마다 호출).

## 작업

### A. (선행) SQL — `docs/sql-handoff/116-entity-neighbors.sql` (수희 선적용)
- `entity_neighbors(p_entity_id, p_limit, p_min_weight)` RPC. `supabase/schema.sql` 반영(#6).

### B. ego 그래프 컴포넌트 — `src/components/entities/KnowledgeGraph.tsx` (개편)
- props 변경: 더 이상 전역 nodes/links 받지 않음. 대신 **초기 중심 엔티티(들) + 엔티티 검색 목록**(또는 검색은 클라에서 호출).
- 상태: `centerId`(현재 중심). 변경 시 `supabase.rpc('entity_neighbors', { p_entity_id: centerId, p_limit: 20, p_min_weight: 1 })` → 이웃 entity_id+weight → 이웃 엔티티 메타 조회(`entities` in 이웃ids: canonical_name·type·is_competitor·mention_count).
- 그래프 데이터: 노드 = 중심 + 이웃, 엣지 = 중심↔각 이웃(weight 두께). force-graph-2d 렌더(112 스타일 재사용: 타입색·크기·라벨).
- **중심 노드 강조**(테두리/크게), 이웃 클릭 → **centerId = 그 이웃**(재중심, 재조회) = 따라가기. 빈 곳/뒤로 → 이전 중심(선택: 히스토리 스택).
- 미니 패널(중심 엔티티: 이름·타입·mention·"상세 보기 →" `/dashboard/entities/{id}`). 타입 필터 범례 유지.
- 이웃 0 → "이 엔티티와 함께 등장한 다른 엔티티가 아직 없습니다(수집 누적 시 생성)".

### C. 검색/선택 + 초기 중심 — `src/app/dashboard/entities/page.tsx` · `EntitiesPageClient.tsx`
- 그래프 뷰 상단에 **엔티티 검색/선택**(이름·동의어 검색 → 선택해 중심 설정). EntityBrowse 의 검색 패턴 재사용 가능.
- 초기 중심 = `entities` mention_count 최상위 1개(서버에서 전달). 없으면 빈 안내.
- [그래프|목록] 토글은 유지. 목록(EntityBrowse)에서 항목 클릭 시 그래프로 그 엔티티 중심 전환(선택).

## 회귀 / 주의
- **신규 SQL(116) 선적용.** 미적용 시 rpc 에러 → "관계 데이터 없음" graceful.
- **데이터 의존**: content_entities 가 있어야 이웃이 나옴 — 99 백필 + 크롤/PDF 누적 필요. min_weight 1 로 최대한 노출. (얕으면 이웃이 적은 게 정상.)
- 112의 전역 60노드 조회·co-occurrence(전역) 의존 제거 — entity_cooccurrence RPC(112)는 미사용화(유지 가능, ego는 entity_neighbors 사용).
- force-graph width: 컨테이너 ResizeObserver 유지(112). 높이 고정(예 520~560).
- 다크모드 색(ENTITY_TYPE→hex), 경쟁사(is_competitor) 빨강 강조 유지.
- 노드 클릭 목적지/상세 = `/dashboard/entities/{id}`(102) 재사용.
- UI 한국어(#1)·색 토큰(#9)·`any` 최소·client leaf.
