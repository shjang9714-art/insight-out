# 지시서 262-2 — 로그인 UI를 프리뷰 HTML에 1:1 정합 + 세로 스크롤 0 하드보증

> David 결정: **현행 로그인 구조는 무시**하고, 마지막에 전달한 프리뷰 HTML(`login_preview.html`, 첨부)을 **UI·디자인 단일 기준(source of truth)**으로 삼는다. 262/262-1의 논의는 배경일 뿐, **최종 픽셀 기준은 프리뷰**다. 세로 스크롤은 **모든 화면폭에서 절대 0**.

목표: 로그인 페이지(`page.tsx`·`LoginCard.tsx`·`BulbScene.tsx`·`globals.css`)를 프리뷰 HTML과 **시각적으로 동일**하게 만든다. 기능(Supabase OTP 2단계 + 관리자 Google)은 현행 `LoginCard` 로직 그대로 유지 — **로직 변경 금지, 마크업/클래스만 프리뷰에 맞춘다.**

전제: 프리뷰 = `login_preview.html`. 현행 워킹트리는 이미 프리뷰와 근접(그라디언트·키프레임·SVG·카드 동일) → **대부분 정합 확인 작업**이며, 어긋난 값만 프리뷰 기준으로 교정한다.

---

## 0. 프리뷰에서 제외할 것 (개발용 보조물)
- 프리뷰 하단 `.stepper`(1단계/2단계 토글 버튼)와 `<script>show()`는 **프리뷰 데모용** — 실제 페이지에 넣지 않는다(단계 전환은 LoginCard 상태로 처리).
- 프리뷰의 OTP 하드코딩 값(`value="482913"`, `hong@lguplus.co.kr`, `코드 재전송 (24s)`)은 예시 — 실제는 상태/쿨다운 바인딩.
- CSS의 `.io-bulb-lit`/`.io-bulb-lit2`는 프리뷰 마크업에서 미사용 → 이식하지 않는다(현행에도 없음, 정상).

## 1. 페이지 컨테이너 · 그리드 (`page.tsx` + `.io-login`)
프리뷰 값 기준(어긋나면 교정):
- `.io-login`: 라이트 컴포지션(다크 무관), **flex 중앙정렬**, `overflow:hidden`, 패딩 **`40px 64px`**(현행 `lg:px-12`=48px → **`lg:px-16`(64px)**로 교정), 높이 뷰포트 고정.
  - 배경 그라디언트: 프리뷰 3중(radial 골드 32%/52% + radial 라벤더 12%/18% + linear 120deg) — **현행 globals.css와 동일, 유지**.
- 그리드: `grid-cols-[minmax(0,1.55fr)_minmax(0,460px)]`, **gap 64px**(`lg:gap-16`), `max-w-[1500px]`, `items-center`, `mx-auto`. (현행 일치 — 확인만.)

## 2. 좌측 히어로 (`page.tsx`)
- `section.hero`: `relative flex flex-col`, **`lg:h-[calc(100vh-5rem)]`**(=100vh-80px, 프리뷰 `calc(100vh-80px)`), 좌상단 정렬(`lg:items-start lg:text-left`).
- `.hero-copy`: `z-10 max-w-2xl`(42rem).
  - 헤드라인(실제 DOM 텍스트): `흩어진 인텔리전스를 <br> 하나의 흐름으로,` — `font-extrabold tracking-[-0.045em] text-[#0f244d]`, `clamp(34px,3.6vw,52px)`, `line-height:1.08`.
  - 서브: `Intelligence in. Insight out.` — italic, `text-slate-400`, 20px(`sm:text-xl`).
  - 설명: `뉴스, 리포트, 영상, 데이터를 모아 <br> 실행 가능한 인사이트로 전환합니다.` — `text-slate-500`, 17px, `leading-relaxed`.
- **씬 래퍼(세로 스크롤 0 핵심)**: `lg:absolute lg:top-[54%] lg:left-[49%] lg:w-[113vw] lg:max-w-none lg:-translate-x-1/2 lg:-translate-y-1/2` (모바일: `mx-auto mt-4 w-full max-w-[840px]`).
  - **절대배치라 레이아웃 높이에 미기여 → 필드/씬이 커도 세로 스크롤 불발생.** `main`의 뷰포트 고정 높이 + `overflow-hidden`이 화면 밖을 클립.

## 3. BulbScene (`BulbScene.tsx`) — 프리뷰 SVG와 1:1

- 구성: bulb aura(io-glow-pulse) / flow line 11 / streak 4 / orb 11(animateMotion, io-anim) / comet head 4 / twinkle 4. `io-extra`(작은 orb) 모바일 숨김.
- 컨테이너 `.io-anim-layer` `pointer-events:none`(globals.css) — 폼 조작 무방해.

## 4. 로그인 카드 (`LoginCard.tsx`) — 프리뷰 카드와 1:1 (로직 불변)
프리뷰 값 대조(어긋나면 클래스만 교정, **핸들러/상태/Supabase 호출은 손대지 않음**):
- 카드: `rounded-[30px] border-slate-200/70 bg-white/95 p-10 backdrop-blur-sm shadow-[0_40px_90px_-30px_rgba(24,39,75,0.30)]` (프리뷰 padding 40px=`p-10`; 현행 `p-8 sm:p-10` → 데스크톱 `p-10` 확인).
- 헤드: 중앙정렬, 타이틀 `Insight Out` `text-[26px] font-extrabold`, 골드 언더바(30×3px, radius-full, 프리뷰 그라디언트), 캡션 `사내 이메일로 로그인하세요`↔`메일로 받은 인증 코드를 입력하세요`(step 바인딩).
- 1단계: 라벨 `회사 이메일`, 메일아이콘(좌 44px 패딩=`pl-11`), input `h-12 rounded-xl` placeholder `name@lguplus.co.kr`, 힌트 `사내 이메일(@lguplus.co.kr)로 로그인하세요`, CTA `인증 코드 받기` (`h-12 rounded-xl bg-gradient-to-b from-[#233052] to-[#131c33]`, `shadow-[0_10px_24px_-10px_rgba(19,28,51,0.55)]`).
- 2단계: 라벨 `인증 코드`, OTP input `h-14 rounded-xl text-center text-[24px] font-bold tracking-[0.5em]` placeholder `······`, 힌트 `<b>{email}</b> 로 6자리 코드를 보냈습니다`, CTA `확인`, 액션행 `코드 재전송 ({n}s)`(쿨다운) + `이메일 변경`.
- 관리자행: `border-t` 위, `관리자는 Google로 로그인` + 멀티컬러 Google 아이콘(저강조).

> 프리뷰 OTP 높이는 56px, 현행은 `h-14`(56px) — 일치. CTA 그라디언트/그림자/언더바 그라디언트 값 모두 프리뷰와 현행 동일(확인만).

## 5. 세로 스크롤 0 — 하드 검증 (이 지시서의 최우선)
- **모든 폭에서 `document.scrollHeight === document.documentElement.clientHeight`**(세로 스크롤 없음) + 가로 스크롤 없음.
- 검증 해상도: **1280×800 / 1440×900 / 1536×864 / 1920×1080 / 2560×1440**. 하나라도 세로 스크롤이 생기면:
  1) 씬 래퍼가 `lg:absolute`로 유효 분리됐는지(레이아웃 높이 미기여), 2) `main`이 뷰포트 높이 고정 + `overflow-hidden`인지, 3) hero `lg:h-[calc(100vh-5rem)]`가 카피+여백보다 큰지 확인.
- 2560 등 초광폭에서 `113vw` 씬이 가로 넘침 → `overflow-hidden`으로 클립되어 **가로 스크롤도 없어야** 한다.

## 6. 회귀 가드
- OTP 흐름(`signInWithOtp`→`verifyOtp`, 6자리 자동제출, 30s 쿨다운, 이메일 변경) 및 관리자 Google(`signInWithOAuth`→`/auth/callback`) **동작 불변** — 마크업/클래스만 조정.
- `.io-login`은 항상 라이트(다크 토글 무관).
- 애니메이션 레이어 `pointer-events:none` — 폼 클릭/입력/탭 무방해.
- 라우팅·미들웨어·`/auth/callback` 변경 없음.
- `prefers-reduced-motion`: `.io-anim` 숨김, glow/twinkle 정적 유지.
- 이미지 가장자리 feather로 배경과 자연 블렌드 — 딱딱한 사각 경계/세로 띠 보이면 asset 문제(262-1 §4), 이번 범위 아님(보이면 보고).
