## 배경 (David)

AI 분석 메뉴 ④ — **경쟁사(KT/SKT/삼성SDS 등) 움직임을 모아 보고, 각 기사의 논조(긍정/중립/부정)를 LLM 태그로 표시**한다. 키워드 맵의 경쟁사 색 강조(94)는 이미 있음. 이번엔 **경쟁사별 동향 섹션 + 논조 배지**를 신설.

## 설계 결정 (Opus, 확정 — 임의 변경 금지)

1. **경쟁사 식별 = `keywords.is_competitor = true` 등록분.** (어드민 키워드 관리에서 KT/SKT/삼성SDS 등 등록.) 사용자 워치리스트(93)와 **별개**. `matched_keywords` 에 그 이름이 담기므로(94 색 강조와 동일 메커니즘) 배열 overlap 으로 매칭.
2. **논조 채우기 = 어드민 온디맨드 백필 endpoint.** 크롤타임 자동 분석은 **하지 않음**(LLM 키 부족 → David 가 실행 시점 통제). 캡으로 호출량 제한. (크롤타임 통합은 후속 백로그.)
3. **논조 의미 = 기사가 경쟁사 움직임을 시장 톤으로 어떻게 다루는지.** 긍정=호재/성과/성공적 평가, 부정=악재/문제/리스크, 중립=사실 전달·혼재. (LGU+ 입장 "위협도"가 아님 — 담당자가 해석.)
4. **`contents.sentiment`** 컬럼은 범용(nullable), **모집단은 경쟁사 기사로 한정**해 채움.

## 작업

### 1. (선행) SQL — `contents.sentiment`
- `docs/sql-handoff/96-content-sentiment.sql` **먼저 커밋·푸시**(수희 적용). `supabase/schema.sql` 의 contents 정의에 `sentiment text check (sentiment is null or sentiment in ('긍정','중립','부정'))` 반영(#6). `src/lib/types.ts` 의 `Content` 에 `sentiment?: '긍정' | '중립' | '부정' | null` 추가.

### 2. LLM 논조 분류 함수 — `src/lib/insight/sentiment.ts` (신규)
- `classify.ts` 의 패턴(코드펜스 제거·JSON 파싱·실패 시 null) 미러.
- 시그니처:
  ```ts
  export async function classifySentiment(
    title: string,
    snippet: string,
  ): Promise<'긍정' | '중립' | '부정' | null>
  ```
- 호출: `llmComplete('classify', system, user)`.
  - system: "당신은 B2B 텔레콤/엔터프라이즈 시장 분석가다. 주어진 경쟁사 관련 기사의 **논조**를 시장 관점에서 판정하라. 긍정=해당 기업에 호재/성과/성공적 평가, 부정=악재/문제/실패/리스크, 중립=사실 전달·혼재. **JSON만 출력**: {\"sentiment\":\"긍정|중립|부정\"}. 설명·머리말 금지."
  - user: `제목: ${title}\n발췌: ${snippet.slice(0, 300)}`
- 파싱: 코드펜스 제거 → `JSON.parse` → `sentiment` 값이 3개 중 하나면 반환, 아니면 null. 키 미등록·한도·파싱오류 = null(조용히).

### 3. 어드민 백필 endpoint — `src/app/api/admin/sentiment/route.ts` (신규)
- `runtime='nodejs'`, `dynamic='force-dynamic'`. `verifyAdmin()`(insights/route.ts 복사) + `createAdminClient()`.
- `POST` body: `{ days?: number (기본 14), max?: number (기본 40, 상한 100) }`.
- 절차:
  1. 경쟁사 이름: `keywords` 에서 `is_competitor=true` 의 `name` 조회. 0건이면 `{ analyzed: 0, candidates: 0, reason: '경쟁사 키워드 미등록' }` 반환.
  2. 후보: `contents` 에서 `status='published'`, `sentiment is null`, `collected_at >= since(KST days)`, **`.overlaps('matched_keywords', names)`**, `order collected_at desc`, `limit max`. (id·title·summary_ko·body_original 선택.)
  3. 순차 루프: `snippet = summary_ko ?? body_original?.slice(0,300) ?? title` → `classifySentiment` → 결과 있으면 `update({ sentiment }).eq('id', ...)`. 실패는 skip(다음 백필에서 재시도).
  4. `{ analyzed: 성공수, candidates: 후보수 }` 반환.
- 예산: `max` 캡 + `llmComplete` 내부 `llm_settings` 한도 자동 적용(추가 예산 객체 불필요).

### 4. 어드민 트리거 버튼 — `src/app/admin/insights/page.tsx`
- 기존 "인사이트 생성"(line ~156) 섹션 옆/아래에 **"경쟁사 논조 분석"** 버튼.
- 클릭 → `fetch('/api/admin/sentiment', { method:'POST', body: JSON.stringify({}) })` → 결과 토스트/문구로 `analyzed/candidates` 표시. 로딩·에러 처리(기존 handleGenerate 패턴 미러). (경쟁사 키워드 미등록 시 reason 노출.)

### 5. 경쟁사 동향 섹션 — `src/app/dashboard/ai-analysis/page.tsx` (서버 컴포넌트)
- 위치: **키워드 맵 섹션 아래, "내 관심업체 동향" 위.** 헤더 아이콘 `Building2`(또는 `Swords`/적절한 lucide), 제목 "경쟁사 동향", 보조 "최근 14일 · 논조".
- 데이터(기존 `fourteenDaysStart` 재사용):
  1. 경쟁사 이름: `keywords` `is_competitor=true` 의 name(≤50). 0건이면 섹션 빈 상태("경쟁사 키워드를 등록하면 동향을 모아 보여줍니다").
  2. 경쟁사 기사: `contents` `status='published'`, `collected_at >= fourteenDaysStart`, `.overlaps('matched_keywords', names)`, `order collected_at desc`, `limit 80`. 선택: id·title·collected_at·sentiment·matched_keywords·sources(name).
  3. 그룹핑: 기사별로 `matched_keywords ∩ 경쟁사이름`(대소문자 무시) → 해당 경쟁사들 아래 배치(중복 허용). 경쟁사별 표시 기사 ≤5.
- 표시(경쟁사별 카드, 워치리스트 카드 UI 미러):
  - 헤더: 경쟁사명 + **논조 분포 배지**(긍 n / 중 n / 부 n — 그 경쟁사 14일 기사 전체 기준, null 제외).
  - 기사 목록: 제목 링크(`/dashboard/contents/{id}`)·출처·날짜 + **논조 배지**(긍정=emerald, 부정=destructive/red, 중립=muted; null=배지 생략).
  - 기사 0이면 경쟁사 카드 자체 생략. 전체 0이면 섹션 빈 상태.
- 배지 색은 토큰/의미색 사용(#9). `sentiment` 컬럼 미적용/미분석이면 배지 없이 제목만(graceful).

## 회귀 / 주의
- **SQL 96 선적용 필수(수희).** 미적용 시: 백필 update 실패(skip·로그), 페이지는 `sentiment` undefined → 배지 생략. 크롤·기존 화면 무영향.
- **경쟁사 키워드 미등록이면 섹션·백필 모두 빈 결과** — 운영상 KT/SKT/삼성SDS 등 `is_competitor=true` 등록이 선행 액션(David/수희). 코드는 빈 상태로 안전.
- `overlaps` 는 **정확 문자열 배열 매칭**(94 색 강조와 동일) — 부분문자열 ILIKE 와 다름. 경쟁사명이 `matched_keywords` 에 그대로 담겨야 잡힘(키워드 카탈로그 등록 = 잡히는 조건).
- 백필은 `sentiment is null` 만 → 멱등·재실행 안전. 캡(`max`)으로 1회 호출량 제한.
- LLM 호출은 endpoint(어드민 세션)에서만. `'use client'` 는 트리거 버튼 leaf 한정. 섹션은 서버 컴포넌트(추가 `'use client'` 금지).
- UI 한국어(#1)·색 토큰(#9)·`cn()`·`@/` alias.
- ④와 별개 후속(이 지시서 범위 아님): ① company-scope 인사이트 카드(워치리스트 업체별 LLM 동향, scope='company'), 논조 크롤타임 통합.
