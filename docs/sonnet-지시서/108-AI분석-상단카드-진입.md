## 배경 (David)

106이 AI 분석/이슈/지식그래프를 탭으로 묶은 건 맞는데, **진입점을 좌측 사이드바에 둔 게 의도와 다름.** 의도: **좌측의 AI 분석은 아예 제거**하고, **상단 카드(CategoryGrid)의 "AI 분석"을 누르면** 탭 페이지([AI 인사이트][이슈][지식그래프])가 보이는 것.

## 원인 (확인됨)

- `CATEGORY_DEFS`의 `ai-analysis` def 에 **`href` 가 없어** CategoryGrid 가 `/dashboard/contents?category=AI분석`(콘텐츠 필터)로 보냄 — 탭 페이지로 안 감.
- `Sidebar.tsx` 에 106이 추가한 **AI 분석 섹션**(ai-analysis + `?tab=issues`·`?tab=entities` 하위 링크)이 남아 있음.

## 작업

### 1. 상단 카드 → 탭 페이지 연결 — `src/lib/categories.ts`
- `ai-analysis` def 에 **`href: '/dashboard/ai-analysis'`** 추가. (유튜브 def 의 `href: '/dashboard/youtube'` 와 동일 패턴.)
- 결과: CategoryGrid 가 `cat.href ?? ...` 로 href 사용 → 상단 "AI 분석" 카드 클릭 시 `/dashboard/ai-analysis`(106 탭 셸: 인사이트/이슈/지식그래프). 활성표시는 `pathname.startsWith('/dashboard/ai-analysis')` 로 자동.

### 2. 좌측 사이드바에서 AI 분석 제거 — `src/components/dashboard/Sidebar.tsx`
- 106이 추가한 **AI 분석 섹션 전체 삭제**(제목 "AI 분석" + ai-analysis 링크 + 이슈/지식그래프 `?tab=` 하위 링크 + 인접 구분선). 미사용 import(Sparkles/Radar/Network 등 해당 섹션 전용) 정리.
- (이슈·지식그래프는 이미 106에서 1차 섹션 제거됨 — 잔재 없도록 확인.)

## 회귀 / 주의
- 탭 페이지·리다이렉트·백링크(106)는 그대로 유지 — 이번엔 **진입점만 이동**(좌측 제거 + 상단 카드 href).
- 상단 "AI 분석" 카드 active 상태: `cat.href` 있으면 `pathname.startsWith` 분기(CategoryGrid 기존 로직) — 정상 동작 확인.
- `?tab=issues`/`?tab=entities` 직접 URL·구 라우트 리다이렉트는 계속 동작(106).
- 전략보고서 카드(href 없음)는 이번 범위 아님(그대로).
- UI 한국어(#1)·색 토큰(#9)·`any` 금지.
