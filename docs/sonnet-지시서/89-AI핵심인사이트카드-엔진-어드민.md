## 배경
AI 분석 메뉴의 심장 = "산업동향을 LLM이 **시사점 + 출처 인용**과 함께 카드로". 모닝브리핑처럼 **배치 생성 → 어드민 검토 → 발행(published)** 흐름. (KA 고정 제외, 관심업체 워치리스트는 후속.) 설계: `docs/AI분석-핵심인사이트카드-설계.md`.

## 작업

### 1. (선행) SQL — `insight_cards`
- `docs/sql-handoff/89-insight-cards.sql` 를 **먼저 커밋·푸시**(수희 적용). 코드는 이 테이블 존재 전제. `supabase/schema.sql` 에도 동일 정의 반영(SSOT, 규칙 #6).
- 타입: `src/lib/types.ts` 에 `InsightCard`·`InsightCardStatus` 추가(DB 동기화).

### 2. 생성 엔진 — `src/lib/insight/generate.ts` (신규, server-only)
- `export async function generateIndustryInsightCards(admin, opts?: { days?: number; maxThemes?: number }): Promise<{ created: number; topics: string[] }>`
- 로직:
  1. 기간: `days`(기본 7) → `period_start`=오늘-6일(KST), `period_end`=오늘.
  2. 후보 수집(admin service client): `contents` published, `collected_at >= period_start`, **`matched_groups` 비어있지 않음**, select `id, title, summary_ko, matched_groups, importance_score, cluster_id, collected_at`. 상한(예: 400).
  3. **테마 그룹핑**: matched_groups 펼쳐 빈도 집계 → 상위 `maxThemes`(기본 5) 그룹. 각 테마: 그 그룹 포함 기사 중 **클러스터 대표 우선(cluster_id null)** + importance desc 상위 6~8건.
  4. 테마별 **LLM 생성**: `llmComplete('report', SYSTEM_PROMPT, userPrompt)`.
     - SYSTEM: "당신은 LG U+ B2B 시장 인텔리전스 분석가다. 주어진 기사들로 이 주제의 **핵심 동향 1줄(headline)**과 **LG U+ B2B(엔터프라이즈/공공/AICC·AIDC 등)에의 시사점 1~2줄(implication)**을 쓰라. **근거 없는 주장 금지** — 각 핵심 주장은 입력 기사에서 15단어 이내 인용과 그 content_id 를 citations 로 제시. JSON만 출력: {\"headline\":\"\",\"implication\":\"\",\"citations\":[{\"content_id\":\"\",\"quote\":\"\"}]}."
     - user: `주제: {group}\n\n` + 기사들 `"[{content_id}] {title}\n{summary_ko}"` 줄바꿈 연결.
     - 출력 **방어 파싱**(JSON.parse try/catch, 코드펜스 제거, 필드 검증). 실패 시 그 테마 skip(graceful).
  5. `insight_cards` **upsert**(멱등 키 `period_start, scope='industry', topic=group`): headline·implication·`source_content_ids`(테마 기사 id)·`citations`(LLM 출력 중 **실제 후보 id에 존재하는 것만** 필터)·`status='draft'`·`generated_at=now`. (citations content_id 검증으로 환각 차단.)
- 예산/안전: 테마 수 상한, LLM 실패·키없음 시 부분 생성·graceful. service_role(admin) 사용(서버 전용).

### 3. 어드민 API — 생성/목록/상태
- `src/app/api/admin/insights/route.ts`:
  - `POST` (admin 게이트, briefings route 미러): body `{ days?, maxThemes? }` → `generateIndustryInsightCards` 호출(동기 또는 `after()` 백그라운드) → `{ created, topics }`.
  - `GET`: 최근 insight_cards 목록(admin 전체, status 포함) 반환.
- `src/app/api/admin/insights/[id]/route.ts`: `PATCH` status 변경(draft↔published↔archived), `DELETE`.

### 4. 어드민 화면 — `/admin/insights` (신규)
- 네비(`ADMIN_NAV_GROUPS`)의 **AI·처리** 그룹에 "AI 인사이트" 항목 추가(icon 예: `Sparkles`).
- 페이지: "인사이트 생성" 버튼(기간 선택 7/14일) + 생성된 카드 목록(headline·implication·출처 수·상태). 카드별 **발행/보류/삭제** + 출처 content_id 링크(`/dashboard/contents/{id}`). 모닝브리핑 매니저 UX 참고. `'use client'` leaf.

## 회귀 / 주의
- **SQL 선적용 필수**(수희) — 미적용 시 생성/조회 실패. 코드는 테이블 없으면 graceful 에러 메시지.
- LLM 키 미설정/예산소진 시 생성 0건 → 어드민에 "생성된 카드 없음"(에러 아님).
- **citations 는 입력 후보 content_id 로 검증된 것만 저장**(환각 출처 차단, 2-1 핵심).
- 자동 노출 금지 — 생성은 `draft`, 어드민이 `published` 로 올려야 사용자 노출(90에서). 자동생성은 후속 크론.
- service_role 은 서버 전용(#8). UI 한국어(#1)·토큰 색(#9)·`'use client'` leaf만.
- `llm_task_routing` 에 'report' 라우팅 없으면 index.ts 고정 폴백으로 동작(기존 안전망).
