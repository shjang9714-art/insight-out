## 2. 코드 참조 교체 (Sonnet 작업)

- `DashboardHeader.tsx`(L66~): 기존 `/logo.png` **워드마크 한 장 방식 → 심볼(`/brand/logo-mark.png`) + 라이브 텍스트** 조합으로 교체 권장.
  - `<Image src="/brand/logo-mark.png" width={32} height={32} alt="Insight Out" />` + 옆에 `<span className="font-semibold text-foreground">Insight Out</span>`(Pretendard·토큰색).
  - 이렇게 하면 텍스트가 토큰색이라 **다크모드 자동 대응**(별도 다크 로고 스왑 불필요). 심볼은 자체 색이라 양 테마 OK.
  - 헤더 로고는 클릭 시 `/dashboard`로 이동(기존 동작 유지).
- `login/page.tsx`(L142): 로그인 히어로는 `/brand/logo-hero.png`(전구형 워드마크) 사용. 로그인은 라이트 고정이면 그대로, 다크 대응 시에도 히어로는 자체 색이라 무관.
- `layout.tsx` `metadata`: Next 파일 기반 아이콘(`src/app/icon.png`·`apple-icon.png`·`favicon.ico`)으로 충분 → `icons` 수동 추가 **불필요**. `metadata.title`/`description` 현행 유지. `manifest`(PWA)는 범위 외.
- 기존 `public/logo.png`·`logo-dark.png`(976×286 워드마크)은 더 이상 헤더에서 참조 안 함 — 사용처 grep 후 미사용이면 정리(또는 잔존 허용, 빌드 영향 없음).
