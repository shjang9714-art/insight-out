# 지시서 262 — 로그인 큰 화면 무스크롤 (세로 높이 제한) + 헤드라인 좌상단

목표: 로그인 페이지가 **어떤 화면 폭에서도(넓은 모니터 포함) 스크롤 없이 한 화면에** 들어오게 한다. 256이 폭 퍼센트(2xl 88%)로 씬 크기를 정해 **넓은 화면(예: 2560×1440)에선 씬이 커져 다시 세로로 넘치는** 문제를 해결한다. 헤드라인 3줄은 좌상단·기존 폰트로 고정.

## 1. 진단 (256 배포 상태의 한계)
- 256: `main` flex-col, `<header>`(헤드라인) 상단 + `flex-1 items-center`(전구+카드 중앙). 씬 폭 = **반응형 퍼센트**(1280~1535 107%, 2xl 88%). 3뷰포트(≤1536)는 무스크롤 확인.
- **문제**: 씬이 **폭 기준**이라 화면이 넓어지면(2560 등) 씬 폭 88%도 절대값이 커짐 → aspect 고정이라 **높이도 커져 세로 넘침** → 스크롤.
- ∴ **폭 기준 → "가용 세로 높이" 기준으로** 씬을 제한해야 화면 폭 무관하게 안 넘침.

## 2. 구현

### 2-1. 씬을 세로 높이로 제한 (핵심)
- 전구 씬을 **가용 세로 공간 안에 반드시 들어오게** 제한:
  - `flex-1` 중앙 영역은 (100vh − header − padding) 만큼의 **정해진 높이**를 가짐(flex-col + min-h-screen).
  - 씬 래퍼(aspect-[1456/1087] 유지)에 **`max-h-full`** + 컨테이너 기준 높이 제한, 또는 씬 래퍼에 **`max-h-[Nvh]`**(예: `max-h-[60vh]`)를 주어 세로가 절대 넘치지 않게.
  - aspect 비율 고정이므로 **높이를 제한하면 폭도 비례 축소** → 넓은 화면에서 씬이 무한정 커지지 않음.
  - BulbScene 이미지: 래퍼가 aspect 유지하며 `object-contain`/`object-cover`로 안에 맞춤. SVG 오버레이는 같은 aspect 박스라 이미지와 함께 스케일 → 정렬 유지.
- 폭 퍼센트(`lg:w-[122%]`·`2xl:w-[88%]` 등)는 **세로 제한과 충돌 없게 조정**(폭은 컬럼 내 `w-full max-w-*`로 두고, 세로 max-h가 실제 크기 결정). 넓게 펼치는 연출이 필요하면 max-h 범위 내에서만.

### 2-2. 헤드라인 좌상단 · 기존 폰트 (256 유지·확정)
- `<header>`(그리드 밖 상단)에 3줄, **좌측 정렬(lg:text-left)**, **기존 타이포 그대로**:
  - `흩어진 인텔리전스를 하나의 흐름으로,` (h1, `clamp(34px,3.6vw,52px)`, extrabold, `#0f244d`)
  - `Intelligence in. Insight out.` (italic, slate-400)
  - `뉴스, 리포트, 영상, 데이터를 모아 실행 가능한 인사이트로 전환합니다.` (slate-500)
- 상단 여백(`pt-*`)은 무스크롤 유지 범위에서. 좌측 정렬·max-w로 화면 좌상단에 자연스럽게.

## 3. 하드 요구 (검증 — 확대된 뷰포트)
- **세로 스크롤 0**(scrollHeight===innerHeight)을 **다음 전부에서**: **1280×800 · 1440×900 · 1536×864 · 1920×1080 · 2560×1440**. 씬·카드·헤드라인 **잘림 없이** 다 보임.
- 화면이 넓어져도 씬이 과도하게 커지지 않음(세로 제한 적용).
- 헤드라인 좌상단·기존 폰트, 모바일 세로 스택·가로 스크롤 0.
- 전구 애니메이션(orb/comet/twinkle)·OTP·248 불변.

- `npx tsc --noEmit` 0 / `npx eslint` 0 / `npm run build`.

## 5. 튜닝 노트
- max-h 값(예: 55~65vh)은 카드 높이·헤드라인 높이와 합쳐 100vh에 맞게 라이브 조정.
- 세로 제한이 우선, 폭 퍼센트는 보조(연출). 넓은 화면에서 여백이 남으면 씬을 max-h 내에서 키움.
