## 0. 전제 정정 — "나머지 3탭은 중복" 은 사실이 아니다

`검토-어드민IA-2차통합안-2026-08-16` 은 "통계분석 4탭 중 발행 분석만 고유하고
나머지는 대시보드·소스 관리와 중복이므로 버린다"고 썼다. 실사 결과:

| 탭 | 재편안 | 실측 |
|---|---|---|
| 수집 분석 | 소스 관리와 중복 | **완전 고유.** `SourceQualityManager` 는 `AnalyticsHub` 에서만 쓰인다(grep 실측). 소스 관리에 이 화면이 없다 |
| 콘텐츠 분석 | 대시보드와 중복 | 5블록 중 **4개만** 중복(일별 추이·카테고리 분포·상태 비율·소스 기여 Top10 = 대시보드 "수집 분석 보기" 팝업의 `DashboardCharts`). **북마크 Top 10 은 고유** |
| AI 사용량·비용 | 대시보드와 중복 | "이번 달 한도 대비 사용률" 만 중복(대시보드 `AdminOpsSignals`). **월별 LLM 토큰 · 월별 번역 · 월별 TTS 추이 3종은 고유** — 대시보드는 당월만 본다 |
| 발행 분석 | 고유 | 동의. 6블록 전부 고유 |

**그대로 지웠으면 수집품질 화면이 통째로 사라진다.** David 결정: **분산 배치.**
(발행 분석 6블록을 운영 대시보드로 미는 안도 기각 — 대시보드는 이미 블록이 8개다.)

## 작업

### 1) 수집 분석 → 소스 관리 탭

- 532 로 만든 `SourcesHub` 에 `{ value: 'source-quality', label: '수집 품질' }` 을
  **`소스 목록` 바로 다음**에 넣고 `SourceQualityManager` 를 렌더한다.
  이 컴포넌트는 `'use client'` 에 자체 fetch 라 **서버 슬롯이 필요 없다.**
- 소스 관리 최종 6탭: 소스 목록 / 수집 품질 / 수집 설정 / 제외 규칙 / 데이터 보강 재처리 / AI 보강

### 2) 발행 분석 → nav 단독 항목으로 승격

- `src/app/admin/analytics/publish/page.tsx` 를 **리다이렉트 스텁에서 실제 페이지로 되돌린다.**
  `PublishAnalyticsPanel` 을 직접 렌더하고 `metadata` 를 붙인다.
  `AdminPageHeader` 는 nav 항목이 생기므로 override 없이 그대로 쓴다.
- `nav.ts` 분석·관리 그룹의 `통계분석`(`/admin/analytics/content`) 항목을
  **`{ href: '/admin/analytics/publish', label: '발행 분석' }` 으로 교체**한다.

### 3) AI 사용량·비용 → 시스템 설정 "AI 모델" 탭

- `src/app/admin/settings/page.tsx` 를 **서버 컴포넌트로 바꾸고** `searchParams` 를 읽어
  `tab === 'llm'` 일 때만 `AiCostAnalyticsPanel` 을 만들어 슬롯으로 넘긴다.
  **패턴은 532 의 `/admin/sources` 를 그대로 따른다**(활성 탭이 아닐 때 서버 조회가 아예 안 만들어지게).
- `SystemSettingsHub` 는 `llmCostPanel: ReactNode | null` 을 받아 `llm` 탭에서
  `LlmManager` **아래**에 렌더한다.
- ⚠️ `AiCostAnalyticsView` 의 **"이번 달 한도 대비 사용률" 블록은 제거**한다 —
  대시보드 `AdminOpsSignals` 와 중복이다. **월별 추이 3종만 남긴다.**
- `src/app/admin/analytics/ai-cost/page.tsx` 스텁 목적지를 `/admin/settings?tab=llm` 로 갱신.

### 4) 북마크 Top 10 → 대시보드 "수집 분석" 팝업

- `ContentAnalyticsView` 의 **북마크 Top 10 블록만** `DashboardCharts` 로 옮긴다.
- 데이터는 대시보드 서버(`src/app/admin/page.tsx`)에서 조회해 `chartData` 에 실어 넘긴다.
  조회 로직은 `ContentAnalyticsPanel` 의 것을 그대로 재사용한다 — **새로 짜지 말 것.**
  ⚠️ 옮겨 오는 쿼리에 `.limit()` 이 없으면 반드시 넣는다(PostgREST 기본 1000행).
- 나머지 4블록은 `DashboardCharts` 와 중복이므로 **`ContentAnalyticsView` ·
  `ContentAnalyticsPanel` 을 삭제**한다.

### 5) 통계분석 껍데기 제거

- `src/components/admin/AnalyticsHub.tsx` 삭제.
- `src/app/admin/analytics/content/page.tsx` → **리다이렉트 스텁**(`/admin/analytics/publish`).
  옛 딥링크(`?tab=source-quality` 등)를 쓰던 사람이 빈 화면을 보지 않게 한다.
- 안 쓰게 된 아이콘 import·죽은 파일을 정리한다. **eslint 경고 0건을 유지할 것.**
