## 0. 한 줄

수집 콘텐츠의 **일괄 처리·삭제 5종**(풀본문 채우기·신호 분류·원문 URL 정규화·수집 기사 삭제·유튜브 영상 삭제)을 신규 **`/admin/content-data` "콘텐츠 데이터 관리"** 페이지(시스템 그룹 레벨1)로 모은다. 콘텐츠 관리 화면에선 처리 도구·"열 너비 초기화"를 없애고, **선택 바에 삭제(벌크)** 를 더한다. `/admin/settings` 의 "데이터 관리" 섹션은 이 페이지로 이사.

## 3. 회귀 가드 / 비기능 요건
- **API·SQL·npm 무변경**(purge·backfill 라우트 그대로). 순수 프런트 재배치.
- 처리 핸들러는 콘텐츠 리스트 상태에 의존 안 함(fetch+자체 결과 state) → 이동 안전. 이동 후 콘텐츠 화면에서 미참조 확인(빌드로 검출).
- 벌크 삭제는 단건/퍼지와 동일 경로(supabase delete, FK cascade). 확인 문구·되돌릴 수 없음 경고 필수.
- 리사이즈 드래그 유지(초기화 버튼만 제거). 205 카테고리·선택 바 sticky·행 순서 유지.
- 203/204 토큰(대비·빨강 톤·폰트) 유지, 신규 hex 0. 비어드민 게이트(페이지·API) 유지. 공개 화면 무영향.
- 사이드바 레벨1 추가 후 199 접이식·활성표시 정상.
