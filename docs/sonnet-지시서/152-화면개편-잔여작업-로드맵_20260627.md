## 2. Phase별 로드맵 (우선순위 순)

### Phase A — 기반층: content_signals 흡수 ★최우선 (Opus 설계 / Code 실행)
의존: 없음 | 산출 지시서: `content_signals-흡수-설계.md`
1. **Step 0 라이브 스키마 실측**(차단) — content_signals 컬럼/FK/건수/샘플, 이슈·연결테이블 존재 확인 → 4개 분기 질문 답 보고
2. Step 1 마이그레이션(Case A/B 확정본) `issue_signals` + GRANT + 백필
3. Step 2 읽기 뷰/API(이슈→근거 드릴다운, 논조 분포) + GRANT
4. 완료기준: 이슈 상세에서 근거 콘텐츠 라이브 1건 이상 end-to-end, 논조 위젯 데이터 정합

### Phase B — AI인사이트 본기능 (A 의존, [O]+[S])
의존: Phase A | 탭: `/dashboard/issues`
1. 이슈 상세 "근거 콘텐츠" 섹션(원문 카드 + 논조 배지) — A의 evidence API 소비
2. 논조 분포 추이 차트 위젯(기간 토글)
3. (후속) 지식그래프, 테마/내러티브 타임라인, 유사 이슈 추적(#105)

### Phase C — 기업동향 본기능 (A 일부 의존, [O]+[S])
의존: Phase A(시그널 entity 연결) | 탭: `/dashboard/entities`
1. 엔티티 한장 브리핑(기업별 요약 카드)
2. 기업별 이슈/시그널 묶음(entity_id 그룹), 논조 배지
3. (현 경쟁사 카드·그래프는 유지·확장)

### Phase D — 전략보고서 워크벤치 (데이터 독립, [S] 단독 가능)
의존: 없음(병렬 착수 가능) | 탭: `/dashboard/reports`
1. 보고서 워크벤치/조립기(콘텐츠 선택→섹션 구성)
2. 뷰어 + PDF 내보내기
3. LLM 다듬기, 근거 연결(완성 시 Phase A evidence 연동)
> 현재는 목록 + "새 보고서" 버튼만 존재. 가장 비어 있는 탭.

### Phase E — 사업기회 소싱(나라장터/조달청) (신규 데이터, [O])

2. 사업기회 전용 메타 컬럼(마감일·발주처·금액) + GRANT

> 사용자가 명시적으로 누락 지적한 항목. 별도 소싱 지시서로 상세화 예정.
