## 2. 구현

### 2.1 `nav.ts` — 발행/생성 2메뉴
현재(83행): `{ href: '/admin/competitor-weekly', label: '경쟁사 주간리포트', … }`
→ **2개로:**
```ts
{ href: '/admin/competitor-weekly',          label: '경쟁사 주간 브리핑', description: '사업영역별 주간 브리핑 발행 목록.', icon: FileText },
{ href: '/admin/competitor-weekly/generate', label: '주간 브리핑 생성',   description: '사실 추출 → 분석 2단계로 새 브리핑을 만듭니다.', icon: <미사용 아이콘, 예: Sparkles/Wand2> },
```

### 2.2 `/admin/competitor-weekly` → 발행 목록만
`page.tsx`: `CompetitorWeeklyHub` → **`CompetitorWeeklyManager` 직접**(+ `AdminPageHeader`).
- 서버 조회(`initialReports`·`schemaMissing`)는 **유지.** 42P01 graceful(`AdminEmptyState`)도 유지.
- `metadata` 제목 `경쟁사 주간 브리핑`.
- 생성·분석·설정은 이 화면에서 **제거**(생성 화면으로 이동).

### 2.3 신규 `/admin/competitor-weekly/generate` — 생성 단계 UI
`src/app/admin/competitor-weekly/generate/page.tsx`(서버, initialReports 조회 — Analyze 가 씀) + 신규 `CompetitorWeeklyGenerateFlow.tsx`(클라이언트).

**단계 UI 스펙:**
```
[AdminPageHeader — "주간 브리핑 생성"]

┌ ① 사실 추출  (큰 번호 + 큰 제목 text-base/lg)
│  설명(text-sm, 쉬운 말): "지난주 경쟁사 기사를 사업영역별로 모아 사실만 뽑습니다.
│                          아래 버튼을 누르면 자동으로 진행됩니다. (몇 분 걸릴 수 있어요)"
│  → AdminCompetitorWeeklyGenerate (액션만)
│
├ ② 분석                (큰 번호 + 큰 제목)
│  설명: "①이 끝난 주를 골라 프롬프트+데이터를 복사하고, 원하는 LLM(Claude·GPT 등)에
│        붙여넣은 뒤 결과 JSON을 다시 붙여넣어 저장합니다."
│  → AdminCompetitorWeeklyAnalyze (액션만)
│
└ ▸ 자동 생성 스케줄  (접이식 details, 기본 접힘 — "순서 아님, 설정")
   설명: "매주 정해진 요일·시각에 ①을 자동 실행할지 설정합니다. (하루 1회, 402)"
   → AdminCompetitorWeeklySchedule
```

- **번호(①②)·큰 제목·쉬운 설명은 `GenerateFlow` 프레임이 렌더**한다. 폰트: 제목 `text-base font-semibold`(또는 lg), 설명 `text-sm text-muted-foreground`.
- 설정은 `<details>` 접이식으로 **순서에서 시각적으로 분리**(들여쓰기·구분선). 기본 접힘.
- Analyze 의 주 선택·프롬프트 복사는 **404 개선분 그대로**(이미 "프롬프트+데이터·어느 LLM이든").

### 2.4 하위 컴포넌트 — 중복 제목 제거 + 폰트
`Generate`·`Analyze`·`Schedule` 각각의 **최상단 `<h2>`(제목)와 그 옆 설명 `<p>`를 제거**한다. 이제 그 역할은 §2.3 프레임이 한다.
- ⚠️ **제목·설명만 제거. 액션(버튼·입력·결과 표시)·로직은 무수정.** 특히:
  - `Generate`: 403의 `useEnrichJobs`(전역 진행) 연동 **유지.**
  - `Analyze`: 404의 프롬프트 문구·복사·검증 **유지.**
  - `Schedule`: 저장 로직 유지.
- 중복 제목을 안 지우면 프레임 제목 + 컴포넌트 제목이 **두 번** 나온다 — 반드시 제거.

## 4. 회귀 가드
1. 사이드바에 **경쟁사 주간 브리핑(목록) · 주간 브리핑 생성** 2메뉴.

5. ① 생성 버튼 → **403 전역 진행 표시(Dock)** 동작.
6. ② 분석 → **404 프롬프트+데이터 복사·저장** 동작.
7. 설정 저장 동작.
8. **제목이 두 번 안 나온다**(프레임 제목만).
9. 폰트가 이전보다 크다(제목 base+, 설명 sm).
