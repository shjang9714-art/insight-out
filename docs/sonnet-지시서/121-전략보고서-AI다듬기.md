## 배경 (David)

118 워크벤치는 **조립기** — 사실 섹션(개요·이슈별 동향)은 DB로 채우고, 판단 섹션(시사점·기회/리스크·대응)은 `> 작성 필요` placeholder로 남긴다. 121은 그 placeholder를 **무료 LLM 풀로 best-effort 채우는** 옵션 버튼. 키 없으면 비활성/실패 메시지, 결과는 항상 사람이 ReportEditor로 재편집.

## 설계 결정 (Opus)

1. **사실 섹션 불변 보장(환각 차단)**: LLM에 전체 문서를 다시 쓰게 하지 않는다. 코드가 **판단 섹션만 교체**한다. 118 `assembleMd`는 항상 `## 3. 시사점 (LG U+ 관점)` ~ (`## 근거 콘텐츠` 직전 또는 문서 끝)을 판단 영역으로 내보내므로, 이 **앵커 사이만** LLM 출력으로 치환.
2. **LLM 입력 = 사실 섹션(개요·동향)** + 보고서 유형. 출력 = 판단 3섹션 markdown만. 근거 밖 사실(회사명·수치·날짜) 날조 금지, 추정은 "일반적으로/추정" 명시(§12).
3. **graceful**: `llmComplete('report')`가 null(키 미설정·한도·실패)이면 503 + 한국어. 앵커를 못 찾으면 실패시키지 말고 LLM 출력을 `## 분석 (AI 보강)` 섹션으로 **append**.
4. **소유자 전용**(RLS). 결과는 `ai_reports.body_md` 갱신(status 변경 안 함, draft 유지). 사람이 편집기로 다듬음.

## 작업

### A. refine API — `src/app/api/reports/[id]/refine/route.ts` (신규, POST)
- 118 패턴으로 `createServerClient`(쿠키) + `supabase.auth.getUser()`. 미로그인 401.
- `ai_reports`에서 `id, user_id, type, body_md` 조회(RLS). 없으면 404. `user.id !== user_id` 면 403.
- **사실 섹션 추출**: `body_md`에서 `## 3. 시사점` 앵커 이전까지를 `factPart`로(개요·동향). 앵커 없으면 `factPart = body_md` 전체.
- **LLM 호출**:
  ```ts
  const system = '당신은 LG U+ B2B 사업 담당자를 위한 전략 분석가입니다. 주어진 보고서의 사실(개요·동향)만 근거로, 판단 섹션을 한국어로 작성합니다. 사실에 없는 회사명·수치·날짜를 새로 만들지 마세요. 추정은 "일반적으로", "추정" 등으로 명시하세요. 마크다운으로만 답하세요.'
  const user = `보고서 유형: ${type}\n\n[사실 근거]\n${factPart}\n\n[작성 요청]\n아래 세 섹션을 위 사실에서 논리적으로 도출해 작성하세요. 다른 머리말 없이 이 형식 그대로:\n## 3. 시사점 (LG U+ 관점)\n(사업 시사점 1~3개)\n## 4. 기회 / 리스크\n(기회·리스크)\n## 5. 대응 방향\n(실행 가능한 대응 1~3개)`
  const out = await llmComplete('report', system, user)
  if (!out) return NextResponse.json({ error: 'LLM 키가 설정되지 않았거나 한도를 초과했습니다.' }, { status: 503 })
  ```
- **치환**: `body_md`에서 `## 3. 시사점` 앵커 위치 ~ `## 근거 콘텐츠`(있으면 그 앞까지, 없으면 끝)를 `out`으로 교체. 근거 콘텐츠 섹션이 있으면 뒤에 다시 붙임. 앵커 미발견 시 `body_md + '\n\n' + out` append.
- `ai_reports.update({ body_md: newBody })`(RLS 본인). 반환 `{ ok: true }`.
- 길이 가드: 합성 결과 10만자 초과면 자르거나 400.

### B. UI 버튼 — `src/components/reports/ReportEditor.tsx`
- 비편집 뷰(소유자) 상단 버튼줄(현재 "편집" 옆)에 **"AI로 다듬기"** 버튼 추가(`Sparkles` 아이콘). `print:hidden`(120과 정합).
- onClick: `confirm('판단 섹션(시사점·기회/리스크·대응)을 AI가 작성한 초안으로 채웁니다. 기존 판단 내용은 대체됩니다.')` → `POST /api/reports/{reportId}/refine` → 성공 시 `router.refresh()`, 실패 시 한국어 에러(특히 503 키 메시지 그대로 노출). 로딩 스피너(`Loader2`).
- 키 설정 여부를 클라가 모르므로 버튼은 항상 노출(best-effort) — 실패 메시지로 안내.

## 환각·출처 (AGENTS §12)
- 사실 섹션·근거 콘텐츠 목록은 코드가 보존(LLM 미접근). LLM은 판단 섹션만 생성. 시스템 프롬프트에 날조 금지·추정 명시 규칙 포함. 결과는 draft 유지 → 사람 검수 전제.
