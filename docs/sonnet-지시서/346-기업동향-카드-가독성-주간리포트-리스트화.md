## 배경 (David)

1. **주요 기업 탭에 테두리 없는 카드가 있다.** (SK하이닉스 등)
2. **경쟁사 최근 뉴스 카드의 폰트가 작다.** 기사 제목이 눈에 안 들어온다.
3. **같은 사건 기사가 두 줄을 다 차지한다.** "KT AI 스테이션, 'WSIS 프라이즈' 챔피언상 수상" / "KT 'AI 스테이션', 국내 유일 WSIS 프라이즈 챔피언상 수상" — 두 줄을 써서 전달되는 정보가 1건뿐이다.
4. **주간 종합 리포트는 카드 그리드에 맞지 않는다.** 건수가 적고(주 1건) 내용이 길다. 홈의 "핵심 Insight"처럼 **1열 전폭 에디토리얼 리스트**로 가고, 목록에서 요약까지 읽히고 클릭하면 상세로 들어가야 한다.

## 설계 결정 (Opus)

1. **골드 글로우 폐기.** 원인은 `isGold ? 'io-gold-glow border-transparent'` — `.io-gold-glow::before`가 `z-index:-1`이라 `bg-card` 뒤로 깔려 **글로우는 안 보이고 테두리만 사라진다**. 카드 표면은 전부 동일하게 두고, 중요 신호는 `● 중요` 마크 하나로만 준다(343 — 강조는 예외만). `isGold` 분기 제거.
2. **중복은 데이터 레이어에서 거른다.** 기존 `titleSimilarity`(크롤러 near-dup, 자가 구현 Jaccard)를 재사용해 **표시용**으로만 중복을 제거한다. `articleTotal`(전체 건수)은 원본 유지 — 사용자에게 보이는 건수는 실제 수집량이어야 한다.
3. **주간리포트는 카드가 아니라 리스트.** 3열 그리드는 "여러 개를 비교"할 때의 형식이다. 주간 리포트는 비교 대상이 아니라 **읽을거리**다.

### C. 표시용 중복 제거 — `src/lib/entities/competitor-news.ts`

```ts
import { titleSimilarity } from '@/lib/crawler/similarity'

const DISPLAY_DUP_THRESHOLD = 0.6

function dedupeForDisplay(articles: CompArticle[]): CompArticle[] {
  const kept: CompArticle[] = []
  for (const a of articles) {
    if (!kept.some(k => titleSimilarity(k.title, a.title) >= DISPLAY_DUP_THRESHOLD)) kept.push(a)
  }
  return kept
}
```
- 적용: `articles: dedupeForDisplay(matched).slice(0, articlesPerCompany)`
- `articleTotal: matched.length` — **바꾸지 말 것**(전체 건수는 원본).
- 임계값 0.6은 위 KT 사례(≈0.78)를 잡고, 다른 사건은 남기는 값. 크롤러의 `SIMILARITY_THRESHOLD`(0.9)와는 **목적이 다르다**(저장 단계 near-dup vs 노출 단계 정보량).

## 회귀 / 주의

- `titleSimilarity`는 `@/lib/crawler/similarity`(서버·클라이언트 무관 순수 함수). `competitor-news.ts`는 이미 `server-only`.
- 중복 제거로 **카드에 보이는 기사 수가 줄 수 있다**(예: 2건 → 1건). 정상이다. `기사 N건`은 원본 건수를 계속 보여준다.
- 주간리포트 리스트의 행 전체가 `<Link>` — 안에 별도 링크 금지(중첩 링크).
- 검증: `npx tsc --noEmit` · ESLint · `check-prefetch` · `npm run build` · 육안 3탭.
