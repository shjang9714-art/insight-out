# 지시서 247 — 로그인 전구 히어로: 목업 v3 애니메이션 + 확장 필드 컴포지션

> ⚠️ 번호 교정: 원래 "246"으로 작성됐으나 **246은 `246-경쟁사-그룹-정정백필.sql`이 선점** → **247**로 변경. 커밋 메시지·본문의 246 참조를 247로 통일.

목표: 로그인 페이지 좌측 히어로를 **목업 v3(`insight_out_image_overlay_mockup_fixed_v3.html`)의 전구+빛 흐름 애니메이션과 동일한 컴포지션**으로 완성한다. 전구 asset(광류 배경 포함) 위에 SMIL 오버레이(orb·comet·twinkle·aura)를 얹고, 필드를 히어로 영역 가득 확장·상단 배치한다. 로그인 카드는 지시서 239(OTP)·240(관리자 Google)의 결과물을 그대로 유지한다.

전제: **David 검수 완료된 구현본이 현재 워킹트리(로그인 세션)에 있다.** 이 지시서는 (a) 스펙 대조 검증, (b) 빌드·접근성·반응형 확인, (c) 커밋까지의 마무리 지시다. 코드를 새로 쓰지 말고, 워킹트리 상태가 아래 스펙과 다를 때만 스펙 기준으로 수정한다.

> ⚠️ **선행(코드 밖·중요) — OTP 실제 발송**: 이 히어로 UI가 완성돼도 **Supabase Auth에 커스텀 SMTP(Brevo 무료 릴레이)가 연결돼야 OTP 메일이 실제로 발송**된다. 상세 절차·OTP 이메일 템플릿은 **`docs/로그인-Supabase대시보드-설정가이드.md`** + **`docs/이메일템플릿-OTP-magiclink.html`** 참조. 결정: Brevo 무료 1계정(하루 300통, 뉴스레터 공유). **이 지시서(UI) 범위 밖이나 로그인 동작 전제 — David가 로그인 세션에서 대시보드 처리.**

- 헤드라인: `흩어진 인텔리전스를 / 하나의 흐름으로,` — 실제 DOM 텍스트, `clamp(34px, 3.6vw, 52px)`(기존 대비 10% 축소본). 서브 `Intelligence in. Insight out.` italic. 설명 2줄.

- 카드 컬럼: max-w 460, `justify-self:end`, Suspense fallback 유지.

## 3. BulbScene 스펙 (`BulbScene.tsx`)
- 컨테이너: `.io-anim-layer relative aspect-[1456/1087] w-full` — **pointer-events:none** (globals.css).
- 전구 asset: `/brand/login-bulb-scene.png` — `absolute inset-0 object-cover z-0`, `next/image` priority.
- 오버레이 SVG: `viewBox="-268 152 1456 1087"`, `overflow-visible`, **`mix-blend-screen`**, z-10, aria-hidden.
  - viewBox 는 asset 크롭과 동일 좌표계 → **목업 v3 의 path·orb·comet·twinkle 좌표를 변환 없이 그대로 사용**한다.
- 오버레이 구성(목업 v3 1:1, id 프리픽스 `iov3-`):
  1. bulb aura: ellipse (460,658) rx225 ry185, `io-glow-pulse` + blur(26).
  2. flow guide line 11개(p1~p11): 좌6·우5, trailGold/trailPink 그라디언트, stroke-width 2.4~4.5.
  3. 별똥별 streak 4개(m1~m4): meteor 그라디언트, 4~4.2.
  4. **orb 11개**: `animateMotion`(dur 4.1~5.6s, begin 음수 스태거)으로 p1~p11 을 따라 전구로 수렴. r 6~12, orbFill + gold dropShadow. 그룹 `className="io-anim"`. 작은 orb 6개에 `io-extra`(모바일 숨김).
  5. comet head 4개: ellipse tail + head circle, m1~m4 따라 이동(dur 3.4~3.9s). 그룹 `io-anim`.
  6. twinkle 4개: (328,566)/(602,566)/(380,778)/(530,748), `io-twinkle` + `s2/s3/s4` 딜레이.

## 4. Asset 스펙 (`public/brand/login-bulb-scene.png`, 1456×1087)
목업 베이스 이미지(1448×1086, 목업 HTML 의 base64)에서 생성. 이미 워킹트리에 존재 — **재생성 불필요**. 재생성이 필요할 때만:
1. 크롭 `(40, 455, 845, 958)` = 805×503 (상단 텍스트·우측 카드 그림자 제외).
2. 여백 확장: 좌308·우343·상303·하281 — 크롭을 반복 미러링으로 이어 붙인 뒤 GaussianBlur(16), 중앙(원본 영역)은 soft mask 로 선명 유지.
3. 외곽 alpha feather: 상310·좌우150·하200px 램프(`v**1.6`) — 상단은 확장부 전체를 페이드해 전구 글로우 미러 얼룩 방지.
4. **전구·구슬 픽셀 크기는 원본 그대로**(필드만 확장). 파일 ~1.1MB.

## 5. CSS 스펙 (`globals.css` — `.io-login` 섹션)
- 배경: 기존 라벤더/골드 radial+linear 그라디언트 유지.
- `.io-anim-layer { pointer-events: none; }`
- 키프레임 — **목업 v3 원본값 그대로**:
  - `ioGlowPulse`: 0/100% opacity .22 scale 1 → 50% opacity .5 scale 1.06, 3.8s.
  - `ioTwinkle`: 0/100% opacity .12 scale .92 → 50% opacity .9 scale 1.18, 2.2s. 딜레이 s2 .8s / s3 1.5s / s4 1.1s.
  - 두 클래스 모두 `transform-box:fill-box; transform-origin:center`.
- 모바일: `@media (max-width:768px) { .io-extra { display:none } }`.
- 접근성: `@media (prefers-reduced-motion: reduce)` 에서 `.io-anim { display:none }`(SMIL 은 CSS 정지 불가), glow/twinkle 은 정적 opacity 로 유지.
- 구(舊) io 키프레임(ioBeamShimmer·ioCorePulse·ioBulbLit·ioSparkFlash·ioPulseRing·ioOrbTwinkle·ioRaySpin)은 **삭제된 상태가 정상**. 잔존 시 제거.

## 6. LoginCard (239·240 유지 — 변경 금지)
- OTP 2단계(`signInWithOtp`→`verifyOtp`), 6자리 자동 제출, 재전송 30s 쿨다운, 이메일 변경.
- 클라이언트 도메인 하드검증 금지(형식만 가드), 에러 매핑(403 도메인/코드 불일치/429) 한국어.
- 타이틀 `Insight Out` 중앙 + 골드 언더바(30×3px, radius 999), 전구 로고 없음.
- 하단 저강조 `관리자는 Google로 로그인` → `/auth/callback`.
- 에러 배너 `--destructive` 토큰(`border-destructive/25 bg-destructive/10 text-destructive`).

## 7. 회귀 가드
- 라우팅·미들웨어·`/auth/callback` 변경 없음. OTP 는 콜백 미사용.
- 애니메이션 레이어가 폼 조작(클릭·입력·탭)을 방해하지 않는다(pointer-events:none 확인).
- 씬이 153%로 넓어져도 `main` 의 `overflow-hidden` 으로 화면 밖 잘림 — 가로 스크롤이 생기면 안 된다.
- 이미지 가장자리 feather 로 페이지 배경과 자연스럽게 블렌드 — 딱딱한 사각 경계·세로 띠가 보이면 asset 재생성(§4).
- 다크모드: `.io-login` 은 항상 라이트 컴포지션 — 다크 토글과 무관해야 함.
