## 0. 한 줄

어드민에서 **입력창·textarea가 회색 배경에 묻히고, 비활성 버튼/입력 글자가 opacity-50으로 안 보이는** 문제를, 어드민 스코프에서 **컨트롤 배경 흰색·placeholder 가독·비활성 상태를 "읽히는 회색"** 으로 바꾸고, 핵심 비활성 버튼엔 **비활성 사유**를 붙인다.

## 1. 원인 진단 (검증된 코드 사실)

- `input`(ui/input.tsx): `**bg-transparent**` + `placeholder:text-muted-foreground` + `**disabled:opacity-50**`. → 어드민 회색 배경(#EEF1F5) 위에서 흐림, 비활성 시 반투명으로 글자 안 보임.
- `button`(ui/button.tsx): `**disabled:opacity-50**` → 라이트에서 비활성 버튼 텍스트 거의 안 보임(“지금 AI 갱신·기사 풀본문 채우기·신호 분류·수정” 등).
- 185가 outline 버튼·select-trigger는 `--card`로 바꿨으나 **input/textarea·disabled 상태는 미처리**.

## 3. 구현

### 3-1. input / textarea — 흰색 surface + 가독 placeholder (admin-scope)
`globals.css` `.admin-scope`:
```css
.admin-scope [data-slot="input"],
.admin-scope [data-slot="textarea"] {
  background-color: var(--card);
  border-color: var(--border);
}
.admin-scope [data-slot="input"]::placeholder,
.admin-scope [data-slot="textarea"]::placeholder {
  color: var(--text-tertiary);   /* 값보다 옅되 읽히는 회색 */
  opacity: 1;
}
```
- 입력값 텍스트는 `--foreground`(진하게) — 컴포넌트 기본 text가 foreground면 OK, 아니면 명시.
- placeholder = `--text-tertiary`(#6B7280) — 값(진한)과 구분되되 읽힘.

### 3-2. 비활성(disabled) — "읽히는 비활성" (admin-scope)
opacity-50 대신 배경·텍스트 톤으로 비활성 표현(글자는 읽히게):
```css
.admin-scope [data-slot="button"]:disabled,
.admin-scope [data-slot="button"][aria-disabled="true"] {
  opacity: 1;
  background-color: var(--muted);
  color: var(--text-tertiary);
  border-color: var(--border);
  cursor: not-allowed;
}
.admin-scope [data-slot="input"]:disabled,
.admin-scope [data-slot="textarea"]:disabled,
.admin-scope [data-slot="select-trigger"][data-disabled] {
  opacity: 1;
  background-color: var(--muted);
  color: var(--text-tertiary);
  cursor: not-allowed;
}
```
- 비활성이어도 **글자 읽힘 + not-allowed 커서**로 "누를 수 없음"을 표현(안 보이게 하지 않음).
- destructive/brand 등 색 버튼의 비활성은 위 규칙이 덮되, 필요 시 변형 최소.

### 3-3. focus / error 상태(확인·보강)
- focus-visible 링(기존)·aria-invalid(에러 빨강 테두리) 유지. 어드민 스코프에서 링 색이 배경 대비 잘 보이는지 확인(brand/ring 토큰).

### 3-4. 핵심 비활성 버튼 "사유" (타겟)
- **AdminContentManager 대량작업**(선택 필요: 노출/숨김/삭제·풀본문·신호 분류): 선택 0일 때 비활성 + **작은 사유 문구/툴팁** "콘텐츠를 1개 이상 선택하면 실행할 수 있습니다."
- **AiRefreshButton** 등 실행 중 비활성: title/툴팁으로 "실행 중…" 표시.
- 전 버튼 사유는 과함 — **대량작업·주요 실행 버튼만** 사유 제공(나머지는 3-2의 읽히는 비활성으로 충분).
