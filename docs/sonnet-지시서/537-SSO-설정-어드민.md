## GoTrue Admin API 계약 (공식 문서 확인)

GET    /auth/v1/admin/sso/providers        (?resource_id= / ?resource_id_prefix= 필터)
POST   /auth/v1/admin/sso/providers
GET    /auth/v1/admin/sso/providers/{id}
PUT    /auth/v1/admin/sso/providers/{id}
DELETE /auth/v1/admin/sso/providers/{id}
헤더: Authorization: Bearer <SERVICE_ROLE_KEY> · apikey: <SERVICE_ROLE_KEY> · Content-Type: application/json

POST 파라미터
  type              필수, "saml"
  metadata_url      택1 필수 (https 만 허용)
  metadata_xml      택1 필수 (원문 XML 문자열)
  domains           선택, 문자열 배열
  attribute_mapping 선택, { keys: { email: { name | names[] , default?, array? }, ... } }
  name_id_format    선택, persistent | emailAddress | transient | unspecified
  resource_id       선택, 외부 식별자(라벨로 쓴다)
  disabled          선택, true 면 등록하되 비활성

응답
  { id, resource_id, disabled, saml: { entity_id, metadata_url },
    domains: [{ domain }], created_at, updated_at }

어드민 등록·관리 화면만. LoginCard 수정과 signInWithSSO 호출 코드는 이번에 만들지 않는다.

## 작업

1) src/lib/admin/sso-admin.ts (신규, 'server-only')
   베이스 `${process.env.NEXT_PUBLIC_SUPABASE_URL}/auth/v1/admin/sso/providers`
   키는 process.env.SUPABASE_SERVICE_ROLE_KEY
   함수: listProviders / getProvider / createProvider / updateProvider / deleteProvider
   - 응답 !ok 면 { status, message } 를 담아 throw 한다. 본문을 삼키지 말 것(운영철학).
   - toPublicProvider() 화이트리스트 직렬화만 반환:
     id, resource_id, disabled, saml.entity_id, saml.metadata_url,
     domains[].domain, created_at, updated_at
   - service_role 키와 metadata_xml 원문은 절대 반환값에 싣지 않는다.

2) src/app/api/admin/sso/providers/route.ts        (신규) — GET 목록 / POST 등록
   src/app/api/admin/sso/providers/[id]/route.ts   (신규) — GET / PUT / DELETE
   전부 verifyAdminRequest({ capability: 'manage_settings' }) 로 시작한다(super_admin 전용).
   POST 입력 검증:
   - metadata_url 또는 metadata_xml 중 정확히 하나 필수. metadata_url 은 https 만 허용.
   - domains 는 선택. 빈 배열이면 키 자체를 보내지 않는다.
   - resource_id / name_id_format / attribute_mapping / disabled 는 선택 통과.
   - 그 외 필드는 버린다. 요청 본문 패스스루 금지.

3) src/components/admin/SsoProviderManager.tsx (신규, 'use client')
   - 상단 SP 정보 카드(고정 문자열 + 복사 버튼): EntityID / ACS URL / Metadata URL.
     IdP 담당자에게 그대로 넘기는 값이다.
   - 등록 폼
