## 0. 한 줄

어드민 v2에서 `--background`가 회색(#EEF1F5)이 되면서, **`outline` 버튼(`bg-background`)·select 트리거(`bg-transparent`)가 배경과 같은 색이 되어 사라진** 문제를, 어드민 스코프에서 **컨트롤 배경을 흰색(`--card`)로** 바꾸고 **투명 카드에 `bg-card`**를 넣어 복구한다.

## 1. 원인 진단 (검증된 코드 사실)

- `components/ui/button.tsx` `outline` variant = `border-border **bg-background** hover:bg-muted`. 어드민 스코프에서 `--background=#EEF1F5`(페이지 배경) → **outline 버튼 = 배경과 동일색 = 안 보임**. (사용처: 기사 풀본문 채우기·신호 분류·기간 드롭다운·행 "노출" 토글·AI 갱신 등.)
- `components/ui/select.tsx` SelectTrigger = `**bg-transparent** border-input` → 회색 배경 위 투명 → 트리거·플레이스홀더 흐림.
- `AdminTodoBlock` 카드(3개): `rounded-xl border border-border p-4` — **`bg-card` 없음** → 투명 → 회색 배경 그대로 비쳐 카드가 안 뜸.
- 정상 카드(대시보드 KPI 등)는 `bg-card` 사용 → 183 그림자와 함께 잘 뜸(대비 정상).

## 3. 구현 (`globals.css` `.admin-scope` + AdminTodoBlock)

### 3-1. outline 버튼 — 흰색 surface
`.admin-scope`에서 outline 버튼 배경을 `--card`로(회색 배경 위 흰 컨트롤):
```css
.admin-scope [data-slot="button"][data-variant="outline"] {
  background-color: var(--card);
}
```
- hover는 기존(`hover:bg-muted`) 유지되되, muted가 배경과 구분되게(180 --muted 값 확인 — 필요 시 hover를 `--accent`로). border-border가 흰 버튼 경계를 잡아줌.
- (secondary/ghost도 어드민에서 안 보이면 동일 원칙: secondary=surface+border+text-primary, ghost는 hover 시만 배경.)

### 3-2. select 트리거 — 흰색 surface
```css
.admin-scope [data-slot="select-trigger"] {
  background-color: var(--card);
  border-color: var(--border);
}
```
- 플레이스홀더(`data-placeholder:text-muted-foreground`)는 v2 --muted-foreground(#4B5563)로 읽힘 — 흰 배경 위라 또렷.

### 3-3. input/검색창
- 검색 input이 `bg-background`/투명이면 어드민에서 `--card`로(동일 원칙). 이미 bg-card/흰색이면 스킵.

### 3-4. AdminTodoBlock 카드 → bg-card
- 3개 카드 `rounded-xl border border-border p-4` → **`bg-card` 추가**(183 그림자 자동 적용, 배경 위로 뜸). 내부 텍스트 대비도 살아남.

### 3-5. 마젠타 링크 대비(참고)
- "검토하기 →" 등 카드 내 링크는 brand(마젠타) — 흰 카드 위라 대비 OK(유지). 회색 배경 직접 위 마젠타 텍스트만 주의(카드 안이면 문제 없음).
