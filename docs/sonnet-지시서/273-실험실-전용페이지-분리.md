# 지시서 (추가분 11) — '실험실' 전용 페이지 분리 (2026-07-10)

**작성**: Cowork Opus
**대상**: Claude Code

## 배경 / 요청
[[지시서_20260710b_실험실-헤더로-이동]]에서 헤더 5탭 줄로 옮겼던 실험실(헤드라인 분석/뜨는 토픽/이슈 타임라인, 관리자 전용)을 `/dashboard/issues?view=...` 쿼리파라미터 방식 대신, 독립적이고 확장 가능한 별도 페이지 `/dashboard/lab`으로 분리한다. 앞으로 생길 실험 탭까지 포함하는 스코프.

## 설계
- 새 라우트 `/dashboard/lab` 신설. 기존 `/dashboard/issues` 페이지·`AiInsightBoard.tsx`·`AiInsightsView.tsx`는 수정하지 않음 — 운영 중인 AI 인사이트 페이지에 리스크를 주지 않기 위해 데이터 패칭 로직을 별도로 복제.
- `src/lib/lab/data.ts`: `getLabData(supabase)` — 헤드라인/뜨는 토픽/이슈 타임라인 3개 탭에 필요한 부분만 추출.
- `src/components/analysis/LabBoard.tsx`: `LAB_TABS` 배열 기반 탭 구성. 탭 추가는 배열 항목 + 렌더 분기만 추가하면 되는 구조.
- `src/middleware.ts`: `/admin` 가드와 동일 패턴으로 `/dashboard/lab` 전용 role 체크 추가.
- `src/app/dashboard/lab/page.tsx`: 서버 컴포넌트, 로그인/role 방어적 이중 체크 + `getLabData` 호출 + `LabBoard` 렌더.
- `DashboardHeader.tsx`의 "실험실" 링크를 기존 3개 쿼리파라미터 링크에서 `/dashboard/lab` 단일 링크로 교체.

## 구현 결과 (Claude Code, 2026-07-10)
- 신규: `src/lib/lab/data.ts`, `src/components/analysis/LabBoard.tsx`, `src/app/dashboard/lab/page.tsx` — 지시서 원안 그대로 적용.
- `src/middleware.ts`: `/admin` 가드 바로 아래 `/dashboard/lab` role 체크 추가. `middleware-manifest.json` 확인 결과 catch-all matcher가 `/dashboard/lab`을 정상 커버함(죽은 코드 아님, 활성 등록 확인).
- `src/components/dashboard/DashboardHeader.tsx`: `LAB_QUICK_LINKS` 상수·3-링크 블록 제거, 단일 `/dashboard/lab` 링크로 교체(`pathname.startsWith('/dashboard/lab')` 기준 활성 스타일). `isAdmin` state·계산 로직은 그대로 유지.
- 기존 `/dashboard/issues?view=headline` 등 경로·`AiInsightBoard.tsx`의 `LAB_TABS`/`LAB_VIEW_IDS`/비관리자 폴백 가드는 손대지 않음 — 병행 유지.
- `npm run build`, `npm run lint`, `npx tsc --noEmit` 모두 통과(기존 무관 warning만 존재, 신규 에러 없음). `/dashboard/lab` 라우트가 빌드 산출물에 정상 포함됨을 확인.
- 브라우저 실사용 확인(관리자/비관리자 리다이렉트, 헤더 활성 스타일, 탭 전환)은 이 환경에서 미실시 — 배포 후 시각 확인 필요.
