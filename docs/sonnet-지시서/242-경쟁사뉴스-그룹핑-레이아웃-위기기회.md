범위: `entities/page.tsx`의 `competitor` 뷰 재작성 + `EntityTabs.tsx` 탭 이름 변경(프론트). 전제: **224 SQL**(competitor_group)·**241 SQL+백엔드**(lgu_impact) 적용. 둘 다 미적용 시 graceful.

## 2. 구현 — `entities/page.tsx` competitor 뷰 재작성

### 2-1. 데이터
- 기존 경쟁사 이름 조회에 **competitor_group 포함**: `entities.select('canonical_name, competitor_group')`(42703이면 그룹 없이 폴백). `entity_aliases`도 조회해 **이름/별칭(lower) → group** 맵(224 trend와 동일).
- 기사 select에 **`lgu_impact` 추가**: `select('id, title, collected_at, lgu_impact, matched_keywords, sources(name)')`. (`sentiment`도 남겨두되 표시엔 미사용 — 42703 방어 위해 lgu_impact는 select 실패 시 없는 값으로.)
- 회사별 집계: 매칭 기사 + **impact 분포** `{위기, 기회, 관망}`(lgu_impact 기준) + 상위 기사(최대 5).
- **그룹 버킷팅**: 각 회사(엔티티 이름)를 그룹 맵으로 → `통신/클라우드·플랫폼/빅테크` 순. 그룹 없는 경쟁사는 **"기타 경쟁사"** 그룹(맨 끝).
- competitor_group 컬럼 미적용(42703) 시: 전원 단일 그룹(무헤더 or "경쟁사")으로 폴백 → 기존과 유사하게라도 렌더.

### 2-2. 렌더 (레이아웃 A — 목업 대응)
그룹 순서대로 **그룹 박스**:
- **그룹 헤더**: 그룹명(`text-[15px] font-bold`) + `N개사 · M건`(muted) + 우측 미니 요약 칩(그룹 합계 위기/기회, 0이면 생략).
- **회사 카드 = 가로 배치**(David 확정): 그룹 박스는 세로로 쌓고, **그룹 내부 회사 카드는 가로 한 줄**(예: 통신 = SKT·KT·SKB·세종텔레콤 가로). 넘치면 **가로 스크롤**. `flex gap-3 overflow-x-auto` + 각 카드 `flex-none w-[288px]`(+ `snap-x`/`snap-start` 선택). 세로 그리드 아님.
  - 회사 카드(`flex-none w-[288px] rounded-xl border bg-card p-4 hover:border-brand-200`):
    - 헤더 행: 회사명(`text-sm font-bold`) + 우측 impact 칩(위기/기회/관망 중 **0 아닌 것만**, `위기 N`·`기회 N`·`관망 N`).
    - 기사 1~2건(제목 line-clamp-1 + `· 출처`), 링크 `/dashboard/contents/{id}`. 초과분 `+N건 더 →`(있으면).
- **칩 색 토큰**: 위기 `bg-negative-soft text-negative`, 기회 `bg-blue-50 text-blue-700 dark:bg-blue-950/40 dark:text-blue-300`, 관망 `bg-muted text-muted-foreground`. (일관: 위기=부정 톤, 기회=블루, 관망=뉴트럴.)
- 상단 **범례**(오른쪽 정렬): `LG U+ 관점: 위기 / 기회 / 관망` 작은 칩(선택, 목업 참고).

### 2-2b. 기간 표시 (David 요청 — "기간이 좀 보여야 함")
- 탭 상단에 **기간 캡션**: 예) `최근 14일 · 경쟁사 관련 뉴스`(muted, 목록 위). 14일은 기존 `fourteenDaysStart` 상수 기준.
- **회사 카드의 각 기사 행에 날짜**: `collected_at`(또는 published_at)을 `M.D`(ko-KR, Asia/Seoul)로 우측/말미에 작게(`text-[11px] text-muted-foreground`). 기사 제목 line-clamp 유지하되 날짜는 별도 span.
- (선택) 회사 카드 헤더에 그 회사 기사들의 **최신 날짜** 1개를 미니 표기해도 좋음.

### 2-3. 빈/폴백 상태
- 경쟁사 미등록: 기존 "경쟁사 키워드를 등록하면…" 유지.
- 기사 없음: 기존 "최근 14일 경쟁사 관련 기사가 없습니다." 유지.
- lgu_impact 전부 null(241 백필 전): impact 칩 없이 회사·기사만 표시(그룹 레이아웃은 유지). 칩은 값 있을 때만.
