## A. 신규 — 스와이프 카드뉴스 `src/components/analysis/NewsCardSlider.tsx`
- **가로 슬라이드**(한 번에 1장 포커스), **좌우 화살표 + 점(dot) 인디케이터 + 터치 스와이프 + 키보드 ←/→**. 라이브러리 없이 CSS scroll-snap 또는 경량 인덱스 상태로(외부 의존 추가 금지).
- **카드 1장 = 큰 글자 에디토리얼**:
  - 키커: 종류 배지(예 `인사이트` / `주요 뉴스`) + 주제/출처·일자
  - **헤드라인 큰 글자**(text-2xl~3xl bold)
  - 1~2줄 요약(implication 또는 summary_ko, line-clamp)
  - 하단: "기사 보기 →"(content 링크) 또는 "자세히"(인사이트 근거)
  - 절제된 톤(단일 brand 액센트, 이모지·그라데이션 금지, [[일반 사용자 우선]]).
- 반응형: 모바일 1장 풀폭, 데스크톱 1~1.2장(다음 카드 살짝 보이게) 정도.

## B. 콘텐츠 (①+②, 직렬화 가능 props로 서버 주입)
- **①인사이트 슬라이드**: 최신 published `insight_cards` 상위 N(예 5) → headline·implication·topic.
- **②오늘의 주요 뉴스 요약**: 최근(예 1~2일) published `contents` 중 `summary_ko` 있는 상위 N(중요도/최근순, 클러스터 대표 우선) → title·summary_ko·source·link.
- 합쳐 ~8~10장. 종류 배지로 구분. (서버 컴포넌트에서 조회 → 슬라이더에 props.)
- **보기(렌즈) 연동(138)**: 활성 보기가 `all`이 아니면 슬라이드도 그 기준으로 필터/우선(매칭 카드 먼저). `all`이면 전체.
