## 3. 구현

### 3-1. 뉴스 카드 — 위계를 세운다

| 층 | 지금 | 바꿀 것 |
|---|---|---|
| 그룹명 | `text-[15px] font-bold` | **그대로** (최상위) |
| 기업명 | `text-sm font-bold` | **`font-semibold`로 낮출 것.** bold 두 층이 겹치면 둘 다 안 보인다 |
| 기사 제목 | (확인 후) | **가장 크게 읽혀야 한다.** 사용자가 실제로 읽는 건 기사 제목이다 |

**⭐ 원칙: 한 카드에 `font-bold`는 하나뿐이다.**

### 3-2. 뉴스 카드 — **2건 + 더보기**

- 기업당 기사를 **2건**만 보이고, 나머지는 **"+N건 더"**.
- `capPerGroup`이 이미 있다 → **props로 넘기거나 기본값을 2로.** 새 로직 금지.
- "더보기"는 **기업 상세로 이동**(기존 링크 재사용).

### 3-3. 뉴스 카드 — **색을 줄인다**

지금 한 카드에 **4가지 색**이 동시에 뜬다(위기 빨강 · 기회 파랑 · 링크 핑크 · hover 핑크).

- **위기/기회 배지는 유지**(신호다).
- **링크 색(brand-600)·hover 테두리(brand-200)를 없애거나 중립으로.** 카드 전체가 클릭 가능하면 링크에 색을 줄 이유가 없다.
- **`0`인 배지는 아예 안 띄운다** — `위기 0`은 정보가 아니라 노이즈다.

> **색은 강조 수단이다. 다 강조하면 아무것도 강조 안 된다.**

### 3-4. 주간 리포트 카드 — 개요를 **읽을 수 있게**

- **`summary`를 3줄까지** 보여준다(`line-clamp-3`). 지금보다 짧으면 늘리고, 길면 줄인다.
- **`overall_impact`(위기/기회/관망)를 배지로** — §3-5의 공용 배지를 쓸 것.
- **`emerging_topics` 상위 2~3개**만 칩으로. 지금 3개면 그대로.
- **주차(`week_start`~`week_end`)는 작게.** 제목이 아니다.

### 3-5. ⭐ 위기/기회 배지를 **공용 컴포넌트로**

**313이 콘텐츠 화면에 같은 배지를 붙인다.** 지금 스타일이 `CompetitorNewsGroups.tsx:40,43`에 **인라인으로 박혀 있다.**

```tsx
// 기존 (이걸 정본으로 삼는다 — 색을 새로 짓지 말 것)
위기: bg-negative-soft text-negative
기회: bg-blue-50 text-blue-700 dark:bg-blue-950/40 dark:text-blue-300
```
→ `src/components/entities/ImpactBadge.tsx`(또는 공용 위치)로 추출하고 **경쟁사 화면·313이 같은 것을 쓰게** 한다.

⚠️ **313이 먼저 배포되면 313이 만든 것을 쓸 것.** 두 개를 만들지 말 것. **어느 쪽이든 하나만 존재해야 한다.**
