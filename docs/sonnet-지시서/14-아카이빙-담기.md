**아카이브에 담기 (`handleAdd`)**
```typescript
async function handleAdd(archiveId: string) {
  setLoading(true)
  setError(null)
  const { error } = await supabase
    .from('archive_items')
    .insert({ archive_id: archiveId, content_id: contentId, order: 0 })
  if (error) {
    setError('저장에 실패했습니다. 잠시 후 다시 시도해주세요.')
  } else {
    setSavedIds(prev => new Set([...prev, archiveId]))
  }
  setLoading(false)
}
```

**신규 아카이브 생성 + 담기 (`handleCreate`)**
```typescript
async function handleCreate() {
  if (!newName.trim()) { setError('아카이브 이름을 입력해주세요.'); return }
  setLoading(true)
  setError(null)
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) { setError('로그인이 필요합니다.'); setLoading(false); return }

  const { data: archive, error: createErr } = await supabase
    .from('archives')
    .insert({ user_id: user.id, name: newName.trim() })
    .select('id, name, updated_at')
    .single()

  if (createErr || !archive) {
    setError('아카이브 생성에 실패했습니다.')
  } else {
    setArchives(prev => [archive, ...prev])
    await handleAdd(archive.id)
    setCreating(false)
    setNewName('')
  }
  setLoading(false)
}
```

- 클릭 시 절대 위치 드롭다운 패널 (포커스 아웃 시 닫힘, `useEffect` + `ref` 활용)
