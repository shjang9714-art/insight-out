## 3. 구현

### 3-1. `src/lib/issues/interpret.ts` (신규, 순수 함수)
이슈 카드 → 규칙 해석. 결정적·LLM 없음.

```ts
import type { IssueCard } from './activity'

export interface IssueInsight {
  why: string            // "왜 중요한가" 한두 문장
  tone: 'risk' | 'positive' | 'neutral'  // why 강조 색 (163 토큰)
}

export function buildIssueInsight(card: IssueCard): IssueInsight {
  // 우선순위: 논조 악화 > 급증 > 신규 > 꾸준
  if (card.changeFlag === 'worsening') {
    return { tone: 'risk',
      why: `부정 논조가 빠르게 늘고 있어 주의가 필요합니다 (최근 부정 ${card.sentimentNeg}건).` }
  }
  if (card.changeFlag === 'surge') {
    const delta = card.changePct === null ? '새로 부상' : `직전 주 대비 +${card.changePct}%`
    return { tone: 'risk',
      why: `최근 7일 ${card.recentCount}건으로 ${delta} — 빠르게 확산 중인 이슈입니다.` }
  }
  if (card.prevCount === 0 && card.recentCount > 0) {
    return { tone: 'neutral', why: `이번 주 새로 등장한 이슈입니다 (최근 ${card.recentCount}건).` }
  }
  // 긍정 우세면 positive 톤
  if (card.sentimentPos > card.sentimentNeg && card.sentimentPos >= 3) {
    return { tone: 'positive',
      why: `최근 7일 ${card.recentCount}건, 긍정 논조가 우세합니다.` }
  }
  return { tone: 'neutral',
    why: `최근 7일 ${card.recentCount}건으로 꾸준히 다뤄지고 있습니다.` }
}

// 내 업무 관련: 매칭 시 한 줄(범위별 문구). 미매칭이면 null.
export function buildIssueRelevance(
  matched: boolean, activeLens: 'all' | 'mine' | 'watch',
): string | null {
  if (!matched || activeLens === 'all') return null
  return activeLens === 'mine'
    ? '내 담당 업무와 연관된 이슈입니다.'
    : '내 관심사와 연관된 이슈입니다.'
}
```
- 문구는 기계적이어도 무방(162 원칙). 숫자는 집계값 그대로.
- 임계값(긍정 ≥3 등)은 가이드 — 미세조정 허용.

### 3-2. `IssueBoardClient.tsx` — 카드에 해석·관련 주입
카드 레이아웃(제목 행 → summary → **신규** → 푸터) 사이에 삽입:
- **"왜 중요한가"**: `buildIssueInsight(card).why` 를 작은 한 줄. 라벨 "왜 중요한가"(또는 아이콘) + tone 색(163 토큰: risk=`text-risk`, positive=`text-positive`, neutral=`text-muted-foreground`). summary 아래.
- **"내 업무 관련"**: `buildIssueRelevance(matched, activeLens)` 가 non-null 이면 옅은 한 줄(brand 또는 muted). 기존 `LensBadge` 와 중복되지 않게 — 배지는 유지하되 문장은 카드 본문에. (배지=표식, 문장=설명.)
- 카드가 `<Link>` 이므로 내부는 텍스트만(중첩 링크 금지).
- 과밀 방지: summary 는 line-clamp-2 유지, why 는 1줄(line-clamp-2 허용), 관련 1줄.
