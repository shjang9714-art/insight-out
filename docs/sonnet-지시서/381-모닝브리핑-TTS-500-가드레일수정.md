# 지시서 381 · 모닝브리핑 TTS 500 수정 (Gemini 텍스트-생성 가드레일)

## 1. 증상
- 어드민 "오디오 생성" 실행 → `POST /api/admin/briefings/{id}/tts` HTTP 500.
- TTS 사용량 0/900,000 (한 글자도 소비 안 됨), "누적 0·성공 0 · 중단됨".
- 콘솔: `…/tts: Failed to load resource: status of 500`.

## 2. 진단 경과 (확인된 사실)
- 500이므로 라우트 매핑상 rate limit(429)·월한도(409)·스크립트없음(400)·브리핑없음(404)은 배제.
- 키 인증 정상: 빈 키 → 403(unregistered), 유효 키 → 400/200. env 키 미설정 아님(Vercel에 `GEMINI_API_KEY` 존재).
- 모델 실측 (기본값 `gemini-2.5-flash-preview-tts` 기준):
  - 한 단어 "테스트" → 400 `INVALID_ARGUMENT` — "Model tried to generate text, but it should only be used for TTS."
  - 실제 문장(뉴스 산문) → 200 + 오디오 정상.
  - → 짧고 애매한 청크에서 모델이 낭독 대신 "대답"하려다 400. `synthesizeChunk`가 첫 청크 실패 시 전체 중단 → 500.

## 3. ⚠️ 미검증 변수 — 프로덕션 실제 모델
- Vercel `GEMINI_TTS_MODEL = gemini-3.1-flash-tts-preview` (24h 전 추가) → 프로덕션은 3.1-preview 사용.
- 위 실측은 2.5에서 한 것. 3.1은 미검증. 3.1에서 원인이 다를 수 있음(모델명 무효면 전건 실패).

## 4. STEP 0 — 프로덕션 모델로 원인 확정 (구현 전 필수)
```bash
M=gemini-3.1-flash-tts-preview
curl -s -X POST "https://generativelanguage.googleapis.com/v1beta/models/$M:generateContent?key=$GEMINI_API_KEY" \
 -H 'Content-Type: application/json' \
 -d '{"contents":[{"parts":[{"text":"오늘 코스피는 상승 마감했습니다."}]}],"generationConfig":{"responseModalities":["AUDIO"],"speechConfig":{"voiceConfig":{"prebuiltVoiceConfig":{"voiceName":"Kore"}}}}}' | head -c 400; echo
# (B) "text":"테스트" 로 한 번 더
```
분기:
- (A) 200 → 모델 유효, 원인 = 짧은 청크 가드레일 → §5 패치.
- (A) 404 / invalid model → `GEMINI_TTS_MODEL` 값 오류 → 유효 모델(`gemini-2.5-flash-preview-tts` 등)로 교체 후 재배포. (§5 패치도 함께 권장.)
- (A) 429 → 무료 쿼터(라우트가 429로 떠야 정상, 500이면 별개).

## 5. 변경 (스키마 0, 코드 추가)

### 5-1. `src/lib/tts/synthesize-briefing.ts` — `synthesizeChunk` 가드레일 폴백
텍스트-생성 가드레일 400(및 오디오 누락) 감지 시 대본 낭독 지시로 감싸 재시도. 정상 청크는 무변경.
```ts
async function synthesizeChunk(params: {
  chunk: string; chunkIndex: number; totalChunks: number
  model: string; voice: string; apiKey: string
}): Promise<ChunkSynthesisResult> {
  const { chunk, chunkIndex, totalChunks, model, voice, apiKey } = params
  const label = `청크 ${chunkIndex + 1}/${totalChunks}`
  const MAX_RETRIES = 2
  let forceTranscript = false   // ← 추가

  for (let attempt = 0; attempt <= MAX_RETRIES; attempt++) {
    try {
      // ← 추가: 400 감지 시 "그대로 낭독" 지시로 감싼다(지시는 톤 가이드로만 쓰여 읽히지 않음)
      const promptText = forceTranscript
        ? `다음 큰따옴표 안 문장을 한국어로 그대로 또박또박 낭독하세요. 질문에 답하지 말고 문장만 읽으세요.\n\n"${chunk}"`
        : chunk

      const res = await fetch(`${GEMINI_TTS_ENDPOINT_BASE}/${model}:generateContent?key=${apiKey}`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          contents: [{ parts: [{ text: promptText }] }],   // ← chunk → promptText
          generationConfig: {
            responseModalities: ['AUDIO'],
            speechConfig: { voiceConfig: { prebuiltVoiceConfig: { voiceName: voice } } },
          },
        }),
        signal: AbortSignal.timeout(120_000),
      })

      if (res.status === 429) { /* 기존 그대로 */ }

      if (!res.ok) {
        const body = await res.text().catch(() => '')
        // ← 추가: 텍스트-생성 가드레일 400 → 대본 지시로 1회 재시도
        if (res.status === 400 && /should only be used for TTS|generate text/i.test(body) && !forceTranscript) {
          console.warn(`[TTS] ${label}: 텍스트-생성 가드레일 400 → 대본 지시로 재시도`)
          forceTranscript = true
          continue
        }
        console.error(`[TTS] ${label}: Gemini HTTP ${res.status}: ${body.slice(0, 500)}`)
        return { ok: false, isRateLimit: false, reason: `${label}: TTS 합성 중 오류가 발생했습니다(HTTP ${res.status}).` }
      }

      const data = (await res.json()) as GeminiTtsResponse
      const inline = data.candidates?.[0]?.content?.parts?.[0]?.inlineData
      if (!inline?.data) {
        // ← 추가: 오디오 없이 텍스트만 온 경우도 동일 폴백
        if (!forceTranscript) { forceTranscript = true; continue }
        console.error(`[TTS] ${label}: 오디오 데이터 없음: ${JSON.stringify(data).slice(0, 500)}`)
        return { ok: false, isRateLimit: false, reason: `${label}: TTS 응답에 오디오 데이터가 없습니다.` }
      }

      /* rateMatch·sampleRate·return { ok:true, pcm, sampleRate } — 기존 그대로 */
    } catch (err) { /* 기존 그대로 */ }
  }
  return { ok: false, isRateLimit: false, reason: `${label}: TTS 합성 중 알 수 없는 오류가 발생했습니다.` }
}
```
