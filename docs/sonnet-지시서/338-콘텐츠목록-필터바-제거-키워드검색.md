### 3-3. 검색 + 키워드 칩 UI

필터 바 자리에 **박스 없이** 배치한다:

```
🔍 [ 제목·요약에서 검색…                                    ]

  #AI데이터센터 24   #클라우드 18   #망사용료 12   #전력수요 9   … (상위 12개)
     ↑ 선택 시 강조 + 누적(AND 아님 — OR)
```

- **검색**: `title` · `summary_ko` **ILIKE** (`or('title.ilike.%q%,summary_ko.ilike.%q%')`)
  - **디바운스 300ms**. 매 타이핑마다 쿼리를 던지지 말 것
  - URL 파라미터 `?q=` 로 동기화 (뒤로가기·공유 가능)
- **키워드 칩**: `?kw=A,B` 로 동기화. 여러 개 선택 시 **OR**(`.overlaps()`) — AND면 대부분 0건이 된다
- **선택된 칩은 상단에 유지**되고, **[모두 지우기]** 를 둔다
- ⛔ **박스로 감싸지 말 것.** 칩만 평평하게 떠 있게 한다 (David 지시: *"내부 박스들도 모두 제거"*)

## 4. 회귀 가드

### 4-0. 🔴 **다른 레인이 `prebuild` 빌드 가드를 걸었다** (⓪ 재검증에서 발견)

`8af73a7` (속도개선 레인) — `package.json:8` `"prebuild": "… && node scripts/check-prefetch.mjs"`

**규칙**: `/dashboard/*` **동적 상세 라우트**로 가는 `<Link>`는 **`prefetch={false}` 가 필수**다.
예외는 `<Link>` **바로 윗줄**에 `{/* prefetch-ok: 사유 */}`.
**위반하면 `prebuild` 가 exit 1 → 빌드가 깨진다.**

→ **키워드 칩은 `<Link>` 가 아니라 `<button>` 으로 만들 것.** URL 동기화는 `router.replace` / `updateParam` 으로 한다(기존 패턴).
→ 새 `<Link>` 를 추가할 일이 생기면 **반드시 `prefetch={false}`.**
→ 빌드 전에 `node scripts/check-prefetch.mjs` 를 단독 실행해 **0건**을 확인할 것.

- ⛔ **`LensSwitcher.tsx` 컴포넌트를 삭제하지 말 것.** 4개 화면(`AiInsightBoard`·`EntitiesPageClient`·`IssueBoardClient`·`LabBoard`)이 쓴다.
- ⛔ **`lib/lens.ts` 를 건드리지 말 것.** `useActiveLens`·`LENS_PRESETS`·`STORAGE_KEY`·`'lens:changed'` 전부 4개 화면이 의존한다. **309 배선을 깨면 안 된다.**
- ⛔ **마이페이지 "기본 보기"(default_lens) 컨트롤을 제거하지 말 것.** 4개 화면의 초기값이다. **문구만 고친다.**
- ⛔ **`/api/keywords/top` 을 수정하지 말 것.** AI 인사이트 계열이 쓴다. 새 API를 만든다.
- **위기/기회 *배지*(`LguImpactBadge`)는 유지한다.** 제거하는 건 **필터**뿐이다. 배지는 12개 파일이 쓴다(`ContentCard`·`ContentRow`·`ContentListCard`·상세 등). **313을 무력화하지 말 것.**
- **소스타입 탭(`InsightViewTabs`, `:672-681`)은 유지.** 뉴스/리포트/유튜브 전환은 필터 바가 아니라 **탭**이다.
- **일별 그룹핑·`cluster` 그룹핑(`:588`)·더보기(`:578`)·`PAGE_SIZE` 유지.** 297에서 정리한 것을 되돌리지 말 것.
- **`total` 카운트가 검색·키워드 필터에 맞게 갱신될 것.** 1,963건 그대로 두면 거짓말이 된다.
- **빈 상태**: 검색·칩으로 0건이면 **"조건에 맞는 콘텐츠가 없습니다 · [필터 지우기]"**. 빈 화면만 띄우지 말 것.
- **`matched_keywords` 가 null/빈 배열인 행**이 있다 (`admin/page.tsx:147` — `matched_groups is null` 카운트가 콘텐츠 건강 지표에 있다). **칩 필터 시 이 행들이 조용히 사라지는 게 정상**이지만, **전체 보기(칩 미선택)에서는 반드시 나와야 한다.**
