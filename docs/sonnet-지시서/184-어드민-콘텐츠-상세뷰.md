## 0. 한 줄

어드민 콘텐츠 관리 목록의 **제목을 클릭하면 `/admin/contents/[id]` 상세 페이지**가 열려, **서비스와 동일한 기사 렌더 + 수집 정보 패널(상태·검토 사유·소스·수집일·본문 상태)**을 보여준다. **모든 상태(검토 대기 포함)** 열람 가능.

## 1. 현행 진단 (검증된 코드 사실)

- 서비스 상세 `app/dashboard/contents/[id]/page.tsx`는 **`.eq('status','published')` + notFound** → 발행만 표시. **검토 대기(pending) 콘텐츠는 여기서 못 봄**(어드민이 봐야 할 대상).
- 어드민 상세 라우트 **없음**(`/admin/contents/page.tsx`만). `AdminContentManager`는 제목 클릭 시 편집(`openEdit`) — 기사 열람 아님.
- `AdminContentManager` 행은 `id, title, category, status, collected_at, bookmark_count, body_fetched_at, review_reason`(178) 보유.

## 3. 구현

### 3-1. 공용 기사 뷰 추출 — `ContentArticleView`
서비스 상세의 **기사 본문 블록(제목·소스/발행일/저자·요약·본문)**을 프레젠테이션 컴포넌트 `src/components/contents/ContentArticleView.tsx`로 추출(props = 직렬화된 content 필드).
- 서비스 상세(`dashboard/contents/[id]`)가 이 컴포넌트를 사용하도록 리팩터(발행 게이트·연관/추천 섹션 등 주변 로직은 페이지에 유지 — **핵심 기사 렌더만 공용화**).
- 목적: 어드민·서비스가 **한 컴포넌트로 동일 렌더**(향후 드리프트 방지).
- 리팩터 최소·회귀 0(서비스 화면 표시 불변).

### 3-2. 어드민 상세 라우트 — `app/admin/contents/[id]/page.tsx`(신규)
- admin 인증(기존 admin 페이지 가드 재사용).
- **admin 클라이언트로 상태 무관 조회**(published 게이트 없음) → 없으면 notFound.
- 렌더: `<ContentArticleView content={…} />` + **수집 정보 패널**(아래) + 상단 "← 콘텐츠 관리" 링크.
- `.admin-scope` 안(어드민 레이아웃) — v2 스타일·타이포 자동.

### 3-3. 수집 정보 패널(어드민 전용)
기사 옆/위에 접이식 또는 사이드 패널:
- **상태 배지**(175 StatusBadge) + **검토 사유**(178 REVIEW_REASON_LABEL, pending일 때).
- 소스명 · 카테고리 · 수집일(collected_at) · 발행일(published_at) · 본문 상태(body_len/풀본문·스니펫·미수집, body_fetched_at) · 원문 URL 링크(원문 열기).
- (선택) 빠른 액션: 상태 변경(발행/검토/숨김)·편집 링크 — 있으면 검수 흐름 완결. 없으면 목록에서 처리(후속).

### 3-4. 목록 제목 → 상세 링크 (`AdminContentManager`)
- 제목을 `<Link href={`/admin/contents/${row.id}`}>`(또는 클릭 핸들러)로 — **편집은 별도 버튼/아이콘으로 분리**(제목 클릭=열람, 편집=명시 액션). 새 탭 여부는 취향(같은 탭 + 뒤로가기 권장).
- 목록 조회 컬럼은 현행 유지(상세에서 전체 필드 재조회).

## 4. 회귀 가드 / 비기능 요건

- **서비스 상세 표시 불변**(ContentArticleView 추출 리팩터는 렌더 동일). 발행 게이트 유지.
- 어드민 상세는 **모든 상태 열람**(admin 인증 필수). 비admin 접근 차단.
- 제목 클릭이 편집을 덮지 않게(열람=상세, 편집=별 액션).
- 어드민 한정 v2 스타일. 신규 hex 0. SQL/의존성 0.
