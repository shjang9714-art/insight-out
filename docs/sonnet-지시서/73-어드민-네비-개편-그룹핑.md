## 배경 (페르소나 회의 결론)
- 상단 네비는 **플랫 11개**, 홈 카드는 **6개만** → 둘이 불일치해 "정신없다". 신규 운영자는 비슷한 탭 구분을 못 한다(예: 서비스 키워드 vs 토픽 규칙).
- 해결: **네비 항목을 한 곳(공유 설정)에서 6그룹으로 정의** → 상단바·홈 카드가 같은 설정을 소비. 불일치 제거 + 그룹 라벨로 길찾기.

### 그룹 구조(David 승인)
| 그룹 | 항목(href · label · 설명) |
|---|---|
| **현황** | `/admin` 대시보드 — 수집·검토·참여 현황 한눈에 |
| **콘텐츠** | `/admin/contents` 콘텐츠 관리 · `/admin/upload` 콘텐츠 추가 · `/admin/briefings` 모닝브리핑 |
| **수집** | `/admin/sources` 소스 관리 · `/admin/crawl-logs` 크롤링 현황 · `/admin/translation` 번역 상태 |
| **분류 규칙** | `/admin/keywords` 서비스 키워드 · `/admin/keyword-groups` 토픽 규칙 |
| **발행** | `/admin/newsletter` 뉴스레터 |
| **시스템** | `/admin/users` 사용자 관리 |

## 작업

### 1. 공유 네비 설정 — `src/lib/admin/nav.ts` (신규)
- export `ADMIN_NAV_GROUPS: { group: string; items: AdminNavItem[] }[]`.
- `AdminNavItem = { href: string; label: string; description: string; icon: LucideIcon }`.
  - 아이콘: lucide-react 만 사용(#아이콘 규칙). 예: 대시보드 `LayoutDashboard`, 콘텐츠 관리 `Newspaper`, 콘텐츠 추가 `FilePlus`, 모닝브리핑 `Sun`, 소스 `Rss`, 크롤링 `ListChecks`, 번역 `Languages`, 서비스 키워드 `Tags`, 토픽 규칙 `Network`, 뉴스레터 `Mail`, 사용자 `Users`.
- 위 표 순서·그룹 그대로. `'현황'` 그룹의 대시보드 항목 1개 포함(홈 자기 자신).

### 2. 상단바 — `AdminNav` 그룹 구분 렌더
- `AdminNav` props 를 `groups: typeof ADMIN_NAV_GROUPS` 로 변경(또는 flatten 받아도 되나, 그룹 사이 **얇은 구분선**을 넣기 위해 그룹 단위로 렌더).
- 렌더: 수평 유지(`overflow-x-auto`). **그룹 사이에 세로 구분선**(`<span className="mx-1 h-4 w-px bg-border" aria-hidden />`) 삽입. 데스크톱에서 공간이 빠듯하면 그룹 첫 항목 앞에 아주 작은 그룹 라벨(`text-[10px] uppercase text-muted-foreground/60`)은 **선택**(과밀하면 생략, 구분선만으로 충분).
- 활성 표시 로직(`pathname` 매칭)·스타일 토큰 기존 유지. `'현황'`의 `/admin` 은 정확 일치(`pathname === '/admin'`)로(기존 분기 그대로).
- `layout.tsx`: 인라인 `NAV_ITEMS` 삭제 → `ADMIN_NAV_GROUPS` import 해 `<AdminNav groups={ADMIN_NAV_GROUPS} />`.

### 3. 홈 메뉴 카드 — 그룹별 섹션으로 (불일치 해소)
- `src/app/admin/page.tsx` 의 인라인 `MENU_ITEMS`(6개) 삭제 → `ADMIN_NAV_GROUPS` 소비.
- "관리 메뉴" 섹션을 **그룹별 소제목 + 카드 그리드**로 렌더(현황 그룹의 대시보드 자기 항목은 카드에서 제외). 카드 디자인(아이콘 배지·hover:brand)·`description` 표시는 기존 스타일 유지.
- 이로써 11개 항목이 모두, 그룹 라벨과 함께 홈에 노출(누락 0).
- ⚠️ 홈의 상단 "운영 현황" KPI 섹션은 **건드리지 말 것**(지시서 74가 현황판으로 교체). 이번엔 메뉴 카드 영역만 그룹화.

## 회귀 / 주의
- 라우트 이동·통합 없음(href 불변) → 링크/북마크 깨짐 0. 그룹은 표시상 분류일 뿐.
- 상단바는 모바일 좁은 폭에서 가로 스크롤 유지(구분선 포함). 줄바꿈 강제 금지.
- UI 한국어(#1)·토큰/brand 색(#9)·lucide 아이콘만(#아이콘)·`'use client'` 는 AdminNav leaf 유지(#12).
- `page.tsx` 는 서버 컴포넌트 유지(설정 import 는 서버에서 OK, 아이콘은 컴포넌트 렌더만).
