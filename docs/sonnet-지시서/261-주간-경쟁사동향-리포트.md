# 지시서 261 — 주간 경쟁사 동향 리포트 (사업영역별 + 위기/기회 + 타임라인)

목표: 경쟁사 동향 탭을 **per-company 카드 나열 → 주 1회 종합 분석 리포트**로 전환한다. 이번 주 경쟁사(통신 3사 중심) 기사를 **사업 영역별(AIDC·AICC·통신B2B·보안·클라우드…)로 종합**하고, 각 영역·리포트에 **LG U+ 위기/기회**를 붙이며, 과거 리포트를 **타임라인**으로 쌓는다. 중복 카드 문제를 종합으로 해소하고 주요 기업(회사별)과 명확히 차별화.

David 확정: 주간 리포트 · 사업별 분류 · 위기/기회 타임라인 · 프롬프트 어드민 편집 · free LLM(전처리로 부담↓, Gemini 우선). **257 대체(폐기).**

범위: SQL(`261-competitor-weekly.sql`: 테이블 + llm_prompts) + 생성 파이프라인(`lib/competitor-weekly/`) + 어드민 트리거 + 경쟁사 동향 탭 렌더. 전제: 253(curated)·241(lgu_impact)·238(LLM).

핵심 원칙: **LLM은 기사를 "찾지" 않는다.** 우리가 (1)기사 검색 (2)사업영역 사전분류(matched_groups) (3)위기/기회 사전판정(241 lgu_impact) 을 하고, LLM은 **영역별 종합·시사점 작성만** 한다.

---

## 1. 데이터 모델 (`261-competitor-weekly.sql`)
```sql
create table if not exists public.competitor_weekly_reports (
  id uuid primary key default gen_random_uuid(),
  week_start date not null,
  week_end   date not null,
  summary    text,                         -- 주간 한 줄 요약
  overall_impact text check (overall_impact in ('위기','기회','관망')),
  emerging_topics text[] not null default '{}',
  sections   jsonb not null default '[]',  -- [{area_key,area_label,moves,companies[],impact,implication,citations[{content_id,quote}]}]
  status     text not null default 'draft' check (status in ('draft','published')),
  generated_at timestamptz not null default now(),
  created_at   timestamptz not null default now(),
  unique (week_start)
);
alter table public.competitor_weekly_reports enable row level security;
create policy "cwr: 인증 조회" on public.competitor_weekly_reports for select using (auth.uid() is not null and status='published');
create policy "cwr: admin 전체" on public.competitor_weekly_reports for all using (public.is_admin()) with check (public.is_admin());
```
- llm_prompts 시드 2건 추가: `competitor_weekly_area`, `competitor_weekly_summary`(§4). (llm_prompts 테이블은 253에 이미 있음.)

## 2. 사업 영역 축 (분류)
- LG U+ 사업 라인 = **keyword_groups** 재사용. 리포트 영역(우선순위): **AIDC(aidc)·AICC(aicc)·통신 B2B(telecom_b2b)·보안(cctv+보안)·클라우드/IT(it_trend)·모빌리티(mobility)·제조 DX(manufacturing_dx)**.
- 그 주에 경쟁사 기사가 있는 영역만 섹션 생성.

## 3. 생성 파이프라인 (`lib/competitor-weekly/generate.ts`)
1. **기사 검색(우리)**: 최근 7일 `contents`(published) 중 **curated_companies(is_competitor) name+aliases ∩ matched_keywords**. (경쟁사 기사만.)
2. **영역 버킷팅(우리)**: 각 기사의 `matched_groups`로 사업 영역에 배정(§2 축). 한 기사 다중 영역 가능.
3. **위기/기회 사전집계(우리)**: 각 기사의 `lgu_impact`(241) → 영역별 위기/기회/관망 분포.
4. **영역별 LLM 종합**: 영역별로 기사(제목·요약·content_id·lgu_impact 힌트)를 `competitor_weekly_area` 프롬프트로 → `{moves, companies, impact, implication, citations}`. 영역별 개별 호출(집중 컨텍스트 → 품질↑). `llmComplete('summarize', …)`(gemini 우선).
5. **주간 헤더 LLM**: 영역별 결과 종합 → `competitor_weekly_summary` 프롬프트로 `{week_summary, emerging_topics, overall_impact}`.
6. **저장**: `competitor_weekly_reports` upsert(week_start). status = 근거 충분하면 published, 아니면 draft(어드민 승인).
7. **캐던스**: 주 1회 cron(예: 월요일) + 어드민 수동 트리거(`/admin/insights`에 "주간 경쟁 리포트 생성" 버튼). deadline 인지.

## 4. 프롬프트 (llm_prompts, 어드민 편집 — 정성껏)

### `competitor_weekly_area` (영역별 종합)
```
당신은 LG U+ B2B 경쟁 인텔리전스 수석 분석가다. 아래는 이번 주 '{area_label}' 영역의 경쟁사 관련 기사들이다. 이를 종합해 LG U+ 관점의 경쟁 동향을 분석하라.
**반드시 한국어로만 작성한다(고유명사 제외 영어 금지).** 단순 나열('누가 무엇을 했다') 금지 — 흩어진 사실을 하나의 흐름으로 종합하고 해석하라.
출력(JSON):
- moves: 이번 주 이 영역의 핵심 경쟁 움직임 2~4개를 종합 서술(각 서술 끝에 근거 [content_id]). 경쟁사별 사실을 연결해 "무슨 일이 벌어지고 있는지".
- companies: 이 영역에서 움직인 주요 경쟁사명 배열.
- impact: LG U+ 관점 판정 — "위기"|"기회"|"관망" 중 하나. (경쟁사 약진·잠식=위기, 경쟁사 부진·틈=기회, 중립·불명확=관망)
- implication: LG U+ B2B가 취해야 할 대응·주목점 2~3문장. 근거 밖 단정·과장 금지.
- citations: 핵심 주장별 15단어 이내 인용 + content_id. 3건 이상 권장.
JSON만 출력.
```
(입력 user 프롬프트: area_label + 기사 목록 `[content_id] 제목 / 요약 / (lgu_impact 힌트)`.)

### `competitor_weekly_summary` (주간 헤더)
```
당신은 LG U+ B2B 경쟁 인텔리전스 수석 분석가다. 아래는 이번 주 사업영역별 경쟁 동향 분석 결과다. 종합해 주간 리포트 헤더를 작성하라. 한국어만.
출력(JSON):
- week_summary: 이번 주 경쟁 구도를 한 줄로(공백 포함 24자 내외, 구체적·사실 기반).
- emerging_topics: 이번 주 새로 부상하거나 주목할 주제 2~3개(배열, 각 10자 내외).
- overall_impact: 종합 판정 "위기"|"기회"|"관망" 중 하나.
JSON만 출력.
```

## 5. 렌더 (경쟁사 동향 탭 — trend 뷰 교체)
- `entities/page.tsx` trend 뷰: 기존 curated 카드 그룹핑 제거 → **최신 published 주간 리포트** 렌더.
- **리포트 헤더**: 주차(week_start~end) + `summary` + `overall_impact` 칩(위기 빨강/기회 파랑/관망 뉴트럴).
- **사업별 섹션**: 각 `sections[]` — 영역 label + **위기/기회 칩** + `moves`(종합 서술, 근거 content_id는 링크로) + `companies` 칩 + `implication`. (245 그룹박스 톤.)
- **부상 주제**: `emerging_topics` 칩.
- **타임라인(핵심)**: 과거 주간 리포트 목록을 시간축으로 — 각 주 = week + `overall_impact` **색 점/바**(위기 빨강·기회 파랑) → 클릭 시 그 주 리포트. "경쟁 위협/기회 레이더".
  - 신규 페이지 `/dashboard/entities/competitor-weekly/[week]`(과거 리포트) 또는 인탭 타임라인.
- 근거 링크 = `/dashboard/contents/{content_id}`.
- 빈 상태(리포트 없음): "이번 주 경쟁 리포트 생성 대기".
