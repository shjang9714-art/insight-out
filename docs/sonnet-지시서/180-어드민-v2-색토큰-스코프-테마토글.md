## 0. 한 줄

## 1. 현행 진단 (검증된 코드 사실)

## 3. 구현

### 3-1. `globals.css` — 어드민 스코프 토큰(라이트+다크)
전역 `:root`/`.dark`는 건드리지 않고, **`.admin-scope` 블록 신설**로 어드민 안에서만 토큰 값 재정의(기존 토큰명 재사용 → 컴포넌트 무수정 자동 반영). hex 직접 값(토큰 정의부 예외 허용).

**라이트 `.admin-scope`**:
```
--background:#F7F8FA · --card:#FFFFFF · --popover:#FFFFFF · --surface-elevated:#FFFFFF
--sidebar:#FFFFFF · --border:#E5E7EB · --input:#E5E7EB · --accent:#F1F5F9 · --muted:#F1F5F9
--foreground:#111827 · --muted-foreground:#4B5563 · --text-tertiary:#6B7280 · --text-disabled:#9CA3AF
--color-brand-600:#DB0078 · --color-brand-700:#C00068
--positive:#2563EB · --positive-soft:#EFF6FF   (성공=블루)
--risk:#D97706 · --risk-soft:#FFF7ED           (주의=앰버)
--negative:#DC2626 · --negative-soft:#FEF2F2   (실패=레드)
--info:#64748B · --info-soft:#F1F5F9           (정보=슬레이트)
--sidebar-accent:#FDF2F8
```
**다크 `.admin-scope[data-admin-theme="dark"]`**:
```
--background:#0B0F14 · --card:#121821 · --popover:#121821 · --surface-elevated:#18202B
--sidebar:#111827 · --border:#273142 · --input:#273142 · --accent:#18202B · --muted:#18202B
--foreground:#F9FAFB · --muted-foreground:#D1D5DB · --text-tertiary:#9CA3AF · --text-disabled:#6B7280
--color-brand-600:#E6007E · --color-brand-700:#FF2C9C
--positive:#60A5FA · --positive-soft:rgba(96,165,250,.14)
--risk:#F59E0B · --risk-soft:rgba(245,158,11,.14)
--negative:#EF4444 · --negative-soft:rgba(239,68,68,.14)
--info:#94A3B8 · --info-soft:rgba(148,163,184,.14)
--sidebar-accent:rgba(230,0,126,.12)
```
- 신규 토큰 `--surface-elevated`·`--info`·`--info-soft`·`--text-tertiary`는 `@theme inline`에도 `--color-*` 매핑 추가(Tailwind 유틸로 쓰려면). 안 쓰면 CSS var 직접.
- 값은 대비 확보 선에서 미세조정 허용. **핵심 = 어드민이 David v2 팔레트로, 사용자 화면은 불변.**

### 3-2. 어드민 레이아웃 스코프 + 테마 상태 — `app/admin/layout.tsx`(+ 클라 래퍼)
- 신규 클라 컴포넌트 `AdminThemeScope`(또는 layout을 클라 래퍼로): 자식을 `<div className="admin-scope" data-admin-theme={theme}>`로 감싸고, `theme`은 `localStorage 'io:admin-theme'`(기본 `'light'`)에서 로드. 최상위 컨테이너 배경도 `bg-background`(스코프 오버라이드 반영).
- **플래시 방지**: 기본 라이트로 즉시 렌더 + 마운트 후 저장값 적용(또는 `<script>` 인라인으로 data-admin-theme 선반영 — 과설계 말고 라이트 기본이면 다크 저장자만 살짝 깜빡, 허용). 
- **전역 next-themes와 독립**: 어드민 스코프는 html.dark 무시하고 data-admin-theme만 따름(위 CSS가 `.admin-scope[data-admin-theme="dark"]`로만 다크 적용). 즉 어드민은 자체 토글로만 다크/라이트.

### 3-3. 어드민 테마 토글 — `AdminThemeToggle`(사이드바 하단)
- 라이트/다크 스위치(아이콘 Sun/Moon), 클릭 시 `theme` 토글 + localStorage 저장 + data-admin-theme 갱신.
- `AdminSidebar` 하단(사용자/시스템 그룹 근처)에 배치. 라벨 "라이트/다크".
