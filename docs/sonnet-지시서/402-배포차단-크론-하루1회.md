## 2. 왜 라우트는 안 고쳐도 되는가 (검산)

`competitor-weekly/route.ts` 는 매시간 호출을 전제로 **런타임 게이트**를 둔다(주석에 명시). 설정과 지금 KST 요일·시각이 맞을 때만 생성한다.

- 기본 설정: `generate_dow=1`(월), `generate_hour=6`(06시 KST) — `DEFAULT_COMPETITOR_WEEKLY_SETTINGS`.
- 게이트: `nowKst.getUTCHours() === generate_hour` **AND** `nowKst.getUTCDay() === generate_dow`.

**`0 21 * * *`(21:00 UTC)가 이 게이트를 정확히 통과한다:**

| 항목 | 계산 |
|---|---|
| 21:00 UTC → KST | `+9h` = **06:00 KST 다음날** → `getUTCHours(nowKst)=6` = `generate_hour` ✓ |
| Hobby ±59분 지터 | 21:00~21:59 UTC = 06:00~06:59 KST → hour 는 **항상 6** ✓ |
| 요일 | 일요일 21:00 UTC = **월요일 06:00 KST** → `getUTCDay(nowKst)=1` = `generate_dow` ✓ |
| 매일 호출인데 주 1회만 생성 | dow 게이트가 월요일만 통과시킨다 ✓ |
| 재실행 안전 | 멱등 가드(`already_exists`)가 대상 주 중복 생성을 막는다 ✓ |

→ **라우트 무수정.** 06시 KST 창과 정확히 일치한다.

### 2.1 ⚠️ 감수하는 제약 (기록)
하루 1회로 내리면 **어드민에서 `generate_hour`·`generate_dow` 를 바꿔도 크론 시각(월 06시 KST)을 벗어나면 생성되지 않는다.** 매시간 크론이 이 자유도를 주던 것이다.
- 기본값이 월 06시라 **지금은 문제없다.**
- 시각을 바꾸려면 `vercel.json` 을 함께 고쳐 재배포해야 한다. 이 사실을 어드민 `생성 설정` 탭 안내에 반영하는 것은 **(나) 범위** — 이번엔 하지 않는다.
- 근본적으로는 Vercel 크론 대신 외부 스케줄러(pg_cron·GitHub Actions)로 옮기면 자유도가 복원된다. (나) 백로그에 기록.
