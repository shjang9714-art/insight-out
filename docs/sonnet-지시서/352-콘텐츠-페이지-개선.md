# 지시서 352 — 콘텐츠 페이지 개선(히어로·그룹핑·뷰토글·키워드 태그)

> 대상: 구현 에이전트 · **신규 SQL 없음**
> ⚠️ 읽을 것: `src/app/dashboard/contents/page.tsx`(카테고리별 목록·groupByKstDay·카드/리스트 분기) · `src/components/dashboard/ContentCard.tsx`·`ContentListCard.tsx` · `src/components/reports/ReportCard.tsx`(히어로) · `src/app/dashboard/reports/[id]/page.tsx` · `src/lib/contents/excerpt.ts`(tagsOf2) · `src/lib/reports/query.ts` · `AGENTS.md`
> 선행: 키워드 상세 링크는 351-B의 `keywords/[name]` 를 가리킨다(351-B 미완이면 기존 `topics/[name]` 로 폴백).

## 배경 (David) — 6건

## 작업

### 1. 히어로 높이 ↓ + 문양 정의 + 보고서 키워드 태그
- `ReportCard` 커버 `aspect-[16/9]` → **`aspect-[21/9]`**(더 낮게). 상세(`reports/[id]`)의 표지 이미지 없을 때 여백도 축소.
- **문양 = 유형별 통일 픽토그램 유지**(David). 지금 유형별 lucide 아이콘(경쟁사분석=Radar 등)을 그대로 두되, 커버에서 **더 크고 은은하게**(중앙 저채도 워터마크) 배치해 "이 리포트가 어떤 유형인지"를 상징하게. 사진·배너 금지.
- **보고서 키워드 태그**: `ai_reports` 에는 키워드 컬럼이 없다. **근거 콘텐츠에서 모은다** — `ai_report_sources` → `contents.matched_keywords`/`matched_groups` 합집합(빈도순 상위 3~4) → **`tagsOf2()` 로 콘텐츠와 동일 표기**. 카드·상세 헤더에 칩으로. 각 칩 클릭 → `keywords/{name}`(351-B, 없으면 `topics/{name}`).
  - `lib/reports/query.ts` 의 리포트 조회에 근거 키워드 집계 추가(리스트는 카드 N개라 N+1 주의 — 한 번에 `in` 조회로).

### 2. 리서치: 일별 그룹핑 제거 → 평면 나열 + 날짜 배지
- `contents/page.tsx`: `리서치` 카테고리는 **`groupByKstDay` 를 적용하지 않고** 평면 그리드. 각 카드에 **발행일 배지**(카드 자체에 날짜 표시). 날짜 헤더(`오늘`/`어제`/`N월 N일`)는 리서치에서 미사용.

### 3. 상세 스크롤 시 상단 네비(레벨1·2) sticky
- `contents/[id]` 진입 시 5탭 네비(레벨1) + 카테고리 서브탭(레벨2)이 스크롤에도 **상단 고정**. 현재 `sticky top-14`(날짜 라벨)와 z-index 충돌 없게. 레이아웃 헤더가 이미 sticky면 상세에서 잘리지 않는지만 확인·보정.

### 4. 유튜브: 발행일 표기 + 일별 그룹핑 제거
- `ContentCard`(유튜브)에 **발행일(수집일)** 노출(현재 "발행 N시간 전" 유지하되 날짜도). `유튜브` 카테고리도 `groupByKstDay` 미적용, 평면 나열.

### 5. 뉴스: 카드 ↔ 리스트 토글 + 리스트 썸네일
- `뉴스` 목록 우측 상단에 **뷰 토글**(카드/리스트, 아이콘 2개). 선택 상태 `localStorage`(`io:contents-view`) 기억.
- 리스트 뷰: **좌측 작은 썸네일**(`thumbnail_url`/`coverUrlFor`, 없으면 유형 픽토그램) + 우측에 [유형·키워드칩] / 제목 / 요약 2줄 / [출처·발행일 / 원문]. `ContentListCard` 확장 or 신규 `ContentListRow`.
- 카드 뷰는 기존 `ContentCard` 그대로.
- 토글은 뉴스에 우선 적용(다른 카테고리는 후속).

## 회귀 / 주의
- 그룹핑 제거는 **리서치·유튜브만**. 뉴스·웹인사이트는 기존 유지(별도 지시 없으면).
- 뷰 토글은 클라이언트 상태 → 목록 렌더 부분만 클라이언트 분리, 서버 페치는 유지.
- 보고서 키워드 집계에서 N+1 금지(근거 content_id 모아 한 번에 조회).
- 색상·태그 표기는 `tagsOf2()` 하나로 통일(하드룰 9, 시스템 키워드 일관성).
- prefetch={false}, 한글 키워드 URL 인코딩.
- 검증: `tsc` · ESLint · `check-prefetch` · `npm run build` · 육안(리서치 평면·유튜브 날짜·뉴스 토글·리포트 태그·상세 sticky).
