# 지시서 260 — 주요 기업 설정 = 큐레이션 선택 (자유 검색 제거)

목표: "주요 기업 설정"을 **자유텍스트 검색/직접추가**가 아니라, **시스템이 제공하는 큐레이션 회사 목록에서 선택**하는 방식으로 바꾼다. 7그룹별 회사를 체크/칩으로 골라 내 주요 기업으로 담는다.

David 확정: "주요 기업 설정은 검색이 아니라 시스템에서 제공해주고 선택하는 것으로."

범위: `WatchlistManager.tsx`(모달 본문) — 검색 인풋·직접추가 제거, curated 그룹 선택을 주 UI로. `WatchlistSettingsModal.tsx` 설명문 정리. SQL 없음(253 재사용).

---

## 1. 현행 진단 (검증된 코드 사실)
- `WatchlistManager`: (a) 자유텍스트 **검색 인풋 + 직접추가**(225) + (b) **curated 그룹 선택 UI**(255/258, `curatedGroups.length>0 && curatedCompanies.length>0`일 때 노출). → 현재 검색이 상단·주(主), curated 선택이 아래.
- curated_groups/curated_companies(253)는 서버(getMajorCompaniesData)에서 정상 조회됨 → 클라(WatchlistManager)도 같은 anon 키라 조회 가능(스크린샷은 258 이전 캐시로 추정: 옛 설명문).
- David 요청: **검색 방식 폐기 → 큐레이션 선택 전용.**

## 2. 구현

### 2-1. WatchlistManager — 큐레이션 선택 전용으로 재구성
- **자유텍스트 검색 인풋·"직접 추가"·`/api/entities/search` 호출 제거**(모달 맥락). 큐레이션에 없는 회사 자유 추가는 폐지(시스템 제공 목록에서만 선택).
  - (공유 컴포넌트라 마이페이지도 영향 — 큐레이션 모델로 통일. 필요 시 `mode='curated'` prop으로 검색 숨김 처리하되, 기본을 큐레이션 선택으로.)
- **curated 그룹 선택을 주 UI로**(항상 노출):
  - `curated_groups`(kind='watchlist', sort_order) 7그룹 + `curated_companies`(groups[]) 로드.
  - 그룹별 섹션: 그룹 label + 소속 회사 **칩/체크** 나열. 선택된 회사는 강조(브랜드 틴트·체크).
  - **토글**: 회사 클릭 = 선택/해제 → `user_watchlist` upsert/delete(company=curated name, entity_id 연결). 기존 `toggleCurated` 재사용.
- **상단 "내 주요 기업"**: 현재 선택된 회사 칩(삭제 가능) 요약. 없으면 "그룹에서 회사를 선택하세요".
- 상한(예: 20개) 안내 유지.

### 2-2. 큐레이션 미로드 대비 (graceful)
- 253 미적용(42P01)·조회 실패 시: "큐레이션 목록을 불러오지 못했습니다"(빈 상태) — **검색 인풋으로 되돌리지 말 것**(자유 검색 폐기 방침). 로그만.
- (curated 섹션이 안 뜨던 문제 재확인: 쿼리 성공하는데 조건 렌더가 막혔으면 조건 수정. 서버에선 읽히므로 클라 쿼리·상태 세팅 점검.)

### 2-3. 모달 설명문 (`WatchlistSettingsModal`)
- 설명을 선택 중심으로: "그룹별 회사 목록에서 **주요 기업을 선택**하세요. 선택한 기업은 기업동향·AI 인사이트에서 모아 보여드립니다." (검색 문구 제거.)

## 3. 회귀 가드
- 선택 저장소는 기존 `user_watchlist`(225) 그대로 — 스키마·필터 로직 불변. 저장 방식만 검색→선택.
- 주요 기업 뷰(255 getMajorCompaniesData)는 user_watchlist 선택을 대표로 사용 — 변경 없음(선택 UI만 교체).
- 마이페이지 공유: 큐레이션 선택으로 통일(자유 검색 사라짐) — 의도된 변경.
- 253 미적용 graceful.
