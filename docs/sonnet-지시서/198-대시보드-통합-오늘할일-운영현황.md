## 1. 현행 진단 (검증된 코드 사실)

- 대시보드(`admin/page.tsx`) 렌더 순서: ① 오늘 할 일(AdminTodoBlock) → AI 갱신 → 운영 신호등 → 콘텐츠 건강 → ② 운영 현황(인라인 6카드) → 차트.
- **오늘 할 일**(AdminTodoBlock, 타일 5): `pending`(검토대기)·`today`(오늘수집)·`failed`(수집실패)·`sources`(소스오류)·`users`(승인대기). deep-link·긴급 톤.
- **운영 현황**(admin/page.tsx :279~357, 6카드): 총콘텐츠·오늘수집·검토대기·북마크·활성소스·리서치반영.

## 2. 구현 (순수 UI — SQL·데이터 무변경)

### 2-1. AdminTodoBlock — "오늘 수집" 타일 제거 (행동만 남김)
- `tiles` 배열에서 `key: 'today'`(오늘 수집) 항목 제거 → **4타일**(검토대기·수집실패·소스오류·승인대기).
- Props에서 `todayCollected` 제거(인터페이스·구조분해). 그리드 `lg:grid-cols-5` → `lg:grid-cols-4`(2 / sm:2 / lg:4 등 균형).
- `allClear`(tiles.every count===0) 자동 개선 — 오늘수집>0가 더 이상 "할 일 있음"으로 오독되지 않음(오늘수집은 상태 지표라 행동 아님).

### 2-2. 운영 현황 — "검토 대기" 카드 제거 (규모만 남김)
- admin/page.tsx 운영 현황 섹션에서 **검토 대기 카드(:315~322) 삭제** → **5카드**(총콘텐츠·오늘수집·활성소스·북마크·리서치반영).
- 그리드 `grid-cols-2 lg:grid-cols-3` 유지(5카드도 자연스럽게 배치). `pendingRes`는 오늘 할 일 타일에서 계속 사용하므로 쿼리 유지.

### 2-3. admin/page.tsx — 호출부 정리
- `<AdminTodoBlock ... />`에서 `todayCollected={todayRes.count ?? 0}` prop 제거(2-1 시그니처와 일치). `todayRes`는 운영 현황 "오늘 수집" 카드에서 계속 사용하므로 쿼리 유지.

### 2-4. (범위 밖)
- 운영 신호등·콘텐츠 건강·차트 섹션은 **무변경**. 카드 스타일/톤(197)·딥링크 경로 유지.
