### 2-3. 셀렉터 헬퍼 (`lib/contents/cover-pool.ts` 신규)
```ts
// 활성 풀 로드(요청 단위 cache). 테이블 없으면(42P01) 빈 맵 → graceful.
export const getCoverPools = cache(async () => {
  const admin = createAdminClient()   // 또는 SSR client(인증 select 정책 허용)
  const { data, error } = await admin
    .from('topic_cover_images')
    .select('key_type, key_ref, image_url')
    .eq('is_active', true)
    .order('sort_order', { ascending: true })
  if (error) return new Map<string, string[]>()   // 42P01 등 graceful
  const map = new Map<string, string[]>()
  for (const r of data ?? []) {
    const k = `${r.key_type}:${r.key_ref}`
    if (!map.has(k)) map.set(k, [])
    map.get(k)!.push(r.image_url)
  }
  return map
})

// 결정적 회전: 같은 콘텐츠는 항상 같은 이미지, 풀 내 고르게 분산.
function hashIndex(id: string, len: number): number {
  let h = 0
  for (let i = 0; i < id.length; i++) h = (h * 31 + id.charCodeAt(i)) >>> 0
  return h % len
}

export function pickCover(
  pools: Map<string, string[]>,
  content: { id: string; category: string | null; entityIds?: string[]; groups?: string[] },
): string | null {
  const tryKey = (k: string) => {
    const pool = pools.get(k)
    return pool && pool.length ? pool[hashIndex(content.id, pool.length)] : null
  }
  for (const eid of content.entityIds ?? []) { const u = tryKey(`entity:${eid}`); if (u) return u }
  for (const g of content.groups ?? [])      { const u = tryKey(`group:${g}`);   if (u) return u }
  if (content.category) { const u = tryKey(`category:${content.category}`); if (u) return u }
  return null
}
```

### 2-4. 콘텐츠 목록 통합 (`contents/page.tsx`, v1)
- 목록 아이템 확정 후:
  1. `getCoverPools()` 로드(빈 맵이면 스킵 — graceful).
  2. **엔티티 링크 배치 조회**: `content_entities.select('content_id, entity_id').in('content_id', ids)` → contentId→entityIds 맵.(테이블/에러 시 빈 맵)
  3. 각 아이템: `thumbnail_url`이 **없을 때만** `pickCover(pools, { id, category, entityIds, groups: matched_groups })` → 결과를 카드 `thumbnailUrl`로 전달. 있으면 폴백(BrandedCover) 그대로.
- **v1 범위 = 콘텐츠 목록만.** 피드/엔티티상세/검색/관련은 후속(동일 헬퍼 재사용).

## 3. 회귀 가드
- **실제 thumbnail_url 있는 카드 불변**(셀렉터는 null일 때만 개입).
- `topic_cover_images` 미생성(42P01)·`content_entities` 오류 → 빈 맵 → 기존 BrandedCover 폴백(크래시 없음). **코드가 SQL보다 먼저 배포돼도 안전.**
- `getCoverPools` 요청 단위 cache로 목록 1회만 조회.
- 결정적 회전: 같은 기사엔 항상 같은 이미지(리로드 시 안 바뀜).
- key_ref(entity)는 entities.id 문자열 — content_entities.entity_id와 일치.
