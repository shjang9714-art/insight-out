## 배경 (David 결정)
웹인사이트 소스로 정상 수집했는데 사용자 "웹인사이트" 화면에 안 보임. 원인 = 관련도 게이트가 `trust_tier<2` 인 웹인사이트 콘텐츠를 점수<임계값 시 **`pending`** 으로 묶어 사용자 피드(published만)에서 가려짐. **결정: 웹인사이트는 큐레이션된 양질 소스 → 게이트 면제(항상 published).**

## 작업

### 1. `orchestrator.ts` — exempt 조건에 web_insight 추가
- 현재(358줄 부근):
  ```ts
  const exempt = src.trust_tier >= 2 || groups.length === 0
  ```
  → **수정**:
  ```ts
  const exempt = src.trust_tier >= 2 || groups.length === 0 || src.type === 'web_insight'
  ```
- `ItemSourceCtx.type: SourceType` 존재 → 타입 기반 면제. 모든 web_insight 소스에 자동 적용(per-소스 trust_tier DB 수정 불필요).
- 효과: web_insight 콘텐츠는 `contentStatus='published'`. `importance_score`·태그(matched_groups/keywords)는 기존대로 계속 산정(점수 자체는 계산, 게이팅만 우회). LLM 애매밴드 재판정(inAmbiguousBand)도 면제로 스킵(현 로직: `!exempt` 조건이라 자동).

## 회귀 / 주의
- 뉴스(news_site)·리포트·유튜브 게이팅 동작 불변. web_insight 만 면제.
- **이미 pending 으로 저장된 기존 web_insight 행은 자동 전환 안 됨** → 어드민 콘텐츠 관리에서 **소스/카테고리=웹인사이트 + 상태=검토 대기 필터 → 일괄 승인**(지시서 52 기능) 또는 재수집. (1회성)
- web_insight 품질이 낮아질 우려 시 후속으로 임계값/별도 정책 재검토 — 지금은 면제(David 결정).
- 서버 전용. DB·enum 무변경.
