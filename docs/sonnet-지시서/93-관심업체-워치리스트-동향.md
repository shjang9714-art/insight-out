## 배경 (David)
③ 키워드 맵을 "관심업체 워치리스트 강조"로 가기로 함. 그 전에 **관심업체 워치리스트**가 있어야 함 — 담당자가 추적할 **업체를 자유 입력**하면, 그 업체 기준으로 동향을 본다. (KA 53곳 고정 제외 — 사용자 선택형.) 이 토대는 ③ 맵 강조 + 향후 ① company-scope 카드에도 쓰임.

## 작업

### 1. (선행) SQL — `user_watchlist`
- `docs/sql-handoff/93-user-watchlist.sql` **먼저 커밋·푸시**(수희 적용). `supabase/schema.sql` SSOT 반영(#6). 타입 `src/lib/types.ts` 에 `WatchlistItem` 추가.

### 2. 마이페이지 — 관심업체 관리 (자유 추가)
- `dashboard/mypage/page.tsx` "담당 서비스" 섹션 옆/아래에 **"관심업체"** 섹션 신설.
- **칩 입력**: 텍스트 입력 → Enter/추가 시 칩 추가, × 로 삭제. (ReportUploadForm 키워드 칩 UX 재사용.) 저장 버튼(담당 서비스 저장 패턴 미러).
- 저장: `user_watchlist` 에 본인 행 동기화 — 현재 칩 집합과 DB 비교해 insert/delete(또는 전체 삭제 후 재삽입, 소량이라 무방). RLS 본인 한정.
- 안내문: "동향을 추적할 업체명을 자유롭게 추가하세요. 기사 제목·요약에 그 이름이 잡히면 모아 보여줍니다."

### 3. 관심업체 동향 — AI 분석 페이지 섹션
- `dashboard/ai-analysis/page.tsx` 상단(또는 인사이트 카드 아래)에 **"내 관심업체 동향"** 섹션.
- 현재 사용자의 `user_watchlist` 조회 → 업체별 최근 기사:
  - 업체별 쿼리(Promise.all, 업체당 limit 5): `contents` published, **`title.ilike.%{company}%` OR `summary_ko.ilike.%{company}%`** (또는 `matched_keywords` 에 포함 시 우선), `order collected_at desc`. (`%`·특수문자 이스케이프; 빈 업체 skip.)
  - 표시: 업체명 헤더 + 그 아래 기사 링크(제목·출처·날짜, `/dashboard/contents/{id}`). 결과 0이면 "최근 동향 없음".
- 워치리스트 비어있으면 섹션에 "관심업체를 추가하면 여기서 동향을 봅니다 → 마이페이지" 안내(빈 상태).

## 회귀 / 주의
- SQL 선적용 필수(수희). 미적용 시 워치리스트 조회/저장 실패 → graceful 안내.
- ILIKE 매칭은 근사(부분 문자열) — 짧은 업체명은 오탐 가능(예: "KT"가 "KTX"에 매칭). 1차 허용, 정밀 매칭(단어 경계·matched_keywords 우선)은 후속.
- per-user RLS(본인만). 마이페이지·AI분석 모두 사용자 세션.
- 업체당 쿼리 limit·워치리스트 상한(예: 20개) 권장(과다 쿼리 방지).
- UI 한국어(#1)·토큰 색(#9)·`'use client'`(마이페이지 칩 입력 leaf).
