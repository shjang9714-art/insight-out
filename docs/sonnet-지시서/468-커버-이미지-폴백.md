# 지시서 468 — 커버 이미지 로드 실패 시 폴백(액박 제거)

**SQL 0 · env 0 · 의존성 0.** 표시 전용. 브랜치 `agent/468-cover-fallback`.

## 배경
`ReportStyleCard`는 `coverImageUrl`이 truthy면 `<img>`를 렌더하고 **`onError` 폴백이 없다**. 그라디언트+아이콘 폴백은 값이 **falsy일 때만** 작동한다.
→ URL이 깨지면 그라디언트로 낙하하지 않고 **액박**이 뜬다. 7월 리전 이동 때 705건이 이 상태로 노출됐다(474로 데이터는 복구).
전 코드베이스에서 이미지 `onError` 폴백은 `IssueEvidenceSection.tsx:66` **1곳뿐**이다.

## 변경
1. **`src/components/reports/ReportStyleCard.tsx`** — `<img onError>`로 로드 실패를 상태로 잡아 **기존 그라디언트+아이콘 분기로 낙하**시킨다(신규 폴백 디자인 만들지 말 것 — 이미 있는 else 브랜치를 재사용).
2. 콘텐츠 카드 등 **커버 `<img>`를 렌더하는 다른 카드**에도 동일 적용. 반복 구현 대신 **작은 공용 컴포넌트/훅 1개**로 묶는다(`CoverImage` 등).
3. 로드 실패는 `console.warn` 1줄로 남긴다(운영철학 — 조용한 실패 금지). 렌더 루프마다 반복 로그가 쌓이지 않게 실패 1회만.

## 완료조건
정상 URL 렌더 **회귀 0** · 깨진 URL이 액박 대신 그라디언트로 낙하 · 폴백 디자인 신규 정의 0 · tsc/lint/build.

## 병행 안내
**475와 파일이 겹치지 않는다**(475=lib 저장·읽기 계층, 468=카드 컴포넌트) → **병렬 진행 가능.**

## 재현검증
