## 배경 (David)

343으로 "주요 기업" 탭만 새 톤이 됐다. 같은 화면의 나머지 두 탭(**경쟁사 최근 뉴스**, **경쟁사 주간리포트**)은 여전히 옛 톤이라 탭을 넘길 때마다 다른 제품처럼 보인다. 옛 톤의 문제는 343과 동일하다.

- **경쟁사 최근 뉴스**: 그룹 박스 + 회사 카드 2중 표면. 기사 사이 점선. `관망 4` 같은 무의미한 배지가 카드마다 반복돼 정작 `위기 11`이 묻힌다. `grid-cols-2` 고정이라 모바일에서도 2열.
- **경쟁사 주간리포트**: 레이더가 박스 하나를 통째로 차지하는데 내용은 점 1개. 카드 요약이 14px/500이라 제목처럼 안 읽히고, `#해시태그`가 다시 등장.

## 설계 결정 (Opus)

1. **343의 원칙을 그대로 적용한다.** 시각 표면 1단계(카드만) · 제목이 최강 요소 · 강조는 예외만 · 3열 고정.
2. **공용 컴포넌트로 추출**해 세 탭이 같은 코드를 쓰게 한다(톤이 다시 갈라지는 것을 구조로 막는다).
   - `src/components/entities/CompanySymbol.tsx` — 343의 이니셜 심볼(회사명 == 이니셜이면 `null`).
   - `src/components/entities/EntitySectionHeader.tsx` — 플랫 섹션 헤더(제목·서브텍스트·우측 메타·전체 보기).
   - `src/lib/text/clean-narrative.ts` — `stripLlmArtifacts` + `①②③` 제거.
3. **`관망` 배지 제거.** 343의 "중요도 중간은 표시하지 않는다"와 같은 논리 — 대부분이 관망이라 배지로 띄우면 신호를 잃는다(`LguImpactBadge` 주석 313이 이미 경고하고 있던 내용). **위기·기회만** 노출.
4. **`LguImpactBadge` 자체는 손대지 않는다.** 앱 전역 공용 정의(313). 호출부에서 `관망`을 안 넘기면 된다. 단, 주간리포트의 **종합 판정**은 `관망`도 유의미한 결과값이므로 `showNeutral` 유지.
5. **데이터 계약 불변.** `CompGroupBucket`·`CompResult`·`CompetitorWeeklyCardRow` 필드 추가 없음. 섹션 서브텍스트는 대표 회사명으로 런타임 조립.

### B. 경쟁사 최근 뉴스 — `CompetitorNewsGroups.tsx`

- 래퍼 `space-y-11`, 그룹은 `<section>` + `EntitySectionHeader`
  - `title` = 그룹명(`통신` 등), `subtitle` = `"KT·KT AI 등 경쟁사의 최근 14일 뉴스"`(대표 2곳 조립)
  - `meta` = `기업 3곳 · 기사 29건`, `metaSlot` = 그룹 위기/기회 배지

- 회사 카드(`div`, 링크 아님 — 안쪽 기사가 링크):
  `flex flex-col gap-3 rounded-xl border border-border bg-card p-5`
  - 헤더: `CompanySymbol` + 회사명(`text-[13px] font-semibold muted`) + `flex-1` + **위기·기회 배지만**
  - 기사 `<ul>`: 행 `py-1 hover:bg-muted/50 rounded-md`, 제목 `text-[13px] text-foreground/85 line-clamp-1 group-hover:text-brand-600`, 출처 `muted-foreground/60`, 날짜 우측 `text-[11px] tabular-nums muted/70`

- 그리드: `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3` (343과 동일, 카드 수 무관 고정)
- **날짜 포맷**: `toLocaleDateString('ko-KR', {month:'numeric',day:'numeric'})` 는 `"7. 13."` 로 나온다. `formatToParts` 로 조립해 **`7.13`** 으로 표기할 것.

## 회귀 / 주의

- **`LguImpactBadge`(313) 파일 수정 금지.** 호출부에서 `관망`을 넘기지 않는 것으로만 처리. 콘텐츠 상세 등 다른 화면의 배지 동작이 바뀌면 안 된다.
- **주간리포트 종합 판정의 `showNeutral`은 유지** — 여기서는 `관망`이 결과값이다. (C와 B의 규칙이 다르다는 점을 혼동하지 말 것.)
- `MajorCompanyGroups` 리팩터는 **추출만**. 343 렌더 결과가 1px도 바뀌면 안 된다.
- 회사 카드는 `<div>`다(안쪽 기사가 각각 링크). 카드 전체를 `<Link>`로 감싸지 말 것 — 중첩 링크가 된다.
- 동적 상세 링크는 전부 `prefetch={false}` 유지(`check-prefetch` 통과 필요).
- 다크모드 `dark:` 변형 확인.
- 검증: `npx tsc --noEmit` · ESLint · `npm run build` · 세 탭(`?view=watchlist|competitor|trend`)과 전체보기 페이지(`/dashboard/entities/competitor-news`) 육안 — **탭을 넘겨도 같은 제품으로 보여야 한다.**
