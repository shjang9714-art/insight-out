## 목표
좌·우 패널을 **전 페이지 상시 노출 + 헤더 바로 아래부터 풀하이트**, 카테고리를 **두 패널 사이(중앙 상단)에 정사각 타일**로, 서비스 필터를 **사업키워드 멀티셀렉트(전체/단수/다수)** 로, 글 리스트에 **카드/목록 토글 + 요약 + 해시태그** 추가. 혼란스러운 브레드크럼 제거 + 홈버튼.

데이터 확인됨: `content_keywords`(크롤러가 태깅) → 해시태그 / `summary_ko` → 요약 / `content_services` → 사업키워드 매핑. 전부 구현 가능.

## 파트 A — 셸 3단 재구조 (`layout.tsx`)
- 현재: 헤더(sticky) → **전폭 sticky 상단 네비** → flex[`Sidebar` | `main`], 우측 레일은 `page.tsx`(홈 전용).
- 변경: 헤더 아래를 **3단 그리드**로. 좌·우 패널은 `layout` 에서 렌더해 **모든 대시보드 페이지에 상시 노출**.
  - 구조: `<header/>` 다음 `<div className="grid grid-cols-1 lg:grid-cols-[224px_minmax(0,1fr)] xl:grid-cols-[224px_minmax(0,1fr)_300px]">`
    1. **좌 패널** = `Sidebar`(아카이빙+최근). 이미 `sticky top-14 h-[calc(100vh-56px)]` — **헤더 바로 아래부터 풀하이트** 유지.
    2. **중앙** = (카테고리 타일 + `{children}`). 카테고리는 파트 C, 중앙 상단에 배치.
    3. **우 패널** = **신규 `RightRail` 컴포넌트**(브리핑 placeholder + `CompetitorTrends` + 트렌딩). `page.tsx` 에서 우측 레일 코드를 **`RightRail.tsx` 로 추출**해 `layout` 에서 렌더. 좌 패널과 동일하게 `sticky top-14 h-[calc(100vh-56px)] overflow-y-auto` 풀하이트.
- **전폭 sticky 상단 네비 박스 제거**(검색은 이미 헤더로 이동됨/38, 서비스 드롭다운은 파트 D 에서 제거). 카테고리만 중앙으로.
- `page.tsx`: 우측 레일 제거(→ `RightRail` 로 이동), 중앙은 `EmailArchiveWidget` + `RecentFeed` 만 남김.

## 파트 B — 홈버튼 + 브레드크럼/뒤로가기 제거
- **홈버튼**: `DashboardHeader` 좌측(로고 옆)에 `Home` 아이콘 버튼 추가, `href="/dashboard"`. (로고도 홈 링크지만 명시적 홈버튼 요구.)
- **브레드크럼 제거**: `contents/page.tsx` 의 "대시보드 › {pageTitle}" 브레드크럼 블록(L369~376) **삭제**. 페이지 제목(`<h1>{pageTitle}</h1>`)·건수는 유지. 내비게이션은 홈버튼 + 중앙 카테고리 타일로 대체.
  - 상세(`[id]/page.tsx`) 브레드크럼의 "대시보드" 백링크도 혼란 유발 시 제거(목록 링크 정도만 유지 가능 — 판단 위임, 보고에 명시).

## 파트 C — 카테고리: 정사각 타일 (중앙 상단, 스크롤 숨김 유지)
- 현재 pill 스트립(38) → **정사각 느낌 컴팩트 타일**로. 가로 한 줄, `flex items-center gap-2 overflow-x-auto scrollbar-hide`.
  - 타일: `flex flex-col items-center gap-1.5 w-16 shrink-0 rounded-xl border px-2 py-2.5`(아이콘 위·라벨 아래·오늘건수 작은 배지). 활성 `border-brand-600 text-brand-600`, 비활성 `border-border`. (이전 카드뷰의 정사각 느낌 복원, 단 작게.)
  - `CategoryGrid` 컴포넌트를 이 타일 행으로 조정. href 로직 유지하되 **`&svc=` 부착 제거**(서비스는 파트 D 에서 목록 페이지 필터로 이동).
- 위치: **중앙 컬럼 최상단**(좌우 패널 사이). `sticky top-14 z-10 bg-background` + **스크롤 다운 숨김/업 표시**(38 의 `translate-y` 로직 유지·이식).
- 노출 범위: 목록형 페이지(홈·contents·youtube·search)에만. 상세·마이페이지에서는 카테고리 타일 숨김(기존 `shouldHideTopNav` 류 판단 재사용). **좌·우 패널은 모든 페이지 노출**(카테고리 타일만 페이지별 분기).

## 파트 D — 서비스 → 사업키워드 멀티셀렉트 (38 전역 드롭다운 되돌림)
> 결정: 전역 "서비스 전체" 드롭다운 **제거**, 콘텐츠 목록 필터바에 **멀티셀렉트(전체/단수/다수)** 로 일원화.
1. **`ServiceTabs` 전역 사용 제거**: `layout` 에서 ServiceTabs/서비스 드롭다운 제거. `layout` 의 `activeService`/`handleServiceChange`/`svc` 전역 배선 제거(또는 미사용 정리). `CategoryGrid` 의 svc 부착도 제거(파트 C).
2. **`RecentFeed`(홈)**: 서비스 필터 제거 → 최근 콘텐츠 전체 표시(props 단순화). (홈은 개요, 정밀 필터는 목록 페이지에서.)
3. **`contents/page.tsx` 필터바에 사업키워드 멀티셀렉트 추가**:
   - "적용 중: 카테고리…" **칩 제거**(activeFilters 에서 category chip 푸시 제거 — L340). 카테고리는 페이지 제목으로 이미 표현됨.
   - 신규 컨트롤: `services` 테이블(이미 로드 중, `services` state) 을 **pill 토글 목록**으로. `[전체]` + 각 서비스 pill. "전체" = 선택 해제, pill 클릭 = 토글(다중 선택).
   - URL 파라미터: 단일 `svc` → **콤마구분 다중** `svc=uuid1,uuid2`. 파싱 `svc.split(',').filter(Boolean)`.
   - 쿼리: `content_services` 에서 `.in('service_id', svcIds)` → content_ids → 기존 교집합 로직에 반영(기존 단일 `eq('service_id', svc)` 대체). 빈 배열(전체)이면 서비스 필터 미적용.
   - 활성칩: 선택된 서비스만 칩으로(각 칩 X = 해당 서비스 토글 해제). 출처·날짜·키워드 칩은 유지.

## 파트 E — 카드/목록 뷰 토글 + 요약 + 해시태그
1. **뷰 토글**: 콘텐츠 목록 툴바(제목줄 우측 또는 필터바 우측)에 카드(`grid`)/목록(`list`) 토글 스위치. 선택 **localStorage `io:content-view`** 영속(SSR 가드). 기본 = 카드.
2. **요약 표출**: `ContentCard` 에 `summary_ko` 를 제목 아래 `line-clamp-2` 로 노출(현재 prop 만 받고 미표시면 표시 추가). 목록 뷰 row 에도 요약 1~2줄.
3. **해시태그**: 콘텐츠 조회 쿼리에 `content_keywords(keywords(name))` 조인 추가(상세페이지 L164 패턴 참고). 매핑 → `string[]`. 카드/행 하단에 `#키워드`(최대 3~4개, `text-brand-600 text-[11px]`). 빈 배열이면 생략.
   - 적용 쿼리: `contents/page.tsx` 목록 쿼리 + `RecentFeed` 쿼리 + `ContentCard` props(`keywords?: string[]`).
4. **목록 뷰 컴포넌트**: 신규 `ContentRow.tsx`(컴팩트 행: 썸네일 작게/생략 · 카테고리 배지 · 제목 · 요약 1줄 · 해시태그 · 메타). 카드뷰는 기존 `ContentCard` 재사용.
