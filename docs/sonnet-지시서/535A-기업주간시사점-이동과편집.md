# 지시서 535-A — 인사이트 카드 → "기업 주간 시사점" 이동·주 재생성·시사점 편집

> 플래너(Opus) · 2026-08-20 · 기준 `origin/main = a55a7cb` · 브랜치 `agent/535a-company-implication`
> 근거: `검토-어드민IA-2차통합안-2026-08-16` §① · 실측 재확인 완료. **DDL·SQL 없음.**
> `curated_companies` 관리 화면은 **535-B** 로 분리한다.

## 실측 사실 (재조사 금지)

- 어드민 "인사이트 카드"(`/admin/insights`)가 서비스 기업동향의 **"LG U+ 시사점" 본체**다.
  `insight_cards(scope='company', period_start=월요일)` → `MajorCompanyGroups` 가 렌더한다.
  **이름이 기능을 숨기고 있고, 어드민 기업동향 그룹에는 이 항목이 아예 없다.**
- 데이터: `scope='company'` 카드 **506건**(발행 298건), 최신 주 `period_start = 2026-08-10`.
- `POST /api/admin/insights` 는 **`weekStart` 를 이미 받는다**(`scope:'company'` 경로 한정,
  `generateCompanyInsightCards(admin, { …, weekStart })`).
  그런데 `InsightCardsManager` 는 `{ scope:'company' }` 만 보낸다 — **특정 주 재생성 UI 가 없다.**
- `PATCH /api/admin/insights/[id]` 는 **`status` 만** 화이트리스트한다 → 시사점 텍스트 편집 불가.

## 작업

### 1) 위치·이름

- `nav.ts` **발행 그룹**에서 `/admin/insights`(라벨 `인사이트 카드`) 항목을 **제거**하고,
  **기업동향 그룹**에 `{ href: '/admin/insights', label: '기업 주간 시사점' }` 으로 넣는다.
  위치는 `기업자료 수집` **앞**(그룹의 첫 항목). description 에 **"서비스 기업동향의
  'LG U+ 시사점'으로 노출됩니다"** 를 명시한다. 경로는 그대로다.
- 페이지 `metadata` 와 화면 제목도 맞춘다.
- 화면 상단에 안내 한 줄: **"여기서 발행한 카드가 서비스 기업동향의 'LG U+ 시사점'입니다."**
  이 지시서의 목적 절반이 이 문장이다.

### 2) 주 선택 + 특정 주 재생성

- `InsightCardsManager` 에 **주 셀렉터**를 넣는다.
  주 목록은 `insight_cards` 의 `scope='company'` `period_start` distinct 를 내림차순으로 쓴다.
  ⚠️ 목록 조회에 **`.limit()` 을 반드시 넣을 것**(PostgREST 기본 1000행. 현재 506건이라
  당장은 안 걸리지만 주가 쌓이면 걸린다).
- 재생성 버튼이 **선택된 주**를 `POST /api/admin/insights` 에 `weekStart` 로 실어 보낸다.
  주를 고르지 않았으면 종전대로 `weekStart` 없이 보낸다(= 직전 완결 주).
- 재생성은 **기존 카드를 덮어쓸 수 있는 동작**이다. `useAdminConfirm()` 으로 확인을 받고,
  문구에 **선택된 주와 그 주의 현재 카드 수**를 넣는다.
- API 는 이미 `weekStart` 를 받으므로 **라우트를 고치지 말 것.**

### 3) 시사점 텍스트 편집

- `PATCH /api/admin/insights/[id]` 화이트리스트에 **`headline` · `card_headline` ·
  `implication`** 세 필드를 추가한다.
  - 각 필드는 선택적. 문자열이 아니면 400.
  - `trim()` 후 **빈 문자열이면 400**(카드가 빈 채로 발행되는 걸 막는다).
  - `status` 와 **함께 보낼 수도, 따로 보낼 수도** 있게 한다.
  - ⚠️ **`citations` 는 절대 화이트리스트에 넣지 말 것.** 근거 인용은 LLM 생성물이고
    사람이 손대면 근거-본문 정합이 깨진다.
  - 그 외 필드는 버린다. 요청 본문 패스스루 금지.
- 화면에서 세 필드를 인라인 편집·저장할 수 있게 한다. 저장 후 목록을 다시 읽는다
  (낙관적 갱신 금지).

## 하지 않을 것

- `curated_companies` · `curated_groups` 관리 화면 — **535-B**
- 생성 로직(`generateCompanyInsightCards`)·크론(`ai-refresh`) 변경
- `insight_cards` 스키마 변경, `citations` 편집
- 서비스(사용자) 화면 수정
- `scope='industry'` 카드 쪽 동작 변경 — 같은 화면에 섞여 있으니 **회귀 없는지 확인만** 한다

## 검증

1. `npx tsc --noEmit` / `npx eslint`(경고 0건) / `npm run build`
2. 사이드바 **기업동향 그룹 첫 항목**에 "기업 주간 시사점"이 뜨고, 발행 그룹에서는 사라졌는지
3. 주 셀렉터에 `2026-08-10` 을 포함한 주 목록이 내림차순으로 뜨는지
4. **특정 주를 골라 재생성**했을 때 그 주의 카드가 갱신되는지(다른 주가 안 건드려지는지)
   — 확인창에 주와 현재 카드 수가 표시되는지
5. 시사점·헤드라인 편집 후 저장 → 새로고침해도 유지되는지
6. 빈 문자열로 저장 시 400 이 뜨고 카드가 비지 않는지
7. `citations` 를 body 에 실어 PATCH 해도 **무시되는지**(패스스루 없음 회귀 가드)
8. 산업(`scope='industry'`) 카드의 생성·상태 변경이 종전대로인지
