## 증상 (David)
콘텐츠 관리 **상태** 컬럼("노출/검토 대기/반려")과 소스 관리 **활성** 컬럼("활성/비활성")이 동그라미(pill) 안에 들어가 있고, 컬럼이 좁아 글씨가 **세로로 줄바꿈("활/성", "검토 대/기")** 되거나 짤린다. → **동그라미 빼고 평문 텍스트로**, 줄바꿈/짤림 없게.

## 작업

### 1. 콘텐츠 관리 상태 셀 — `AdminContentManager.tsx`
- `STATUS_STYLE` 의 `className` 을 **텍스트 색만** 남김(테두리·배경 제거):
  - published: `text-green-700`, pending: `text-yellow-700`, rejected: `text-red-600`(현 라벨/색 톤 유지).
- 상태 셀(현 `inline-flex rounded-full border px-2 py-0.5 text-xs font-medium` span):
  → `<span className={cn('whitespace-nowrap text-xs font-medium', statusStyle.className)}>{statusStyle.label}</span>`
  (rounded-full·border·bg·px·py 제거, `whitespace-nowrap` 추가)
- 해당 `<td>` 에 `whitespace-nowrap` 추가(셀이 글자폭만큼 확보되게).
- `STATUS_STYLE.label` 을 쓰는 다른 곳(상태 Select 565줄 부근)은 라벨만 사용 → 영향 없음.

### 2. 소스 관리 활성 셀 — `SourceManager.tsx`
- 활성 토글 버튼(현 `rounded-full px-2.5 py-0.5 text-xs font-medium ... bg-green-50/bg-muted`):
  - **pill 배경 제거**, 평문 텍스트로. 토글 동작(`handleToggle`)·`<button>` 유지.
  - className → `cn('whitespace-nowrap text-xs font-medium transition-colors', src.is_active ? 'text-green-700 hover:text-green-800' : 'text-muted-foreground hover:text-foreground')`.
  - 라벨 `{src.is_active ? '활성' : '비활성'}` 유지.
- 활성 `<td>`(현 `px-4 py-3`)에 `whitespace-nowrap` 추가.

### 3. (확인) 같은 패턴의 세로 짤림 점검
- 위 두 컬럼만 대상. 유형/수집방법 칩(SourceManager 800·806줄 `rounded-full bg-muted`)은 David 지적 대상 아님 → **변경 금지**(요청 범위 유지).
