## 배경
89가 산업동향 인사이트 카드를 생성·발행(published)한다. 이걸 **사용자 AI 분석 페이지**에 노출한다. 핵심 가치 = **출처 인용(2-1)** — 각 카드의 주장 밑에 근거 기사(인용 + 링크).

## 작업

### 1. 페이지 — `src/app/dashboard/ai-analysis/page.tsx` (신규, 서버 컴포넌트)
- briefings 페이지 미러(쿠키 서버 클라이언트, `await cookies()`).
- 조회: `insight_cards` `status='published'`(RLS가 이미 보장하나 명시), `scope='industry'`, `order('period_start', desc)` + `generated_at desc`, limit 30. select: `id, period_start, period_end, topic, headline, implication, source_content_ids, citations, generated_at`.
- **출처 제목 매핑**: 모든 카드의 `source_content_ids` + `citations[].content_id` 를 모아 1회 조회 — `contents.select('id, title, category, sources(name)').in('id', [...uniqueIds])` → `Map<id, {title, sources}>`. (RLS: published만 보이므로 비공개분은 매핑 누락 → 링크 생략 처리.)
- metadata: `title: 'AI 분석 | Insight Out'`.

### 2. 카드 렌더
- 컨테이너 `mx-auto max-w-5xl px-4 py-8 …`. 제목 "AI 분석" + 부제("AI가 짚는 산업 동향과 시사점").
- 기간 그룹 헤더(예: `2026.06.11 ~ 06.17`) 아래 그 기간 카드들.
- 카드(`rounded-xl border bg-card p-5`):
  - 상단: `topic` 배지(토큰 색) + 기간(작게).
  - **headline**(`text-base font-semibold`).
  - **implication**: `시사점:` 라벨 + 본문(`text-sm text-muted-foreground`).
  - **출처 인용 블록**(citations.length>0): 각 인용 — `"{quote}"` + 매핑된 기사 제목(있으면 `Link href={/dashboard/contents/${content_id}}`, 없으면 텍스트). 작은 회색, `ti-quote` 느낌의 아이콘/따옴표.
  - (citations 없으면) `source_content_ids` 를 "관련 기사" 링크 목록으로 폴백 표시.
- 빈 상태: "아직 발행된 인사이트가 없습니다." (dashed empty).

### 3. 진입점 — 사용자 네비
- `src/components/dashboard/Sidebar.tsx` 에 **"AI 분석"** 링크 추가(모닝브리핑 링크 패턴 미러, 별도 섹션 또는 상단). `href='/dashboard/ai-analysis'`, 아이콘 `Sparkles`(lucide). onClose 처리 동일.
- (배치는 잠정 — 사용자 IA 정식 네비는 후속. 지금은 도달 가능성 확보.)
