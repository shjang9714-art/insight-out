## 3. 구현

### 3-1. `InsightCardsSectionClient.tsx` — 보고서 버튼 삭제
`248-254`의 `<Link …>보고서로 만들기</Link>` 제거. 우상단 우측 그룹(`<div className="flex items-center gap-1.5">`)에는 "관심 표시" 배지만 남긴다. 배지마저 없으면 빈 div가 되므로, matched 가 false 이면 우측 그룹 자체를 렌더하지 않도록 정리(`{matched && <div…>…</div>}`).

### 3-2. `InsightCardNewsList.tsx` — 보고서 버튼 삭제
`157-163`의 `<Link …>보고서로 만들기</Link>` 제거. 같은 액션 행에 남는 건 "근거 N / 접기" 토글뿐 → 토글만 있을 때 레이아웃(좌우 정렬) 깨지지 않게 `justify-end` 또는 단독 정렬로 정리.

### 3-3. `AiInsightsView.tsx` — 카드뉴스 캐러셀 제거
- ① 섹션(`434-444`, `{newsSlides.length > 0 && (<section>…<NewsCardSlider/></section>)}`) 전체 삭제.
- 미사용이 되는 코드 정리: `insightSlides`(375-387), `newsContentSlides`(389-406), `newsSlides`(408-414), `formatSlideDate`(23-26), `newsSlideRes` Promise(164-169) 및 구조분해 대상에서 제거, `NewsCardSlider`·`NewsSlide` import(19) 제거.
- `reports/new` href가 이 파일에서 완전히 사라지는지 확인(:382 포함).

### 3-4. `NewsCardSlider.tsx` — 미사용 시 삭제
다른 곳에서 import 되지 않으면 파일 삭제. (grep 으로 참조 0 확인 후 삭제. 참조 있으면 보존.)

### 3-5. `reports/page.tsx:90` — 카피 수정
"AI 인사이트에서 '보고서로 만들기'로 시작하세요." → 예: "관심 토픽·이슈를 골라 전략보고서를 시작하세요." (보고서 진입은 전략보고서 탭 중심으로 안내.)

## 4. 회귀 가드 / 비기능 요건

- 인사이트 카드의 헤드라인·시사점·근거(인용/링크)는 그대로 유지 — "자세히 보기"는 근거의 콘텐츠 링크가 대신한다.
- 카드뉴스 제거로 ② AI 인사이트 섹션이 화면 최상단이 됨(렌즈 스위처 다음). 빈 화면 아님.
- 전략보고서 탭(`/dashboard/reports`, `reports/new`) 기능 자체는 무변경 — AI 인사이트에서의 진입 동선만 제거.
- 하드코딩 hex 0. 신규 의존성 0.
