# Sonnet 지시서 11 — 반응형 모바일 UI (#33)

> 작성: Opus(Cowork) · 대상: Claude Code(Sonnet) · Phase 2-B 용주 트랙 #33
> ⚠️ 작업 전 `AGENTS.md`(디자인 토큰 §9, `'use client'` 최소화 §5, cn() 사용) + 현재 `src/app/dashboard/layout.tsx`·`Sidebar.tsx`·`DashboardHeader.tsx`·`CategoryGrid.tsx` 를 읽을 것.

## 0. 목표 (한 줄)
375 / 768 / 1280 에서 대시보드가 **깨짐 없이 사용 가능**하게 만든다. **데스크톱(lg≥1024) 레이아웃은 그대로**, 모바일/태블릿만 보강(v1 = "예쁘게"보다 "안 깨지고 쓸 수 있게").

## 1. 핵심 원칙
- **데스크톱 회귀 금지**: 기존 `lg:` 이상 모양 유지. 모바일 우선 클래스 + `lg:` 로 기존값 복원.
- 가로 스크롤(의도치 않은 overflow) 제거: 넓은 표/행은 `overflow-x-auto` 래핑.
- `'use client'` 는 상태가 필요한 곳(사이드바 드로어 토글)만.
- 색·간격은 AGENTS §9 토큰, `cn()` 사용.

## 2. 할 일 (우선순위 순)

### 2.1 사이드바 → 모바일 드로어 (핵심)
현재 `dashboard/layout.tsx` 는 `flex` 안에 `<Sidebar className="w-56 shrink-0">` 고정. 모바일에선 이게 화면을 잡아먹음.
- **lg 미만**: 사이드바를 숨기고(`hidden lg:block` 또는 조건부), **헤더의 햄버거 버튼**으로 여는 **슬라이드인 드로어**(좌측, `fixed inset-y-0 left-0 z-40 w-64`, 뒤 backdrop `fixed inset-0 z-30 bg-black/30`)로 표시. 닫기: backdrop 클릭·항목 선택·ESC.
- **lg 이상**: 지금처럼 고정 사이드바(정적, 드로어 아님).
- 구현: `layout.tsx`(이미 `'use client'`)에 `sidebarOpen` state 추가. 데스크톱용 정적 `<aside class="hidden lg:block">` + 모바일용 드로어(같은 Sidebar 내용 재사용) 두 벌, 또는 Sidebar에 `variant`/`onClose` prop. 중복 최소화 위해 Sidebar 내부 콘텐츠를 그대로 쓰되 래퍼만 분기.
- 서비스 항목 선택 시 모바일에선 드로어 자동 닫기.

### 2.2 헤더 (`DashboardHeader.tsx`)
- **lg 미만에 햄버거 버튼**(lucide `Menu`) 추가 → `sidebarOpen` 토글. lg 이상 숨김(`lg:hidden`).
- 로고·우측 액션이 좁은 화면에서 넘치지 않게(불필요 텍스트 `hidden sm:inline`, 간격 축소).

### 2.3 CategoryGrid (`grid-cols-8` → 반응형)
- `grid-cols-8` → `grid-cols-3 sm:grid-cols-4 md:grid-cols-6 lg:grid-cols-8` (8칸은 lg에서 복원). 카드 내부 텍스트/아이콘 모바일에서 안 깨지게.

### 2.4 페이지 컨테이너·간격 (공통)
- `main`/페이지 래퍼 패딩을 `px-4 sm:px-6 lg:px-8`, 섹션 간격 모바일 축소. 대상: `dashboard/page.tsx`, `contents/page.tsx`, `contents/[id]/page.tsx`, `search/page.tsx`, `mypage/page.tsx`, `youtube/page.tsx`.
- 상세페이지 본문은 모바일에서 읽기 좋게 폭/줄간격 유지(`max-w-3xl` 등).

### 2.5 위젯 오버플로/스택 점검
- `ServiceTabs`(가로 탭) → 모바일 `overflow-x-auto` 가로 스크롤.
- `RecentFeed`·`EditorPick`·`TrendKeywords`·`CompetitorTrends`·`YoutubeSection`: 여러 칸 그리드면 모바일 1~2칸으로 스택(`grid-cols-1 md:grid-cols-...`). 가로 넘침 제거.
- 표(예: 검색결과)·넓은 블록은 `overflow-x-auto`.
