## 0. 한 줄
`AiMark`(Sparkles)가 **AI 리포트 한 곳에만** 붙어 있다. AI 생성물 3곳에 더 붙이고, 위치를 **텍스트 오른쪽 인라인 → 좌측 상단 위쪽**으로 바꾼다.

---

## 1. 현행

`src/lib/nav/taxonomy.tsx` L2 탭 정의:
```tsx
{ id: 'ai', label: <>AI 리포트<AiMark className="ml-1" /></>, value: 'ai' },
```
현재 유일한 사용처다. `AiMark`(`size='md'` = `h-3.5 w-3.5`, `text-brand-600`)는 `inline-flex align-middle` 로 **글자 오른쪽에 나란히** 붙는다.

**358 원칙(AiMark.tsx 주석)**: *"AI 생성/분석 산출물에만 붙인다. 남발 금지 — 단순 수집 콘텐츠(뉴스·유튜브·외부리포트 등)엔 붙이지 않는다."*

---

## 2. 구현

### 2.1 위치 변경 — 좌측 상단 위쪽, 작게

`taxonomy.tsx` 안에 헬퍼를 하나 두고 4곳이 공유한다.

```tsx
/** 397 — AI 생성물 탭 라벨. 심볼은 글자 좌측 상단에 작게 얹는다(어깨글자 형태). */
function aiLabel(text: string) {
  return (
    <span className="relative inline-block">
      <AiMark size="sm" className="absolute -left-2 -top-1.5" />
      {text}
    </span>
  )
}
```

- `size="sm"`(`h-3 w-3`) — 기존보다 작게.
- `absolute -left-2 -top-1.5` — 글자 좌측 상단 바깥. **실측 후 미세조정 가능**(±0.5 단위).
- 부모가 `relative inline-block` 이어야 기준점이 잡힌다.
- ⚠️ **탭 컨테이너에 `overflow-hidden` 이 있으면 심볼이 잘린다.** 잘리면 `-top-1` 로 줄이거나 컨테이너 패딩을 확인할 것.

### 2.2 적용 대상 4곳 (전부 `taxonomy.tsx`)

| 경로 | 탭 | 조치 |
|---|---|---|
| `/dashboard/reports` | **AI 리포트** | 기존 `<>…<AiMark className="ml-1"/></>` → `aiLabel('AI 리포트')` |
| `/dashboard/reports` | **지식보고서** | `aiLabel('지식보고서')` 신규 |
| `/dashboard/entities` | **경쟁사 주간 브리핑** | `aiLabel('경쟁사 주간 브리핑')` 신규 |
| `/dashboard/issues` | **핵심 인사이트** | `aiLabel('핵심 인사이트')` 신규 |

### 2.3 붙이지 말 것 (358 원칙)
- **외부 리포트** — 수집물이다.
- **뉴스 · 유튜브 · 웹인사이트** — 수집물이다.
- **주요 기업 · 경쟁사 최근 뉴스 · 기업·기술 자료** — 수집·집계물이다.
- **키워드 분석 · 관계지도** — 통계·그래프 산출물이라 AI 생성물과 성격이 다르다. 붙이려면 별도 판단.

> ⚠️ **지식보고서는 경계 사례다.** 최종안 §9.3 은 *"HTML 기반 작성 … AI 초안·요약 보조"* 로, **사람이 쓰고 AI가 돕는** 형태다. 순수 AI 생성물인 AI 리포트·경쟁사 주간 브리핑과는 다르다. 디렉터가 붙이기로 결정했으므로 붙이되, **이 판단을 §5 에 기록**한다. 나중에 "AI 심볼의 기준이 뭐냐"는 질문이 다시 나온다.

### 2.4 `LG U+ 시사점` 블록에 AI 심볼 (디렉터 결정 2026-07-20)

**배경**: 디렉터가 `기업동향 > 주요 기업` 과 `경쟁사 최근 뉴스` 의 성격이 유사해 보인다고 지적. 화면 대조 결과 **둘은 `사용자-IA-3평면-설계` 의 서로 다른 평면**이었다.

| 탭 | 평면 | 내용 |
|---|---|---|
| 경쟁사 최근 뉴스 | **수집** | 원본 기사 헤드라인 + 날짜 + 출처. 해석 없음 |
| 주요 기업 | **생성** | 기업당 대표 1건 + **LG U+ 시사점**(AI 해석) |

3평면 문서는 *"수집 카테고리와 생성물을 개념상 분리한다"* 고 했으나 **UI 에서는 같은 층에 나란히** 놓여 구분이 안 된다. 통합·이동보다 **차이를 보이게 하는 것**이 먼저다(디렉터 결정: 안 A).

**조치**: `src/components/entities/MajorCompanyGroups.tsx` 의 `ImplicationBlock`(51행) 라벨 옆에 `AiMark` 를 붙인다.

```tsx
<p className="text-[11px] font-semibold tracking-tight text-brand-700 dark:text-brand-300">
  LG U+ 시사점<AiMark size="sm" className="ml-1" />
</p>
```

- ⚠️ **여기는 §2.1 의 `aiLabel` 헬퍼를 쓰지 않는다.** 탭 라벨이 아니라 블록 내부 라벨이므로 **오른쪽 인라인**(`ml-1`)이 자연스럽다. 좌측 상단 배치는 탭 전용이다.
- 탭 라벨 `주요 기업` 에는 **붙이지 않는다.** 그 탭은 수집+생성 혼합이라 탭 전체를 AI 생성물로 표시하면 과하다. **시사점 블록만** 표시한다.
- `cleanNarrative(text)` 호출은 그대로 둔다.

> **후속 판단 근거**: 이 변경 후에도 두 탭이 헷갈리면 문제는 "구분이 안 된다"가 아니라 **"정보가 겹친다"** 다. 그때는 계층 재배치(경쟁사 최근 뉴스를 기업 상세 탭으로 흡수) 또는 실험실 이동을 검토한다.
> 참고로 대상 기업이 실제로 겹친다 — `주요기업`은 DB `curated_groups`, `경쟁사뉴스`는 하드코딩 `COMPETITOR_GROUP_ORDER = ['통신','클라우드·플랫폼','빅테크']` 로 **이중 관리**되어 KT·SKT 가 양쪽에 나온다. 반대로 **빅테크(MS·AWS·Oracle)는 경쟁사 뉴스에만** 있어, 그냥 없애면 소실된다.

## 3. 회귀 가드
1. 탭 **클릭·활성 표시·URL 파라미터**가 그대로 동작한다(라벨만 바뀐다).
2. 심볼이 **잘리거나 겹치지 않는다.** 특히 첫 번째 탭은 좌측 여백이 부족할 수 있다 — `핵심 인사이트`(issues 기본 탭)와 `AI 리포트`(reports 기본 탭)가 각 그룹의 **첫 탭**이다. 잘리면 컨테이너 좌측 패딩을 늘린다.
3. 모바일 폭에서 탭이 줄바꿈되거나 가로 스크롤될 때도 심볼이 따라간다.
4. 다크모드에서 `text-brand-600` 대비가 유지된다.
5. `aria-label="AI 생성"` 이 유지된다(스크린리더).
6. `AiMark.tsx` **자체는 수정하지 않는다.** 위치는 호출부 className 으로만 제어한다.
