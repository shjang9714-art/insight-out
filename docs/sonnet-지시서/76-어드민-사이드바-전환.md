## 배경 (David 확정)
상단 수평바 11개는 가로 공간·중복으로 직관성↓. 대시보드 제품 관행(좌측 고정 사이드바·5~7섹션·섹션 헤더·설정 하단 분리)대로 **좌측 사이드바**로 전환. **정적(접기·모바일 햄버거는 후속)**. Raw 데이터는 사이드바 미노출(흡수는 지시서 77).

### 7섹션 구조(확정)
| 섹션 | 항목(href · label · icon) |
|---|---|
| **개요** | `/admin` 대시보드 · `LayoutDashboard` |
| **콘텐츠** | `/admin/contents` 콘텐츠 관리 `Newspaper` · `/admin/upload` 콘텐츠 추가 `FilePlus` · `/admin/briefings` 모닝브리핑 `Sun` |

| **분류 엔진** | `/admin/keywords` 서비스 키워드 `Tags` · `/admin/keyword-groups` 토픽 규칙 `Network` |
| **AI·처리** | `/admin/translation` 번역 `Languages` · *(예정)* LLM 라우팅 `Cpu` (비활성·"예정" 배지) |

## 작업

### 1. `src/lib/admin/nav.ts` — 7섹션으로 갱신
- `AdminNavItem` 에 선택 필드 추가: `disabled?: boolean`, `badge?: string`.
- `ADMIN_NAV_GROUPS` 를 위 표대로 재구성(개요/콘텐츠/수집/분류 엔진/AI·처리/발행). LLM 항목: `{ href: '#', label: 'LLM 라우팅', icon: Cpu, disabled: true, badge: '예정', description: 'LLM 모델·라우팅 관리' }`.
- 하단 분리용 **별도 export** `ADMIN_NAV_BOTTOM: AdminNavGroup`(시스템: 사용자 관리). (사이드바가 본문/하단을 나눠 렌더.)

### 2. `AdminSidebar.tsx` (신규, `'use client'`) — AdminNav 대체
- **`ADMIN_NAV_GROUPS`·`ADMIN_NAV_BOTTOM` 를 직접 import**(props 로 icon 전달 금지 — 73의 RSC 직렬화 이슈 회피, 클라이언트 번들에 아이콘 포함).
- 세로 레이아웃: 상단 로고(`Insight Out` + `어드민` 배지) → 스크롤 영역(섹션별: 작은 회색 라벨(`text-xs text-muted-foreground/60`, 한국어 그대로·대문자화 금지) + 항목들) → `mt-auto` 하단 구분선 + 시스템 그룹.
- 항목: 아이콘(`h-[18px]`)+라벨, `rounded-md px-2.5 py-2 text-sm`, `usePathname` 활성(=`/admin` 정확일치, 그 외 `startsWith(href+'/')`)=`bg-accent text-brand-600 font-medium`, 비활성호버 `hover:bg-accent`.
- `disabled` 항목: `<span>`(링크 아님), `opacity-60 cursor-default`, 우측 `badge`(`예정`) 칩.
- 폭 `w-[232px] shrink-0`, 전체 높이, `bg-card border-r border-border`, 내부 `flex flex-col`. 색은 토큰만(#9).

### 3. `src/app/admin/layout.tsx` — 셸을 사이드바+본문으로
- 기존 sticky 상단 `<header>`+`AdminNav` 제거. 구조:
```tsx
<div className="flex min-h-screen bg-background">
  <AdminSidebar />
  <main className="flex-1 min-w-0">
    <div className="mx-auto max-w-7xl px-4 py-8 sm:px-6 lg:px-8">{children}</div>
  </main>
</div>
```
- 로고는 사이드바로 이동했으므로 상단바 없음. (사이드바는 `sticky top-0 h-screen overflow-y-auto` 로 스크롤 고정 — `<aside>` 자체에 적용.)

### 4. `src/app/admin/page.tsx` — 홈 "관리 메뉴" 카드 섹션 제거
- 사이드바가 상시 네비를 제공하므로 홈의 그룹별 메뉴 카드(③ 섹션, 지시서 73)는 **중복 → 삭제**. `MENU_GROUPS`·관련 import 정리.
- 홈은 **현황판(KPI + 차트)만** 남김(지시서 74). h1 "어드민 홈" 유지 또는 "대시보드"로.

## 회귀 / 주의
- 라우트·href 불변(개명·이동은 표시·그룹뿐). 모든 기존 페이지 진입 정상.
- `AdminNav.tsx` 는 `AdminSidebar` 로 대체 → 사용처(layout) 교체 후 구파일 삭제 또는 미사용. 잔존 import 0 확인.
- `'use client'` 는 `AdminSidebar` leaf 만. `layout.tsx`·`page.tsx` 서버 유지.
- 정적 1차: 접기 토글·모바일 햄버거 **미포함**(후속). 단 좁은 화면에서 사이드바가 본문을 밀어도 1차 허용(후속 반응형).
- `disabled` LLM 항목은 클릭 불가(`href='#'` 라우팅 금지 — `<span>` 으로).
- UI 한국어(#1)·토큰/brand(#9)·lucide만.
