## 점검 결과 & 작업 대상

### A. 어드민 폼 — 고정 `grid-cols-*`(브레이크포인트 없음) → 모바일 압축
다음 위치의 고정 컬럼 그리드는 작은 화면에서 입력칸이 과도하게 좁아짐. **`grid-cols-1` 기본 + `sm:grid-cols-2`(또는 적정 bp)** 로 변경:
- `src/components/admin/KeywordManager.tsx:267` `grid grid-cols-2`
- `src/components/admin/SourceManager.tsx:453, 494, 535` `grid grid-cols-2`, `:810` `grid-cols-4`(통계 → `grid-cols-2 sm:grid-cols-4`)
- `src/components/admin/ReportUploadForm.tsx:396, 431` `grid grid-cols-2`
- 폼 내부 2열 입력은 모바일에서 1열이 자연스러움. 통계 카드 4열은 모바일 2열.

### B. 어드민 테이블 — 이미 `overflow-x-auto`+`min-w-[...]` 적용됨(가로 스크롤). **유지**
- `AdminContentManager`(min-w-[920px]), `SourceManager`(700), `UserManager`(700), `KeywordManager`(600), `SourceImportDialog`(900), `NewsletterManager`. → 가로 스크롤 동작만 모바일에서 육안 확인. 헤더 NAV(`overflow-x-auto`)도 OK.

### C. 검색 페이지 `src/app/dashboard/search/page.tsx`
- 카드 내부는 `flex-wrap`·`min-w-0` 사용 중 — 대체로 안전. **결과 카드 우측 액션(저장 버튼)** 이 좁은 화면에서 제목과 겹치는지(`flex items-start justify-between gap-4`) 육안 확인 후, 필요 시 모바일에서 세로 스택(`flex-col sm:flex-row`).

### D. 콘텐츠 상세 `src/app/dashboard/contents/[id]/page.tsx`
- `mx-auto max-w-3xl px-4 sm:px-6 lg:px-8` — 폭은 OK. 브레드크럼/메타 줄(`flex items-center gap-2`)이 모바일에서 줄바꿈되는지(`flex-wrap`) 확인, 안 되면 `flex-wrap` 추가. 본문 이미지·표가 컨테이너를 넘치면 `max-w-full`.

### E. 마이페이지 `src/app/dashboard/mypage/page.tsx`
- `max-w-2xl` — OK. 내부 카드/버튼 줄이 모바일에서 넘치는 곳만 보강(`grid-cols-2` 류 있으면 A와 동일 처리).

## 원칙
- **모바일 우선**: 기본 1열/세로 스택 → `sm:`/`md:`/`lg:` 로 확장.
- 가로 스크롤은 표에만 허용. 일반 콘텐츠는 가로 스크롤/넘침 금지(`min-w-0`, `flex-wrap`, `break-words` 활용).
- 시맨틱 토큰 유지, 색상 하드코딩 금지.
