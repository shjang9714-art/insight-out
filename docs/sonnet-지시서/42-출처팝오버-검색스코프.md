## 파트 A — 출처: 검색형 팝오버 (공용 컴포넌트)
> 출처 pill 행 **제거** → 접이식 팝오버. **사업(svc, 7개)은 pill 유지**(few). 출처(src, ~50)만 팝오버.
1. 신규 `src/components/dashboard/SourcePopover.tsx` (공용, contents·search 양쪽 사용):
   - 트리거 버튼: `출처` + 선택 수 배지(예: `출처 · 3`). 선택 있으면 brand 강조.
   - 클릭 → 팝오버 패널(`absolute`, z-30, `w-72`, `max-h-72 overflow-y-auto`):
     - 상단 **검색 input**: 출처명 부분일치 필터(클라이언트, `sources` 목록 대상).
     - **체크박스 다중 목록**: 각 출처 토글. 상단에 "전체 해제".
   - 바깥 클릭/ESC 닫기(기존 SourceDropdown 패턴 재사용).
   - props: `sources: {id,name}[]`, `value: string[]`(=srcIds), `onChange: (ids:string[])=>void`.
2. 선택 → URL `src` 콤마 다중 갱신(**기존 `srcIds` 규약 그대로**). `updateParam('src', ids.join(','))`.
3. 활성 칩(필터바 아래)은 **유지** — 선택 출처별 개별 칩 X 해제(이미 구현됨). 팝오버는 "선택 수단"만 담당.
4. `contents/page.tsx`·`search/page.tsx` 의 **출처 pill 행 삭제** → `SourcePopover` 로 교체. 날짜·사업(pill)·출처(팝오버 버튼)가 한 줄에 컴팩트하게.

## 파트 B — 검색 영역(스코프) 선택 (`SearchBar`)
> 상시 보이는 스코프 칩 + "/" 단축키 병행. **스코프 단위 = 카테고리**(세부 출처는 결과 화면 팝오버로).
1. **상시 스코프 칩**: 검색 input 왼쪽에 `전체 ▾` 칩(작게). 현재 URL 의 `category` 가 있으면 그 라벨 표시(맥락 반영).
   - 클릭 → 카테고리 메뉴: `전체` + 콘텐츠 카테고리(뉴스·가트너·KRG·웹인사이트·오피니언·뉴스레터·AI보고서·유튜브). 카테고리 목록은 공용 상수로(현재 `CategoryGrid` 정의를 `lib` 공용 상수로 추출 권장, 과하면 SearchBar 내 상수).
2. **"/" 단축키**: input 이 비었거나 맨 앞에서 `/` 입력 시 동일 카테고리 메뉴 오픈(타이핑 가속). 메뉴에서 선택 시 칩 갱신, input 의 "/" 제거.
3. **placeholder 힌트**(회색): `콘텐츠 검색 — '/' 로 영역 선택`.
4. **제출(Enter)**: `/dashboard/search?q=<q>` + 선택 스코프 있으면 `&category=<cat>`. `전체`면 category 생략.
   - 기존 맥락 상속(현재 페이지 category 자동 전달)과 통합: **명시 선택 > 현재 페이지 맥락** 우선순위. 명시 선택 없고 현재 category 있으면 기존대로 상속.
5. 결과 페이지는 이미 `category` 패싯 처리(#41) → 그대로 연결. 칩 해제로 전체 확장도 기존대로.
