## 0. 한 줄

홈이 pull 전용이라 "내가 마지막으로 본 뒤 뭐가 새로 생겼나"를 알 수 없다. `users.last_seen_at`을 기록하고, 홈 상단에 **"지난 방문 이후 새 콘텐츠 N건 · 새 이슈 M건"** 배지를 띄워 재방문 유인을 만든다. 표시는 *직전* last_seen 기준(서버 읽기), 마크는 마운트 시 now로 갱신(클라 비콘) → 이번 방문 델타는 보존되고 다음 방문부터 새 기준. 컬럼/로그인 없으면 graceful 숨김(회귀 0).

## 1. 현행 진단

- 재방문 유인 0: 홈(`src/app/dashboard/page.tsx`)은 추천질문·피드·이슈신호·동향 — 전부 "지금 상태"만, "지난 방문 이후 변화" 없음.
- `last_seen`류 추적 **전무**(grep 0). 신규.
- 홈은 서버 컴포넌트. 인증 패턴 = `createServerClient(cookies)` → `auth.getUser()` → `users` 테이블(role 등).

## 2. DB / SQL 핸드오프 (먼저 푸시)

`docs/sql-handoff/153-last_seen_at.sql`:
```sql
-- 153: 재방문 델타용 마지막 방문 시각. 후방호환 nullable.
ALTER TABLE users ADD COLUMN IF NOT EXISTS last_seen_at timestamptz;
```
멱등·안전. 미적용 시 코드 graceful(읽기 42703 → 배지 숨김, 쓰기 실패 무시).

## 3. 구현

### 3-1. `src/app/api/me/seen/route.ts` (신규, POST) — 방문 마크

```ts
import { NextResponse } from 'next/server'
import { createServerClient } from '@supabase/ssr'
import { cookies } from 'next/headers'

export const runtime = 'nodejs'
export const dynamic = 'force-dynamic'

export async function POST() {
  const cookieStore = await cookies()
  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    { cookies: { getAll() { return cookieStore.getAll() }, setAll(s){ s.forEach(({name,value,options})=>cookieStore.set(name,value,options)) } } },
  )
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return NextResponse.json({ ok: false }, { status: 401 })

  // last_seen_at = now (컬럼 미적용 시 graceful)
  const { error } = await supabase.from('users').update({ last_seen_at: new Date().toISOString() }).eq('id', user.id)
  if (error && error.code !== '42703') {
    console.error('[me/seen] 갱신 실패:', error.message)
  }
  return NextResponse.json({ ok: true })
}
```
- RLS: 사용자가 자기 행 update 가능해야 함(기존 users 셀프 업데이트 정책 확인; 없으면 admin 경유로 대체 — 단 self만). **기존 마이페이지 프로필 저장이 users를 self-update 하는지 확인**(하면 정책 있음, 그대로 사용).

### 3-3. `src/components/dashboard/VisitDelta.tsx` (신규, 서버 컴포넌트)

직전 last_seen 읽기 → 새 콘텐츠/이슈 카운트 → 배지 + `<MarkSeen/>`.

```tsx
import Link from 'next/link'
import { Sparkles } from 'lucide-react'
import { cookies } from 'next/headers'
import { createServerClient } from '@supabase/ssr'
import MarkSeen from './MarkSeen'

export default async function VisitDelta() {
  const cookieStore = await cookies()
  const supabase = createServerClient(/* anon + cookies, 위와 동일 */)

  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return null

  // 직전 방문 시각 (42703 graceful)
  const { data: profile, error: profErr } = await supabase
    .from('users').select('last_seen_at').eq('id', user.id).single()
  if (profErr) return <MarkSeen />   // 컬럼 없거나 조회 실패 → 마크만(다음부터)
  const lastSeen = (profile as { last_seen_at: string | null } | null)?.last_seen_at
  if (!lastSeen) return <MarkSeen />  // 첫 방문 → 배지 없음, 기준만 세움

  // 새 콘텐츠·이슈 카운트 (published, 직전 방문 이후)
  const [contentRes, issueRes] = await Promise.all([
    supabase.from('contents').select('*', { count:'exact', head:true })
      .eq('status','published').gt('collected_at', lastSeen),
    supabase.from('issues').select('*', { count:'exact', head:true })
      .eq('status','published').gt('created_at', lastSeen),
  ])
  const newContent = contentRes.count ?? 0
  const newIssues  = issueRes.count ?? 0

  if (newContent === 0 && newIssues === 0) return <MarkSeen />  // 변화 없음 → 조용히

  const cap = (n: number) => (n > 99 ? '99+' : String(n))
  return (
    <>
      <Link
        href="/dashboard/contents"
        className="flex items-center gap-2 rounded-xl border border-brand-600/30 bg-brand-600/5 px-4 py-2.5 text-sm text-foreground transition-colors hover:border-brand-600/50"
      >
        <Sparkles className="h-4 w-4 text-brand-600 shrink-0" />
        <span>
          지난 방문 이후 새 콘텐츠 <b className="tabular-nums">{cap(newContent)}</b>건
          {newIssues > 0 && <> · 새 이슈 <b className="tabular-nums">{cap(newIssues)}</b>건</>}
        </span>
      </Link>
      <MarkSeen />
    </>
  )
}
```
- 색은 기존 토큰(`brand-600`)만 — 하드코딩 hex 금지.
- 카운트는 head:true(바운디드). cap 99+.

## 4. 회귀 가드 / 비기능 요건

- SQL 미적용(42703) → 읽기 실패=배지 숨김, 쓰기 실패=무시. **회귀 0**(홈 무변화).
- 첫 방문/무변화/비로그인 → 배지 없음(넛지 과함 금지).
- 표시(직전값)와 마크(now)를 분리 → 이번 방문 델타 보존, 다음 방문부터 새 기준.
- 카운트 head:true 바운디드. cap 99+.
- 하드코딩 hex 0·신규 의존성 0.

## 6. 후속 (범위 밖)

- **개인화 델타**: 워치리스트/보기(렌즈) 범위로 "내 관심 기업 새 소식 N건"(P4 연계, 더 강한 유인).
- 새 항목으로 바로 가는 필터 딥링크(`?since=`), 읽음 표시.
