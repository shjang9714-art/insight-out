# 지시서 443 — 사이드바 리사이즈 핸들 수정 (442 후속)

> 작성: Opus · 2026-07-26 · SQL 0·env 0·의존성 0. 브랜치 `agent/443-sidebar-handle`.

## 원인
`src/components/admin/AdminSidebar.tsx` 리사이즈 핸들(~L435) 클래스에 **`focus:bg-brand-600/40`** + `tabIndex={0}` → 클릭 시 포커스가 잡혀 **마우스를 떼도 보라색 라인이 잔존**.

## 수정 (Claude 데스크톱앱식 리사이즈 감)
1. 핸들 클래스 `focus:bg-brand-600/40` → **`focus-visible:bg-brand-600/40`**(키보드 포커스만 표시). `focus:outline-none`은 유지.
2. 드래그 중 시각 피드백: 클래스에 **`isDragging && 'bg-brand-600/40'`** 추가(hover·focus-visible·dragging 3경우만 라인).
3. `handleMouseUp`(또는 onMouseDown 직후)에서 **핸들 blur** — 클릭 포커스 잔상 제거(핸들에 ref 걸어 mouseup 시 `ref.current?.blur()`).
4. 결과: 평소 투명 → hover 시 옅은 라인 → 드래그 중 라인 → 놓으면 즉시 깨끗. 키보드 탭(a11y)은 focus-visible로 유지.

## 검증
- `focus:bg-*` 잔존 없음(focus-visible만). mouseup 후 핸들에 포커스 안 남음(blur). 드래그 동작·클램프·localStorage 지속 기존과 동일.
