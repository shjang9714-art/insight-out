## 파트 A — 요약 폴백 (summary_ko → body_original 발췌)
1. 목록 메인 쿼리(L395) select 에 **`body_original`** 추가. `RecentFeed` 쿼리에도 추가. 아이템 타입에 `body_original: string | null` 추가.
2. 발췌 헬퍼 신설(`src/lib/contents/excerpt.ts` 또는 inline util):
   ```ts
   export function toExcerpt(summaryKo: string | null, bodyOriginal: string | null, max = 120): string | null {
     const raw = summaryKo?.trim() || bodyOriginal?.trim()
     if (!raw) return null
     const text = raw.replace(/<[^>]*>/g, ' ').replace(/\s+/g, ' ').trim() // HTML 태그 제거
     return text.length > max ? text.slice(0, max) + '…' : text
   }
   ```
3. 카드/행 요약 표시를 `toExcerpt(summary_ko, body_original)` 로 교체. 결과가 null 일 때만 "요약 정보가 없습니다"(또는 문구 생략). → 대부분 기사에서 초입이 보이게.
   - 적용처: `contents/page.tsx` 인라인 카드(L261) · `ContentRow` · `ContentCard`(L135 부근, summaryKo → excerpt).

## 파트 B — 해시태그 모든 기사 노출 (폴백)
> 매칭 키워드가 있으면 그걸, 없으면 **카테고리 + 사업(서비스)명** 으로 폴백해 항상 ≥1개 태그.
1. 목록 쿼리 select 에 **`content_services(services(name))`** 조인 추가(서비스명 확보). `content_keywords(keywords(name))` 는 유지.
2. 태그 산출 헬퍼:
   ```ts
   // 우선순위: 매칭 키워드 → (없으면) 카테고리 + 서비스명. 최대 4개.
   function tagsOf(keywords: string[], category: string, services: string[]): string[] {
     const base = keywords.length ? keywords : [category, ...services]
     return [...new Set(base)].slice(0, 4)
   }
   ```
3. 카드/행 해시태그를 `tagsOf(...)` 결과로 렌더(빈 placeholder 분기 제거 — 항상 값 있음). `ContentCard` 에 **`keywords?: string[]` prop 추가**(홈도 동일 동작), `RecentFeed` 가 매핑해 전달.
4. ⚠️ 한계 명시: 이건 "항상 태그가 보이게" 하는 폴백이지, **기사별 진짜 키워드 추출(NLP/LLM)은 별도 큰 작업**(향후 항목). 보고에 명시.

## 파트 C — 출처 단/복수 멀티셀렉트
> `svc`(사업) 멀티셀렉트와 동일 패턴으로 통일.
1. `src` 단일 → **콤마 다중** `src=uuid1,uuid2`. `srcIds = src.split(',').filter(Boolean)` (svcIds 처럼 **useMemo** 로 감싸 lint 경고 방지).
2. 쿼리: `eq('source_id', src)` → **`.in('source_id', srcIds)`** (빈 배열=전체).
3. `SourceDropdown` → **다중 선택**(체크 토글, 패널 안 닫힘 유지·"전체 출처"=해제). 또는 사업 pill 처럼 토글 pill 행으로 통일(택1, 일관성 권장: 사업과 같은 pill 토글).
4. 활성칩: 선택 출처마다 개별 칩(X=해당 출처 토글 해제).
5. **동작 점검**: 출처 1개 선택 시 목록이 실제로 좁혀지는지 육안 확인(현재 단수도 체감상 안 먹는다는 보고 → in() 재작성으로 배선 검증).
