# 지시서 276 — 전략보고서 재설계 (3/3) 어드민: HITL 생성·재생성·표지·발행 워크플로우

> 설계: `docs/설계-전략보고서-리서치카드형-정기발행.md`. 274(백엔드)·275(서비스 UI) 후속. 관리자가 **주제 선택 → AI HTML 생성 → 검토·재생성 → 표지·발행자·발행일 → 발행**을 수행하는 human-in-the-loop 정기 발행 관리 화면.

전제: 274 API(`/api/reports/generate-strategy`, `/api/reports/[id]/publish`) 배포. 표지 업로드는 기존 `src/lib/contents/upload-cover.ts` 재사용.

대상: 어드민 보고서 관리(`src/app/admin/reports/*` 신규 또는 어드민 섹션), 기존 유저용 `dashboard/reports/new` 정리.

---

## 1. 어드민 보고서 관리 화면 (`/admin/reports`)
- **인증 게이트**(admin 전용 — 기존 어드민 라우트 패턴).
- 목록: **전체**(초안·생성중·완료·실패·발행) 상태 배지 + published_at 표시. 필터(발행/미발행).
- 각 행 액션: 미리보기(상세, 미발행도 어드민은 열람) / 재생성 / 표지 / 발행·해제 / 삭제.

## 2. 생성 (HITL) 
- **새 보고서** 폼: `type`(시장동향·경쟁사분석·키워드분석·서비스리포트·자유주제) + `topic`(주제 입력) + `title`(선택) + (선택) 소스 이슈/콘텐츠 선택 + (선택) 프롬프트 오버라이드.
- "생성" → `POST /api/reports/generate-strategy`(274) → 초안(status='completed', 미발행). 생성 중 상태 표시.
- **재생성**: 같은 API 재호출(reportId 전달, 주제/프롬프트 조정) → body_html 갱신. 편집은 최소(원하면 원본 HTML 미세수정 textarea 옵션 — 선택 구현).

## 3. 표지 (업로드 + AI 훅)
- **업로드**: 파일 선택 → `upload-cover.ts`로 Supabase Storage 업로드 → 반환 URL → `cover_image_url` 저장(publish API 또는 별도 PATCH).
- **AI 생성(나노바나나)**: 버튼 자리 배치하되, 이미지 생성 엔드포인트 미구현 → **비활성/후속 안내**(툴팁 "준비 중"). 엔드포인트 붙으면 연결.
- 이미지 타입·용량 제한(기존 업로드 유틸 규칙 준수).

## 4. 발행 워크플로우
- 발행 폼: `publisher`(기본 '인사이트 아웃', 편집 가능) + `published_at`(기본 now, 조정 가능) + cover 확인.
- "발행" → `POST /api/reports/[id]/publish` → published_at 설정 → 서비스 카드 노출(275).
- "발행 해제" → published_at=null(서비스에서 숨김).

## 5. 프롬프트 관리 노출
- `llm_prompts` `strategy_report`(274 시드)를 **어드민 프롬프트 관리에서 편집** 가능하게 노출(263 도움말/프롬프트 관리 흐름과 통일). "전략보고서 생성 프롬프트 — 퀄리티 핵심, 한글 강제 유지" 안내.

## 6. 기존 정리
- 유저용 `dashboard/reports/new`(구 markdown 생성) → **어드민 전용으로 이동 또는 제거**(서비스에서 사용자가 보고서를 생성하지 않음). 서비스 `dashboard/reports`는 275의 발행 카드 열람만.
- 구 `/api/reports/generate`(markdown)는 미사용화 확인 후 정리(호환 필요 없으면 제거, 아니면 남김).
