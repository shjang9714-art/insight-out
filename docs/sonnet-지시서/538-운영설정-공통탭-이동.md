# 지시서 538 — 운영 설정 패널을 '공통' 탭 안으로

> 플래너(Opus) · 2026-08-19 · 기준 `origin/main = 0ad06ca` · 브랜치 `agent/538-ops-settings-tab`
> 537 이후 육안 확인에서 드러남. 537 이 만든 결함이 아니라 원래 있던 배치 문제다.

## 증상

`src/app/admin/settings/page.tsx` 가 `OpsSettingsPanel` 을 `SystemSettingsHub` **바깥**에 렌더한다.

```tsx
<SystemSettingsHub />   {/* 탭: 공통 · AI 모델 · 외부 API · MCP · SSO · 유지보수 */}
<OpsSettingsPanel />    {/* 탭과 무관하게 항상 하단에 붙는다 */}
```

그래서 **어느 탭을 눌러도** "운영 설정 / 브리프 수신자 이메일" 카드가 아래에 따라온다.
SSO 탭에서는 프로바이더 목록 바로 밑에 붙어 SSO 설정의 일부처럼 보인다.

## 작업

1. `src/app/admin/settings/page.tsx` 에서 `OpsSettingsPanel` 렌더를 제거한다.
   페이지는 `<Suspense><SystemSettingsHub /></Suspense>` 만 남긴다.
2. `src/components/admin/SystemSettingsHub.tsx` 의 `'general'` 케이스에서
   `AdminAppearanceSettings` 아래에 `OpsSettingsPanel` 을 함께 렌더한다.
   두 블록 사이 간격은 다른 탭과 같은 리듬으로 맞춘다(`space-y-*` 등 기존 관례 따를 것).
3. `OpsSettingsPanel` 자체 로직은 건드리지 않는다.

## 하지 않을 것

- 운영 설정 항목 추가·삭제 (`tts_monthly_char_cap` 등은 화면에 없지만 이번 범위 밖)
- 새 탭 신설
- `OpsSettingsPanel` 내부 리팩터

## 검증

1. `npx tsc --noEmit` / `npx eslint` / `npm run build`
2. `/admin/settings` 의 **여섯 탭 전부**를 눌러 운영 설정 카드가 '공통' 탭에서만 보이는지
3. 브리프 수신자 저장이 종전대로 동작하는지
