## 2. 현행 (확인된 코드 사실)

`src/app/admin/competitor-weekly/page.tsx` (64줄) 는 **서버 컴포넌트**이며 4개 섹션을 세로로 쌓는다.

```
AdminPageHeader
AdminCompetitorWeeklyGenerate    ← 패스① 사실 추출 실행
AdminCompetitorWeeklyAnalyze     ← 패스② 컨텍스트 복사 / 결과 import
AdminCompetitorWeeklySchedule    ← 크론 요일·시각 설정
CompetitorWeeklyManager          ← 최근 브리핑 10건 (서버 fetch → initialReports)
```

**384 선례**(`InsightHub.tsx`, 29줄):
```
page.tsx  → Suspense + Hub 만 (얇게)
Hub       → 'use client' + AdminTabShell({ tabs, defaultTab, renderContent })
하위 Manager → 각자 데이터 조회
```

## 3. 구현

### 3.1 신규 `src/components/admin/CompetitorWeeklyHub.tsx`

`'use client'`. `InsightHub` 와 같은 모양으로 작성한다.

| 탭 value | 라벨 | 내용 |
|---|---|---|
| `list` | **발행 브리핑** | `CompetitorWeeklyManager` (기본 탭) |
| `generate` | **생성 실행** | `AdminCompetitorWeeklyGenerate` |
| `analyze` | **분석 (패스②)** | `AdminCompetitorWeeklyAnalyze` |
| `settings` | **생성 설정** | `AdminCompetitorWeeklySchedule` |

- `defaultTab = 'list'` — 들어오면 최근 브리핑부터 보이는 것이 자연스럽다.
- `aria-label="경쟁사 주간리포트 관리"`

### 3.2 ⚠️ 서버 데이터 전달 — 이 슬라이스의 기술 핵심

현재 page 는 **서버에서** `competitor_weekly_reports` 를 조회해 `initialReports` 로 넘긴다. Hub 가 `'use client'` 가 되면 **함수는 넘길 수 없지만 직렬화 가능한 데이터는 넘길 수 있다.**

→ **서버 fetch 를 page 에 그대로 두고**, Hub 에 prop 으로 전달한다.

```tsx
// page.tsx (서버) — 조회 로직 무변경
<Suspense fallback={null}>
  <CompetitorWeeklyHub initialReports={reports} schemaMissing={error?.code === '42P01'} />
</Suspense>
```

`renderContent` 는 Hub **내부**에서 정의되므로 경계를 넘지 않는다. **page 에서 `renderContent` 를 만들어 넘기려 하면 "Functions cannot be passed directly to Client Components" 로 실패한다 — 하지 말 것.**

### 3.3 page.tsx 정리
- `AdminPageHeader` 는 `AdminTabShell` 이 내부에서 렌더하므로 **page 에서 제거**한다(중복 방지).
- `AdminSectionHeader`("최근 브리핑")는 탭 라벨이 그 역할을 하므로 **제거**한다.
- 42P01 graceful 처리(`AdminEmptyState`)는 **유지**하되 `list` 탭 안으로 옮긴다.
- `metadata`·`dynamic = 'force-dynamic'`·Supabase 조회는 **무변경**.

### 3.4 하지 말 것
- 하위 4개 컴포넌트의 **내부 로직·UI 를 수정하지 않는다.** 이번엔 배치만 바꾼다.
- 최종안 §7.3 의 미구현 탭(리포트 유형·프롬프트·모델 설정·실행 이험·사용량·비용)을 **만들지 않는다.**
- `nav.ts` 를 건드리지 않는다. 이 화면은 이미 활성이다.

## 4. 회귀 가드
1. **패스① 생성 버튼이 동작한다.** (디렉터가 오늘 실행 예정 — 깨지면 안 된다)
2. **패스② "컨텍스트 복사" → 클립보드 복사, JSON 붙여넣기 → import** 가 동작한다.
3. 크론 요일·시각 설정 저장이 동작한다.
4. 최근 브리핑 목록 10건이 뜨고, 발행/삭제 등 기존 액션이 동작한다.
5. `competitor_weekly_reports` 테이블 부재(42P01) 시 빈 상태 안내가 뜬다(페이지가 깨지지 않는다).
6. URL `?tab=generate` 로 직접 진입하면 해당 탭이 열린다(`useTabParam`).
7. 브레드크럼이 `기업동향 / 경쟁사 주간리포트` 로 뜬다.
