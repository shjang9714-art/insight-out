# 지시서 373 — 로그인 인증코드 유효시간 안내 + 남은시간 카운트다운

> 대상: 구현 에이전트 · **신규 SQL 없음** · 로그인 UI 소소 개선
> ⚠️ 읽을 것: `src/components/login/LoginCard.tsx`(`signInWithOtp`·`verifyOtp`·`RESEND_COOLDOWN_SECONDS`·`step==='otp-verify'` 렌더·`otp-hint`) · `AGENTS.md`
> ⚠️ 전제: OTP 실제 만료는 **Supabase Auth 설정**(Email OTP Expiration)에서 관리한다. 이 지시서는 **화면 안내만** 담당하며, 표시값은 Supabase 설정과 일치시켜야 한다.

## 배경 (David)
인증코드 입력 화면에 유효시간이 안 보여 사용자가 얼마나 여유가 있는지 모른다. **"코드는 10분간 유효합니다" 안내 + 남은시간 카운트다운**을 추가해, 10분 동안 여유 있게 입력하도록 한다.

## 작업 (`LoginCard.tsx`)
1. **상수** `OTP_VALIDITY_SECONDS = 600`(10분) 추가. 주석으로 **"Supabase Email OTP Expiration 설정과 일치시킬 것"** 명시(둘이 어긋나면 안내가 거짓말이 됨).
2. **코드 전송 성공 시**(`otp-send`→`otp-verify` 전환, resend 성공 포함) `otpExpiresAt = Date.now() + OTP_VALIDITY_SECONDS*1000` state 설정. `resendCooldown` 타이머 패턴(`setInterval` 1s + cleanup) 재사용해 **남은시간(mm:ss) 카운트다운** state 유지.
3. **`otp-verify` 화면**의 `otp-hint`(현재 "…로 6자리 코드를 보냈습니다") 근처에:
   - **"코드는 10분간 유효합니다"** 안내 + **남은시간 `mm:ss`** 표시(예: `유효시간 09:32`).
   - 0에 도달하면 문구를 **"코드가 만료되었습니다. 재전송해 주세요."**(destructive 톤)로 바꾸고 재전송 유도. (verify 버튼은 그대로 두되, 만료 후 시도는 기존 에러 처리로 흡수)
4. **재전송 시** 카운트다운·`otpExpiresAt` 리셋(새 코드 = 새 10분). resend 쿨다운(60s)은 기존대로 유지(별개 개념 — 혼동 없게 라벨 구분).

## 회귀 / 주의
- 순수 화면 안내 — 인증 로직(`verifyOtp`)·실제 만료는 **건드리지 않는다**(서버=Supabase가 정답). 안내 표시는 best-effort.
- 타이머 cleanup 필수(언마운트·step 이탈 시 `clearInterval`). 색 토큰·한국어 문구·접근성(aria-live로 만료 안내 알림 권장).
- 모바일·데스크톱 레이아웃 회귀 없게. `RESEND_COOLDOWN_SECONDS`(60s)와 `OTP_VALIDITY_SECONDS`(600s)는 다른 개념 — 코드·문구에서 섞지 말 것.
- 검증: `tsc`·ESLint·`check-prefetch`·`build` + (dev)코드 받기→카운트다운 감소 확인, 0 도달 시 만료 문구, 재전송 시 리셋.
