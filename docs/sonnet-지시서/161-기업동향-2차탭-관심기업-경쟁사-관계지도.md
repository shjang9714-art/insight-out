## 0. 한 줄

기업동향 탭(`/dashboard/entities`)을 **2차 탭 [관심기업] [경쟁사] [관계지도]** 로 정리한다. 관심기업·경쟁사는 AI 인사이트에서 쓰던 **실제 로직을 이전**해 채우고, 관계지도는 기존 지식그래프를 재사용한다.

## 1. 현행 진단 (검증된 코드 사실)

`src/app/dashboard/entities/page.tsx` 현재 3섹션 세로 나열:
- `CompetitorTrends` — **목업**(`./mock-data` `COMPETITOR_TRENDS`, 하드코딩 큐레이션일 `2026-06-10`).
- `KATrends` — **빈 placeholder**("준비 중", 데이터 연동 전).
- `EntitiesPageClient`(지식그래프, `KnowledgeGraph` dynamic import).

**실제 경쟁사·관심기업 로직은 AI 인사이트(`AiInsightsView.tsx`)에 있다**:
- 관심 기업 인사이트: `companyCardsRes`(insight_cards scope=company) → `companyCards`(워치리스트 `isWatched` 필터) → `companyInsightGroups` → `InsightCardsSectionClient`.
- 경쟁사 동향(⑥): `competitorNamesRes`(entities.is_competitor) + `competitorResults`(최근 14일 contents 논조 분포 긍/중/부).

→ 160이 이걸 AI 인사이트에서 제거하므로, **161이 받아 기업동향에 배치**한다.

## 3. 구현

### 3-1. 탭 라우팅 — `?view=`
`/dashboard/entities?view=watchlist|competitor|graph`. 기본값 `watchlist`(없으면 `graph`도 가능 — 아래 3-5 빈상태 고려). 잘못된 값은 기본값 폴백. `entities/page.tsx`가 `searchParams.view` 읽어 분기.

### 3-2. 2차 탭 바 — `EntityTabs.tsx` (신규, 클라)
`AnalysisTabs`/`AiInsightTabs`(160)와 동일 pill 스타일. 탭:
```tsx
const TABS = [
  { id: 'watchlist',  label: '관심기업' },
  { id: 'competitor', label: '경쟁사' },
  { id: 'graph',      label: '관계지도' },
]
```
`href={`/dashboard/entities?view=${t.id}`}`.

### 3-3. 관심기업 탭 — AI 인사이트에서 이전
`AiInsightsView`의 관심기업 인사이트 로직을 기업동향(server)으로 옮긴다:
- 쿼리: `user_watchlist` + `insight_cards`(scope=company, status=published) + `card_headline` 보강(148 패턴, graceful) + 근거 contentMap.
- `isWatched` 필터 → `companyInsightGroups` → `InsightCardsSectionClient groups=… contentMap=…` 재사용.
- 워치리스트 0 → 마이페이지 설정 유도 빈상태(기존 AiInsightsView 카피 재사용).
- 카드에서 "보고서로 만들기"는 159로 이미 제거됨(재발 금지).

### 3-4. 경쟁사 탭 — 실제 로직 이전(목업 대체)
- `AiInsightsView`의 `competitorNames`(entities.is_competitor) + `competitorResults`(14일 contents, `overlaps(matched_keywords, competitorNames)`, 긍/중/부 분포, 대표기사) 로직을 이전.
- 렌더는 기존 ⑥ 섹션 카드 구조(기업명 + 긍/중/부 배지 + 대표기사 링크) 재사용.
- **목업 `CompetitorTrends`는 제거**(또는 데이터 없을 때만 보이는 폴백으로 강등 — 권장: 제거하고 빈상태 안내).
- 설계안 §4-4: **경쟁사 탭엔 기업만**. `is_competitor` 기준이라 이미 기업만 걸러짐. 주제성 키워드(AX·AIDC·데이터센터)는 노출하지 않음 확인.

### 3-5. 관계지도 탭 — 기존 재사용
- `EntitiesPageClient`(+`KnowledgeGraph`) 그대로. 표면 라벨 "지식그래프" → **"관계지도"** 로 명칭 통일(설계안 §4-5, §11 이름변경). 내부 컴포넌트명은 유지 가능.
- (관계성 강화 — 동시출현·급증 연결 — 는 후속 슬라이스. 161은 명칭·탭 배치까지.)

### 3-6. `KATrends`(준비 중) 처리
빈 placeholder → 메인 흐름에서 제외(주석/후속). 노출이 필요하면 관심기업 탭 하단 "준비 중"으로만. 기본은 숨김.

### 3-7. 최상위 nav 라벨
`DashboardHeader` `NAV_TABS`의 "기업동향" 유지(흡수 X). 변경 없음.
