## 0. 한 줄

어드민 스코프 **테이블 요소 CSS로 헤더/본문 폰트·행 높이·헤더 대비·hover를 일괄 상향**하고, 가장 많이 쓰는 **콘텐츠 관리 표**는 제목 2줄·액션 위계(삭제=danger, 맨끝)·선택행 강조로 타겟 개선한다.

## 1. 현행 진단 (검증된 코드 사실)

- 어드민 표 공통 패턴(감사): `thead tr` = `bg-muted text-xs font-semibold text-muted-foreground`(작고 흐림), `td` = `px-4 py-3`(행 낮음), 본문 `text-sm`(14). 행 hover·선택행 강조 약함.
- 컴포넌트마다 인라인 `<table>`(콘텐츠 관리·소스·크롤로그·키워드·사용자…). **admin-scope 요소 셀렉터**(`.admin-scope thead th` 등)는 Tailwind 유틸(text-xs 등)보다 특이도 높아 **일괄 오버라이드 가능**.
- 삭제 아이콘이 일반 아이콘과 비슷(위험 액션 구분 약함).

## 3. 구현

### 3-1. 테이블 기본 — `globals.css` `.admin-scope`(일괄)
```css
.admin-scope table { font-size: 15px; }
.admin-scope thead th {
  font-size: 14px; font-weight: 600;
  color: var(--muted-foreground);
  background-color: var(--muted);
  padding-top: .625rem; padding-bottom: .625rem;   /* 헤더 대비·여백 */
}
.admin-scope tbody td { padding-top: .875rem; padding-bottom: .875rem; }  /* 행 높이 ~56 */
.admin-scope tbody tr { border-bottom: 1px solid var(--border); }
.admin-scope tbody tr:hover { background-color: var(--accent); }
```
- 헤더 폰트 14/600·본문 15로 상향(§6 폰트 기준), 행 높이 확대(56 지향). 배지/칩은 각 컴포넌트 유지(별건).
- 과밀 방지: 셀 내부 badge·버튼은 그대로. 표 컨테이너(`rounded-xl border bg-card`)는 유지(183 그림자와 함께 뜸).

### 3-2. 콘텐츠 관리 표 타겟 (`AdminContentManager`)
- **제목 컬럼**: 한 줄 강제 대신 **2줄 허용**(`line-clamp-2`), 가장 진한 색(`text-foreground`). (제목 클릭=상세 184 링크 유지.)
- **액션 위계**: 순서 정리 — 보기(상세) · 승인/노출 · 숨김 · 수정 · **삭제(맨끝)**. **삭제는 danger**(빨강, `variant="destructive"` 또는 red 톤), 나머지와 시각 분리. 대량 삭제는 확인(191/기존 유지).
- **선택행 강조**: 체크된 행 배경 옅은 brand(`bg-brand-600/5` 등) — hover와 구분.
- 상태 배지는 175 StatusBadge(그린 없음) 유지, 크기만 표 폰트와 균형.

### 3-3. 기타 표(일괄만)
- 소스·크롤로그·키워드·사용자 등은 3-1의 일괄 CSS로 폰트·행·hover 개선(개별 타겟은 후속). 회귀 없는지 확인(레이아웃 깨짐 0).
