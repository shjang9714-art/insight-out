## 3. 구현 — `src/components/analysis/InsightCardNewsList.tsx`

### 3-1. 상대 신선도 헬퍼(KST 일자 기준)

```ts
function freshnessLabel(generatedAt: string | null | undefined): { text: string; stale: boolean } | null {
  if (!generatedAt) return null
  const toKstDay = (d: Date) => {
    const k = new Date(d.getTime() + 9 * 60 * 60 * 1000)
    return Date.UTC(k.getUTCFullYear(), k.getUTCMonth(), k.getUTCDate())
  }
  const days = Math.round((toKstDay(new Date()) - toKstDay(new Date(generatedAt))) / 86_400_000)
  const text = days <= 0 ? '오늘 생성' : days === 1 ? '어제 생성' : `${days}일 전 생성`
  return { text, stale: days >= 14 }  // 2주 넘으면 신선도 경고(흐리게)
}
```

### 3-3. 배지 렌더 — 키커 행에 합류

기존 키커(L43~54)의 `<span>topic · 기간</span>` 옆/아래에 신뢰 배지 줄 추가:
```tsx
<div className="flex items-center gap-2 flex-wrap text-[11px]">
  {fresh && (
    <span className={cn(
      'inline-flex items-center gap-1 rounded px-1.5 py-0.5 font-medium',
      fresh.stale ? 'bg-amber-50 text-amber-700' : 'bg-muted text-muted-foreground'
    )}>
      <Clock className="h-3 w-3" />{fresh.text}
    </span>
  )}
  {evidenceCount > 0 && (
    <span className="inline-flex items-center gap-1 rounded bg-muted px-1.5 py-0.5 font-medium text-muted-foreground">
      <FileText className="h-3 w-3" />근거 {evidenceCount}건
    </span>
  )}
</div>
```
- `fresh = freshnessLabel(card.generated_at)`.
- 아이콘 `Clock`·`FileText` (lucide-react, 기존 import 패턴).
- 색은 토큰만(`bg-amber-50`·`text-amber-700`·`bg-muted` 등) — **하드코딩 hex 금지**.
- 배치: 키커 아래 한 줄(헤드라인 위) 권장 — 헤드라인 임팩트 안 해치게 작게.

## 4. 회귀 가드 / 비기능 요건

- `generated_at` null → 신선도 배지 숨김(근거 배지만). 근거 0 → 근거 배지 숨김. 둘 다 없으면 배지 줄 자체 비표시.
- 기존 카드 레이아웃(헤드라인·시사점·근거 펼치기·보고서) 무변경 — 배지 한 줄만 추가.
- 산업·회사 카드 양쪽 자동 적용(공통 컴포넌트).
- 하드코딩 hex 0·신규 의존성 0·SQL 0.
