## 1. 현행 진단 (검증된 코드 사실)

## 2. 구현

### 2-A. 추출 API — `src/app/api/admin/import-url/route.ts`(신규, `runtime = 'nodejs'`)
- `POST { url }`. `verifyAdmin`(기존 패턴: createServerClient+users.role, 다른 admin 라우트와 동형) 게이트.
- 처리:
  1. url 유효성(http/https) 검사 → 아니면 400.
  2. `const resolved = await resolveArticleUrl(url)`(리다이렉트 해소; 실패 시 원 url 유지).
  3. `const art = await extract(resolved, {}, { signal: AbortSignal.timeout(8000) })`(타임아웃 8s).
  4. 성공 시 반환:
     ```
     { title: art?.title ?? '',
       author: art?.author ?? '',
       bodyText: cleanBodyText(htmlToPlainText(art?.content ?? '')),
       summary: art?.description ?? '',
       publishedAt: art?.published ? art.published.slice(0,10) : '',
       originalUrl: resolved }
     ```
  5. 본문·제목 모두 비면(추출 실패) → 422 `{ error: '이 URL에서 본문을 추출하지 못했습니다. 직접 붙여넣기를 이용하세요.' }`.
- try/catch로 네트워크·타임아웃 오류 → 422 한국어 메시지. **SSRF 우려는 기존 크롤러가 이미 임의 URL을 fetch하는 것과 동일 수준**(어드민 전용 게이트로 한정).

### 2-B. `TextPasteForm` 프리필 지원(재사용 위해 소폭 확장)
- Props에 `initialForm?: Partial<FormState>` (+ 필요 시 `initialKeywords?: string[]`) 추가. `useState`(현재 `FORM_INIT`)를 `{ ...FORM_INIT, ...initialForm }`로 시드. **props 없으면 현행과 100% 동일**(회귀 0).
- (선택) 상단에 "가져온 원문: {originalUrl}" 라벨 노출은 UrlImportForm에서 처리(폼 자체는 최소 변경).

### 2-C. 신규 `src/components/admin/UrlImportForm.tsx`(`'use client'`)
- 상태: `url`, `loading`, `error`, `extracted: Partial<FormState> | null`.
- 화면 1(추출 전): URL `Input` + "가져오기" `Button`. 안내문 "기사 URL을 넣으면 제목·본문·발행 정보를 자동으로 가져옵니다. 가져온 뒤 수정할 수 있어요."
  - "가져오기" → `POST /api/admin/import-url {url}` → 성공 시 `setExtracted(data)`; 실패 시 `setError`(한국어). 로딩 스피너.
- 화면 2(추출 후): "가져온 원문: {originalUrl}" + "다시 가져오기"(초기화) + **`<TextPasteForm initialForm={extracted} />`**(키로 remount해 프리필 반영). 이후 편집·저장은 TextPasteForm 기존 로직.
- 기본 category는 추출 결과에 맞춰 '웹인사이트'(뉴스 소스 판별 로직은 후속; 사용자가 폼에서 바꿀 수 있음).

### 2-D. `ContentAddTabs` 3번째 탭
- `TABS`에 `{ value: 'url', label: 'URL 가져오기' }` 추가(Tab 타입 확장). `tab === 'url'`이면 `<UrlImportForm/>` 렌더. (209 AdminTabs 그대로, 시각 일관.)

## 3. 회귀 가드 / 비기능 요건
- **SQL·신규 npm 없음**. 저장은 기존 paste 경로(본문 평문) 그대로 — 리치 에디터(HTML)는 별건.
- TextPasteForm은 prop 없을 때 기존과 동일(파일/붙여넣기 탭 무영향).
- 추출 API 어드민 게이트, 타임아웃·graceful(추출 실패 시 직접 붙여넣기 안내).
- 203/204 토큰·209 탭 스타일 유지. 공개 화면 무영향.
- article-extractor는 서버(nodejs)에서만 실행(클라이언트 CORS 회피).
