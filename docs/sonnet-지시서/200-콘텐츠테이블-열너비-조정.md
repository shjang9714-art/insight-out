## 0. 한 줄

콘텐츠 관리 테이블의 각 열 경계에 **드래그 리사이즈 핸들**을 달아 사용자가 열 너비를 조정하고, 그 값을 **localStorage에 영속**한다(새로고침·재방문 유지). 라이브러리 없이 경량 훅으로 구현.

## 1. 현행 진단 (검증된 코드 사실)

- `AdminContentManager.tsx`(:1006~): `<div overflow-x-auto>` > `<table className="w-full min-w-[960px] border-collapse text-sm">`. 열 폭은 **브라우저 자동**(사용자 조정 불가).
- 8열: ①선택(체크) ②제목(min-w-220, line-clamp-2) ③카테고리 ④소스 ⑤상태 ⑥본문 ⑦수집일(KST) ⑧관리(우측). `<th>`·`<td>` 다수 `whitespace-nowrap`.
- 자동 폭이라 제목이 좁고 소스/수집일이 넓는 등 사용자가 원하는 배분 불가.

## 2. 구현 (순수 UI — SQL·데이터 무변경, 라이브러리 없음)

### 2-1. 리사이즈 훅 — `useResizableColumns`(신규, `src/components/admin/` 또는 `src/lib/admin/`)
- 입력: 컬럼 정의 `{ id, defaultWidth, minWidth }[]` + localStorage 키.
- 상태: `widths: Record<colId, number>` — 초기값 = 저장값(있으면) ?? default. **SSR 가드**(마운트 후 localStorage 읽기, 초기 렌더는 default로 hydration mismatch 방지).
- `startResize(colId, e)`: pointerdown → `document`에 pointermove/pointerup 리스너. move에서 `width = max(minWidth, startWidth + (e.clientX - startX))`. up에서 리스너 해제 + **localStorage 저장**.
- 반환: `widths`, `startResize`, `resetWidths`(저장 삭제 + default 복원).
- 드래그 중 `body` `user-select:none`·`cursor:col-resize`(전역 클래스 토글)로 텍스트 선택 방지.

### 2-2. 테이블 적용 — `table-fixed` + `<colgroup>`
- `<table>`을 `table-fixed`로(폭이 colgroup 기준으로 확정). `<colgroup>`에 컬럼별 `<col style={{ width: widths[id] }}>`.
- 총합 최소폭 유지(`min-w-[960px]` 대체: 합계가 컨테이너보다 크면 `overflow-x-auto`로 가로 스크롤 — 기존 래퍼 유지).
- 리사이즈 대상: 제목·카테고리·소스·상태·본문·수집일(6열). **선택(체크)·관리 열은 고정**(리사이즈 제외, 고정 폭).
- 기본 폭 예시(px): 제목 320·카테고리 96·소스 140·상태 130·본문 80·수집일 150(육안 후 조정). min: 제목 200·기타 64~110.

### 2-3. 리사이즈 핸들 (각 리사이즈 `<th>` 우측)
- `<th className="relative ...">` 안에 우측 경계 핸들:
  ```tsx
  <span
    role="separator" aria-orientation="vertical"
    onPointerDown={(e) => startResize(col.id, e)}
    className="absolute right-0 top-0 h-full w-1.5 cursor-col-resize select-none hover:bg-border active:bg-brand-600/40"
  />
  ```
- 헤더 셀 내용은 `truncate`(고정 폭에서 넘침 방지). 셀(`<td>`)은 `table-fixed`상 넘침 → 제목은 기존 line-clamp-2, 나머지는 `truncate`(title 툴팁).

### 2-4. 초기화
- 테이블 상단(또는 헤더 우측)에 "열 너비 초기화" 작은 버튼(ghost) → `resetWidths()`. (실수 복구·기본 배분 회귀.)

### 2-5. (범위 밖)
- 열 순서 변경(드래그 재배치)·열 표시/숨김 = 후속(요청 시).

## 3. 회귀 가드 / 비기능 요건

- 순수 UI. 데이터·쿼리·라우트·SQL 무변경. 신규 npm 의존 0(자체 pointer 이벤트).
- **SSR 안전**: 초기 렌더 default 폭 → 마운트 후 저장값 적용(hydration mismatch 0). localStorage 접근 try/catch.
- min-width 클램프로 열이 사라지지 않음. table-fixed 전환 후에도 제목 line-clamp-2·기타 truncate로 내용 안 깨짐.
- 드래그가 행 클릭/정렬/선택과 충돌 안 하게(핸들에서 stopPropagation). 터치도 pointer 이벤트로 커버.
- 어드민 한정, 사용자 화면 무영향. 197 다크 대비·타이포 유지, 신규 hex 0(brand/border 토큰).

## 4. 검증 (Sonnet 자체)

1. `npx tsc --noEmit` 0 / `npx eslint` 0 / build 통과
2. 열 경계 드래그로 너비 조정, 놓으면 확정(제목 넓히기·소스 좁히기 등)
3. 새로고침·재방문 후에도 조정 폭 유지(localStorage), "초기화"로 기본 복원
4. min-width 이하로 안 줄고, table-fixed에서 제목 2줄·기타 truncate 정상
5. 드래그가 행 선택/정렬과 충돌 없음, 가로 스크롤 정상, 다크·라이트 스크린샷
6. SSR hydration 경고 0, 신규 hex 0, 사용자 화면 무영향
