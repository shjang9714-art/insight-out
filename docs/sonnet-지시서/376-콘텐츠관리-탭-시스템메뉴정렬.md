## 배경 (David)
콘텐츠 관리 탭이 현재 **전체/뉴스/리서치/웹인사이트/유튜브**인데, 시스템 메뉴(콘텐츠: 뉴스·유튜브·웹인사이트 / 리포트: 외부리포트·지식보고서)와 어긋난다. **콘텐츠 관리 탭을 시스템 메뉴에 맞춰 재구성**한다. **단 contents 테이블 카테고리만** — AI리포트(`ai_reports`)·핵심인사이트(`daily_insights`)는 별도 테이블·별도 어드민(`/admin/reports`·`/admin/insights`)으로 **그대로 유지**(이번 범위 아님, 링크만).

## 작업

### 1. 어드민 전용 탭 목록 (CATEGORY_DEFS 직접 수정 금지)
- `CATEGORY_DEFS`는 사용자 화면(CategoryGrid·SearchBar)과 공유 → **직접 바꾸면 사용자쪽 회귀**. 따라서 **AdminContentManager 안(또는 `src/lib/admin/*`)에 어드민 전용 탭 정의**를 만들어 여기서만 순서·라벨·매핑을 다룬다.
- 탭 구성(시스템 메뉴 순서):
  - **전체**
  - **뉴스** (dbCategories `['뉴스']`)
  - **유튜브** (`['유튜브']`)
  - **웹인사이트** (`['웹인사이트','오피니언']`)
  - **외부리포트** (현 "리서치" 라벨 교체 · dbCategories `['리포트','가트너','KRG']`)
  - **지식보고서** (신규 탭 · dbCategories `['지식보고서']`) — 현재 전용 탭이 없어 전체에만 섞여 있음
- 각 탭 클릭 시 기존 category 필터 로직(`toDbCategories`/`.in('category', …)`) 재사용해 해당 dbCategories로 조회. 라벨은 시스템 메뉴와 동일 문구("외부리포트"·"지식보고서").

### 2. AI리포트·핵심인사이트 (링크만)
- 콘텐츠 관리 상단 또는 탭 영역에 **"AI리포트 관리 →"(`/admin/reports`)·"핵심인사이트 관리 →"(`/admin/insights`)** 링크를 두어 이동 경로만 제공(이 테이블들은 콘텐츠 관리에서 조회·편집하지 않음).

## 회귀 / 주의
- **`CATEGORY_DEFS` 원형 유지**(사용자 CategoryGrid·SearchBar 회귀 금지). 어드민 탭은 별도 정의로.
- 기존 그리드 관리 기능(상태전환·삭제·열람·편집·표지)은 그대로 — 탭 구조만 변경.
- '리서치' dbCategories(리포트·가트너·KRG) 매핑을 "외부리포트" 탭으로 옮길 때 **조회 누락 없게**(같은 dbCategories 유지, 라벨만 변경). 지식보고서는 신규 탭이라 기존 "전체"에서 보이던 것과 동일 데이터.
- URL 파라미터(`?category=`) 호환 — 기존 링크(예: `?view=external`·`?category=리서치`)가 깨지지 않게 별칭 처리 또는 확인.
- 색 토큰·한국어·`prefetch={false}`.
- 검증: `tsc`·ESLint·`check-prefetch`·`build` + (dev)탭 6개(전체·뉴스·유튜브·웹인사이트·외부리포트·지식보고서) 각각 올바른 카테고리 조회 / 사용자쪽 CategoryGrid·SearchBar 회귀 없음 / AI리포트·핵심인사이트 링크 이동.
