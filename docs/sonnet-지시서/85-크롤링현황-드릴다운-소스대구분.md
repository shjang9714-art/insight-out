## 배경 (David)
- ⑤ 크롤링 현황의 숫자(신규/보류)를 눌러 **어떤 기사를 수집했는지 팝업**으로 보고 **상태를 수정**하고 싶음.
- ⑦ 크롤링 현황 표에 **소스 대구분(뉴스/리포트/웹인사이트/유튜브)** 이 안 보여 리서치인지 뉴스인지 모름.

`crawl_logs` 는 카운트만 저장(기사 id 없음) → 한 실행분 기사는 **소스 + 시간창(started_at~finished_at)으로 `contents.collected_at` 역조회**로 근사한다.

## 작업

### 1. 서버 페이지 — 데이터 보강 + 클라이언트 테이블 분리
- `crawl-logs/page.tsx`(서버 유지): logs select 에 **`source_id` 와 `sources(name, type)`** 추가.
  ```ts
  .select('id, status, fetched_count, inserted_count, duplicate_count, held_count, error_message, started_at, finished_at, created_at, source_id, sources(name, type)')
  ```
- 요약 카드는 그대로 서버 렌더. 로그 표는 **신규 클라이언트 컴포넌트 `<CrawlLogsTable logs={logs} />`** 로 교체(상호작용 위해).

### 2. ⑦ 소스 대구분 배지 — `CrawlLogsTable`
- 소스명 옆에 **유형 배지**(SOURCE_TYPE_LABELS: news_site=뉴스·report_publisher=리포트·web_insight=웹인사이트·youtube_channel=유튜브). 작은 회색 배지(토큰 색, #9).
- `SOURCE_TYPE_LABELS` 는 SourceManager 에만 있으니 **`src/lib/admin/source-types.ts`(신규)로 추출·export** 후 양쪽(SourceManager·CrawlLogsTable)에서 import(중복 제거). 라벨 값 동일 유지.

### 3. ⑤ 드릴다운 다이얼로그 — `CrawlLogsTable` (`'use client'`)
- 표의 **신규(`inserted_count`)·보류(`held_count`) 셀을 버튼**으로(0이면 비활성). 클릭 시 Dialog 오픈, 대상 = 그 로그의 `source_id` + 시간창.
- Dialog 내용:
  - 조회(browser `createClient`, admin RLS): `contents` 에서 `source_id = log.source_id` AND `collected_at >= log.started_at` AND `collected_at <= (log.finished_at ?? log.created_at)` (끝에 +5초 버퍼), `order('collected_at', desc)`, 최대 100. select: `id, title, category, status, collected_at, original_url`.
  - **보류 셀 클릭 시** 추가로 `status='pending'` 필터(그 외 셀은 전체).
  - 목록 렌더: 제목(원문 링크 있으면 새 탭) · 카테고리 · 수집시각(KST) · **상태 배지 + 변경 버튼**(노출/검토대기/숨김 = published/pending/rejected). 상태 변경 = `supabase.from('contents').update({ status }).eq('id', id)` 후 낙관적 갱신(AdminContentManager 패턴 참고). 한국어.
  - 헤더: "{소스명} · {실행시각 KST}에 수집한 기사" + 건수. 빈 결과 안내문.
- Dialog 는 `@/components/ui/dialog` 사용. ESC/바깥 클릭 닫힘 기본.

### 4. 표 행동 유지
- 기존 컬럼·상태 배지·에러·소요·요약 카드 그대로. 신규/보류만 클릭형으로.

## 회귀 / 주의
- DB·스키마 무변경. 시간창 역조회는 **근사**(collected_at 이 실행 중 now() 로 찍힘) — 같은 소스가 짧은 간격 재실행되면 약간 겹칠 수 있음(허용, 안내문에 "이 실행 시간대 수집분" 명시).
- 상태 변경은 admin RLS(쿠키 세션) 통과. service_role 불필요.
- `source_id` null 로그(소스 삭제됨)는 드릴다운 비활성 처리.
- `SOURCE_TYPE_LABELS` 추출 시 SourceManager import 경로만 교체(값·동작 불변).
- 페이지(`page.tsx`)는 서버 유지, 상호작용은 `CrawlLogsTable` leaf 만 `'use client'`(#12). UI 한국어(#1)·토큰 색(#9).
