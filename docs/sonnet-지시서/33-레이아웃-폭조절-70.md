## 배경 (현재 문제)

- `src/app/dashboard/layout.tsx` 의 상단 네비 div(`CategoryGrid`+`ServiceTabs`+`SearchBar`)와 `<main className="min-w-0 flex-1">` 가 **폭 제한이 없어** 와이드 모니터에서 콘텐츠가 화면 끝까지 늘어남(특히 카드 그리드·피드가 과도하게 넓어 가독성 저하).
- 상세(`contents/[id]` `mx-auto max-w-3xl`)·마이페이지(`max-w-2xl`)·어드민(`max-w-7xl`)은 이미 폭 제한이 있으나, **대시보드 홈/목록 계열은 없음** → 일관성도 깨짐.

## 설계 의도

- **단일 폭 토큰을 정해 본문 콘텐츠 영역에 일괄 적용**한다. 사이드바(`w-56`)는 그대로 두고, `<main>` **내부 콘텐츠**를 `mx-auto` + `max-w-*` 로 가운데 정렬·폭 제한.
- 목표 폭: **`max-w-screen-xl`(1280px)** 을 기준으로 한다(피드/카드 3열이 자연스러운 폭). 단 상세·마이페이지의 기존 좁은 폭(`max-w-3xl`/`2xl`)은 **건드리지 않는다**(가독 목적상 의도된 좁은 폭).

## 작업

### 1. 상단 네비 폭 제한 — `layout.tsx`
- 상단 네비 바깥 박스(`border-b ... px-4 py-4 sm:px-6`)는 **풀폭 배경 유지**(border가 화면 전체로 가야 자연스러움).
- 그 **안쪽에 래퍼** 추가: `<div className="mx-auto w-full max-w-screen-xl">` 로 `CategoryGrid`+`ServiceTabs`+`SearchBar` 를 감싼다. → 배경/보더는 풀폭, 내용은 중앙 정렬.

### 2. 본문 폭 제한 — `layout.tsx` 의 `<main>`
- `<main className="min-w-0 flex-1">` → 내부에 폭 래퍼를 두는 방식 권장:
  `<main className="min-w-0 flex-1"><div className="mx-auto w-full max-w-screen-xl">{children}</div></main>`
- 단, 상세·마이페이지처럼 페이지가 **자체 `mx-auto max-w-*`** 를 쓰는 경우 이중 중앙정렬이 되어도 더 좁은 쪽이 이기므로 시각적 문제 없음(확인할 것). 문제가 있으면 `<main>` 래퍼 대신 **페이지별 적용**(아래 3)으로 전환.

### 3. 페이지별 확인(2번이 깔끔하면 생략 가능)
- `dashboard/page.tsx`(`space-y-6 px-4 py-6 sm:px-6`), `contents/page.tsx`, `youtube/page.tsx`, `search/page.tsx` 가 2번 래퍼 아래에서 의도대로 폭 제한되는지 육안 확인. padding(`px-*`)은 페이지에 유지.
