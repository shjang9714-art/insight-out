## 배경 (David)

전략보고서 = IA 흐름의 종착점("결과물"). 지금 111/113의 "보고서로 만들기"가 비활성 자리만. 캡스톤 **1단계 = 뷰어 + 샘플** — `ai_reports`(body_md) 를 보는 화면을 만들고, **Opus 가 작성한 샘플 보고서 1편을 시드**해 포맷·가치를 확인. (이슈/콘텐츠 선택 → 자동 생성하는 워크벤치는 후속.)

## 설계 결정 (Opus)

1. **뷰어 우선**: `/dashboard/reports` 목록 + `/dashboard/reports/[id]` 상세(body_md 마크다운 렌더 + 근거 출처). 생성은 당분간 **Claude 루틴**(Opus 가 body_md 작성 → 시드), 인앱 LLM 생성 워크벤치는 후속.
2. **마크다운 = react-markdown + remark-gfm**(표·GFM). 서버 컴포넌트에서 렌더(정적 md). `dangerouslySetInnerHTML` 회피.
3. **per-user**: `ai_reports.user_id` NOT NULL → 샘플은 David(`yjhead@gmail.com`) user_id 로 시드(본인에게 노출). 공유/발행(shared) 개념은 후속.
4. 전략보고서 상단 카드 → `/dashboard/reports` 연결(108 패턴).

## 작업

### A. (선행) SQL — `docs/sql-handoff/114-sample-report.sql` (수희 적용)
- Opus 작성 샘플 보고서(body_md) 를 `ai_reports` 에 INSERT(user_id = David, type='시장동향', status='published'(또는 'completed'), title) + `ai_report_sources` 에 근거 content_id 몇 건. (파일 제공됨.)

### B. 의존성 + 마크다운 렌더 컴포넌트
- `react-markdown` + `remark-gfm` 추가(#18 사유 명시).

### C. 목록 — `src/app/dashboard/reports/page.tsx` (신규, 서버)
- metadata("전략보고서 | Insight Out"). 현재 사용자 `ai_reports` 조회(RLS 본인) select(id·title·type·status·created_at) order created_at desc.
- 카드/행: 유형 배지(AiReportType)·제목·상태·날짜 → 클릭 `/dashboard/reports/{id}`. 빈 상태("아직 보고서가 없습니다 — AI 인사이트에서 '보고서로 만들기'로 시작").

### D. 상세 — `src/app/dashboard/reports/[id]/page.tsx` (신규, 서버)
- `params: Promise<{id}>`. 보고서 조회(없으면 notFound). 헤더(제목·유형 배지·생성일). `<ReportMarkdown>{body_md}</ReportMarkdown>`.
- **근거 출처**: `ai_report_sources` join `contents`(title) → 하단 "근거 콘텐츠" 목록(링크 `/dashboard/contents/{id}`). (#출처표기 §12.)
