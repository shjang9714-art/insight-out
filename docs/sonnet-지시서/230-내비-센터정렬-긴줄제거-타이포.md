# 지시서 230 — 내비 센터 정렬 + 긴 밑줄 제거 + 타이포 위계(L1/L2)

목표: L1·L2 내비를 **센터 정렬**로 통일하고, 풀폭 긴 밑줄(라인)을 없애 **짧은 활성 밑줄만** 남기며, 폰트를 키워(L1 17 / L2 15) 프리미엄 위계를 준다. 상단 유틸리티 바·로고는 유지.

범위(David 확정): L2 있는 세 섹션(AI인사이트·기업동향·콘텐츠) 전부 동일 적용. 톤은 refined(무트 마젠타) 유지. Pretendard는 이미 적용돼 있으므로 **폰트 로드 변경 없음**(크기·굵기만). SQL 없음.

확정 요소: L1·L2 **센터** · 긴 줄 없음(짧은 활성 밑줄만: L1 2px / L2 1.5px) · **L1 17 / L2 15** · L1 간격 40 · 무트 마젠타.

---

## 1. 현행 진단 (검증된 코드 사실)
- **L1** `DashboardHeader.tsx`:
  - 헤더 `<header className="sticky ... border-b border-border ...">`(177) — **하단 풀폭 라인**(내비 아래 긴 줄).
  - 내비 `<nav className="hidden border-t border-border md:flex">`(315) — 유틸바와 사이 **상단 라인**.
  - 컨테이너 `mx-auto flex w-full max-w-6xl items-stretch px-4 sm:px-5`(318) — **좌측 정렬**(227).
  - 항목(322–329): `relative flex items-center px-3 py-3.5 text-[16px] font-medium ... after:h-[1.5px]` 활성 `text-foreground after:bg-brand-muted`, 비활성 `text-muted-foreground after:bg-transparent hover:after:bg-border`.
- **L2** `src/components/analysis/InsightViewTabs.tsx`: 컨테이너 `inline-flex items-center gap-5 border-b border-border`(**풀폭 하단 라인**), 항목 `text-[14px]`, 활성 언더라인 `after:left-0 right-0 h-[1.5px] bg-brand-muted`. (AiInsightBoard·EntityTabs·contents가 사용)

## 2. 구현

### 2-1. L1 (DashboardHeader nav)
- 컨테이너 318: `items-stretch` → **`justify-center`**, 항목 사이 **`gap-10`**(40px). (좌측정렬·flex-1 흔적 제거)
- 항목 322–329: `px-3` **제거**(밑줄이 글자폭이 되도록), `text-[16px]` → **`text-[17px]`**, `after:h-[1.5px]` → **`after:h-[2px]`**(L1 굵게). 활성/비활성 색은 유지(text-foreground / text-muted-foreground, `after:bg-brand-muted`).
- **긴 줄 제거**: 내비 `border-t border-border` 삭제 + 헤더 `border-b border-border`(177) 삭제. sticky `bg-card/90 backdrop-blur`가 분리감 제공(긴 라인 없이). → **짧은 활성 밑줄만** 남음.

### 2-2. L2 (InsightViewTabs)
- 컨테이너: `inline-flex items-center gap-5 border-b border-border` → **`flex items-center justify-center gap-6`**(센터), **`border-b` 삭제**(긴 줄 제거).
- 항목 폰트 `text-[14px]` → **`text-[15px]`**.
- 활성 언더라인: L1과 차별화 — **1.5px, 짧게 중앙**. `after:left-0 right-0`(글자폭 전체) 대신 **중앙 고정 짧은 밑줄**(예: `after:left-1/2 after:-translate-x-1/2 after:w-4 after:h-[1.5px]`)로. 비활성 언더라인 없음.
- 좌측정렬 흔적 제거(센터 정렬).

### 2-3. 적용 확인
- AiInsightBoard·EntityTabs(기업동향)·contents(소스탭) 모두 InsightViewTabs 사용 → **자동으로 센터·15px·짧은 밑줄** 반영. 콘텐츠 카운트 탭도 센터.

### 2-4. 타이포(Pretendard, 로드 변경 없음)
- 폰트는 이미 Pretendard(가변). 크기/굵기만: L1 17/활성 500, L2 15/활성 500. 자간은 기본 유지(한글 과도 자간 금지). 필요 시 L1에 아주 미세한 음수 자간은 선택.

## 3. 회귀 가드
- 상단 유틸바(로고·검색·날짜·다크토글·알림·프로필) 무변경.
- 활성 판정(`isTabActive`)·탭 전환 동작 불변.
- 모바일 내비(`hidden md:flex`)는 데스크톱 전용 — 모바일 별도 메뉴 영향 없음.
- 다크/라이트 모두 짧은 무트 마젠타 밑줄 정상, 긴 라인 사라져도 헤더 분리감 유지(sticky bg).
- L2 센터 후 콘텐츠 페이지의 "총 N건·뷰 토글" 행 레이아웃 안 깨지는지(별개 행).
