## 파트 A — "지금 수집" 버그 (최우선)

### A-1. 수동 수집은 활성 소스 전부 강제 실행
- 현재 `crawl-now` → `runCrawl()` 기본 = **due(주기 도래) 소스만** → 최근 수집했거나 `crawl_interval_minutes`=null 이면 **0건**.
- 수정: `runCrawl` 에 `{ force?: boolean }` 추가 → **force 면 due-체크 우회하고 활성 소스 전부 실행**(단 `since`는 당일 0시 KST 유지, 소급 아님). `crawl-now` 라우트는 `runCrawl({ force: true })` 호출.
- 정기 크론(`/api/cron/crawl`)은 기존 동작(due-체크) 그대로.

### A-2. "The string did not match the expected pattern" 재현·수정
- **재현**: `npm run dev` → 로그인(admin) 후 `/admin/sources` "지금 수집" 또는 `POST /api/admin/crawl-now` → **서버 콘솔 스택 확보**.
- `runCrawl`은 소스별 `Promise.allSettled`라 개별 실패는 안 던짐 → 이 raw 에러는 **셋업 단계에서 throw**. 유력 후보 순서로 점검:
  1. `createAdminClient()` / supabase 클라이언트 — `SUPABASE_SERVICE_ROLE_KEY`·`NEXT_PUBLIC_SUPABASE_URL` 값 이상(비ASCII·공백·오타) 시 throw. → **수희 env 점검 병행**(아래 핸드오프).
  2. 키워드/소스 쿼리 결과 미검증, 날짜 헬퍼(`new Date` NaN→`toISOString`).
  3. 번역 경로: 영문 기사 있을 때 `translation_usage`/`translation_settings` 테이블 미생성(수희 SQL 미실행) → 조회 에러는 **현재 가드돼 null 반환**이라 throw 아님(확인만).
- **수정**: 원인 제거 + `runCrawl` 셋업(클라이언트 생성·소스/키워드 로드)을 try/catch로 감싸 **사용자에게 한국어 메시지**(raw DOMException 노출 금지). 라우트는 이미 catch 있음 — 메시지를 한국어로 정규화.
- **수희 핸드오프(보고에 명시)**: Vercel `SUPABASE_SERVICE_ROLE_KEY`·`NEXT_PUBLIC_SUPABASE_URL`·`NEXT_PUBLIC_SUPABASE_ANON_KEY` 값 정상 여부 재확인(이전 ByteString 사고 재발 가능). 번역 SQL 2건(`2026-06-06-번역사용량/번역설정`) 실행 여부 확인.

## 파트 B — 당일 발행분만 수집
- 어댑터에 `since` 필터는 있으나 **발행일 없으면 포함**이라 과거/미상 글이 섞일 수 있음.
- 정책: `news_site` 는 **발행일(published_at)이 있고 `since`(당일 KST 0시) 이상인 항목만** 수집. **발행일 파싱 실패·누락 항목은 제외**(보수적 포함 → 보수적 제외로 전환).
- 단 RSS에 발행일이 원래 거의 없는 소스가 있으면 과수집/누락 트레이드오프 → 보고에 영향 소스 있으면 명시. youtube 는 기존대로(video_id 멱등).

## 파트 C — 발행일 표시 (수집일 아님)
- 콘텐츠 카드·목록·상세에서 날짜를 **`published_at`(실제 기사 발행일, KST)** 으로 표시. `collected_at`(수집일) 표기 제거 또는 보조로만.
- `published_at` 이 null 이면 "발행일 미상" 등 폴백. 포맷은 기존 KST 포맷 유틸 재사용.

---

## 파트 D — 본문 전문 + 이미지 빈공간 + 보일러플레이트 제거
상세(`/dashboard/contents/[id]`)에서:
- **전문 노출**: `ensureFullBody` 로 원문 전문이 보이도록(동작 확인·강화). RSS 요약만 있고 전문 미추출이면 추출 시도.
- **이미지 빈공간 제거**: `htmlToPlainText`/렌더에서 **이미지 태그·깨진 img 자리·그로 인한 빈 줄**을 제거(연속 공백/빈 단락 정리). 본문은 텍스트 위주로, 못 가져온 이미지의 빈 박스 없게.
- **보일러플레이트/광고 제거**: 네비·푸터·연락처·약관 류 정크 라인 제거. 예시(요즘IT): `서비스 전체보기 / 위시켓 / 요즘IT / AIDP / 고객 문의 / 02-…/ 이용약관 / 개인정보 처리방침 / 청소년보호정책 / 슬랙봇 / 크롬 확장 프로그램 / 콘텐츠 제안하기 / 광고 상품 보기` 등.
  - 접근: ① `@extractus/article-extractor` 가 본문 영역만 뽑게 유지하고, ② **정크 라인 필터**(짧은 메뉴/링크성 라인, 반복 네비, 연락처/약관 키워드 포함 라인, 이메일·전화 패턴) 클리너를 `full-body` 또는 별도 `clean-body.ts` 로 추가. ③ `quality.ts` `isAdLike` 광고 키워드도 본문 정제에 재활용 가능.
  - 과도 제거로 본문이 비지 않게 가드(정제 후 너무 짧으면 원본 유지).

## 파트 E — Admin 차단 규칙 (이번엔 설계·항목만)
- 향후 admin 에서 **차단 규칙**(키워드/도메인/URL 패턴) 등록 → 수집·표시에서 제외하는 기능.
- 이번 작업에선 **구현하지 않고**, 작업계획서에 **신규 항목으로만 추가**(예: `#P8 콘텐츠 차단 규칙 어드민`, ⚪ 예정) + 한두 줄 설계 메모(테이블 `content_block_rules(pattern, type, enabled)` 후보, 적용 지점=크롤 적재 필터 + 표시 필터). 별도 지시서로 분리 예정.
