세 상태 모두 새로고침·재방문 유지 (`localStorage`).

## 2. 구현

- 상태 키: `io-admin-sb-width` / `io-admin-sb-collapsed` / `io-admin-sb-folded`
- 상수: `MIN_W=220`, `MAX_W=480`, `DEFAULT_W=288`, `RAIL_W=60`
- 하이드레이션 안전: `useState`는 기본값으로 초기화 → mount 후 `useEffect`에서 `localStorage` 로드해 반영. 이 프로젝트의 새 eslint 규칙(`react-hooks/set-state-in-effect`)이 effect 내부 직접 `setState`를 막아, `AdminThemeScope.tsx`가 이미 쓰던 패턴(`startTransition`으로 감싸기)을 동일하게 적용.
- 폭 + 리사이즈: `aside`의 고정 `w-[288px]` 제거 → `style={{ width: collapsed ? RAIL_W : width }}`. 드래그 중엔 `transition-[width]` 클래스를 빼서 끌림 없이 즉시 반응, 드래그 종료 시에만 클래스 복귀. 우측 경계 `role="separator" aria-orientation="vertical"`, 마우스 드래그(`window` mousemove/mouseup, 언마운트/드래그종료 시 리스너 해제 + `document.body.style.userSelect` 복원) + 키보드 ←/→ 16px 조절, 값은 `[220,480]` 클램프.
- 전체 접기(레일): 로고 행에 토글 버튼(`PanelLeftClose`/`PanelLeftOpen`) 배치(로고와 같은 줄). collapsed 시 라벨·배지·그룹헤더·검색창 숨김, 아이콘만 세로 나열 + `title`/`aria-label` 툴팁, 활성 하이라이트 유지. 해제 시 저장돼 있던 `width` 그대로 복원(collapsed는 별도 상태라 width를 덮어쓰지 않음).
- 그룹 폴딩: 그룹 헤더 `<p>` → `<button>`(좌측 `ChevronDown`/`ChevronRight` + 그룹명), 클릭 시 `folded: Set<string>` 토글 + 저장. folded면 해당 `<ul>` 미렌더. **검색 중(`trimmedQuery`)에는 폴딩 무시** — 기존 평면 검색 결과 분기 그대로 유지. collapsed(레일) 상태에는 그룹헤더 자체가 없어 폴딩 UI 노출 안 함(레일에선 그룹 배치만 유지, 폴딩 상태 무관하게 항상 전체 아이콘 표시).
- 접힌 그룹 미확인 배지: 그 그룹에 배지 있는 항목(`/admin/requests`·`/admin/insights`)이 있고 카운트>0이면 헤더에 작은 점(`bg-risk`) 표시.

- 하이드레이션: 초기 렌더 = 기본값(SSR/CSR 동일) → mount 후 `startTransition`으로 반영. 콘솔 하이드레이션 경고 없음(로컬 빌드 확인).
