# 지시서 223 — 기업동향 인사이트 카드 라우팅 수정(카드/제목 → 상세)

목표: 기업동향(관심기업 등) 인사이트 카드에서 **카드/제목 클릭 시 상세로 전환**한다. 현재 제목이 클릭 불가하고, "자세히 보기"는 빈 토픽 페이지로 가 "아무것도 없음"으로 보이는 문제를 해결한다.

범위(David, p13-1·2): 라우팅 버그 수정. 관심기업 구조 자체는 유지. SQL 없음.

---

## 1. 현행 진단 (검증된 코드 사실)
- `src/components/analysis/InsightCardsSectionClient.tsx`
  - 카드 컨테이너 `<article>`(268~) — **링크 없음**(클릭 불가).
  - 제목(290–293): `<p class="text-base font-semibold ...">{card.card_headline ?? card.headline}</p>` — **클릭 불가**.
  - "자세히 보기": `/dashboard/topics/${encodeURIComponent(card.topic)}`(토픽 타임라인) — 관심기업/렌즈 필터 상황에선 매칭 0 → 빈 화면("아무것도 없음").
- 카드 데이터: `card.source_content_ids: string[]`(근거 콘텐츠 id), `card.citations[].content_id`. → **상세 대상으로 사용 가능.**
- 상세 라우트 존재: `/dashboard/contents/{id}`(콘텐츠 상세) ✓, `/dashboard/topics/{topic}` ✓.
- 같은 카드 UI가 리스트/카드뉴스 변형에도 쓰임(파일 내 다른 렌더 분기) — grep로 제목 렌더 전수 확인해 함께 처리.

## 2. 구현 (InsightCardsSectionClient.tsx)
- **상세 대상 헬퍼**: `const detailHref = card.source_content_ids?.[0] ? \`/dashboard/contents/${card.source_content_ids[0]}\` : (card.citations?.[0]?.content_id ? \`/dashboard/contents/${card.citations[0].content_id}\` : \`/dashboard/topics/${encodeURIComponent(card.topic)}\`)` — 근거 콘텐츠 우선, 없으면 토픽 폴백.
- **제목을 Link로**: 290–293의 `<p>`를 `<Link href={detailHref} className="... hover:text-brand-600 hover:underline">`로 감싸(제목 클릭 → 상세).
- **카드 클릭도 상세로**: `<article>` 내부에 근거 링크(citations → contents)가 있어 전체를 `<Link>`로 감싸면 링크 중첩이 됨 → 대신 카드 우하단/상단에 눈에 띄지 않는 전체 클릭 대신, **제목 링크 + 기존 "자세히 보기"도 `detailHref`로 변경**(토픽 대신 상세). 근거 인용 링크는 개별 콘텐츠로 유지.
  - (전체 카드 클릭이 꼭 필요하면: `<article>`을 `<Link>`로 바꾸고 내부 근거 링크는 `stopPropagation` 처리 — 회귀 위험 있어 2순위. 기본은 제목+자세히보기 링크화.)
- 카드뉴스/리스트 변형에도 동일 `detailHref` 적용.

## 3. 회귀 가드
- 근거 인용(citations) 링크는 그대로 각 콘텐츠 상세로.
- 렌즈/필터/기간 로직 불변(라우팅만 수정).
- AI 인사이트 메뉴(issues)에서 같은 컴포넌트를 쓰는 곳도 제목→상세로 동일 적용(일관). 빈 토픽 이동 제거.
- 근거가 전혀 없는 카드(희귀)는 토픽 폴백 → 최소한 빈 AI인사이트로는 안 감.

## 4. 검증
- `npx tsc --noEmit` 0, `npx eslint` 0, `npm run build`.
- grep로 `card.headline`/`card_headline` 제목 렌더 위치 전수 확인해 누락 없이 링크화.

- [ ] "자세히 보기"도 상세(또는 근거 없으면 토픽)로.
