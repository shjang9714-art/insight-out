# 지시서 355-D — 기업자료 연결·상호링크 (entity 상세 ↔ 기업자료 ↔ 주간브리핑)

> 대상: 구현 에이전트 · 선행: 355-A(모델)·355-B(사용자 탭·`query.ts`·`CompanyDocumentCard`) · **신규 SQL 없음**(content_entities·company_documents·entities 재사용)
> ⚠️ 읽을 것: `src/lib/company-docs/query.ts`(355-B — `getPublishedCompanyDocuments({ entityId })`·review_status='none' 필터) · `src/components/entities/CompanyDocumentCard.tsx`(355-B) · `src/app/dashboard/entities/[id]/page.tsx`(주요기업 상세) · `src/app/dashboard/contents/[id]/page.tsx`(콘텐츠 상세 — 기업자료 판별·entity 링크) · `src/lib/contents/citations.ts`(관련조회 패턴) · `AGENTS.md`

## 배경 (상위설계 §355-D)
기업자료(355-A/B/C/F)가 수집·검토·사용자 탭까지 됐다. 이제 **문서↔기업을 양방향으로 연결**한다: ①주요기업 상세에 그 기업의 "자료" 영역 ②기업자료 콘텐츠 상세 ↔ 연결 기업·형제 자료 ③주간브리핑에 "활용된 자료" 출처. `content_entities`·`ai_report_sources` 재사용. **모두 published + review_status='none'만**(검토대기·비공개 노출 금지 — 355-B 규약 유지).

## 작업

### 1. 주요기업 상세(entities/[id])에 "자료" 영역
- 엔티티 상세 페이지에 **"기업·기술 자료" 섹션** 추가 — `getPublishedCompanyDocuments({ entityId: <해당 엔티티 id>, limit: 6~8 })` 재사용 → `CompanyDocumentCard`(355-B)로 렌더. 유형(doc_type) 소수 노출.
- **0건이면 섹션 숨김 or "아직 등록된 자료가 없습니다"**(그레이스풀). 전체 보기는 `/dashboard/entities?view=documents&entity=<id>`(355-B 탭에 entity 프리필터 있으면 연결, 없으면 탭으로).
- AiMark 금지(비-AI 자료). 색 토큰·`prefetch={false}`.

### 2. 기업자료 콘텐츠 상세 ↔ 기업·형제 자료 (양방향)
- 콘텐츠 상세(`contents/[id]`)가 **category='기업자료'** 일 때:
  - 연결된 **기업(entity) 링크** 노출(`content_entities` → `entities/[id]`). 이미 entity 링크 인프라 있으면 재사용.
  - **같은 기업의 다른 자료 상위 N** ("이 기업의 다른 자료")를 `getPublishedCompanyDocuments({ entityId })`로 조회해 하단에 링크(자기 자신 제외).
- 역방향(뉴스 상세 → 관련 기업자료)은 **선택**: 뉴스가 특정 기업과 강하게 연결되면 "관련 기업 자료" 소수 노출(과하면 생략, 이번 필수 아님).

### 3. 주간브리핑 "활용된 자료" 출처 (가능 범위)
- 경쟁사 주간 브리핑 상세에 **"활용된 자료"** 출처 영역 — 그 브리핑 생성에 쓰인 기업자료가 추적 가능하면(`ai_report_sources`/source_content_ids 등 기존 출처 링크 재사용) 링크로 노출.
- **추적 소스가 없으면 이번 범위에서 생략하고 문서에 사유 기록**(무리한 신규 스키마 금지). 있으면 최소 연결만.

## 회귀 / 주의
- **published + review_status='none'만**(검토대기·비공개 절대 노출 금지). 355-B `query.ts` 필터 그대로 재사용(중복 구현 금지).
- 0건·조회 실패는 그레이스풀(섹션 숨김/안내, 크래시 금지). 상한 가드.
