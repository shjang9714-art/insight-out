## 4. 회귀 가드

- **라우트·API·코드 명칭은 그대로 둔다** — `/admin/ai-jobs`, `/api/admin/*-backfill`, 함수명 `drain*Backfill` 전부 **변경 금지**. 이번 건은 **UI 문구만**이다.
- `nav.ts`의 `href`·`icon` 변경 금지(label·description만).
- **`/admin/content-data` shim을 지우지 말 것** — 리다이렉트로 북마크를 살리는 정상 코드다.
- **섹션을 쪼개거나 합치지 말 것** — 279가 만든 2섹션 구조는 이미 맞다. 이름만 바꾼다.
- `AdminDataReset`(위험 작업)을 ai-jobs로 가져오지 말 것 — maintenance에 격리된 상태 유지.
- 기능·동작·엔드포인트 호출은 **일절 변경 없음**. 순수 문구 변경이다.
