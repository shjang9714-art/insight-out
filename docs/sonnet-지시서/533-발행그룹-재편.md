# 지시서 533 — 발행 그룹 재편

> 플래너(Opus) · 2026-08-20 · 기준 `origin/main = 55f457e` · 브랜치 `agent/533-publish-group`
> 근거: `검토-어드민IA-2차통합안-2026-08-16` 「발행 그룹」 항. 540(프롬프트 DB 이관) 완료가 전제다.
> 성격: **화면 배치·명칭 재편 + 프롬프트 탭 배선.** DB 스키마·생성 로직은 건드리지 않는다.

## 실측 사실 (재조사 금지)

- `daily_insights.day_of` 는 **2026-07-20 이후 전부 월요일**이다(주당 10~11건).
  그 이전 값(07-11 토 · 07-12 일 · 07-14 화 · 07-15 수)은 주간 게이트 도입 전 레거시다.
  → 셀렉터는 사실상 **"주"를 고르고 있는데 라벨이 "날짜"** 다. 라벨만 정정한다.
  ⚠️ **레거시 데이터를 고치지 말 것.** 값은 그대로 노출한다.
- `daily_insights` 전체 74행 / 서로 다른 `day_of` 10개.
- `PromptConsole` 은 전체 프롬프트를 한 번에 보여준다. 필터 prop 이 없다.
- `BriefingHub` 는 `tabs={[]}` 로 탭이 없다. `NewsletterHub` 는 3탭이다.

## 작업

### 1) "일일 핵심" → "핵심 인사이트" 개명 + 주 단위 명시

- `nav.ts` 발행 그룹 `/admin/daily-insights` 라벨 `일일 핵심` → **`핵심 인사이트`**,
  description 에 **"주 1회(월요일) 생성"** 을 넣는다. href 는 그대로.
- 페이지 `metadata.title` 도 맞춘다.
- `DailyInsightsManager` 표기 정정
  - 셀렉터 라벨 `날짜` → **`주(월요일 시작)`**
  - 빈 상태 문구 `이 날짜에 생성된 일일 핵심 Insight가 없습니다.`
    → `이 주에 생성된 핵심 인사이트가 없습니다.`
  - 화면 어딘가에 **"월요일에 주 1회 생성됩니다"** 안내 한 줄.
- **API·DB·쿼리 파라미터(`day_of`)는 바꾸지 않는다.** 표기만 바꾼다.

### 2) 조용한 절단 하나 — `daily-insights` 날짜 목록

`src/app/api/admin/daily-insights/route.ts` 의 `select('day_of').order(...)` 에 **`.limit()` 이 없다.**
PostgREST 기본 1000행 상한에 걸리면 오래된 주가 목록에서 조용히 사라진다.
현재 74행이라 **지금은 무해하지만** 체크리스트 항목이다. `.limit(500)` 을 넣는다.

### 3) 홈 화면 구성 → 시스템 설정 탭

- `SystemSettingsHub` 에 `{ value: 'homepage', label: '홈 화면 구성' }` 탭을 추가한다.
  위치는 `mcp` 와 `sso` 사이. 내용은 기존 `HomeSectionsSettings` 를 그대로 렌더한다
  (`AdminSectionHeader` 문구도 현행 유지).
- `src/app/admin/homepage-sections/page.tsx` 는 **리다이렉트 스텁**으로
  (`/admin/settings?tab=homepage`). 전례: `src/app/admin/keyword-groups/page.tsx`.
- `nav.ts` 발행 그룹에서 `홈 화면 구성` 항목 제거. 안 쓰는 아이콘 import 도 정리한다.

### 4) `PromptConsole` 에 선택 필터 추가

```ts
interface Props { keys?: readonly string[] }   // 없으면 현행대로 전체 노출
```

- `keys` 가 주어지면 그 key 만 렌더한다. **필터는 화면단에서만** 한다 —
  `/api/admin/prompts` 는 건드리지 않는다.
- 기존 호출부(`ReportsHub` 프롬프트 탭)는 prop 없이 그대로 두어 전체 노출을 유지한다.

### 5) 모닝브리핑 탭화

`BriefingHub` 를 2탭으로 바꾼다.

| value | label | 내용 |
|---|---|---|
| `list` | 발행 목록 | 기존 `BriefingManager` |
| `prompts` | 프롬프트 | `<PromptConsole keys={['briefing_script']} />` |

### 6) 뉴스레터에 프롬프트 탭

`NewsletterHub` 에 `{ value: 'prompts', label: '프롬프트' }` 를 **마지막**에 추가하고
`<PromptConsole keys={['newsletter_card_insight']} />` 를 렌더한다.

### 7) 핵심 인사이트에도 프롬프트 탭 — 하지 않는다

`/admin/daily-insights` 는 현재 탭 셸이 아니다. 탭화까지 하면 이번 지시서가 커진다.
`daily_insight` 프롬프트는 **AI 리포트 > 프롬프트** 탭(전체 노출)에서 계속 편집할 수 있다.

## 하지 않을 것

- `daily_insights` 데이터 보정, `day_of` → `week_of` 컬럼 변경
- 생성 로직·크론·요일 게이트 변경
- `/api/admin/prompts` 수정
- "인사이트 카드"를 기업동향으로 옮기는 것 — **535 에서 한다**
- "급상승 뉴스" 개명·랭킹 미리보기 — David 결정 대기 중이다
- 프롬프트 문구 변경
