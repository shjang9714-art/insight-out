## 배경 (David)
서비스(대분류: AICC·AIDC·Connectivity 등)마다 세부 키워드가 있는데, 현재 KeywordManager 는 **평면 테이블**(키워드/서비스/경쟁사 컬럼, service_id 순 정렬)이라 *어떤 세부 키워드가 어느 서비스에 매핑되는지* 한눈에 안 보임. → **서비스 대분류 헤더 + 그 아래 세부 키워드 그룹**으로 재구성.

## 작업 — `KeywordManager.tsx` 목록 재구성

### 1. 서비스별 그룹핑 데이터
- `services`(대분류) 순서대로 + 마지막에 "미지정"(service_id null) 그룹.
- `keywordsByService`: `Map<serviceId|'', KeywordRow[]>` 구성(기존 `keywords` 에서). 그룹 내 키워드는 이름 가나다 정렬.

### 2. 평면 테이블 → 그룹 섹션 렌더
- 기존 단일 `<table>`(366줄~) 제거. 대신 **서비스별 섹션** 반복:
  - 섹션 헤더: 서비스명(대분류) + `{n}개` 카운트. 키워드 0개면 빨강 힌트("키워드 없음 — 추가 필요")로 강조(기존 요약 칩 색 규칙 재사용).
  - 섹션 본문: 그 서비스의 세부 키워드 목록. **칩 또는 콤팩트 행**으로 — 각 항목에 키워드명, 경쟁사 배지(해당 시), 수정·삭제 버튼. (기존 행의 작업 버튼·삭제 confirm 로직 그대로 재사용.)
  - 미지정 그룹은 맨 아래.
- 상단 "서비스별 키워드 수 요약" 칩 행(226줄)은 **빠른 개요로 유지**(클릭 시 해당 섹션으로 스크롤은 선택).
- 추가/수정 폼·서비스 Select·경쟁사 토글은 **그대로**(로직 불변). "새 키워드 추가" 시 기본 service_id 를 현재 보고 있는 섹션으로 프리필하면 UX↑(선택).

### 3. 표시 디테일
- 서비스 헤더는 `Card` 또는 구분선 섹션(토큰 색, #9). 키워드 칩은 `Badge`/`rounded-lg` 콤팩트.
- 경쟁사 키워드는 작은 배지("경쟁사")로 구분.
- 로딩·빈 상태 문구 한국어 유지.

## 회귀 / 주의
- DB·쿼리·CRUD 로직 불변(표시만 재배치). 추가/수정/삭제·서비스 매핑 동작 동일.
- `service_id` null = "미지정" 그룹(기존 라벨 유지).
- 키워드 많을 때 세로 길이↑ — 서비스 섹션 접기(collapse)는 **선택**(과하면 생략, 1차는 펼침).
