## 3. 구현

### 3-1. KPI 카드 재구성 (`/admin/page.tsx`)
각 KPI 카드 구조를 통일:
```
[라벨: admin-card-title]                (예: 콘텐츠 검토)
[숫자 admin-metric] [단위 admin-metric-unit]   (예: 1,838 건)
[설명 1줄: admin-caption/text-muted]    (예: 검토가 필요한 콘텐츠)
[분류 breakdown: admin-caption]         (기존 catTotals 등, 유지)
```
- 숫자 `text-2xl font-bold` → **`admin-metric`**, 단위(건/개/곳)를 **별도 span `admin-metric-unit`**(숫자보다 작게, baseline 정렬).
- **설명 1줄 추가**(카드별): 총 콘텐츠="수집·저장된 전체 콘텐츠" · 오늘 수집="오늘 새로 들어온 콘텐츠" · 검토 대기="검토가 필요한 콘텐츠" · 북마크="사용자가 저장한 콘텐츠" · 활성 소스="수집 중인 소스"(기존 전체 N개 유지) · 리서치 반영=기존 "준비중".
- 라벨 `text-xs` → `admin-card-title`(15).
- **밀도**: `KPI_CARD` padding `p-5`→`p-6`(24), radius `rounded-xl`→`rounded-2xl`(14~16). hover는 `hover:bg-brand-50`(라이트)·다크 대응 — 스코프 토큰이면 `hover:bg-accent`로 통일 권장(마젠타 hover 과함 완화).

### 3-2. 섹션 헤더 (`AdminSectionHeader`)
- 타이틀 `text-sm` → **`admin-section-title`**(20/700). hint → `admin-section-desc`(15) 또는 caption.
- **아이콘 `text-brand-600` → `text-muted-foreground`**(마젠타 규율: 모든 섹션 아이콘 마젠타 금지). 하단 여백 `mb-3`→`mb-4`.
- 이 컴포넌트가 OpsSignals·ContentHealth·CrawlLogs 등에서 공용 → 일괄 반영.

### 3-3. 하위 컴포넌트 타이포/규율
- `AdminOpsSignals`·`AdminContentHealth`·`AdminTodoBlock`: 내부 섹션 제목은 `admin-section-title`(공용 헤더 쓰면 자동), 큰 수치는 `admin-metric`(또는 상황상 중간), 라벨/설명 `admin-card-title`/`admin-caption`. 상태 점등은 175 status-style(성공=블루·주의=앰버·실패=레드) 유지.
- `AiRefreshButton`: 버튼 `admin-btn-text`·height 유지(181), 마젠타는 **주요 액션(brand)** 이므로 허용.

### 3-4. 마젠타 규율 점검(대시보드)
- **허용**: KPI 카드 hover 강조(또는 accent), 활성 링크, 주요 CTA(AI 갱신).
- **완화**: 섹션 아이콘(→중립), 항상 켜진 마젠타 텍스트/보더. 상태·수치는 의미색/중립.
