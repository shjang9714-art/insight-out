## 배경 (David)

지금 좌측 1차 메뉴에 **이슈 보드 · 엔티티 브라우즈 · AI 인사이트**가 따로 있다. 1차 계위 개편은 아직이므로, **일단 AI 분석 페이지 안의 탭**으로 모은다. (이슈/지식그래프 사이드바 항목 제거.) 추후 IA 진화 시 다시 1차로 승격 가능 — 가볍고 되돌릴 수 있게.

## 설계 결정 (Opus)

1. **AI 분석 = 탭 셸**: 탭 3개 — `AI 인사이트`(기본) / `이슈` / `지식그래프`. `?tab=` 쿼리로 전환(서버 컴포넌트가 분기 렌더, 탭바는 클라 leaf).
2. **기존 화면을 뷰 컴포넌트로 추출**해 탭에서 렌더(로직 변경 없이 이동). 상세 라우트(`/issues/[id]`, `/entities/[id]`)는 **그대로 유지**.
3. **사이드바에서 이슈·지식그래프 섹션 제거**, AI 분석만 남김(그 안에 셋 다).
4. **구 라우트는 리다이렉트**(죽은 링크 방지): `/dashboard/issues` → `/dashboard/ai-analysis?tab=issues`, `/dashboard/entities` → `?tab=entities`.

## 작업

### A. 뷰 추출 (로직 불변, 이동만)
- `src/app/dashboard/issues/page.tsx` 의 보드 본문 → `src/components/issues/IssueBoardView.tsx`(서버 컴포넌트, 자체 데이터 페치 — 104 `lib/issues/activity.ts` 사용). 
- `src/app/dashboard/entities/page.tsx` 의 본문(데이터 페치 + `<EntityBrowse>`) → `src/components/entities/EntityBrowseView.tsx`(서버 컴포넌트).
- (선택) 현 AI 인사이트 본문 → `src/components/analysis/AiInsightsView.tsx` 로 추출(또는 page 내 인라인 유지). 

### B. AI 분석 탭 셸 — `src/app/dashboard/ai-analysis/page.tsx`
- `searchParams: Promise<{ tab?: string }>` → `const { tab } = await searchParams`; 기본 `'insights'`. 허용값 `insights|issues|entities`.
- 상단 **탭바**(`src/components/analysis/AnalysisTabs.tsx`, `'use client'`): Link 3개(`?tab=insights|issues|entities`), 활성표시는 `useSearchParams`. 
- 본문: tab 에 따라 `AiInsightsView` / `IssueBoardView` / `EntityBrowseView` 렌더.
- 페이지 헤더는 공통("AI 분석") + 탭바.

### C. 사이드바 정리 — `src/components/dashboard/Sidebar.tsx`
- **'이슈' 섹션·'지식그래프' 섹션 제거**(구분선 포함 정리). 'AI 분석' 섹션 유지(링크 `/dashboard/ai-analysis`). 미사용 아이콘 import(Radar/Network) 정리.
- (선택) AI 분석 아래 하위 링크로 이슈/지식그래프(`?tab=`)를 노출해도 됨 — 단 1차 섹션으로는 두지 않음.

### D. 구 라우트 리다이렉트 + 백링크
- `src/app/dashboard/issues/page.tsx` → `redirect('/dashboard/ai-analysis?tab=issues')`(next/navigation). `entities/page.tsx` → `?tab=entities`. (본문은 B의 뷰로 이동했으므로 페이지는 리다이렉트만.)
- 상세 백링크 조정: `issues/[id]` "이슈 보드로" → `/dashboard/ai-analysis?tab=issues`; `entities/[id]` 뒤로 → `?tab=entities`.
- 홈(104 IssueSignals)·콘텐츠 칩(102) 등 `/dashboard/issues/{id}`·`/dashboard/entities/{id}` 상세 링크는 **그대로 유효**(상세 라우트 유지) — 변경 불필요.

- **104·105 선행 권장**: 이슈 보드/홈 변경 후 추출해야 충돌 최소. IssueBoardView 는 105까지 반영된 보드를 추출.
