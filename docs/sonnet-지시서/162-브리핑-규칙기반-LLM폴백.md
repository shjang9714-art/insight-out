AI 인사이트 **브리핑 탭 상단에 "이번 주 AI 브리핑" 요약 카드**(핵심 변화 3 · 주요 리스크 · 주목 키워드 · 내 업무 시사점)를 추가한다. **규칙 기반으로 항상 생성**되고, LLM 키가 붙으면 같은 데이터를 자연어로 고도화한다. LLM 미연결·실패 시 규칙 기반 결과를 폴백 문구와 함께 보여준다("AI 요약 실패" 같은 에러 노출 금지).

## 3. 구현

### 3-1. `src/lib/briefing/insight-brief.ts` (신규)

규칙 기반 브리핑 데이터 산출 + 선택적 LLM 고도화. 순수 서버.

```ts
export interface InsightBrief {
  keyChanges: string[]      // 핵심 변화 (최대 3)
  risks: string[]           // 주요 리스크
  keywords: string[]        // 주목 키워드 (상승)
  myImplication: string | null // 내 업무 시사점 (관심사 있을 때)
  source: 'rule' | 'llm'    // 생성 방식 (배지/폴백 문구용)
}

// 규칙 기반: 증가 토픽·상승 키워드·관심기업 등장·리스크 키워드로 결정적 문장 구성
export function buildRuleBrief(input: {
  trendingTopics: { group: string; cur: number; changePct: number | null }[]
  risingKeywords: string[]
  watchlistHits: { company: string; count: number }[]
  riskKeywords: string[]   // 전력·냉각·공급망·GPU 등 사전 정의 리스크 어휘와 매칭된 상승 키워드
}): InsightBrief { /* 결정적 한국어 문장 */ }

// LLM 고도화: 같은 입력을 자연어로. 실패(null)면 ruleBrief 그대로 반환.
export async function enhanceBriefWithLlm(
  rule: InsightBrief, rawInput: unknown,
): Promise<InsightBrief> {
  const out = await llmComplete('briefing', SYSTEM, buildUserPrompt(rawInput))
  if (!out) return rule        // ← 폴백: 규칙 기반 유지
  // 파싱 성공 시 source:'llm', 실패/형식오류 시 rule 반환
}
```

- 리스크 어휘는 상수 배열(예: `['전력','냉각','공급망','GPU','입지','병목']`)로 시작, 상승 키워드와 교집합을 리스크로 본다.
- 규칙 문장 예(설계안 §4): "AI 데이터센터 관련 이슈가 최근 7일 기준 가장 많이 증가했습니다." / "전력·냉각·GPU 공급망 관련 키워드가 함께 증가하고 있습니다."
- 문장은 다소 기계적이어도 무방(David §4). 숫자(건수·증가율)는 집계값 그대로.

### 3-2. `src/components/analysis/InsightBriefCard.tsx` (신규, 서버 또는 클라)

`InsightBrief`를 받아 카드 렌더:
- 제목 "이번 주 AI 브리핑"
- 핵심 변화(번호 목록) / 주요 리스크 / 주목 키워드(칩) / 내 업무 시사점
- `source==='rule'` 일 때 하단에 옅은 폴백 문구: **"수집 데이터 기준으로 감지된 주요 변화입니다."** (에러 톤 아님)
- `source==='llm'` 일 때는 157 신뢰·신선도 배지 톤과 일치(생성 시점 등). "AI 요약을 생성할 수 없습니다" 류 문구 **금지**.

### 3-3. 브리핑 탭에 배선 (160 자리)

`AiInsightsView`(`view==='briefing'`) 최상단에:
1. 집계 입력 구성(기존 `trendingTopics`·`risingKws`·watchlist 매칭 재사용 — 가능하면 공통 함수로 추출).
2. `const rule = buildRuleBrief(input)`
3. `const brief = await enhanceBriefWithLlm(rule, input)` (LLM 없으면 rule)
4. `<InsightBriefCard brief={brief} />` 렌더 → 그 아래 기존 ② 인사이트 카드·④ 토픽.

### 3-4. "내 관점" 탭 업무 시사점 (160 미완분)

`myImplication` 을 "내 관점" 탭에도 사용: 관심 키워드/담당 서비스와 겹치는 상승 토픽 기반 한 줄. 미설정이면 `null` → 빈상태 안내(160 처리분 유지).

## 4. 회귀 가드 / 비기능 요건

- **LLM 키 없음 = 정상 동작**(규칙 기반). 빌드/런타임에 LLM 키를 전제하지 않는다.
- LLM 호출 예외·타임아웃·형식오류 → `catch` 후 규칙 기반 반환(화면 안 깨짐, 에러 미노출).
- 데이터 0(집계 비었음) → "이번 주 집계할 변화가 충분하지 않습니다" 류 차분한 빈상태(에러 아님).
- 요약은 매 요청 산출이라 결정적·캐시 친화(같은 입력=같은 규칙 출력).
- 하드코딩 hex 0. 신규 외부 의존성 0(`llmComplete` 재사용).
