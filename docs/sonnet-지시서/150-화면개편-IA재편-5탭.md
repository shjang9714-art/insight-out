## 1. 배경 & 목표

현재 홈 카테고리(뉴스/리서치/웹인사이트/유튜브/AI분석/전략보고서)는 **계위가 섞여 있음**:
- 뉴스·리서치·웹인사이트·유튜브 = 인사이트를 뽑아낼 **리소스(원천) 콘텐츠**
- AI분석·전략보고서 = 가공된 **결과물**

이를 **결과물 중심 + 리소스 통합**의 5탭 IA로 재편한다. 네비게이션은 **상단 헤더 가로 탭**으로 올리고, **왼쪽 사이드바는 제거**한다.

### 목표 IA (상단 헤더 5탭)

| # | 탭 | 라우트 | 성격 |
|---|-----|--------|------|
| 1 | **홈** | `/dashboard` | 진입 허브 |
| 2 | **AI 인사이트** | `/dashboard/issues` | 결과물(이슈·분석) |
| 3 | **기업동향** | `/dashboard/entities` | 결과물(엔티티) · **신규 라우트** |
| 4 | **콘텐츠**(유튜브 포함) | `/dashboard/contents` | 리소스 통합 라이브러리(뉴스·리서치·웹인사이트·유튜브) |
| 5 | **전략보고서** | `/dashboard/reports` | 결과물(보고서) |

## 3. Phase P0 — IA 골격 재편 (먼저 완료 → 배포)

> **목표**: 화면을 5탭으로 재편하고 사이드바를 없앤 "배포 가능한" 상태. 신규 기능 없이 **이동·매핑·리다이렉트**만으로 동작해야 함.

### P0-1. 상단 헤더 가로 탭 도입
- **대상**: 헤더 컴포넌트 (grep `메뉴 열기`, `홈으로`, banner/Header 컴포넌트).
- 헤더 로고 우측(또는 하단 행)에 **5탭 가로 nav** 배치: `홈 / AI 인사이트 / 기업동향 / 콘텐츠 / 전략보고서`.
- 각 탭 `href`: `/dashboard`, `/dashboard/issues`, `/dashboard/entities`, `/dashboard/contents`, `/dashboard/reports`.
- **active 상태 표시**: 현재 경로 prefix 매칭으로 활성 탭 하이라이트(`usePathname`). `/dashboard/issues/{id}`도 "AI 인사이트" 활성.
- 데스크톱: 헤더 가로 탭. 모바일(≤768px): 햄버거 `메뉴 열기` 안에 동일 5탭 노출(드로어 재사용) **또는** 하단 탭바 — 기존 햄버거 로직 재활용해 5탭만 넣는 쪽이 공수 최소.
- **완료 기준**: 모든 페이지 상단에서 5탭으로 이동 가능, 활성 탭 정확히 표시.

### P0-2. 왼쪽 사이드바 제거 + 항목 재배치
- **대상**: `complementary` 사이드바 컴포넌트(grep `사이드바 접기`, `아카이빙 콘텐츠`, `최근 본 항목`).
- 사이드바 컴포넌트와 `사이드바 접기/메뉴 열기` 토글 로직 제거. **본문은 풀폭(full-width)으로 확장.**
- 사이드바에 있던 항목 재배치(기능 유실 금지):
  - `아카이빙 콘텐츠`, `내 북마크`, `최근 본 항목` → **마이페이지로 통합**(이미 `#archives`/`#bookmarks` 존재). 헤더 `마이페이지` 링크 유지.
  - `모닝브리핑` → **홈의 모닝브리핑 플레이어카드 + `/dashboard/briefings`** 로 흡수(아래 P1-홈).
- **완료 기준**: 좌측 사이드바가 모든 페이지에서 사라지고, 위 항목 접근 경로가 마이페이지/홈에 존재.

### P0-3. 리소스 카테고리 → 콘텐츠 facet 매핑
- 기존 카테고리 링크(뉴스/리서치/웹인사이트/유튜브)는 **콘텐츠 탭의 facet 필터**로 흡수.
- 라우팅 유지/리다이렉트:

| 기존 | 신규 |
|------|------|
| `/dashboard/contents?category=뉴스` | 유지 (콘텐츠 facet) |
| `/dashboard/contents?category=리서치` | 유지 |
| `/dashboard/contents?category=웹인사이트` | 유지 |
| `/dashboard/youtube` | `/dashboard/contents?category=유튜브` 로 **리다이렉트**(또는 콘텐츠 내 소스 facet으로 통합). 기존 유튜브 카드 UI는 콘텐츠 목록 카드로 재사용 |
| `/dashboard/ai-analysis` | `/dashboard/issues` 로 **리다이렉트**(AI 인사이트로 흡수, 아래 P1) |

- **완료 기준**: 위 구 경로 접근 시 신규 위치로 자연스럽게 연결, 깨진 링크 0건.

### P0-4. 홈의 "경쟁사 동향" 이동
- 현재 홈에 있는 **경쟁사 동향 패널 + KA 동향**을 **기업동향 탭(`/dashboard/entities`)으로 이동**(아래 P1-기업동향). P0 단계에서는 우선 `/dashboard/entities` 라우트를 만들고 기존 경쟁사 동향 컴포넌트를 그대로 마운트만 해도 됨.
- **완료 기준**: `/dashboard/entities` 진입 시 기존 경쟁사 동향이 보임, 홈에서는 요약본만 남김(P1에서 정리).

> **P0 배포 게이트**: 위 4개 완료 후 커밋·push·배포, `/api/version` 확인, 5탭 전부 클릭 검증 후 P1 착수.

## 4. Phase P1 — 카테고리별 신규 기능

> 각 항목 앞 **[S]**=Sonnet 단독 구현 가능(UI/프론트), **[O]**=Opus DB/아키텍처 선행설계 필요(데이터·스키마·외부연동). [O] 항목은 착수 전 Opus에 설계 요청.

### 4-1. 홈 `/dashboard` — 진입 허브
홈은 "오늘 무엇을 봐야 하나"를 5초 안에 보여주는 허브로 재구성.

- **[S] 오늘의 이슈**: 상단 히어로. AI 인사이트의 오늘자 주요 이슈 1~3건 카드. 클릭 → `/dashboard/issues/{id}`.
- **[O] 급상승 키워드** (지시서 #104 연계): 키워드 급상승 랭킹 위젯. #104 산출 데이터/뷰 재사용. 칩 클릭 → 해당 키워드 콘텐츠/이슈 스코프 검색.
- **[S] 추천 질문 칩 레일**: 가로 스크롤 칩. 클릭 시 검색/이슈로 라우팅(초기엔 정적 프리셋 → 후속 개인화).
- **[S] 모닝브리핑 플레이어카드**: 기존 "오늘의 브리핑 열기" 미니플레이어를 홈 카드로 승격. 재생 + `지난 브리핑`(`/dashboard/briefings`) 링크.
- **[S] 관심기업 동향 요약**: 기업동향 탭의 요약본(경쟁사 동향 top N). 클릭 → `/dashboard/entities`.

### 4-2. AI 인사이트 `/dashboard/issues` — 결과물 허브
현 `ai-analysis`를 흡수하고 이슈 중심으로 통합.

- **[S] 오늘의 카드뉴스**: 오늘자 카드뉴스 묶음.
- **[S] AI 인사이트**: 기존 `/dashboard/ai-analysis` 주간 카드(논조·근거·`보고서로 만들기`)를 이 페이지로 이전.
- **[S] 이번 주 뜨는 토픽 / 시장 주요 이슈**: 이슈 리스트(홈 "급상승 이슈" 데이터 재사용), 정렬/기간 필터.
- **[O] 지식그래프**: 엔티티-이슈-키워드 관계 그래프. 데이터 모델/뷰 설계 선행.
- **[O] 테마·내러티브 단위 타임라인**: 이슈를 테마/내러티브로 묶어 시간축 전개.
- **[O] content_signals(약 1,159건) 흡수**: `content_signals` 테이블을 이슈 근거 레이어로 연결(이슈→시그널→콘텐츠).
- **[O] 논조 분포 추이**: 이슈별/기간별 논조(긍·중·부) 분포 차트.
- **[O] 유사 이슈·변화 추적** (지시서 #105 연계): #105 산출물 연계, 유사 이슈 묶기·변화 시계열.
- **[S] 이슈 → 근거 콘텐츠 드릴다운**: 이슈 상세에서 근거 콘텐츠 리스트로 내려가기(이슈→시그널→원문).

### 4-3. 기업동향 `/dashboard/entities` — 신규 라우트
- **[S] 경쟁사 동향 카드 + 논조**: 홈에서 이동한 경쟁사 동향(SKT/KT/Anthropic/Google/AWS 등)에 **논조 배지** 추가.
- **[O] 엔티티 한장 브리핑**: 기업별 1페이지 요약(최근 이슈·시그널·논조·관련 콘텐츠). 엔티티 데이터 모델 선행.
- **[O] 기업별 이슈/시그널 묶음**: 엔티티 기준으로 이슈·`content_signals` 그룹핑.
- KA 동향(준비중) 블록은 이 탭에 유지하고 데이터 연동 후 활성화.

### 4-4. 콘텐츠 `/dashboard/contents` — 리소스 통합 라이브러리
기존 라이브러리(발행순/수집순·일별·카드/목록·날짜·관련성)를 확장.

- **[S] 전 출처 통합**: 뉴스/리서치/웹인사이트/유튜브를 한 라이브러리로. 유튜브 카드 UI 흡수.
- **[S] facet 필터 강화**: **출처 / 카테고리 / 소스** 다중 facet. 본문(풀본문)·요약 토글, 검색 스코프(제목/본문/전체), 아카이빙.
- **[S] 북마크 담기 / 소스 신뢰 배지**: 카드에 북마크 액션 + 소스 신뢰도 배지.
- **[O] 기회영역(사업기회) 소싱**: **나라장터/조달청 공공데이터 API**로 사업공고·RFP 신규 소싱. 어댑터·스케줄·dedup 설계 선행([[deploy-verification]] 크롤러 검증 절차 준용).
- **[O] `content_signals`에 "사업기회" 클래스 추가**: 시그널 분류에 사업기회 타입. **마감일·발주처·금액** 컬럼/필터 추가. 신규 컬럼/뷰 GRANT 필수.

### 4-5. 전략보고서 `/dashboard/reports` — 워크벤치
기존 보고서 목록(새 보고서·상태 초안/완료) 위에 생성·편집·내보내기 도입.

- **[S] 생성 워크벤치(조립기)**: 근거 콘텐츠/이슈를 끌어와 섹션 조립.
- **[S] 뷰어**: 보고서 읽기 화면.
- **[O] PDF 내보내기**: 서버사이드 렌더링. (워크스페이스 `pdf` 스킬은 산출물 포맷 참고용; 서비스 내 구현은 별도.)
- **[O] AI로 다듬기(LLM)**: 기존 LlmTask 파이프라인에 'report-polish' 태스크 추가(모닝브리핑 #47 패턴 준용).
- **[S] 근거 콘텐츠 연결**: 보고서 섹션 ↔ 콘텐츠/이슈 링크. 기존 `보고서로 만들기`(ai-analysis) 흐름과 통합.

## 6. DB/백엔드 선행작업 ([O] 묶음 — Opus 설계 요청 대상)

아래는 UI 전에 데이터가 필요한 항목. 각 신규 테이블/뷰/컬럼은 `supabase/` SQL + **anon·authenticated GRANT** 필수.
1. 급상승 키워드(#104) 데이터/뷰 노출 확인 — 홈 위젯 연동.
2. 지식그래프 / 테마·내러티브 타임라인용 관계 모델(엔티티-이슈-키워드-시그널).
3. `content_signals`(약 1,159건) 이슈 근거 연결 + "사업기회" 클래스 + 마감일·발주처·금액 컬럼.
4. 논조 분포 추이 집계 뷰.
5. 유사 이슈·변화 추적(#105) 산출물 연동.
6. 엔티티 한장 브리핑 데이터 모델.
7. 나라장터/조달청 공공데이터 소싱 어댑터.
8. 전략보고서 LLM 다듬기 LlmTask + PDF 내보내기.

> ⚠️ 라이브 DB 스키마를 레포 SQL이 아니라 **실제 DB와 직접 대조**해 작업할 것([[feedback-db-schema-vs-code]] — #54 번역 0건 사건 교훈).

## 7. 실행 순서 & 완료 기준

1. **P0 (IA 재편)** 전체 → 배포 → `/api/version` 확인 → 5탭 클릭 검증. **여기까지가 "화면 개편" 1차 완료.**
2. **P1-홈 / P1-AI인사이트(흡수)** 의 [S] 항목 우선(기존 컴포넌트 이동·재배치).
3. **P1-기업동향** [S](경쟁사 동향 이동+논조).
4. **P1-콘텐츠** [S](facet·북마크·배지).
5. **P1-전략보고서** [S](워크벤치·뷰어·근거연결).
6. **[O] 항목**은 Opus 설계 지시서 수령 후 데이터→UI 순으로 별도 차수.

### 라우트 가드 주의
신규 `/dashboard/entities` 등은 보호 라우트로 실제 등록되는지 **빌드 매니페스트로 검증**할 것([[feedback-middleware-guard]] — proxy.ts 죽은 코드 사건 교훈).
