## 2. 구현

### 2-1. 공유 `src/components/admin/ui/AdminTabs.tsx`(신규, `'use client'` 불필요 — 순수 표시, 부모가 상태 관리)
- Props: `items: { value: string; label: string; count?: number; disabled?: boolean }[]`, `value: string`, `onChange: (value: string) => void`, `className?`, `aria-label?`.
- 렌더(세그먼트 박스, 기준=ContentAddTabs 확장):
  ```
  <div role="tablist" className="inline-flex max-w-full flex-wrap gap-1 rounded-lg border border-border bg-muted p-1">
    {items.map(it => (
      <button role="tab" aria-selected={value===it.value} disabled={it.disabled}
        onClick={() => !it.disabled && onChange(it.value)}
        className={cn('admin-btn-text h-9 rounded-md px-3.5 transition-colors',
          value===it.value ? 'bg-brand-600 text-white shadow-sm'
          : it.disabled ? 'cursor-default text-text-disabled'
          : 'text-muted-foreground hover:text-foreground')}>
        {it.label}
        {typeof it.count === 'number' && <span className="ml-1.5 tabular-nums opacity-70">{it.count}</span>}
      </button>
    ))}
  </div>
  ```
- 다수 항목(엔티티 타입 등) 대응: `flex-wrap`로 박스 안에서 줄바꿈(고정 h-11 대신 항목 h-9). 활성색 brand로 통일(반전 foreground 폐기).

### 2-2. 적용 (5곳)
- **AdminContentManager 카테고리**(:639~653): 큰 알약 → `<AdminTabs items={categoryTabs.map(t=>({value:t.value,label:t.label}))} value={category} onChange={(v)=>{ setCategory(v); setSourceId(SOURCE_ALL); setPage(1) }} aria-label="카테고리" />`. (하단 border-b 구분선은 유지 가능.)
- **ContentAddTabs**(:15~40): 인라인 세그먼트 → `<AdminTabs items=[{file,'파일 업로드'},{paste,'텍스트 붙여넣기'}] value={tab} onChange={setTab} />`. (시각 변화 거의 없음.)
- **RequestsBoard**(:186~): 인라인 세그먼트 → AdminTabs(요청/공지). (시각 변화 거의 없음.)
- **IssueManager 상태 탭**(:680~697): → AdminTabs, items에 `count` 포함(all/draft/published/archived). 활성 brand로 바뀜.
- **EntityManager 타입 탭**(:1024~1043): → AdminTabs, `count` + 빈 타입 `disabled:true`. 활성 brand.
- 각 위치의 기존 onClick 부수효과(set*·setPage 등)는 onChange 안으로 그대로 이전.
