# 지시서 419 — 로그인 "아이디 저장" (이메일 기억)

> 근거: `src/components/login/LoginCard.tsx` 실측 — 이메일+비번/OTP/Google, remember 옵션 없음. autocomplete 는 이미 있음(브라우저 저장). 이번은 **앱 자체 "아이디 저장" 체크박스**.
> 협업 루프: 검증용 브랜치 `agent/419-login-remember-id`(from `origin/main`) → 재현검증 → "커밋해" → 머지.

## 0. 한 줄
로그인 화면에 **"아이디 저장" 체크박스**를 두고, 체크 시 이메일을 `localStorage`에 저장해 **다음 방문에 자동으로 이메일 칸을 채운다**. 비밀번호는 저장하지 않는다(브라우저 autocomplete 몫).

---

## 1. 착수 전 확인
- `src/components/login/LoginCard.tsx`: 스텝 머신(`password`/`otp-send`/`otp-verify`/`set-password`). 이메일 input `autoComplete="email"`, 비번 `current-password`. `handlePasswordLogin`이 `<form onSubmit>`.
- `'use client'` 컴포넌트라 `localStorage` 사용 가능(단 SSR 가드 필요).
- remember/아이디저장 UI **없음** — 신규.

## 2. 구현 (파일 1개: `LoginCard.tsx`)

### 2.1 상태·저장 키
- 키: `const REMEMBERED_EMAIL_KEY = 'insightout:remembered-email'`(충돌 방지 네임스페이스).
- 상태: `const [rememberEmail, setRememberEmail] = useState(false)`.

### 2.2 초기 로드 — 저장된 이메일 자동 채움
- `useEffect`(마운트 1회, 클라이언트): `typeof window !== 'undefined'` 가드 후 `localStorage.getItem(REMEMBERED_EMAIL_KEY)` 읽어, 있으면 **이메일 입력 상태에 프리필** + `setRememberEmail(true)`.
- 이메일 입력 상태 변수명은 기존 것 재사용(신규 state 만들지 말 것 — 기존 email state 에 set).

### 2.3 저장/삭제 — 로그인 제출 시
- `handlePasswordLogin`(및 OTP 발송 경로 `otp-send` 제출처 — 이메일을 다루는 곳)에서, 유효 이메일로 진행할 때:
  - `rememberEmail` 참 → `localStorage.setItem(REMEMBERED_EMAIL_KEY, email.trim())`
  - 거짓 → `localStorage.removeItem(REMEMBERED_EMAIL_KEY)`
- 저장 시점은 **제출 시**(인증 성공/실패와 무관하게 사용자가 입력한 이메일 기억 — 실패해도 다시 칠 필요 없게). `typeof window` 가드.

### 2.4 체크박스 UI
- 위치: **비밀번호 입력 아래, 로그인 버튼 위**(스크린샷 흐름 기준). `password` 스텝에서만 노출.
- `<label>` + `<input type="checkbox" checked={rememberEmail} onChange={e=>setRememberEmail(e.target.checked)}>` + 텍스트 "아이디 저장".
- 접근성: `id`+`htmlFor` 연결. 기존 폼 톤/색(brand)에 맞춤, 작게.
- ⚠️ 체크박스가 **폼 제출을 유발하지 않게**(type="checkbox" 기본은 안전, 버튼 아님).

### 2.5 하지 말 것
- **비밀번호 저장 금지**(localStorage 에 비번 절대 넣지 않음 — autocomplete 로만).
- OTP·Google·set-password 스텝 로직 무변경(이메일 프리필만 공유되면 됨).
- 기존 `autoComplete` 속성 제거하지 않기(브라우저 저장 병행 유지).
- 인증 흐름·Supabase 호출 무수정 — 이메일 기억은 클라이언트 로컬만.
- 새 의존성 없음.

## 3. 회귀 가드
1. "아이디 저장" 체크 후 로그인 → 다음 방문 시 **이메일이 자동 채워지고 체크박스가 켜져 있다**.
2. 체크 해제 후 로그인 → 저장된 이메일 삭제, 다음 방문에 빈 칸.
3. 비밀번호는 저장되지 않는다(localStorage 확인).
4. 체크박스 클릭이 폼을 제출하지 않는다.
5. 이메일+비번 로그인·OTP·Google·비번설정 모두 기존대로 동작.
6. SSR/최초 렌더 시 `localStorage` 접근 에러 없음(가드).
7. 브라우저 autocomplete 저장도 여전히 동작(속성 유지).
