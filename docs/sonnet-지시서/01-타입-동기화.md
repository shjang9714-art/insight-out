# Sonnet 지시서 01 — TypeScript 타입 동기화

> 작성: Opus(Cowork) · 대상: Claude Code(Sonnet) · Phase 1-B 마무리(#11 일부)
> 선행: `supabase/schema.sql` 콘텐츠+북마크 스키마 적용됨(설계 완료)

## 0. 목표 (한 줄)
`supabase/schema.sql` 에 새로 추가된 **enum 4개 + 테이블 11개**를 `src/lib/types.ts` 에 1:1 동기화한다.

## 1. 배경
- 스키마 단일 진실 파일은 `supabase/schema.sql` (AGENTS §8). 방금 콘텐츠/북마크 도메인이 추가됨.
- 기존 `src/lib/types.ts` 는 users/services/newsletter 타입만 있음 → 신규 테이블 타입이 없어 후속 UI·쿼리 작업이 막힘.
- **이 작업은 DB row 타입 추가가 전부.** UI mock 타입(`src/components/dashboard/mock-data/*`)은 **건드리지 말 것**(별개 관심사).

## 2. 할 일

### 2.2 주의
- 이름 충돌: mock-data 의 `YoutubeVideo`(YouTube API shape) 와 구분하려고 DB row 는 **`YoutubeVideoRow`** 로 명명함. 그대로 둘 것.
- enum 값은 schema.sql 과 **글자 하나까지 동일**해야 함(한국어 포함). 임의 변경 금지.
- 날짜/타임스탬프는 전부 `string`(ISO) 으로.
