# 지시서 266 — 유튜브 요약: 수집 시점 1회 생성 + 요약을 제목 밑으로 + 영상 크기 복원

> David 결정 2가지. (1) 유튜브 요약을 **사용자 클릭 온디맨드로 생성하지 말고, 어드민이 유튜브를 수집할 때 1회 생성**해 DB에 넣어둔다. (2) 요약 "주요 내용"을 **제목 밑으로 배치**하고, 인앱 플레이어 **영상 크기가 264의 2단(400px)으로 줄지 않도록 원래 크기(252, 전체폭)로 복원**한다.

목표: 264에서 우측 분석 패널 + 2단 축소로 바꿨던 유튜브 상세를, **단일 컬럼(제목 → 주요 내용 요약 → 전체폭 플레이어 → 관련)**으로 되돌리고, 요약 생성 시점을 사용자 경로 → 수집/백필 시점으로 옮긴다.

전제: 252(유튜브 인앱 상세·태깅), 264(해시태그·패널) 배포됨. 관련 캐러셀·해시태그·엔티티는 유지.

---

## 1. 요약 생성 시점 이동 (온디맨드 → 수집 1회)
### 1-1. 수집/태깅 시 생성
- 유튜브 콘텐츠가 수집·태깅될 때(252 `tagYoutubeContent` 인접) `summary_ko`가 없으면 **그 자리에서 1회 생성**: `llmComplete('summarize', …)`, 제목+채널(추후 265 자막 있으면 자막 포함) 기반, **한글**, 3~5줄. 생성 실패는 graceful(다음 회차/백필에서 재시도).
- 이미 `summary_ko` 있으면 스킵(멱등).

### 1-2. 어드민 백필 버튼
- 어드민에 **"유튜브 요약 생성"** 버튼(`/api/admin/youtube-summary`) — `summary_ko` 없는 유튜브 published 대상 배치 생성(번역/LLM budget 준수, 회차 분할). 263 도움말에 한 줄 추가("유튜브 요약 생성: 요약 없는 유튜브에 제목/채널(추후 자막) 기반 요약 생성 → 상세 '주요 내용'").

### 1-3. 온디맨드 경로 제거
- `/api/contents/[id]/youtube-summary` 라우트의 **사용자 트리거 LLM 생성 제거**. 상세 화면은 **`summary_ko`가 있으면 표시, 없으면 섹션 생략**(생성하지 않음). → 사용자 클릭 경로에서 LLM 호출 0.
- 라우트를 삭제하거나, 남긴다면 **어드민 인증 게이트**를 붙여 백필 용도로만. (권장: 삭제하고 1-2 백필 API로 일원화.)
- `YoutubeAnalysisPanel`의 온디맨드 `fetch` 로직 제거 — 요약은 서버가 넘긴 `summary_ko`만 렌더.

## 2. 레이아웃 복원 (단일 컬럼, 영상 원래 크기)
`src/app/dashboard/contents/[id]/page.tsx` 유튜브 분기:
- **2단 그리드 제거**: `lg:grid-cols-[minmax(0,400px)_1fr]` → 단일 컬럼. 플레이어 `lg:max-w-[400px]` 제거.
- 순서(위→아래):
  1. (헤더) 배지 + **해시태그**(264 2-1 유지) + 제목·메타.
  2. **주요 내용(요약)** — 제목 바로 밑. `summary_ko` 있으면 텍스트 블록으로 표시(라벨 "주요 내용"), 없으면 생략. 전체폭.
  3. **플레이어** — 252와 동일하게 `aspect-video w-full`(전체폭, 400px 캡 없음)로 복원. 임베드 차단 시 "YouTube에서 보기" 폴백 유지.
  4. **관련 엔티티** 칩 — 하단 섹션으로 복귀(264에서 패널로 옮기며 `!isYoutube`로 막아둔 하단 관련엔티티 섹션을 유튜브도 표시하도록 되돌림).
  5. **관련 영상 / 관련 기사** 캐러셀(기존 유지).
- `YoutubeAnalysisPanel`은 (a) "주요 내용" 텍스트 블록 컴포넌트로 축소하거나, (b) 인라인 렌더로 대체 후 삭제. 우측 패널 형태는 폐기.

> 세로 영상 여백 활용(264 취지)보다 **영상 크기 유지**를 우선한다(David 결정). 세로 영상은 aspect-video 내 좌우 레터박스가 생기지만 그대로 둔다(추후 필요 시 플레이어 max-width 별도 튜닝).

## 3. 회귀 가드
- 비유튜브 상세 불변.
- `summary_ko` 없는 유튜브: "주요 내용" 섹션 생략, 플레이어·해시태그·관련은 정상.
- 사용자 클릭 경로 LLM 호출 0(온디맨드 제거 확인).
- 해시태그 클릭 → `/dashboard/topics/{kw}` 유지. 관련 캐러셀 유지.
- 백필/수집 생성은 budget 준수, 멱등(summary_ko 있으면 스킵).

## 4. 검증 (Sonnet)
- `npx tsc --noEmit` 0 / `npx eslint`(변경 파일) 0 / `npm run build`.
- 유튜브 상세: 제목 밑 "주요 내용", 그 아래 **전체폭 플레이어(축소 없음)**, 하단 관련 엔티티·관련 영상/기사.
- 요약 없는 영상: "주요 내용" 생략, LLM 호출 없음.
- 어드민 "유튜브 요약 생성" 백필 → summary_ko 채워지고 상세에 노출.
- 온디맨드 라우트 제거(또는 어드민 게이트) 확인.
