# 지시서 268 — 로그인 페이지 "배치(레이아웃)만" 스크린샷에 정합

> ⚠️ 범위 정정(중요): David 명시 — **애니메이션(전구 SVG)·로그인 박스(카드)·폰트는 모두 지금 그대로 유지**한다. 바꾸는 것은 **오직 배치(각 컴포넌트·텍스트의 화면상 위치·간격)** 뿐이다. 폰트 크기/굵기/색, 카드 스타일(라운드·그림자·언더바·필드·CTA), SVG/키프레임은 **절대 수정 금지**.

목표: 첨부 **타깃 스크린샷의 컴포넌트 배치**를 정확히 재현한다. 카피 좌상단 클러스터, 전구 좌측·중앙 대형, 카드 우측 세로중앙, 세로 스크롤 0.

대상: 주로 `src/app/login/page.tsx`(레이아웃 골격)와 필요 시 `.io-login` 컨테이너 규칙(높이/패딩/그리드). **`LoginCard.tsx`·`BulbScene.tsx` 내부는 손대지 않는다**(배치를 위해 감싸는 래퍼 위치만 조정).

---

## 1. 타깃 배치 (첨부 스크린샷 기준)
2단 구성: 좌측 히어로(넓음) + 우측 카드.

**좌측 히어로 — 카피는 "좌상단"에 고정 클러스터**
- 헤드라인 `흩어진 인텔리전스를 / 하나의 흐름으로,` — 화면 **최상단·좌측**(상단 여백 소, 좌측 여백 소)에서 시작. 세로 중앙 아님.
- 바로 아래 서브 `Intelligence in. Insight out.`
- 그 아래 설명 `뉴스, 리포트, 영상, 데이터를 모아 / 실행 가능한 인사이트로 전환합니다.` — 서브와 **여유 간격**을 두되, 여전히 화면 **상단부**(중앙까지 내려오지 않음).
- 세 요소 모두 **좌측 정렬**, 좌상단에 모여 있음.

**전구 씬 — 좌측/중앙에 대형, 세로 중앙(약 55%)**
- 전구(INSIGHT OUT)와 빛 흐름이 좌측 컬럼 중앙에 **크게**. 빛 줄기가 좌우로 넓게 퍼짐.
- 카피(좌상단)와 세로로 겹치지 않게, 씬은 히어로의 **중앙~하단**을 차지.

**우측 카드 — 세로 중앙**
- 로그인 카드는 우측에서 **세로 중앙** 정렬(스크린샷 카드 위치). 현재 카드 컴포넌트 그대로.

## 2. 구현 지침 (배치만)
- `page.tsx`의 그리드/히어로/씬 래퍼/카드 컬럼의 **위치·정렬·간격 값만** 조정해 §1과 일치시킨다.
  - 히어로 `section`: 카피가 **상단(flex-start)**에 오도록(세로중앙 금지). 카피 블록은 좌상단.
  - 헤드라인↔서브↔설명 간 **수직 간격**을 스크린샷처럼(서브 아래 설명에 여유 gap). 폰트 자체는 불변, margin만.
  - 씬 래퍼: 절대배치로 히어로 중앙(약 `top:54%`, 좌측 중앙)에 대형 배치 — **레이아웃 높이 미기여**(세로 스크롤 0). 크기/위치는 스크린샷의 전구 크기에 맞춰 조정(현행 폭 파라미터 재사용).
  - 카드 컬럼: 우측, 세로 중앙 정렬.
- **금지**: 폰트 속성, 카드 내부 마크업/스타일, SVG 좌표/애니메이션, 색상 변경. (배치를 위한 래퍼 `className`의 위치/여백/정렬 유틸만 허용.)

## 3. 세로 스크롤 0
- 컨테이너는 뷰포트 높이 고정 + `overflow:hidden`, 씬은 절대배치(높이 미기여). 5개 해상도(1280×800/1440×900/1536×864/1920×1080/2560×1440)에서 `scrollHeight === clientHeight`, 가로 스크롤도 0.
- 모바일(<1024): 단일 컬럼 스택 폴백(카피 위→전구→카드) — 데스크톱 배치는 스크린샷과 동일 유지.

## 4. 검증 (Sonnet) — 스크린샷 대조 필수
- **로그인 페이지는 인증 불필요 → Sonnet이 직접 렌더·스크린샷 가능**. 데스크톱(예 1440×900, 1920×1080)에서 페이지를 띄워 스크린샷을 찍고 **첨부 타깃 스크린샷과 나란히 비교** — 카피 좌상단 위치, 헤드라인/서브/설명 간격, 전구 크기·중앙 배치, 카드 우측 세로중앙이 일치할 때까지 **배치 값만 반복 조정**.
- `npx tsc --noEmit` 0 / `npx eslint` 0 / `npm run build`.
- 폰트·카드·애니메이션이 이전과 **동일함**(회귀 없음) 확인 — 배치 외 변경 0.
- 세로/가로 스크롤 0(§3).
- 커밋: `fix: 로그인 컴포넌트 배치 스크린샷 정합 (지시서 268, 배치 전용)` — 배포까지. unstaged 로그인 파일도 이 커밋으로 정리.

## 5. 참고
- 타깃: 첨부 스크린샷. 폰트·카드·애니메이션은 현행 코드가 정답 — **배치만** 스크린샷에 맞춘다.
- 튜닝 파라미터(요청 시): 씬 폭/위치, 카피 상단여백, 서브↔설명 gap.
