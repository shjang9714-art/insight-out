## 배경 (B2 — RAG의 입구)

RAG(142)는 됐는데 **"뭘 물어볼지 막막한"** 사용자가 진입을 못 함(콜드스타트). 해결 = **추천 질문 칩** — 클릭하면 `/dashboard/search?q=...`로 이동해 **바로 AI 답변(RAG)**. 보기(렌즈 138)·관심 기업·뜨는 토픽으로 개인화.

**원칙(브레이크)**: v1은 **템플릿 + 개인화 채움**(LLM 생성 질문 = v2). 클릭 = 검색 페이지로 navigate(인라인 RAG는 v2).

---

## A. 질문 생성 — `src/lib/search/suggested-questions.ts` (신규)
```ts
export function buildSuggestedQuestions(ctx: { watchlist: string[]; serviceNames: string[] }, topThemes: string[]): string[]
```
- **개인화 우선**(보기 설정 시): 워치리스트 회사 → `"{회사} 최근 동향은?"` · 담당 서비스 → `"{서비스} 관련 이슈는?"`.
- **뜨는 토픽**: `topThemes`(최근 14일 matched_groups 상위) → `"{토픽} 정리해줘"`.
- **기본 템플릿**(항상): `"최근 경쟁사 동향은?"` · `"이번 주 규제·정부 소식은?"` · `"AI 데이터센터 관련 새 소식은?"` · `"최근 통신 B2B 이슈는?"`.
- 중복 제거 → **6~8개** 반환(개인화 → 뜨는 토픽 → 기본 순).

## B. 칩 컴포넌트 — `src/components/search/SuggestedQuestions.tsx` (신규, 클라이언트)
- `useLensContext`(워치리스트·서비스) + `topThemes`(props 또는 경량 fetch: 최근 14일 matched_groups 상위) → `buildSuggestedQuestions`.
- 헤더(평이어): **"이런 걸 물어보세요"**. 칩 목록(기존 칩/`AdminFilterChip` 톤, 하드코딩색 0).
- 칩 클릭 → `router.push('/dashboard/search?q=' + encodeURIComponent(question))` → 검색 페이지가 RAG 실행.
- graceful: 워치리스트·서비스 없으면 기본 템플릿만.

## C. 배치
- **홈 `/dashboard`**: 상단(예 IssueSignals 근처)에 `SuggestedQuestions` 레일 — 콜드스타트 진입점.
- **검색 `/dashboard/search`**: `q`가 비었을 때(검색 전) 검색바 아래 레일 노출. `q` 있으면 숨김.
