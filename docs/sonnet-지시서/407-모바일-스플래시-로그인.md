## 2. 구현 — A. 모바일 스플래시

### 2.1 신규 `src/components/login/MobileSplash.tsx` (클라이언트)
- **모바일 뷰포트에서만** 렌더(`lg:` 미만). 데스크톱은 아예 마운트 안 함(CSS `hidden lg:...` 또는 매치미디어).
- 전구는 **`/brand/login-bulb-scene.png`** 사용(프로토타입의 base64 대신 실제 에셋). 세로 크롭·`object-position` 은 프로토타입 비율(`.bulb-wrap{width:128%; margin-top:-90px}`)을 참고해 맞춘다.
- orb/streak/twinkle SVG는 프로토타입 마크업(`#orbG`·`#orbP` radialGradient + animateMotion 6개 + twinkle 4개)을 **그대로 이식.**
- 키프레임(`bulbAppear`·`bulbIgnite`·`bulbBreath`·`flashPop`·`riseIn`·`load`)을 컴포넌트 스코프 CSS(모듈 or styled) 또는 `globals.css` 에 추가. **기존 `ioGlowPulse`·`ioTwinkle` 와 이름 충돌 금지.**
- 3.4초 후 자동 `onDone()`, 화면 탭 시 즉시 `onDone()`. `exiting` 클래스로 페이드+전구 확대 후 언마운트.

### 2.2 🔴 노출 조건 — 매번 뜨면 안 된다
- **`sessionStorage`(예: `io_splash_seen`)로 세션당 1회.** 이미 봤으면 스킵.
- 모바일 뷰포트 + 비로그인 `/login` 진입 시. (로그인 세션 있으면 미들웨어가 `/dashboard` 로 보내 `/login` 자체를 안 거친다.)
- ⚠️ **PWA standalone 실행 시 항상 보여줄지**는 판단 지점: `@media (display-mode: standalone)` 로 감지 가능. **이번엔 세션 1회로 통일**하고, standalone 매번 노출은 §7 에 후속 여지로 기록. (첫인상 과다 노출 방지.)

### 2.3 `login/page.tsx` 통합
- `page.tsx` 상단(또는 클라이언트 래퍼)에서 `MobileSplash` 를 조건부 마운트. 스플래시가 끝나면 그 아래 로그인 UI 노출.
- **서버 컴포넌트인 `page.tsx` 에 상태가 필요하면 얇은 클라이언트 래퍼**를 만든다(`LoginScreen.tsx`). page 는 그대로 두고 래퍼가 스플래시↔로그인 전환.

## 3. 구현 — B. 모바일 클린 로그인

프로토타입 §4.2(David 확정): *"스플래시 뒤에는 로고·전구 없이 클린 로그인 박스만."*

### 3.1 반응형 분기 (데스크톱 무변경)
- **`lg:` 이상**: 현재 landing 그대로(좌 히어로+우 카드). **손대지 않는다.**
- **`lg:` 미만(모바일)**: 좌측 히어로(`BulbScene`+카피)를 **숨기고**, `LoginCard` 만 화면 중앙 클린 배치.
  - `BulbScene` 컨테이너에 `hidden lg:block` 류.
  - `LoginCard` 컨테이너는 모바일에서 `w-full max-w-[420px] mx-auto`, 세로 중앙.
  - 배경은 `.io-login`(라벤더/골드) 유지 — 클린하되 브랜드 톤.
- **`LoginCard` 내부 로직·마크업은 무수정.** 배치(부모 레이아웃)만 반응형으로.

## 4. 하지 말 것
- **데스크톱 로그인(lg:) 레이아웃 무변경.** 지금 landing 그대로.
- `LoginCard`·`BulbScene` 의 **인증 로직·OTP·플로우 무수정.** 배치·표시만.
- 미들웨어·세션·인증 무수정.
- `dashboard/*`·어드민 무관.
- 하단 탭바·미니플레이어 등 **앱 셸은 이 슬라이스 아님**(M-2b/M-3).

## 5. 회귀 가드
1. **데스크톱**(`lg:`) 로그인이 지금과 **완전히 동일**하다(히어로+카드).
2. **모바일** 최초 진입 → **스플래시**(전구 점화 → 3.4초/탭) → **클린 로그인 박스**.
3. 스플래시는 **세션당 1회**(재진입 시 안 뜸).
4. 모바일 로그인에서 **이메일→OTP 플로우가 정상**(실제 인증).
5. 로그인 성공 → `/dashboard`(기존).
6. 스플래시 애니메이션이 프로토타입과 육안 동일(점화·카피·로딩바 타이밍).
7. 데스크톱에서 스플래시가 **뜨지 않는다.**
8. 저사양/reduced-motion 존중(가능하면 `prefers-reduced-motion` 시 애니 축약).
