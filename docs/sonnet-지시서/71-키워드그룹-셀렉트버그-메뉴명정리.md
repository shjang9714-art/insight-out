## 배경
1. **버그(P0)**: `/admin/keyword-groups` 에서 그룹 **수정 진입 시 페이지 크래시**("This page couldn't load"). 원인 = `KeywordGroupManager` 의 signal_hint 셀렉트가 `<SelectItem value="">없음</SelectItem>`(빈 문자열)을 사용 — **Radix Select 는 빈 문자열 value 를 금지**(런타임 throw). 폼(showForm)이 렌더되는 순간 터짐. tsc/lint 가 못 잡는 런타임 오류.
2. **메뉴명 혼동**: "키워드 관리"(=`keywords`, 콘텐츠→LGU+ **서비스 태깅**)와 "키워드 그룹"(=`keyword_groups`, **관련도 게이트+해시태그+검색어+시그널**)이 헷갈림. 직관적 이름으로 변경.

### 설계 결정(David)
- signal_hint "없음" = 센티넬 값(`'none'`)으로(ReportUploadForm EMPTY_SOURCE_VALUE 패턴 동일).
- 메뉴명: **키워드 관리 → "서비스 키워드"**, **키워드 그룹 → "토픽 규칙"**. (경로 URL 은 유지 — 링크·북마크 안 깨지게.)

## 작업

### 1. 버그 수정 — signal_hint 셀렉트 빈 value 제거
- `KeywordGroupManager.tsx`:
  - 상수 추가: `const NO_SIGNAL = 'none'`.
  - 셀렉트 value: `value={form.signalHint || NO_SIGNAL}`.
  - onValueChange: `(v) => setForm(p => ({ ...p, signalHint: v === NO_SIGNAL ? '' : (v as SignalType) }))`.
  - 옵션: `<SelectItem value={NO_SIGNAL}>없음</SelectItem>` (빈 문자열 제거).
  - 저장 payload 는 기존대로 `signal_hint: form.signalHint || null` (NO_SIGNAL 은 '' 로 환원되므로 그대로 null 저장).
- **다른 빈 value Select 없는지 같은 파일 점검**(tag_type 은 enum 값이라 OK). 발견 시 동일 센티넬 처리.

### 2. 메뉴명 직관화
- `layout.tsx` NAV_ITEMS:
  - `{ href: '/admin/keywords', label: '서비스 키워드' }`
  - `{ href: '/admin/keyword-groups', label: '토픽 규칙' }`
- `/admin/keywords/page.tsx`: metadata title·헤더 "서비스 키워드" + 설명 "콘텐츠를 LG U+ 서비스에 자동 태깅하는 키워드를 관리합니다."
- `/admin/keyword-groups/page.tsx`: metadata title·헤더 "토픽 규칙" + 설명 유지("관련도 게이트·해시태그·검색어(search_seeds)·시그널을 정의합니다. include=관련도↑/태그, exclude=하드 제외, search_seeds=뉴스·유튜브 검색어, weight=가중치, signal_hint=시그널 매핑.").
- 경로(`/admin/keywords`, `/admin/keyword-groups`) **변경 금지**(라벨만).
