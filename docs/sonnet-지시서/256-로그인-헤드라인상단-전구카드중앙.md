# 지시서 256 — 로그인: 헤드라인 상단 고정 + 전구·카드 세로 중앙 (무스크롤)

목표: 로그인 페이지를 **헤드라인(폰트)은 상단 고정**, 그 **아래 남은 공간에서 전구 애니메이션 + 로그인 카드를 세로 중앙**에 배치한다. 스크롤은 0 유지.

David 확정: "헤드라인 폰트는 위쪽에 고정하고 전구+카드만 중앙." (250 상단정렬은 과했고, 전체 중앙(직전 256안)도 아님 — **헤드라인 top-pin + 나머지 center**.)

범위: `src/app/login/page.tsx`(구조 재배치). 250의 씬 스케일·카드 높이 유지(무스크롤 근거). 로그인 세션 워킹트리. 코드·248 구성·애니메이션 불변.

---

## 1. 현행(250 반영) 진단
- 현재 `main`이 grid 하나로, **좌측 컬럼에 헤드라인+전구가 같이** 있고 grid가 `items-start`. → 헤드라인이 전구와 한 덩어리라 분리 배치 불가.
- 250 씬: `w-[122%]`·`-mt-[44%]`(헤드라인과 겹치려 위로 당김)·`-ml-[12%]`, 카드 560. 3뷰포트 무스크롤 확인됨.

## 2. 구현 — 헤드라인을 그리드 밖 상단으로 분리

### 2-1. 구조 재배치 (`login/page.tsx`)
```
<main className="io-login relative flex min-h-screen w-full flex-col overflow-hidden px-4 sm:px-8 lg:px-12 xl:px-16">
  {/* ① 헤드라인 — 상단 고정 */}
  <header className="hero-copy relative z-10 mx-auto w-full max-w-[1500px] pt-8 lg:pt-12 text-center lg:text-left">
    <h1 ...>흩어진 인텔리전스를<br/> 하나의 흐름으로,</h1>
    <p ...>Intelligence in. Insight out.</p>
    <p ...>뉴스, 리포트, 영상, 데이터를 모아 …</p>
  </header>

  {/* ② 전구 + 카드 — 남은 공간에서 세로 중앙 */}
  <div className="flex flex-1 items-center pb-6 lg:pb-8">
    <div className="grid w-full max-w-[1500px] mx-auto items-center gap-10 lg:grid-cols-[minmax(0,1.55fr)_minmax(0,460px)] lg:gap-16">
      <section className="relative min-w-0">
        {/* 전구만 (헤드라인 제거) */}
        <div className="mx-auto w-full max-w-[840px] lg:w-[122%] lg:-ml-[12%] lg:max-w-none">
          <BulbScene />
        </div>
      </section>
      <section className="w-full max-w-[460px] justify-self-center lg:justify-self-end">
        <Suspense …><LoginCard /></Suspense>
      </section>
    </div>
  </div>
</main>
```
- **헤드라인을 그리드 밖 `<header>`로 이동**(상단 고정). 폰트 크기·타이포·자간은 기존 유지(`clamp(34px,3.6vw,52px)` 등).
- **전구 래퍼에서 `-mt-[44%]` 제거**(헤드라인과 겹칠 필요 없어짐, 이제 아래 중앙). `w-[122%]`·`-ml-[12%]`는 유지(폭). 세로 위치는 flex 중앙이 결정.
- `flex-1 items-center`로 **전구+카드를 남은 공간 세로 중앙**. `overflow-hidden`으로 넘침 클립.

### 2-2. 무스크롤 유지
- 전체 = 헤드라인(상단) + 전구·카드(중앙) 가 **100vh 안에** 들어와야 함. 250의 축소값 유지가 핵심.
- 헤드라인이 그리드 밖으로 나오며 세로 공간을 더 쓰므로, 전구가 그만큼 여유가 줄 수 있음 → 필요 시 씬 폭 **`122%`→`115%`** 등 **아주 살짝만** 축소해 맞춤(상단정렬·전체중앙으로 되돌리지 말 것).

## 3. 하드 요구 (검증)
