## 배경 (David 피드백 2026-06-22)

① **"렌즈"라는 용어가 직관적이지 않음**(은유·전문어). ② **렌즈를 눌러도 안 바뀜** — 원인: 마이페이지에 담당 서비스·관심 기업 미설정 시 거를 게 없어 **조용히 아무것도 안 함**(칩 비활성/빈 결과인데 화면이 이유를 안 알려줌) = "일반 사용자 고려 실패". → 용어를 쉬운 말로 바꾸고, 미설정·빈 결과를 **명확히 안내**하고, 동작을 **눈에 보이게**.

**원칙**: 코드 식별자(`lens.ts`·`LensKey`·`useActiveLens` 등)는 **내부라 유지**. **사용자에게 보이는 텍스트만** 변경.

## A. 용어 변경 (사용자 노출 텍스트만)
- `LENS_PRESETS` 라벨: `mine` **"내 담당"**(유지) · `watch` **"경쟁사 워치" → "관심 기업"** · `all` **"전체"**(유지). desc도 쉬운 말로(예: watch="관심 기업·경쟁사 소식만").
- **"렌즈"·"내 관점" 단어 제거**: LensSwitcher 등에서 묶음 명칭을 없애고 앞에 작은 라벨 **"보기:"** 만. 배지/문구의 "렌즈 조건"·"내 관점 하이라이트" → **"보기 조건"·"관심 표시"** 같은 평이어. (KnowledgeGraph 범례 "내 관점 하이라이트" → "관심 기업 표시" 등.)
- 8개 파일 사용자 노출 문자열 일괄 점검(`렌즈`/`내 관점`/`경쟁사 워치` grep 0 목표, 코드 식별자는 제외).

## B. LensSwitcher — 미설정 안내 + 가시화 (`LensSwitcher.tsx`)
- `useLensContext` 결과로 **설정 여부 판단**: 담당 서비스 없음 → "내 담당" 비활성, 관심 기업 없음 → "관심 기업" 비활성(기존 동작).
- **비활성 사유를 침묵하지 말 것**: 비활성 칩 아래/옆에 작은 안내 + 링크 — 예: *"담당 서비스를 설정하면 내 담당만 모아볼 수 있어요 → 마이페이지"* (`/dashboard/mypage` 링크). 둘 다 미설정이면 한 줄 통합 안내.
- **활성 표시 강화**: 현재 선택된 보기가 `all`이 아니면 스위처를 눈에 띄게(활성 칩 강조 유지) + **"전체로 ✕"** 빠른 해제 제공.

## C. 빈 결과 안내 (3화면 공통)
보기가 `all`이 아닌데 매칭 0건이면 **이유 있는 빈 상태**(`AdminEmptyState` 톤):
- 미설정 탓: *"담당 서비스/관심 기업을 설정하면 여기에 모아 보여드려요 → 마이페이지"*
- 설정했는데 0건: *"설정하신 담당/관심 기업 관련 콘텐츠가 아직 없어요. 전체 보기로 전환하거나 나중에 다시 확인하세요."* + **"전체 보기"** 버튼.
- 적용 위치: `IssueBoardClient`(이슈) · `InsightCardsSectionClient`(인사이트, 기존 "현재 렌즈 조건에 해당하는 인사이트가 없습니다" 문구 교체) · `EntitiesPageClient`(기업 목록 뷰).

## D. 동작 가시화 (선택 결과 보이게)
- 각 화면에서 `all`이 아닐 때 상단에 **현재 보기 + 결과 수**를 명확히(예: `관심 기업 · 12건`, 기존 EntitiesPageClient 패턴을 이슈·인사이트에도). 클릭 한 번에 전체 복귀.
