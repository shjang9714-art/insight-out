## 배경 (마스터플랜 §4.5)

어드민 전반에 섹션헤더·빈상태·필터칩이 **제각각**(색·모양·문구 패턴 불일치). 공통 프리미티브로 표준화해 일관성·유지보수성을 올린다. 단 **전 화면 일괄 교체는 디프가 크고 회귀 위험** → 프리미티브를 만들고 **대표 위치에만 채택**, 나머지는 후속 점진 이관.

## 설계 결정 (Opus)

1. 프리미티브 **3종** 신설: `AdminSectionHeader`, `AdminEmptyState`, `AdminFilterChip`. (목록행 `ListRow`는 페이지별 편차가 커 이번엔 제외 — 후속.)
2. 위치: `src/components/admin/ui/`(신규 폴더). 순수 presentational, `'use client'` 불필요(필요 시 호출부에서).
3. 채택은 **아래 지정 목록만**(리뷰 가능 범위). 동작·라우팅 변화 없이 **시각/구조 동치 치환**.
4. **§4 준수**: 의미색만(emerald/red/amber/muted/brand-600), 하드코딩 hex 금지(AGENTS §9). 기존 `green-*` 칩은 채택 시 `emerald-*`로 정정(§4.2).

## 작업

### A. `src/components/admin/ui/AdminSectionHeader.tsx` (신규)
```tsx
import type { LucideIcon } from 'lucide-react'

interface Props {
  icon: LucideIcon
  title: string
  hint?: string          // 목적 한 줄
  action?: React.ReactNode // 우측 액션(선택)
}
export default function AdminSectionHeader({ icon: Icon, title, hint, action }: Props) {
  return (
    <div className="mb-3 flex items-center gap-2">
      <Icon className="h-4 w-4 text-brand-600" />
      <h2 className="text-sm font-semibold text-foreground">{title}</h2>
      {hint && <span className="text-xs text-muted-foreground">{hint}</span>}
      {action && <div className="ml-auto">{action}</div>}
    </div>
  )
}
```
- 채택: `AdminTodoBlock`·`AdminOpsSignals`의 기존 헤더 블록을 이 컴포넌트로 치환(아이콘·제목·hint 그대로). 시각 동치.

### B. `src/components/admin/ui/AdminEmptyState.tsx` (신규)
```tsx
import type { LucideIcon } from 'lucide-react'

interface Props {
  message: string
  hint?: string          // "무엇을 하면 채워지는지"(§4.4)
  icon?: LucideIcon
  className?: string
}
```
- 렌더: `rounded-xl border border-dashed p-8 text-center`(또는 호출부 맥락에 맞춰 패딩), icon(있으면 muted), `message`(text-sm text-muted-foreground), `hint`(text-xs muted, 한 줄). §4.4 "빈 상태는 항상 안내".
- 채택(시각 동치, 문구 유지/보강):
  - `AdminContentManager` L683 "조건에 맞는 콘텐츠가 없습니다." → `<AdminEmptyState message="조건에 맞는 콘텐츠가 없습니다." hint="필터를 바꾸거나 수집을 실행해보세요." />`
  - `AdminSidebar` L102 검색 빈결과 → `message="일치하는 메뉴가 없습니다."`(hint 생략 가능, 사이드바 좁으니 컴팩트 variant 또는 className로 패딩 축소).
  - `CrawlLogsTable` L275 "아직 수집 기록이 없습니다." → hint="소스를 등록하고 수집을 실행하면 기록이 쌓입니다."
- (주의) 사이드바는 폭이 좁으므로 border-dashed 큰 패딩이 어색하면 `className`으로 조정하거나 EmptyState에 `compact` 변형 허용.

### C. `src/components/admin/ui/AdminFilterChip.tsx` (신규)
```tsx
interface Props {
  active: boolean
  onClick: () => void
  children: React.ReactNode
  count?: number
}
```
- 렌더: `inline-flex items-center gap-1.5 rounded-full border px-3 py-1 text-xs font-medium transition-colors`, active면 `border-brand-600 bg-brand-600/10 text-brand-600`, 비활성 `border-border text-muted-foreground hover:text-foreground`. `count != null`이면 우측에 `tabular-nums` 숫자.
- 채택: `AdminContentManager`의 필터칩(L472~, 검토 대기 칩 등) 중 **상태 필터 토글 칩**을 이 컴포넌트로 치환. 기존 `green-*` 정보 배지는 §4.2 따라 `emerald-*`로 색만 정정(토글이 아니면 FilterChip 대신 색만 교체).
