## 현 상태(완비된 것)
- `bookmarks(user_id, content_id?, youtube_video_id?, one-item CHECK)` + RLS `본인 조회/추가/삭제`(auth.uid()=user_id) + unique 인덱스(user×content, user×youtube) + `bookmark_count` after insert/delete 트리거. **스키마/SQL 변경 없음.**
- 상세페이지엔 `ArchiveButton`만 있고 북마크 버튼·마이페이지 북마크 목록은 **없음**.

## 1. BookmarkButton 컴포넌트
`src/components/bookmark/BookmarkButton.tsx`(client):
- props: `{ contentId?: string; youtubeVideoId?: string }` — 둘 중 하나(콘텐츠/유튜브 재사용 가능). 둘 다 없으면 렌더 안 함.
- **초기 상태 조회**: 마운트 시(또는 lazy) `bookmarks` 에서 본인+해당 항목 존재 여부 1건 조회(`.eq('content_id', contentId).limit(1)`; RLS가 user 스코프). → `isBookmarked`.
- **토글**:
  - 추가: `auth.getUser()` 로 user.id → `insert({ user_id, content_id })`(또는 youtube_video_id). **23505(중복)는 이미 담긴 것으로 간주**(에러 아님).
  - 해제: `delete().eq('content_id', contentId)`(user는 RLS).
  - **낙관적 UI**(아이콘 즉시 토글) + 실패 시 롤백·한국어 에러. `bookmark_count`는 트리거가 자동 갱신(클라가 직접 안 건드림).
- 아이콘: lucide `Bookmark`(외곽)/`BookmarkCheck`(채움), 라벨 "북마크"/"북마크됨". 미로그인 시 클릭하면 "로그인이 필요합니다" 안내. AGENTS 토큰.

## 2. 상세페이지 배치
- `contents/[id]/page.tsx` 의 `<ArchiveButton .../>` 옆에 `<BookmarkButton contentId={content.id} />` 추가. 기존 레이아웃 깨지지 않게.
- (선택) `bookmark_count` 를 실제 값으로 표시하고 싶으면 select에 포함(현재 `bookmark_count: 0` 자리). 트리거가 정확값 유지.

## 3. 마이페이지 북마크 목록
- `mypage/page.tsx` 에 **북마크 섹션**(아카이브 섹션과 동일 패턴, 탭 또는 별도 카드):
  - 조회: `bookmarks` + 조인 `contents(id, title, category, original_url)`·`youtube_videos(id, title, ...)`, `order by created_at desc`.
  - 표시: 제목·카테고리·발행/링크. 콘텐츠는 상세(`/dashboard/contents/[id]`)로, 유튜브는 외부 링크.
  - **삭제(북마크 해제)**: `bookmarks.delete().eq('id', bookmarkId)` → 목록에서 제거. 빈 상태·로딩·한국어 에러.

## 4. (선택) 카드 재사용
- 콘텐츠 카드/RecentFeed·유튜브 카드에 작은 BookmarkButton 아이콘 추가 가능(과하면 상세+마이페이지만). 유튜브는 `youtubeVideoId` prop 사용.
