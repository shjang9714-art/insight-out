## 0. 한 줄

다크모드 **네이비 박스 + 검은 글씨 대비 불량을 토큰 한 곳에서 근본 수정**하고, 대시보드 **KPI 숫자 폰트 축소**, **사용량 바 색 연하게**, 콘텐츠 관리 **일괄 툴바 상태별 폰트 통일**, **제목 열 최소폭 확보**까지 5개 폴리시를 한 묶음으로 처리한다.

## 1. 항목별 진단·수정 (검증된 코드 사실)

### 1-1. 다크 네이비+검은 글씨 대비 (근본) — 슬라이드 2(KPI)·6(배지)
- 다크 시맨틱 토큰(globals.css): `--positive #60A5FA`(파랑)·`--info #94A3B8`·soft는 `rgba(...,.14)`. 배지(StatusBadge)=`bg-*-soft text-*`, 상태 라벨 "노출"=positive.
- **재현 먼저**: 다크모드로 `/admin`(KPI 카드=AdminTodoBlock 타일)·`/admin/contents`(상태·사유 배지) → 파랑/네이비 배경 위 어두운 글씨 조합을 콘솔/DevTools로 특정. 원인이 (a) 특정 soft 토큰 대비 부족인지 (b) 하드코딩 파랑 배경+dark 텍스트인지 확정.
- **수정**: 해당 토큰/클래스의 **전경색을 밝게**(또는 배경 대비 확보)해 **WCAG AA ≥4.5:1** 충족. 가능하면 globals.css **다크 블록 한 곳** 수정으로 전 어드민 반영(근본). 하드코딩이면 토큰으로 치환.
- **라이트모드 회귀 0**(다크 블록만 손댐). 검증에 대비비(4.5:1) 계산 근거 첨부.

### 1-2. KPI 숫자 폰트 축소 — 슬라이드 2·3
- `admin-metric` = 44px/54(globals.css:210)이 대시보드 KPI(오늘 할 일 타일·운영현황 카드)에서 과대.
- **대시보드 문맥만 축소**(다른 화면 admin-metric 유지): globals.css에 `.admin-scope .admin-metric-dashboard { font-size: 30~34px; line-height: 38~42px; font-weight: 700; }` 신설 → AdminTodoBlock·운영현황 KPI 카드 숫자에 적용(`admin-metric` → `admin-metric-dashboard`). 단위(admin-metric-unit)도 비례 축소 클래스. **정확한 px는 다크·라이트 육안 후 조정.**
- (운영현황 카드는 198에서 오늘할일과 통합 예정 — 197에선 폰트만 축소, 통합은 건드리지 않음.)

### 1-3. 사용량 막대그래프 색 연하게 — 슬라이드 2
- AdminOpsSignals 바(:32-34): `pct>=100 bg-destructive` · `>=80 bg-amber-500` · else `bg-brand-600`(마젠타). 트랙 `bg-muted`.
- **연한 톤으로**: 정상 구간 `bg-brand-600` → 더 연한 브랜드 톤(brand-400/300 또는 `/70` 투명도), amber/red 구간도 한 단계 연하게(soft 계열) 하되 **100% 위험만 또렷하게** 유지(경고 가독성). 트랙 유지. 신규 hex 대신 기존 brand/토큰 스케일 우선.

### 1-4. 일괄 툴바 상태별 폰트 통일 — 슬라이드 5
- AdminContentManager 일괄 바(:940~): 컨테이너 `text-sm`, 상태 라벨 `<span className="font-medium text-foreground">`이 "선택된 콘텐츠 없음" ↔ "N건 선택"으로 바뀜.
- **재현 후 통일**: 두 상태의 라벨 **타이포(크기·굵기·행높이) 동일** 보장 + 상태 전환 시 **바 높이/패딩 점프 없게**(비선택 시 `<p className="w-full text-xs">` 힌트가 줄바꿈을 유발하면 고정 높이 또는 배치 조정). 버튼 disabled 스타일은 유지.

### 1-5. 제목 열 — 슬라이드 6
- **이미 `line-clamp-2` 적용됨**(AdminContentManager :1052, td `max-w-md`). David 스크린샷의 5줄은 **구버전 가능성** → **현재 배포 재확인 먼저**.
- 여전히 과다 줄바꿈이면 원인은 **열 폭 부족**: 제목 `<td>`에 `min-w-[220px]`(또는 적정값) 부여 + 다른 열 `whitespace-nowrap` 유지로 제목이 2줄 내 안정. (열 너비 사용자 조정=200에서 별도.) 이미 2줄이면 197에선 **min-width만** 보강.
