## 배경 (B1 — 새 역량)

LLM이 점등됐으니 **수집 코퍼스 기반 자연어 Q&A**가 가능. 현재 검색은 ILIKE 키워드 매칭(title·summary_ko·body_original, 본문 백필 완료)뿐 → **질문에 "정리된 답"을 못 줌.** RAG = 질문 → 관련 기사 검색(retrieve) → LLM이 **근거 기반 답변 종합**(citation, 환각 차단).

**v1 원칙(브레이크)**: **임베딩 없이** 기존 ILIKE 검색을 검색기로 재사용(pgvector·시맨틱 검색 = v2). LLM 호출은 **종합 1회**(검색은 코드). 결과 없으면 추측 금지.

## A. 검색기(retrieve) — `src/lib/search/rag-retrieve.ts` (신규)
```ts
export interface RagDoc { content_id: string; title: string; summary_ko: string|null; snippet: string; published_at: string|null; source: string|null }
export async function retrieveForQuestion(admin, question: string, opts?: { limit?: number }): Promise<RagDoc[]>
```
- 질문 토큰화: 공백 분리 → 2자 미만·불용어 제거 → 중복 제거(상위 ~6개).
- **ILIKE OR 검색**(기존 검색 패턴 재사용): 각 토큰을 `title/summary_ko/body_original` ILIKE OR, `status='published'`, 최근순, **상위 `limit`(기본 10)**. (토큰 다수 매칭 우선 정렬 가능하면 가산.)
- (보너스) **엔티티 보강**: 질문 토큰이 `entity_aliases`와 일치하면 그 엔티티의 최근 콘텐츠도 후보에 합류(dedupe). 가벼우면 포함.
- 각 doc: `snippet`=body_original 300자 발췌(없으면 summary_ko). 빈 결과면 `[]`.

## B. 종합(generate) — `src/lib/search/rag-answer.ts` (신규)
```ts
export interface RagAnswer { answer: string; citations: string[]; sources: RagDoc[] }
export async function answerQuestion(admin, question: string): Promise<RagAnswer | { answer: null; reason: 'no_results'|'no_llm' }>
```
- `retrieveForQuestion` → 빈 결과면 `{answer:null, reason:'no_results'}`.
- 프롬프트: "아래 기사들을 **근거로만** 질문에 한국어로 간결히 답하라. 추측·외부지식 금지. 근거가 부족하면 '제공된 자료로는 확인되지 않습니다'라고 답하라. 각 핵심 주장에 근거 content_id 표기. JSON: {\"answer\":\"...\",\"citations\":[\"content_id\"]}." + 질문 + docs({content_id,title,snippet}).
- `llmComplete('report')` → `looseJsonParse`. 키 없음/실패 → `{answer:null, reason:'no_llm'}`.
- **환각 가드**: citations ⊂ retrieved content_id. sources = citations에 해당하는 RagDoc(없으면 retrieved 상위).

## C. API — `POST /api/search/rag` (신규)
- **인증 사용자**(어드민 아님 — 일반 사용자 기능), `runtime nodejs`, `maxDuration 60`.
- body `{ question }`(길이 가드). → `answerQuestion` → `{ answer, citations, sources }` 또는 `{ answer:null, reason }`. (no_llm도 200 + reason, UI가 폴백.)

## D. UI — 검색 페이지 "AI 답변" 섹션 (`search/page.tsx`)
- 검색 실행 시(또는 **"AI에게 묻기"** 토글/버튼) `/api/search/rag` 호출 → **결과 목록 위**에 **AI 답변 카드**:
  - 헤더: "AI 답변" + 작은 안내 *"수집된 기사들을 근거로 정리했어요. 아래 출처를 확인하세요."* (비전문 사용자, [[일반 사용자 우선]]).
  - 본문: `answer` + **근거 출처 칩**(citations → 기사 제목 링크 `/dashboard/contents/{id}`).
  - 로딩 스피너. `answer:null` → 카드 숨김(기존 키워드 결과만, "AI 답변 없음" 정도). LLM 미설정(no_llm) → 조용히 폴백.
- 기존 ILIKE 키워드 결과 목록은 그대로 아래 유지(회귀 0).
