# 지시서 255 — 주요 기업 UI (계층 그룹카드 + 풍부 카드 + 골드 테두리)

목표: 기업동향 첫 탭을 **관심기업 → "주요 기업"**으로 개명하고, curated 7그룹/41개사를 **계층 UI**로 보여준다. (1) 7 그룹 섹션 → (2) 각 그룹에 **대표 기업 3~5(사용자 선택)** 풍부 카드 → (3) "전체 보기" 시 그룹 전체 회사. 카드는 **제목·시사점3줄·근거3건·해시태그**, **이슈 중요도 높은 기업은 골드 형광펜 반짝 테두리**. 카드 클릭 → 249 상세.

David 확정: 주요 기업(일반 동향, 고객 포함), 계층(그룹카드→대표3~5 사용자선택→전체), 이슈중요도순, 골드 반짝 테두리.

범위: `EntityTabs.tsx`(개명) + `entities/page.tsx`(watchlist 뷰 재작성) + 회사 카드 컴포넌트 + 사용자 선택(설정 모달, 225 재사용) + globals.css(골드 애니메이션). 전제: **253 SQL + 254 생성** 적용. SQL 없음.

## 1. 현행 진단 (검증된 코드 사실)
- 249로 watchlist 뷰 = 회사별 카드 그리드(회사당 최신 카드, 압축). getCardDetailHref → 249 상세.
- 225 `WatchlistManager`/`WatchlistSettingsModal`(자유텍스트/엔티티 검색) — 이제 **curated_companies 선택**으로 전환.
- 데이터: 회사 카드 = `insight_cards`(scope='company', topic=회사, 254가 curated 대상 생성).
- 그룹 정의·회사·별칭 = `curated_groups`(kind='watchlist' 7)·`curated_companies`(groups[]).

## 2. 구현

### 2-0. 탭 개명 (`EntityTabs.tsx`)
- `관심기업` → **`주요 기업`**(id·href 유지: watchlist).

### 2-1. 데이터 (`entities/page.tsx` watchlist 뷰)
- `curated_groups`(kind='watchlist', sort_order) 7개 로드.
- `curated_companies`(is_active) 로드(name·aliases·groups·is_competitor·role·entity_id).
- 회사별 최신 company 카드(`insight_cards` scope='company', topic=회사명 or alias 매칭) 조인 → 카드 있는 회사만 노출.
- **사용자 선택**: `user_watchlist`(225)를 curated 회사 선택 저장소로 사용(company=curated name, entity_id 연결). 그룹별로 사용자가 고른 회사 = 대표. 선택 없으면 **이슈 중요도 top 5 기본**.
- **이슈 중요도** = computeImportance(card)·importance_score·최근성 조합. 정렬·골드 판정에 사용.
- 42P01/빈 상태 graceful(253/254 전).

### 2-2. 계층 렌더 (7 그룹 섹션)
- 그룹 순서대로 **그룹 섹션**(245 CompetitorNewsGroups 톤과 통일 가능):
  - **그룹 헤더**: 그룹 label + 회사 수 + "전체 보기 →".
  - **대표 기업 3~5**: 사용자 선택분(없으면 이슈중요도 top5) 회사 카드 그리드(`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`).
  - **전체 보기** → 그룹 전체 회사(제한 없음). 신규 페이지 `/dashboard/entities/major/[group]` 또는 인탭 확장(모달/펼침). (245처럼 전용 페이지 권장.)
- 상단 **"주요 기업 설정"** 버튼(2-4).

### 2-3. 풍부 회사 카드 (제목·시사점3·근거3·해시태그 + 골드)
- 회사 카드(클릭 전체 → 249 상세 `/dashboard/insights/[cardId]`):
  - 상단: 회사명(그룹 톤) + 중요도/내관련도 배지 + **해시태그**(카드 matched_groups·연결 엔티티, 최대 4).
  - **제목**(card_headline) 굵게.
  - **시사점**(implication) **3줄 clamp**.
  - **근거 3건**: citations 상위 3건(인용문 or 출처 제목 미리보기).
  - 날짜(period).
- **골드 반짝 테두리**: 이슈 중요도 high(또는 급상승)면 카드에 `io-gold-glow` 클래스 → 골드 형광펜 애니메이션 테두리.
  ```css
  .io-gold-glow{position:relative;border-color:transparent}
  .io-gold-glow::before{content:'';position:absolute;inset:-1.5px;border-radius:inherit;
    background:linear-gradient(120deg,#F5B301,#FFE07A,#F5B301);background-size:200% 200%;
    z-index:-1;animation:ioGoldShift 3s ease infinite;filter:blur(.3px)}
  @keyframes ioGoldShift{0%,100%{background-position:0% 50%}50%{background-position:100% 50%}}
  @media (prefers-reduced-motion:reduce){.io-gold-glow::before{animation:none}}
  ```
  (구현 디테일은 톤 맞춰 조정 — "형광펜 반짝" 느낌: 골드 그라디언트 테두리 + 은은한 shimmer.)

### 2-4. 사용자 선택 (설정 모달 — 225 전환)
- `WatchlistSettingsModal`을 **curated_companies 선택**으로: 그룹별 회사 목록 + 체크(내 대표 기업). 검색 API도 curated 우선.
- 저장 = user_watchlist upsert(curated name·entity_id). 그룹 카드가 사용자 선택 반영.
- 미설정 사용자: 각 그룹 이슈중요도 top5 기본 노출(빈 화면 없음).
