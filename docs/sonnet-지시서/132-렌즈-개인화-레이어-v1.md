## A. 렌즈 코어 — `src/lib/lens.ts` (신규)

```ts
export type LensKey = 'mine' | 'watch' | 'all'
export interface LensContext {        // 사용자별 1회 로드
  serviceIds: string[]                // user_services
  serviceNames: string[]
  watchlist: string[]                 // user_watchlist company (lower 보관)
}
export interface LensTarget {          // 렌즈 판정 대상 정규화
  serviceIds?: string[]
  names?: string[]                     // 매칭 후보 텍스트(제목·canonical_name·match_keywords 등)
  isCompetitor?: boolean
}
```
- **프리셋 정의**: `mine`(내 담당) / `watch`(경쟁사·관심 기업) / `all`(전체). 라벨·설명 상수.
- **판정 함수** `matchesLens(key, ctx, t): boolean`:
  - `all` → true
  - `mine` → `t.serviceIds`와 `ctx.serviceIds` 교집합 ≥1
  - `watch` → `t.isCompetitor === true` **또는** `t.names` 중 하나가 `ctx.watchlist`의 회사명을 포함(lower substring)
- **부스트 점수** `lensScore(key, ctx, t): number`(정렬용, 매칭=상단). 매칭 0/1 + 약한 가중(경쟁사>워치>서비스) 정도면 충분.
- **`useLensContext()` 훅**(클라이언트): 로그인 사용자의 `user_services`(서비스명 조인)·`user_watchlist` 1회 fetch → `LensContext`. 캐시(모듈 스코프 or context). 비로그인/빈 경우 빈 컨텍스트.
- **활성 렌즈 영속**: `useActiveLens()` — localStorage `io:lens`(기본 `all`). setter가 localStorage 갱신 + 이벤트(`lens:changed`)로 동일 화면 내 구독 갱신.

## B. 렌즈 스위처 — `src/components/lens/LensSwitcher.tsx` (신규, 클라이언트)

- 프리셋 칩 3개: **내 담당 / 경쟁사 워치 / 전체**(기존 `AdminFilterChip` 톤 재사용, 하드코딩색 금지). 활성 칩 강조.
- **빈 상태 가드**: 담당 서비스 없음 → "내 담당" 비활성 + 툴팁("마이페이지에서 담당 서비스 설정"). 워치리스트 없음 → "경쟁사 워치" 비활성 + 마이페이지 링크 안내.
- 인텔리전스 페이지 상단 공통 배치(이슈·기업·AI인사이트). 선택 시 `setActiveLens` → 해당 화면 즉시 재필터.

## C. 적용 (클라이언트 사이드 필터 + "내게 관련" 우선정렬 + 배지)

각 화면: 이미 가져온 목록에 `useLensContext`+`useActiveLens` → `matchesLens`로 **필터**(또는 `lensScore`로 **상단 정렬**), 매칭 항목에 **"내 담당"/"관심"/"경쟁사" 배지**. `all`이면 무변경(회귀 0).

### C-1. 기업 `EntitiesPageClient.tsx`
- LensTarget = `{ serviceIds: [entity.service_id], names: [entity.canonical_name], isCompetitor: entity.is_competitor }`.
- `mine`=담당 서비스 소속 엔티티, `watch`=워치리스트·경쟁사. 매칭 상단 정렬 + 배지. graph/list 토글은 유지.

### C-2. 이슈 보드 `IssueBoardView.tsx` (+ 필요 시 `fetchIssueActivity` 확장)
- LensTarget = `{ names: [issue.title, ...issue.match_keywords] }`(+가능하면 issue에 연관 서비스/회사 요약 포함하도록 activity 쿼리 경량 확장).
- `watch`=워치리스트 회사명이 제목/키워드에 닿는 이슈, `mine`=담당 서비스 키워드 매칭. 매칭 이슈 상단 + "내 관련" 배지. (정밀 issue↔service 조인은 v2.)

### C-3. AI 인사이트 `AiInsightsView.tsx`
- 인사이트 카드·트렌드의 `matched_keywords`/`matched_groups`/엔티티명을 LensTarget.names로 → 렌즈 필터/하이라이트. (현재 워치리스트 "시각 강조"만 → 필터·우선순위로 격상.)
