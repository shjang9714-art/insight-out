## 목표 3
1. **액션 버튼 톤 통일** — 노출/숨김·보기·수정·**삭제** 톤앤매너 정리. `삭제`는 `variant="destructive"`(또는 hover 시 negative), 나머지 일관(outline/ghost). 하드코딩 `ACTION_BTN='h-8 ... text-xs'`가 옆 컬럼·표준 Button size와 안 맞는 부분 정합(size 통일, 임의 색 제거). 아이콘/라벨 간격·정렬 옆 라인과 맞춤.
2. **검토대기 사유 가시화** — `status='pending'` 행에 **review_reason 배지 항상 표시**(REVIEW_REASON_LABEL: 본문없음/본문잘림/본문과소/추출실패/관련도낮음/LLM무관/제외규칙). `review_reason=null`(레거시)면 폴백 추론: `body_fetched_at=null → "본문 없음"`, `matched_groups=null → "매칭 없음"`(select에 matched_groups 추가). 상태 컬럼 옆에 사유 배지 인접 배치 → 한눈에.
3. **테이블 가독성** — 상태+사유를 한 묶음으로 명확히, 열 여백·정렬 정리(기존 컬럼 구조 유지하되 톤·간격 일관). 과한 재설계 금지.
