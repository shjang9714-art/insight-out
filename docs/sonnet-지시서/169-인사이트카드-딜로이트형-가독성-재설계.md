## 3. 구현 — `CardNewsItem` 재구성 (딜로이트형)

위→아래 구조:

### 3-1. 상단 메타 (정리)
- 한 줄: `[카테고리 칩(버킷색, 167 BUCKET_CHIP_CLS)]` · `기간` …… 우측 `[내 관련도 높음]`(있을 때).
- **중요도·신선도 배지는 상단에서 빼서 하단 푸터로**(3-5). 상단 배지 몰림 해소.

### 3-2. 헤드라인 (어그로 앵커)
- `card.card_headline ?? card.headline` 을 **가장 지배적인 요소로**(현행 2xl/3xl 유지~강화, leading-tight). 카드의 시선 1순위.
- 끌림 강화 보조(과하지 않게): 헤드라인 좌측에 버킷색 얇은 액센트 바(2px) 또는 최신 그룹 카드에 미세 강조. **내부 도구라도 "안 끌리면 안 들어온다" 반영 — 단 자극은 절제.**
- (헤드라인 문구 자체의 punch 는 생성 영역 — §6 후속.)

### 3-3. 핵심 요약 (리드) — `headline`
- `card_headline` 과 `headline` 이 다르면 `headline`(분석 한 줄)을 **헤드라인 바로 아래 리드 문단**으로(15~16px, text-secondary, **클램프 없음 또는 line-clamp-3**). 같으면 생략.
- 라벨 없이 데크처럼, 또는 옅은 라벨 "핵심".

### 3-4. 시사점 — `implication` (충분히)
- 라벨 "시사점" + `implication` 전문. **`line-clamp-2` 제거** → 최소 3~4줄까지 보이게(필요 시 `line-clamp-4` 정도로 상한만, 한 줄 금지).
- 본문 톤(text-foreground/secondary), 읽기 좋은 `leading-relaxed`, `max-w` 로 행 길이 제한(가독성).

### 3-5. 왜 주목하나 (맥락/선정 이유)
- 라벨 "왜 주목하나" + `buildSelectionReason({evidenceCount, matched, generatedAt})` 결과를 문장으로(근거 N건·관심 키워드 일치·최근). 짧아도 한 줄짜리 메타가 아니라 **맥락 문장**으로 제시(예: "최근 7일 근거 4건이 모였고, 관심 키워드와 일치해 우선 노출했습니다.").
- 은은한 좌측 보더(버킷색/brand) 또는 배경 옅게로 섹션 구분(163 토큰).

### 3-6. 근거 (유지)
- 대표 근거 1건 인용 + "근거 N건 더 보기" 접기(현행 로직 유지). 인용구는 본문보다 약하게(이미 muted/italic).

### 3-7. 푸터 메타 (정리)
- 작은 회색 줄: `중요도 {라벨}` · 신선도(`오늘`/`N일 전`) · (선택) `근거 N건`. 상단에서 내려온 배지를 **한 줄 메타로 절제**.

### 3-8. 그리드(analysis) 뷰 정합 (경량)
- `InsightCardsSectionClient` 그리드 카드(164)도 같은 라벨 체계(핵심/시사점/왜 주목하나)와 일관되게 — 단 그리드는 공간 작으니 시사점 line-clamp-3 정도. 과개편 금지(에디토리얼 카드가 주 대상).

## 4. 회귀 가드 / 비기능 요건

- 데이터 변경 0 — 기존 필드(card_headline/headline/implication/citations)만 재배치. 없는 필드는 섹션 생략(빈 라벨 금지).
- 색: 163 토큰 + 167 버킷색만(신규 hex 0). 상태색과 혼동 없게.
- 관련도/중요도 규칙은 164 `card-meta` 그대로(재계산 로직 추가 금지).
- 접근성: 헤드라인 `h3` 유지, 섹션 라벨은 시각만(과한 강조 금지). 행 길이 제한으로 가독성.
- 168(클라이언트 토글)과 충돌 없게 — 순수 프레젠테이션 변경.
