## 0. 한 줄

회사별 인사이트 카드 생성기(`generateCompanyInsightCards`)와 어드민 생성·승인 UI는 **이미 완비**됐는데, ① **사용자 화면에 안 보이고**(`AiInsightsView`가 `scope='industry'`만 조회) ② **야간 cron이 회사 카드를 안 만든다**(industry만). 이 둘만 배선한다. 생성 로직·DB·승인 흐름은 그대로 재사용.

## 1. 현행 진단 (검증된 코드 사실)

- `src/lib/insight/generate.ts:248` `generateCompanyInsightCards` — 워치리스트 인기순 회사별로 LLM 카드 생성, `insight_cards` upsert(`scope='company'`, `topic=회사명`, `status='draft'`, onConflict `period_start,scope,topic`). **작동·완성.**
- `src/app/api/admin/insights/route.ts` — `POST {scope:'company'}` 로 호출 가능. `src/app/admin/insights/page.tsx:123` "관심업체 카드 생성" 버튼·승인(draft→published)·삭제 **완비.**
- ❌ `src/components/analysis/AiInsightsView.tsx:130` — insight_cards 조회가 `.eq('scope','industry')` 고정. **published 회사 카드는 사용자에게 절대 안 보임.** 워치리스트(`watchlistRes`, line 142)는 로드되지만 키워드 분류(`isWatched`)·경쟁사 섹션에만 쓰임.
- ❌ `src/app/api/cron/ai-refresh/route.ts` — `generateIndustryInsightCards`만 호출(①). 회사 카드 자동 생성 없음.
- 산업 카드도 cron·어드민 모두 `status:'draft'` → 승인 후 노출. **회사 카드도 동일 정책(draft→승인) 유지**(자동발행은 D2 별건).

## 3. 구현

### Part A — 사용자 노출 (`src/components/analysis/AiInsightsView.tsx`)

서버 컴포넌트. 목표: 로그인 사용자의 **워치리스트에 해당하는 published 회사 카드**를 별도 섹션 "관심 기업 인사이트"로 렌더. 기존 `InsightCardsSectionClient`(보기/렌즈·카드뉴스 토글·인용 처리) 재사용.

**A-1. 회사 카드 조회** — 기존 `Promise.all`(line 125~)에 항목 추가:

```ts
// published 회사 카드 (워치리스트 필터는 아래에서)
supabase
  .from('insight_cards')
  .select('id, period_start, period_end, scope, topic, headline, implication, source_content_ids, citations, generated_at, status')
  .eq('status', 'published')
  .eq('scope', 'company')
  .order('period_start', { ascending: false })
  .order('generated_at', { ascending: false })
  .limit(60),
```

(industry 카드 select 에는 이미 빠져 있는 `scope`/`status` 컬럼은 industry 쪽은 건드리지 말 것. 회사 카드 select 만 위 컬럼 사용.)

**A-2. 워치리스트 필터** — `watchlist`/`isWatched`(line 209~213) 산출 이후:

```ts
const rawCompanyCards = (companyCardsRes.data ?? []) as InsightCard[]
const companyCards = watchlist.length > 0
  ? rawCompanyCards.filter(c => c.topic && isWatched(c.topic)).slice(0, 12)
  : []
```

**A-3. contentMap 확장** — 인용 제목 해소를 위해 회사 카드 source/citation id도 `allIds` 집합에 포함(line 283~303 블록에서 `cards` 외에 `companyCards`도 순회). 한 군데서 둘 다 모으도록 수정.

**A-4. 직렬화·그룹** — 회사 카드를 기간별 그룹으로 변환(산업 `insightGroups`와 동일 방식, 별도 배열):

```ts
const companyGroupsMap = new Map<string, InsightCard[]>()
for (const card of companyCards) {
  const key = `${card.period_start}|${card.period_end}`
  if (!companyGroupsMap.has(key)) companyGroupsMap.set(key, [])
  companyGroupsMap.get(key)!.push(card)
}
const companyInsightGroups: InsightGroup[] = [...companyGroupsMap.entries()].map(([key, gc]) => {
  const [start, end] = key.split('|')
  return { key, start, end, cards: gc }
})
```

**A-5. 렌더** — 산업 인사이트 섹션 근처(아래)에 새 섹션. 워치리스트 유무로 graceful 분기([[insight-out-일반사용자-우선]] 빈상태 안내 원칙):

```tsx
<section>
  <h2 className="...">관심 기업 인사이트</h2>
  {watchlist.length === 0 ? (
    <p className="text-sm text-muted-foreground">
      <Link href="/dashboard/mypage" className="text-brand-600 hover:underline">마이페이지</Link>
      에서 관심 기업을 설정하면 기업별 AI 인사이트가 여기 표시됩니다.
    </p>
  ) : companyInsightGroups.length === 0 ? (
    <p className="text-sm text-muted-foreground">관심 기업 인사이트가 아직 없습니다. (생성·승인 후 표시)</p>
  ) : (
    <InsightCardsSectionClient groups={companyInsightGroups} contentMap={contentMapRecord} />
  )}
</section>
```

- 마이페이지 경로는 코드베이스의 실제 워치리스트 설정 경로로 맞출 것(확인 후 사용; `/dashboard/mypage` 가정).
- `InsightCardsSectionClient` 는 내부에서 보기(렌즈)·카드뉴스/분석 토글을 처리하므로 회사 카드도 동일 UX. **보기 'all'에서 전부, 'watch/mine'에서 렌즈 필터** 동작이 자연스러움(추가 배선 불필요).
- 만약 회사 섹션이 보기 렌즈와 이중 필터로 비어 보이는 회귀가 있으면, 그때만 경량 읽기전용 리스트로 폴백(이번엔 재사용 우선).

**A-6. (선택) 카드뉴스 슬라이드** — 여력 있으면 `insightSlides`(line 333~) 뒤에 회사 카드 슬라이드(badge '관심 기업', `type:'insight'`)를 소량(≤3) 추가. 부담되면 생략(범위 밖 처리 가능). 슬라이드 추가 시 `matchNames`에 `topic` 넣어 렌즈 하이라이트 유지.

### Part B — 야간 자동 생성 (`src/app/api/cron/ai-refresh/route.ts`)

`generateCompanyInsightCards` 를 cron에 추가. 패턴은 기존 단계 미러(try/catch 격리·deadline 체크).

**B-1. import 추가:**
```ts
import { generateIndustryInsightCards, generateCompanyInsightCards } from '@/lib/insight/generate'
```

**B-2. result 필드 추가:** `companyInsights: 0,`

**B-3. 단계 추가** — ①(산업 인사이트) 직후, ②(이슈 후보) 앞:
```ts
// ── ①b 관심 기업 카드 생성 ────────────────────────────────────────────────
try {
  const { created } = await generateCompanyInsightCards(admin)
  result.companyInsights = created
} catch (err) {
  result.errors.push(`companyInsights: ${err instanceof Error ? err.message : String(err)}`)
}

if (Date.now() >= deadline) {
  console.log('[ai-refresh] 데드라인 초과 — companyInsights 이후 중단')
  return Response.json(result)
}
```

- `generateCompanyInsightCards` 는 maxCompanies 기본 15·회사당 LLM 1회로 자체 바운디드. cron 기본 인자(days 7) 사용.
- 생성 카드는 `draft` → 어드민 승인 후 Part A에 노출(정책 일관).

## 4. 회귀 가드 / 비기능 요건

- 비로그인/워치리스트 0 → 회사 섹션 = 안내문(노출 0, 회귀 0). 산업 인사이트·경쟁사·키워드 섹션 **무변경**.
- LLM 키 없음 → cron 전체 skip(기존), 회사 카드 미생성(graceful).
- 회사 카드 select 에만 `scope/status` 추가. industry select·트렌드·경쟁사 쿼리 무변경.
- 하드코딩 hex 색 0(violet 등은 기존 토큰/유틸 재사용, 신규 hex 금지).
- 신규 의존성·SQL 없음.
