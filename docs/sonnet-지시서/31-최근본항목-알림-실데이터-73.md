## 파트 A — 최근 본 항목 (localStorage 실데이터)

> DB 테이블 없이 클라이언트 localStorage로 구현(개인 기기 기준 "최근 본"). 서버 동기화는 범위 외.

### A-1. 기록 유틸 — `src/lib/recent-views.ts`
- 타입 `RecentView { id: string; title: string; category: string | null; viewedAt: number }`.
- `addRecentView(v)`: localStorage 키 `io:recent-views` 읽기 → 같은 id 제거 후 맨 앞 삽입 → **최대 8개** 슬라이스 → 저장 → `window.dispatchEvent(new CustomEvent('recent-views:changed'))`.
- `getRecentViews(): RecentView[]`: 파싱(에러 시 빈 배열).
- SSR 가드: `typeof window === 'undefined'` 체크.

### A-2. 기록 트리거 — `src/components/contents/RecordRecentView.tsx` (`'use client'`)
- props: `{ id, title, category }`. `useEffect`로 마운트 시 `addRecentView` 1회 호출(렌더 없음, `return null`).
- 상세 페이지 `src/app/dashboard/contents/[id]/page.tsx`(서버 컴포넌트)의 `<article>` 내부에 `<RecordRecentView id={content.id} title={content.title} category={content.category} />` 삽입(서버→클라이언트 props 전달, 직렬화 가능 값만).

### A-3. Sidebar "최근 본 항목" 교체
- `RECENT_VIEWS` import 제거. `useState<RecentView[]>` + `useEffect`에서 `getRecentViews()` 로드 + `window.addEventListener('recent-views:changed', reload)` + `window.addEventListener('storage', reload)`(다른 탭 동기화), 언마운트 해제.
- 각 항목을 `<Link href={`/dashboard/contents/${v.id}`}>`로 렌더(현재 `cursor-default` div 제거). 시간 표시는 `viewedAt` 기준 상대시간(기존 `formatDate`/`timeAgo` 류 재사용).
- 빈 상태: "최근 본 콘텐츠가 없습니다" 문구.

## 파트 B — 알림 (실제 콘텐츠 기반)

> 알림 전용 테이블은 범위 외. **최근 수집 콘텐츠**로부터 알림을 파생해 각 항목이 상세로 링크되게 한다(이슈의 "링크 연결" 충족).

### B-1. 데이터
- `DashboardHeader`(이미 client)에서 Supabase로 **오늘(KST) 또는 최근 N건** 콘텐츠 조회:
  `from('contents').select('id, title, category, published_at, created_at').eq('status','published').order('created_at',{ascending:false}).limit(8)`.
- 각 행 → 알림 항목 `{ id, title, category, time: timeAgo(created_at), href: '/dashboard/contents/'+id }`.
- "오늘 업데이트 N건"(`TODAY_UPDATES` 대체): `created_at >= 오늘 0시 KST` count 쿼리(`head:true, count:'exact'`) 또는 위 목록에서 파생. 0건이면 배지 숨김.

### B-2. UI
- `NOTIFICATIONS`/`TODAY_UPDATES` import·"샘플 데이터" 안내 제거.
- 드롭다운 각 항목을 `<Link href={href}>`로 → 클릭 시 상세 이동 + 드롭다운 닫기.
- 읽음 처리(선택, 가벼움): 클릭한 알림 id를 localStorage `io:read-notifications`에 저장, 안 읽은 것만 빨강 배지 카운트. 미구현 시 배지는 "오늘 신규 수" 기준.
- 유튜브 등 상세 없는 카테고리는 링크 제외하거나 목록에서 제외(상세 라우트 없는 항목 클릭 시 404 방지 — `category === '유튜브'` 분기).

## 파트 C — mock 정리
