## 2. 구현

### 2-1. InsightViewTabs 확장 (count·href·폰트)
`src/components/analysis/InsightViewTabs.tsx`:
- item 타입에 **`count?: number`**, **`href?: string`** 추가.
- `href` 있으면 `<Link href={href}>`로 렌더(라우팅형, 기업동향), 없으면 기존 `<button onClick={onChange}>`.
- **count** 표시: 라벨 우측에 작은 숫자 — 비활성 `text-muted-foreground`, 활성 `text-brand-muted`. `count===0`이면 흐리게(선택적으로 "0"). 1000+ 는 `Xk` 축약(기존 콘텐츠 로직 유지).
- 폰트 `text-[13px]` → **`text-[14px]`**. 활성 언더라인(`after:bg-brand-muted`)·비활성 `text-muted-foreground` 유지. 테두리·틴트·pill 없음.
- 좌측 정렬·지속형·`gap-5` 유지. 카운트 있는 콘텐츠 탭은 `gap`을 약간 넓혀도 됨.

### 2-2. 기업동향 EntityTabs → InsightViewTabs(href)
`EntityTabs.tsx`: 큰 pill 마크업 제거, `InsightViewTabs`에 `items=[{id:'watchlist',label:'관심기업',href:'/dashboard/entities?view=watchlist'} …]` 전달(현재 `view`로 활성 판정). Link 기반이므로 `value`=현재 view. (224가 items를 관심기업/경쟁사(뉴스)/경쟁사(동향)로 교체 예정 — 컴포넌트·스타일은 그대로 재사용.)

### 2-3. 콘텐츠 탭 → InsightViewTabs(count)
`contents/page.tsx:488–511`의 pill map을 `InsightViewTabs`로 교체:
- `items = CONTENT_SOURCE_TABS.map(t => ({ id: t.value, label: t.label, count: catCounts[t.value] }))`, `value=activeSourceTab`, `onChange=(v)=>updateParam('category', v)`.
- 기존 "데이터 없음"·카운트 배지 마크업 제거(카운트는 InsightViewTabs가 표시).

### 2-4. 중복 섹션 헤더 제거
- `issues/page.tsx:26–27`: `<h1>AI 인사이트</h1>` + desc **블록 제거**(내비가 이미 표시). AiInsightBoard 뷰별 캡션이 맥락 설명 담당.
- `entities/page.tsx:268–269`: `<h1>기업동향</h1>` + desc **제거**. (필요하면 탭 아래 작은 `admin-caption`류 1줄만 — 기본은 제거.)
- `reports/page.tsx:72–74`: `<h1>전략보고서</h1>` **제거**, desc "AI가 분석한…모음"은 작은 캡션으로 유지(또는 제거), **새 보고서 버튼은 우측 유지**.
- 콘텐츠 `pageTitle`(카테고리명)+총N건 H1은 **유지**.
- 각 페이지 `<head>`용 `metadata.title/description`은 그대로(SEO·탭 제목).

### 2-5. 내비 L1 폰트
`DashboardHeader.tsx` nav: `text-[15px]` → **`text-[16px]`**.
