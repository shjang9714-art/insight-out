# 지시서 368 — 콘텐츠 검수(어드민) 개선: 원문 파일 바로 열람 + 커버 이미지 자동 축소

> 대상: 구현 에이전트 · 관리자 전용 · **신규 SQL 없음**
> ⚠️ 읽을 것: `src/components/admin/AdminContentManager.tsx`(검수 편집 모달 — L811 filePath·L935 handleThumbnailUpload·L1301 filePath 분기·L1320 커버 영역) · `src/lib/contents/upload-cover.ts`(uploadCoverFile) · `src/lib/contents/*`의 `getReportSignedUrl`(상세페이지 `dashboard/contents/[id]/page.tsx` L212에서 사용) · `src/components/admin/CoverImageField.tsx`·`src/components/admin/reports/ReportRow.tsx`(동일 2MB 체크) · `AGENTS.md`

## 배경 (David, 스샷 — 콘텐츠 검수 화면)
1. **원문 열람 불가**: 외부 리포트 검수 시 `edit.filePath`(저장된 PDF/PPTX)가 있는데도 화면에서 **원문 파일을 열 방법이 없다**. filePath는 지금 "1페이지 다시 가져오기" 버튼 노출 조건으로만 쓰임. 검수자가 본문·표지를 판단하려면 원문을 바로 봐야 한다.
2. **커버 2MB 초과 시 거부**: `handleThumbnailUpload`가 2MB 초과 이미지를 에러로 반려. 검수자가 이미지를 직접 리사이즈해야 하는 불편. **알아서 용량을 줄여** 올려주면 된다.

## 작업

### 1. 검수 편집 모달에 "원문 파일 열람"
- `edit.filePath`가 있을 때, 제목/커버 근처에 **[원문 열기] 버튼(또는 링크)** 추가. 클릭 시 `getReportSignedUrl(edit.filePath)`로 **서명 URL을 받아 새 탭(`target=_blank`, `rel=noopener`)으로 연다**(상세페이지 L212 패턴 재사용). PDF는 브라우저 뷰어로 열리고, PPTX는 다운로드 폴백.
- 서명URL 발급은 클라이언트에서 직접 불가하면 **경량 어드민 라우트**(`GET /api/admin/contents/[id]/file-url` 등, `verifyAdmin` 게이트)로 감싸 `{ url }` 반환 → 프런트가 그 url을 연다. (상세페이지가 서버에서 뽑는 구조면 어드민도 동일 서버 헬퍼 재사용.)
- 파일 없거나 서명 실패는 **그레이스풀**(버튼 비활성 또는 안내 토스트, 크래시 금지).

### 2. 커버 이미지 클라이언트 자동 축소
- **재사용 헬퍼 신규**: `src/lib/images/compress-image.ts` — `async function compressImageToLimit(file: File, opts?): Promise<File>`.
  - 이미지가 아니면 그대로 반환. 이미지면 `createImageBitmap`/`<img>`+`canvas`로 **최대 변(예: 1600px) 축소** 후 재인코딩(webp 우선, 폴백 jpeg), **품질을 낮춰가며 2MB 이하가 될 때까지** 반복(하한 품질·최소 치수 가드). 결과를 `File`로 반환(파일명 유지, 확장자만 인코딩에 맞게).
  - 실패(디코드 불가 등)하면 원본 반환하고 호출부가 기존 2MB 검증으로 처리.
- **적용**: `handleThumbnailUpload`에서 2MB 초과 즉시 반려 대신 **먼저 `compressImageToLimit` 시도 → 그래도 2MB 초과면 그때 에러**. 이미지 타입 검증은 유지. 진행 중 표시(`isUploadingThumb`) 재사용, 안내문구를 "용량이 크면 자동으로 줄입니다"류로.
- **공용화**: 같은 2MB 반려 로직이 `CoverImageField.tsx`·`reports/ReportRow.tsx`에도 있으니 **동일 헬퍼로 통일**(각 업로드 전 compress 시도). 최소 AdminContentManager는 필수, 나머지 둘도 같은 패턴 적용.

## 회귀 / 주의
- `verifyAdmin` 게이트 유지, 서명URL은 단명·서버발급(공개버킷 직링 금지). 색 토큰·한글 문구·`prefetch={false}`.
- 자동 축소는 **클라이언트 canvas**(서버 부담 0). EXIF 회전은 범위 밖(문제되면 후속). 투명 PNG→webp 시 배경 유지(알파 보존, 필요시 jpeg 폴백 시 흰 배경).
- 업로드 파이프라인(`uploadCoverFile`)·표지 필드 계약은 그대로(압축은 업로드 직전 단계만 추가).
- 검증: `tsc`·ESLint·`check-prefetch`·`build` + (dev)검수화면에서 원문 PDF 새 탭 열림 + 3MB 이미지 올리면 자동 축소돼 저장(2MB 이하). 완료보고에 커밋 해시.
