## 0. 한 줄

대시보드 "오늘 할 일"을 **클릭 가능한 액션 타일**로 바꿔, 각 숫자가 **필터된 화면으로 바로 이동하는 딥링크**가 되게 한다: 검토 대기·오늘 수집·수집 실패·소스 오류·**승인 대기**.

## 1. 현행 진단 (검증된 코드 사실)

- `AdminTodoBlock`(props: pending·todayCollected·todayFailed·sourcesToCheck): 3개 카드가 **평범한 div(클릭 불가)**. 숫자만 표시.
- `/admin/page.tsx`: pending·today·crawlFailed·crawlSources 집계 있음. **승인 대기(미승인 사용자) count 없음**.
- 딥링크 지원: 콘텐츠는 `?status=`·`?from=`·`?bookmarked=`·`?source=`·`?category=`(raw redirect). **crawl-logs·users는 필터 파라미터 없음** → 페이지 링크(best-effort).

## 3. 구현

### 3-1. 승인 대기 count 추가 (`/admin/page.tsx`)
- 미승인 사용자 count 추가(users의 승인 컬럼 기준 — 실제 컬럼명 확인, 예: `approved=false`/`is_approved=false`). `AdminTodoBlock`에 `pendingUsers` prop 전달.

### 3-2. `AdminTodoBlock` — 액션 타일화
- props에 `pendingUsers` 추가.
- 타일 5종(데이터·목적지 깨끗한 것):
  | 타일 | 숫자 | 링크 | 긴급 톤 |
  |---|---|---|---|
  | 검토 대기 | pending | `/admin/contents?status=pending` | neutral/info |
  | 오늘 수집 | todayCollected | `/admin/contents?from=today` | neutral |
  | 수집 실패 | todayFailed | `/admin/crawl-logs` | risk(>0) |
  | 소스 오류 | sourcesToCheck | `/admin/sources` | risk(>0) |
  | 승인 대기 | pendingUsers | `/admin/users` | info(>0) |
- 각 타일 = **`<Link>` 카드**(hover:bg-accent, 커서 포인터, 우하단 화살표). 숫자 `admin-metric`(또는 큰 크기)+단위, 라벨 `admin-card-title`, 짧은 설명 1줄.
- **0일 때**: "없음 ✓"(muted, 비링크 또는 옅은 링크) — 급한 것 없음 표현.
- **긴급 강조**: 실패·소스 오류가 >0이면 숫자/배지에 risk 톤(175 status-style, 그린 없음). 검토·수집은 중립.
- 그리드: 반응형(2~3~5열). 카드 밀도 v2(padding·radius).

### 3-3. 범위 밖(후속)
- 중복 의심·저품질 의심 타일 → 콘텐츠 관리에 해당 필터(중복/review_reason) 추가 후 딥링크(별건).
- crawl-logs `?status=failed`·users `?filter=pending` 필터 파라미터 추가(딥링크 정밀화) — 후속.
