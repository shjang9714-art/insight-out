# 지시서 351-A — 키워드 분석: 기간·필터 + 급상승 랭킹 + 버블 색상

> 대상: 구현 에이전트 · 상위설계: `docs/키워드분석-재설계-사전분석.md` · **신규 SQL 없음**
> ⚠️ 읽을 것: `src/components/analysis/AiInsightsView.tsx`(데이터 조립) · `AiInsightBoard.tsx`(keyword 뷰 렌더) · `src/lib/tag-buckets.ts`(유형 버킷) · `AGENTS.md`
> 범위: 이번엔 A만. 상세 페이지·시계열·LLM은 351-B/C.

## 배경
현 keyword 뷰는 `entity_signal_summary` 카드 그리드뿐. 급상승 랭킹·기간 선택·유형 색상·범례가 없어 "지금 뭐가 커지는가"에 못 답한다.

## 작업

### A. 키워드 증감률(%) — `AiInsightsView.tsx`
- `classifiedKeywords`가 이미 `kwCurFreq`/`kwPrevFreq`(이번주 6일 vs 직전주)를 갖는다. `KeywordItem`에 **`changePct`·`cur`·`prev` 추가**.
  - `changePct = prev === 0 ? (cur > 0 ? 100 : 0) : Math.round((cur - prev) / prev * 100)`
  - `prev === 0 && cur > 0` 은 **신규(NEW)** 로 표시(별도 플래그 `isNew`).
- `tag-buckets.ts`의 `KeywordItem` 인터페이스에 optional 필드 추가(하위호환).

### B. 급상승 랭킹 패널 — `AiInsightBoard.tsx` keyword 뷰
- keyword 뷰를 **2열(7:3)** 로: 좌측 기존 카드/버블, 우측 **급상승 랭킹 Top 10**.
- 랭킹 행: 순위 · 키워드 · `changePct`(▲/▽ + %, NEW 배지) · 관련 문서 수. 클릭 → 기존 링크(`entities/{id}` 또는 `topics/{name}`).
- 정렬 기준 토글: **급상승 / 신규 / 관심 지속**(= 상승·신규·큰 누적). 기본 급상승.

### C. 상단 요약 스트립
- keyword 뷰 최상단: `급상승 N · 신규 N · 관심 지속 N · 하락 N` (색 점 + 숫자). 데이터는 `classifiedKeywords`에서 집계.

### D. 버블/카드 유형별 색상 — `AiInsightBoard.tsx`
- 현 마젠타 단색 → `bucket`별 색상. `tag-buckets.ts` 버킷 매핑:
  - 기술·제품 → blue, 기업·기관 → violet, 시장·산업 → teal, 정책·규제 → amber, 그 외 → gray.
- **상승은 색이 아니라 배지·외곽선으로** 구분(`▲ 32%`·`NEW`). 색은 유형 전용.
- 하단에 **범례** 한 줄(유형 4색 + 상승/신규 표식).

### E. 기간 필터 (프레젠테이션만, 데이터 창은 유지)
- keyword 뷰 상단에 기간 셀렉트(`오늘/최근 7일/최근 30일`) UI 배치. **현재 집계 창(14일 2버킷)은 351-A에서 바꾸지 않는다** — 셀렉트는 표시하되, 실제 재집계는 351-B에서 시계열이 생긴 뒤 연결. (지금 바로 창을 가변화하면 서버 재조회 구조가 커진다.)
  - A에서는 "최근 7일 기준" 같은 **기준 라벨만 명시**해 현재 숫자가 어느 기간인지 분명히 한다.

## 회귀 / 주의
- `KeywordItem` 신규 필드 전부 optional. `kwStrip`(뜨는 토픽 탭) 기존 동작 유지.
- 서버 컴포넌트/클라이언트 경계 유지. 랭킹 패널이 인터랙션 필요하면 클라이언트 분리.
- 색상은 `--color-*` 토큰/tailwind 클래스만(하드룰 9). `prefetch={false}` 유지.
- 검증: `tsc` · ESLint · `check-prefetch` · `npm run build` · 육안(keyword 뷰 2열·랭킹·범례·색상).
