## 1. 지금 무엇이 잘못됐나

```
[홈  인사이트  분석  기업동향  자료실]   ← L1 (헤더)
─────────────────────────────────
주간 인사이트                            ← 제목
매주 업계 주요 이슈 중…                  ← 설명
[주간 인사이트 · 인사이트 리포트]        ← L2 (본문)
본문
```

**L1과 L2 사이에 제목·설명이 끼어 계층이 끊긴다.** 그리고 L2는 그 L1을 **클릭해서
들어가야만** 알 수 있다 — 무엇이 있는지 미리 볼 방법이 없다.

일부 L2는 제목·설명이 아예 없다(PR #169 가 자료실 다섯 화면에서 제목 블록을 제거했다).
`인사이트 리포트` 를 누르면 아무 설명 없이 탭만 덩그러니 남는다.

### 원래 설계가 이미 이랬다

코드에 흔적이 그대로 남아 있다. 되살리는 작업이지 새로 만드는 게 아니다.

- `taxonomy.tsx:4` 주석 — *"DashboardHeader 가 L1 아래 **sticky L2 행**을 렌더할 때
  이 파일 하나만 참조한다"*
- `taxonomy.tsx:162` — *"l1Href(활성 **또는 호버 프리뷰 대상** L1)"*
- `DashboardHeader.tsx:202` `id="l1-nav-row"` · `:220` `id="l1-active-label"`
- `src/components/dashboard/NavGroupAlign.tsx` — L2 그룹의 좌측 시작점을
  활성 L1 라벨의 x좌표에 맞추는 컴포넌트. 지금은 `EntityTabs.tsx` 만 쓴다.

## 2. 목표

```
┌ 홈   인사이트   분석   기업동향   자료실       ← L1
│           └ 주간 인사이트 · 인사이트 리포트    ← L2 (헤더, L1 바로 아래)
├─────────────────────────────────────────
  주간 인사이트                                 ← 제목 (본문 맨 위)
  매주 업계 주요 이슈 중…                       ← 설명
  본문
```

**동작**

1. L2 행은 **`DashboardHeader` 안**, L1 행 바로 아래에 있다.
2. 기본은 **활성 L1** 의 L2 를 보여준다.
3. **L1 에 마우스를 올리면 그 L1 의 L2 를 미리 보여준다** — 이동하지 않는다.
   L1 은 **여전히 클릭 가능**하다. 호버는 미리보기일 뿐 클릭을 대체하지 않는다.
4. 마우스가 벗어나면 활성 L1 의 L2 로 돌아온다.
5. L2 가 없는 L1(홈·기업동향)에 호버하면 행이 비거나 접힌다.
   ⚠️ **행이 사라졌다 나타나며 아래 내용이 튀지 않게 하라.** 높이를 유지하거나
   부드럽게 처리해라. 레이아웃 점프는 이 작업의 실패다.
6. L2 그룹의 좌측 시작점은 **그때 보여주는 L1 라벨**에 맞춘다(`NavGroupAlign` 재사용).
   ⚠️ `NavGroupAlign` 은 `#l1-active-label` 을 찾는다. 호버 중에는 **호버 대상**에
   맞춰야 하므로 기준 id 를 어떻게 줄지 네가 설계해라.
   `remeasureKey` 에 "지금 보여주는 L1" 을 넘기면 재측정된다.
7. 모바일(`md` 미만)에서는 L1 행 자체가 숨겨진다(`hidden md:flex`). **L2 행도 같이 숨겨라.**
   모바일 내비게이션은 542-C 로 끝났다 — 건드리지 마라.

## 3. 본문에서 L2 탭을 걷어낸다

지금 `<ContentsL2Tabs />` 를 렌더하는 곳 **전부**에서 제거한다.

```
src/components/analysis/AiInsightBoard.tsx   (558 에서 넣은 것)
src/components/contents/ContentsBoard.tsx
src/app/dashboard/entities/page.tsx          (DocumentsView)
src/app/dashboard/reports/page.tsx
```

⚠️ **`ContentsBoard` 는 PR #169 로 "탭(왼쪽) + 카드·리스트 토글(오른쪽)" 한 줄이 됐다.**
탭이 빠지면 토글만 남는다. **토글을 우측 정렬로 그 줄에 유지**하고 빈 왼쪽을 정리해라.
줄 자체를 없애지 마라.

⚠️ `ContentsL2Tabs` 컴포넌트를 **지우지 마라.** 헤더용으로 재사용하거나, 헤더 전용
컴포넌트를 새로 만들고 이건 남겨둘지 네가 판단해라. 다만 **L2 정의는 `NAV_SECTIONS`
한 곳에서만 읽어야 한다.**

## 4. 모든 L2 에 제목·설명

PR #169 는 "L2 탭이 본문 맨 위에 있으니 볼드 제목은 중복" 이라는 전제로 제목을 뺐다.
**L2 가 헤더로 올라가면 본문에 라벨이 하나도 안 남는다.** 전제가 바뀌었으므로 되돌린다.
#169 가 원한 "다섯 탭이 같은 구조" 는 그대로 지켜진다 — 다섯 개 다
[헤더 L2] + [제목·설명] + [본문] 이 된다.

### 이미 있는 것 — 건드리지 마라

`AiInsightBoard.tsx:111-125` `TAB_HEADER_META` 의 `brief`·`keyword`·`graph` 3개.

### 새로 넣을 것 — 아래 문구를 그대로 써라

| L2 | 화면 | 제목 | 설명 |
|---|---|---|---|
| 인사이트 리포트 | `/dashboard/reports?view=ai` | 인사이트 리포트 | AI가 수집한 자료를 분석해 작성한 전략보고서와 지식보고서입니다. |
| 전문기관 보고서 | `/dashboard/reports?view=external` | 전문기관 보고서 | 가트너·KRG 등 외부 전문기관이 발행한 시장·기술 리포트입니다. |
| 기업 공시 | `/dashboard/entities?view=documents` | 기업 공시 | DART 공시와 기업이 직접 공개한 IR·기술 자료입니다. |

  **정의는 한 곳**이어야 한다.
- 기업동향(L2 없음)은 지금의 `PageHeader title="기업동향"` 을 그대로 둔다.
