# Sonnet 지시서 02 — 카테고리 미읽음 뱃지 → "오늘 N건 업데이트" 텍스트

> 작성: Opus(Cowork) · 대상: Claude Code(Sonnet) · PRD 변경사항 #14
> 독립 작업(서비스 분류·DB 의존 없음) — 단독 진행 가능

## 0. 목표 (한 줄)
대시보드 카테고리 카드의 **빨간 미읽음 카운트 뱃지를 제거**하고, 그 자리에 **"오늘 N건 업데이트"** 텍스트로 교체한다.

## 1. 배경
- PRD 변경: 미읽음 뱃지(빨강 숫자)는 사용자에게 압박감을 줌 → 중립적 "오늘 N건 업데이트" 텍스트로 변경.
- 대상 파일: `src/components/dashboard/CategoryGrid.tsx` (현재 `cat.count` 를 빨강 원형 뱃지로 표시 중, 26~33행).
- 데이터: 지금은 mock(`src/components/dashboard/mock-data/taxonomy.ts` 의 `CATEGORIES[].count`). 실제 "오늘 신규 건수" DB 연동은 후속 작업 — **이번엔 기존 `count` 값을 그대로 "오늘 N건" 자리에 사용**(placeholder).

## 2. 할 일

### 2.1 `CategoryGrid.tsx` 수정
1. 아이콘 위 빨강 카운트 뱃지(`<span className="absolute -right-2 ...">{cat.count}</span>`) **제거**.
2. 카테고리 라벨(`cat.label`) **아래**에 신규 텍스트 한 줄 추가:
   - `cat.count > 0` → `오늘 {cat.count}건 업데이트`
   - `cat.count === 0` → `업데이트 없음`
3. 스타일: 작고 차분하게. 신규 텍스트는 `text-[11px] text-gray-400` (0건은 동일 톤). 브랜드 색·볼드 쓰지 말 것(압박감 제거가 목적).
4. 아이콘을 감싸던 `<div className="relative">` 는 뱃지 제거 후 불필요하면 정리(레이아웃 안 깨지게).

### 2.2 건드리지 말 것
- `taxonomy.ts` 의 `count` 필드/값 (구조 변경 금지 — 후속 DB 연동에서 처리).
- 다른 컴포넌트, 라우팅(`CATEGORY_HREF`), `activeService` 로직.

## 3. 완료 조건
- [ ] 빨강 원형 카운트 뱃지가 화면에서 사라짐
- [ ] 각 카드에 "오늘 N건 업데이트"(또는 "업데이트 없음") 텍스트 표시
- [ ] 텍스트가 차분한 톤(`text-gray-400`, 비볼드)
- [ ] 8개 카드 그리드 레이아웃 안 깨짐 (`grid-cols-8` 유지)
- [ ] `npx tsc --noEmit` 통과
