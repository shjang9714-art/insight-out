# Sonnet 지시서 02 — 카테고리 미읽음 뱃지 → "오늘 N건 업데이트" 텍스트 (#14)

> 작성: Opus(Cowork) · 대상: Claude Code(Sonnet) · PRD 변경사항 #14
> 갱신: 2026-06-02 — `CategoryGrid.tsx` 가 실제 Supabase 데이터로 바뀐 현행에 맞춰 재작성.
> 독립 작업(크롤러·서비스 분류 의존 없음).

## 0. 목표 (한 줄)
대시보드 카테고리 카드의 **빨간 카운트 뱃지(누적 총건수)를 제거**하고, 그 자리에 **"오늘 N건 업데이트"**(= 오늘 수집된 신규 건수) 텍스트로 교체한다. 압박감 주는 빨강 숫자 → 중립적 안내.

## 1. 현행 코드 (반드시 먼저 읽기)
`src/components/dashboard/CategoryGrid.tsx`:
- `'use client'` 컴포넌트. `useEffect` 에서 Supabase `contents` 를 `status='published'` 로 조회 → 카테고리별 **누적 총건수**를 `counts` state 에 담음.
- 아이콘 위에 **빨강 원형 뱃지**(`<span className="absolute -right-2 -top-1 ... bg-brand-600 ...">{count}</span>`, 약 70~74행)로 그 총건수를 표시 중.
- `CATEGORY_DEFS` 에 `category: ContentCategory | null`(유튜브는 null) 매핑 존재.

## 2. 할 일

### 2.1 "오늘 수집분" 집계로 변경
- 조회를 `select('category, collected_at')` 로 바꾸고(여전히 `eq('status','published')`), **오늘(KST 0시 이후) `collected_at` 인 행만** 카테고리별로 세어 `todayCounts` state 에 담는다. (누적 총건수는 더 이상 표시 안 하므로 불필요)
- "오늘 KST 0시" ISO 계산(클라이언트):
```ts
function todayStartKstIso(): string {
  const now = Date.now()
  const kst = new Date(now + 9 * 60 * 60 * 1000)          // KST 벽시계
  const midnightUtc = Date.UTC(kst.getUTCFullYear(), kst.getUTCMonth(), kst.getUTCDate()) - 9 * 60 * 60 * 1000
  return new Date(midnightUtc).toISOString()
}
```
- 집계: `collected_at >= todayStartKstIso()` 인 행만 `todayCounts[category]++`.

### 2.2 뱃지 제거 + 텍스트 추가
1. 아이콘 위 **빨강 원형 뱃지(`<span className="absolute ... bg-brand-600 ...">` 블록) 제거.** 뱃지를 감싸던 `<div className="relative">` 도 뱃지 제거 후 불필요하면 정리(아이콘만 남기되 레이아웃 안 깨지게).
2. 카테고리 라벨(`cat.label`) **아래**에 신규 텍스트 한 줄 추가:
   - `today > 0` → `오늘 {today}건 업데이트`
   - `today === 0` → `업데이트 없음`
   - 유튜브 카드(`category === null`)는 today 집계 대상 아님 → `업데이트 없음` 또는 텍스트 생략(택1, 일관되게).
3. 스타일: 작고 차분하게 — `text-[11px] text-gray-400`(0건도 동일 톤). **브랜드 색·볼드 금지**(압박감 제거가 목적).

### 2.3 건드리지 말 것
- `CATEGORY_DEFS` 구조·라우팅(`href`)·`activeService` 로직.
- 다른 컴포넌트, `contents.status` 외 쿼리 조건.
