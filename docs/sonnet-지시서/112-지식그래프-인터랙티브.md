## 배경 (David)

현 지식그래프(엔티티 칩·목록)는 "의미는 알겠지만 인사이트를 따라가기 어렵고 임팩트가 약함." → **노드-엣지 그래프**로 엔티티(기업·기술·이슈) 관계를 **직접 클릭하며 탐색**(따라가기) 가능하게. 가독성·임팩트·활용성↑.

## 설계 결정 (Opus)

1. **관계 = content_entities 공기출현**(112 RPC). 노드=엔티티(mention 상위), 엣지=공기출현 가중치. (이슈 노드 포함은 후속 — v1은 엔티티 그래프.)
2. **시각화 = `react-force-graph-2d`**(canvas, force 레이아웃). 클라 전용 → `dynamic(import, { ssr:false })`(window 필요).
3. **바운디드**: 노드 ~60(mention desc), 엣지 RPC(min_weight 3, limit 400) 중 양끝이 노드집합인 것만. 가독성·성능.
4. **노출**: `/dashboard/entities` 에 **[그래프 | 목록] 뷰 토글**(그래프 기본). AI분석 ⑥ 지식그래프 티저 링크가 여기로(111).

## 작업

### A. (선행) SQL — `docs/sql-handoff/112-entity-cooccurrence.sql` (수희 선적용)
- `entity_cooccurrence(p_min_weight, p_limit)` RPC(공기출현 엣지). `supabase/schema.sql` SSOT 반영(#6).

### B. 그래프 데이터 — `src/app/dashboard/entities/page.tsx`(서버) 또는 `/api/graph`
- **노드**: `entities` select(id·canonical_name·entity_type·is_competitor·mention_count) `order mention_count desc` `limit 60`.
- **엣지**: `supabase.rpc('entity_cooccurrence', { p_min_weight: 3, p_limit: 400 })` → `{source,target,weight}[]`. **양끝이 노드집합(상위60)에 있는 엣지만** 필터.
- 그래프 데이터 `{ nodes:[{id,label,type,val,isCompetitor}], links:[{source,target,weight}] }` 를 클라 컴포넌트로 전달.

### C. 그래프 컴포넌트 — `src/components/entities/KnowledgeGraph.tsx` (신규, `'use client'`)
- `react-force-graph-2d` **dynamic import(ssr:false)**. 컨테이너 고정 높이(예 560px), border-radius.
- 노드: **타입별 색**(ENTITY_TYPE: 기업=brand/경쟁사 red, 기술 blue, 정책 amber, 산업 muted, 제품 violet, 인물 emerald), 크기=`val`(mention 정규화). 라벨 표시(줌 따라).
- 엣지: 두께=weight(정규화), 연한 회색.
- 인터랙션:
  - **노드 클릭 → ego 강조**(이웃·연결 엣지만 진하게, 나머지 dim) + 우측/하단 **미니 패널**(엔티티명·타입·mention·"상세 보기 →" `/dashboard/entities/{id}`). 다시 클릭/빈곳 클릭 → 해제.
  - 줌·팬(기본 제공), hover 라벨/커서.
  - **타입 필터 범례**(클릭 토글로 타입 표시/숨김).
- 빈 데이터(노드 0) → "아직 관계 데이터가 없습니다(엔티티·콘텐츠 적재 필요)".

### D. 뷰 토글 — `src/app/dashboard/entities/page.tsx`
- 상단에 **[그래프 | 목록]** 토글(세그먼트). 그래프=`<KnowledgeGraph>`, 목록=기존 `<EntityBrowse>`. 기본 그래프. (URL `?view=list` 로 목록 직접 진입 허용 — 선택.)

## 회귀 / 주의
- **신규 의존성**(react-force-graph-2d) — 번들 큼 → **dynamic ssr:false**(SSR/window 오류 방지), 그래프 뷰에서만 로드. PR 사유 명시(#18).
- RPC 없으면(SQL 미적용) rpc 에러 → graceful("관계 데이터 없음"), 목록 뷰는 정상.
- 바운디드(노드60·엣지400 캡) — 과밀 방지. 더 키우면 성능·가독성 저하.
- 노드 클릭 목적지 `/dashboard/entities/{id}`(102 상세) 재사용.
- 다크모드 대응(canvas 색을 토큰/팔레트 hex로, 라이트·다크 모두 가독). 캔버스는 CSS 변수 직접 못 쓰니 ENTITY_TYPE→hex 맵을 컴포넌트에 정의(라이트/다크 분기 또는 중립 hex).
- 색 토큰 의미(#9)·UI 한국어(#1)·`any` 금지·서버는 데이터만, 그래프는 client leaf.
- 이슈 노드·GraphRAG 검색은 이번 범위 아님(후속).
