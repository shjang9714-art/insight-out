## 배경 (David)
어드민 "분류 엔진" 섹션의 라벨이 와닿지 않음.
- **토픽 규칙**(`/admin/keyword-groups`) → **수집 키워드** (관련도 게이트·검색어로 *무엇을 수집할지* 결정).
- **서비스 키워드**(`/admin/keywords`) → **카테고리 분류기준** (콘텐츠를 서비스/카테고리로 분류·태깅하는 기준).

라우트(href)·기능·DB는 불변. 라벨/제목 문구만 변경.

## 작업

### 1. `src/lib/admin/nav.ts` — 분류 엔진 그룹 라벨
- `/admin/keywords`: `label: '서비스 키워드'` → **`'카테고리 분류기준'`**, `description: '서비스별 자동 태깅 키워드'` → **`'콘텐츠를 서비스·카테고리로 분류하는 기준 키워드'`**.
- `/admin/keyword-groups`: `label: '토픽 규칙'` → **`'수집 키워드'`**, `description: '관련 키워드 그룹·해시태그'` → **`'수집 관련도·검색어·시그널 기준'`**.
- 그룹명 `'분류 엔진'` 은 유지(요청 범위 밖).

### 2. `src/app/admin/keywords/page.tsx` — 제목 일치
- `metadata.title`: `'서비스 키워드 | 어드민 | Insight Out'` → **`'카테고리 분류기준 | 어드민 | Insight Out'`**.
- `<h1>` `서비스 키워드` → **`카테고리 분류기준`**.
- 설명 문단(있으면) 문구를 분류 기준 취지로 자연스럽게(예: "콘텐츠를 서비스·카테고리로 자동 분류·태깅하는 키워드를 관리합니다.").

### 3. `src/app/admin/keyword-groups/page.tsx` — 제목 일치
- `metadata.title`: `'토픽 규칙 | …'` → **`'수집 키워드 | 어드민 | Insight Out'`**.
- `<h1>` `토픽 규칙` → **`수집 키워드`**.
- 설명 문단은 기존 취지(관련도 게이트·검색어·시그널) 유지하되 첫 문구만 "수집 키워드"에 맞게.
