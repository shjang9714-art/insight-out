# 지시서 (추가분 10) — '실험실' 위치를 상위 네비 높이로 이동 (2026-07-10)

**작성**: Cowork Opus
**대상**: Claude Code

## 배경
`/dashboard/issues` 페이지의 `AiInsightBoard.tsx`가 렌더링하던 '실험실'(헤드라인 분석/뜨는 토픽/이슈 타임라인, 관리자 전용) 하위탭 줄을, 상위 5탭 네비게이션(`DashboardHeader.tsx`)의 두 번째 줄 우측 끝(프로필 열과 정렬)으로 이동한다. 이렇게 하면 관리자가 어느 대시보드 페이지에 있든 실험실에 바로 접근할 수 있다.

## 변경 파일 1: `src/components/dashboard/DashboardHeader.tsx`
- `NAV_TABS` 아래 `LAB_QUICK_LINKS` 상수 추가(헤드라인 분석/뜨는 토픽/이슈 타임라인).
- `isAdmin` state 추가, 기존 `name, team` 조회를 `name, team, role`로 확장해 `role === 'admin'`으로 계산.
- 5탭 네비 줄(`<nav>`) 안 `NAV_TABS.map(...)` 뒤에 `isAdmin &&`로 감싼 실험실 블록 추가 — `ml-auto`로 우측 끝 배치, 각 링크는 `/dashboard/issues?view=<id>`로 이동하며 `pathname`+`searchParams.get('view')`로 활성 표시.

## 변경 파일 2: `src/components/analysis/AiInsightBoard.tsx`
- 헤더로 옮긴 실험실 렌더링 블록 제거. 상시 노출 3개 탭(`PRIMARY_TABS`)만 남김.
- `LAB_TABS`/`LAB_VIEW_IDS`/`VALID_VIEW_IDS`와 비관리자 URL 직접 접근 시 `brief` 폴백 가드는 유지 — 방어 로직은 헤더 이동과 무관하게 계속 필요.

## 구현 결과 (Claude Code, 2026-07-10)
- `DashboardHeader.tsx`: `LAB_QUICK_LINKS` 상수, `isAdmin` state, role 조회 확장, 5탭 줄 우측 실험실 블록 추가.
- `AiInsightBoard.tsx`: L2 영역에서 실험실 UI 제거, `PRIMARY_TABS`만 렌더링. `LAB_VIEW_IDS` 기반 비관리자 폴백 가드는 그대로 유지.
- `npm run build`, `npm run lint` 통과(기존 무관 warning만 존재, 신규 에러 없음).
