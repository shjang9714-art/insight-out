## 배경 (David)

AI 분석이 "위젯 나열"이라 **사용자가 의도·활용을 모른다.** → (1) **탭 제거, 한 페이지 세로 스크롤**로 흐름 통합, (2) 각 섹션을 **"무엇을 보여주는지 한 줄 + 1차 액션"**으로 활용 가능하게, (3) 키워드맵은 단순 빈도 → **트렌드(▲/▽)**로, (4) 상단 검색의 **'/' 표식 제거**(혼선).

## 설계 결정 (Opus, David 지정)

- **섹션 순서(확정)**: ① 이번 주 뜨는 토픽(가로 스크롤, 최상단) → ② 키워드 트렌드 → ③ 시장 주요 이슈 → ④ 경쟁사 동향 → ⑤ AI 인사이트 → ⑥ 지식그래프.
- 데이터 로직 재사용(기존 페치/집계), **배치·스타일·액션 라벨**만 신규.
- 일부 액션(보고서로·배틀카드)은 **전략보고서 캡스톤 전이라 자리만**(비활성/툴팁 "준비 중") 또는 기존 라우트 연결.

### B. 섹션별 구성 (각 섹션 = 목적 한 줄 + 신호 + 1차 액션)
AiInsightsView 를 섹션 단위로 분해해 셸이 순서대로 조합(또는 셸에서 직접). 데이터는 기존 그대로.

1. **이번 주 뜨는 토픽 (가로)**: 목적("이번 주 가장 빠르게 늘어난 주제"). **가로 스크롤**(`flex gap overflow-x-auto`) 카드: 토픽 · ▲%/NEW · 왜 뜨는지 한 줄 · 클릭 → `/dashboard/topics/{group}`.
2. **키워드 트렌드**: 목적("빈도가 아니라 뜨는/식는 방향"). KeywordMap 재프레임 — 이번 주 vs 직전 주 빈도(14일 데이터)로 **▲상승/▽하락** 칩, 클릭 → 타임라인. (카테고리 필터는 선택 유지.)
3. **시장 주요 이슈**: 목적("추적 이슈의 변화"). `IssueBoardView` **컴팩트 인라인**(상위 N) + 변화배지(105) + "추적/전체 보기" 액션.
4. **경쟁사 동향**: 목적("경쟁사가 뭘 했고 시장이 어떻게 봤나"). 업체별 **한 줄 움직임 요약 + 논조** + 액션 "배틀카드"(캡스톤 전 = 비활성/타임라인 링크).
5. **AI 인사이트**: 목적("이번 주 읽어야 할 결론"). 인사이트 카드(헤드라인·시사점·근거) + 액션 **"보고서로 만들기"**(캡스톤 전 = 비활성/툴팁) · "근거 보기". 0건 → "생성 대기" 빈상태.
6. **지식그래프**: 목적("엔티티 관계를 직접 탐색"). 이번엔 **티저**(소형 관계 일러스트 또는 EntityBrowse 상위 미리보기) + **"관계 탐색 →"** 링크(`/dashboard/entities`). 본격 인터랙티브 그래프는 112.

### C. 검색 '/' 표식 제거 — `src/components/dashboard/SearchBar.tsx`
- placeholder(L151) `콘텐츠 검색 — '/' 로 영역 선택` → **`콘텐츠 검색`**.
- `/` 키 핸들러(L51 `if (e.key === '/')`) 로 영역 선택이 열리는 동작 **제거**(혼선 원인). 검색 자체 기능은 유지.
