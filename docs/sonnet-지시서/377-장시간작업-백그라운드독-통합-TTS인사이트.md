# 지시서 377 — 장시간 작업을 백그라운드 작업 독에 통합 (TTS·인사이트 재생성 등, 페이지 전환·유지)

> 대상: 구현 에이전트 · 관리자 전용 · **신규 SQL 없음**
> ⚠️ 읽을 것: `src/components/admin/EnrichJobsProvider.tsx`(작업 실행·localStorage 지속·`useEnrichJobs`) · `src/components/admin/EnrichJobsDock.tsx`(우하단 `fixed` 독·레이아웃 레벨) · `src/lib/admin/enrich-jobs.ts`(`ENRICH_JOBS` 레지스트리·key/endpoint/kind/method) · `src/app/admin/layout.tsx`(Provider+Dock 마운트 위치) · `src/components/admin/BriefingManager.tsx`(`generateAudio` TTS·`highlights` 인사이트 재생성 — 현재 로컬 fetch) · `AGENTS.md`

## 배경 (David)
논조분석·요약백필 등은 이미 **EnrichJobs 독**(레이아웃 레벨 `fixed` 플로팅)에 붙어 **페이지를 넘겨도 작업이 계속되고 진행 인디케이터가 유지**된다. 그러나 **TTS 오디오 생성·인사이트 재생성**은 로컬 `fetch`+`pendingAction`이라 **다른 페이지로 가면 작업이 끊기고 인디케이터도 사라진다**. David 요청: **모든 장시간 작업(AI 생성·수집·TTS 등)이 페이지 전환에도 계속되고, 로딩 인디케이터가 계속 보이게** — 즉 **기존 독 시스템으로 통합**한다.

## 작업

### 1. 작업 레지스트리 — 항목(per-item) 작업 지원
- `ENRICH_JOBS`(전역 작업 위주)를 **per-item 작업**(대상 id·파라미터 필요)도 담도록 확장하거나, 동일 패턴의 항목작업 정의를 추가한다. 최소:
  - **`admin:briefing-tts`** — 브리핑 오디오 생성. endpoint `/api/admin/briefings/{id}/tts`(id 치환), kind `once`, method `POST`, label `오디오 생성`.
  - **`admin:briefing-highlights`** — 인사이트(하이라이트) 재생성. endpoint `/api/admin/briefings/{id}/highlights`, kind `once`, POST, label `인사이트 재생성`.
- endpoint에 **`{id}` 치환·params** 전달 경로 마련(Provider가 이미 searchParams 처리 → id는 경로 치환으로). 서버 라우트는 그대로(계약 유지).

### 2. 트리거를 독으로 라우팅 (BriefingManager)
- `generateAudio`·(하이라이트 재생성) 트리거를 **`useEnrichJobs()`로 디스패치**(로컬 `fetch`+`pendingAction` 대신). 작업은 **Provider(레이아웃 레벨)에서 실행** → 클라이언트 네비게이션 시에도 유지, 독에 진행상황 표시.
- 완료 시 기존 후처리(목록 갱신·audio_url 반영)는 **독 완료 콜백/이벤트나 `router.refresh()`** 로 대체(로컬 상태 의존 제거). 실패·429는 독에서 에러 표기(기존 EnrichJobs 에러 패턴 재사용).
- 버튼은 "진행 중" 표시를 **독 상태 기준**으로(중복 실행 방지: 같은 item 작업 진행 중이면 재클릭 가드).

### 3. 지속·가시성 (이미 있는 것 활용·확인)
- 독은 이미 `fixed bottom-4 right-4 z-50`·레이아웃 레벨·localStorage 지속 → **페이지 전환·새로고침에도 표시**. TTS/인사이트가 여기 들어오면 자동으로 그 혜택을 받는다. 동작 확인만.
- (참고) 클라이언트 실행 작업은 **탭 닫기/전체 새로고침 중 진행 중이던 fetch는 중단**될 수 있음(서버 백그라운드 잡은 이번 범위 밖). "다른 페이지로 이동"(SPA 네비)에서 유지가 핵심 목표.

### 4. 일반화(패턴 문서화) — 확장 지침
- 앞으로 추가되는 **모든 장시간 트리거(AI 생성·수집·발견·백필 등)는 EnrichJobs 레지스트리에 등록해 독으로** 실행하도록 패턴을 코드/주석으로 명시. 지금 로컬 fetch로 남아있는 다른 장시간 트리거가 있으면 목록화(이번 커밋에서 최소 TTS·인사이트는 이관, 나머지는 후속 가능).

## 회귀 / 주의
- 기존 EnrichJobs 작업(논조·요약백필 등) 회귀 금지. 독 UI·localStorage 스키마 호환 유지(기존 진행중 작업 깨지지 않게).
- per-item 작업이 전역 작업과 키 충돌 없게(같은 id 중복 실행 가드). verifyAdmin 서버 게이트 유지.
- 색 토큰·한국어·`prefetch={false}`.
- 검증: `tsc`·ESLint·`check-prefetch`·`build` + (dev)브리핑 오디오 생성 시작 → **다른 어드민 페이지로 이동해도 독에 진행 표시 유지·완료 후 반영** / 인사이트 재생성 동일 / 기존 EnrichJobs 작업 정상.
