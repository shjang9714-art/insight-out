# 지시서 252 — 유튜브 인앱 상세 + 임베드 플레이어

목표: 유튜브 콘텐츠를 누르면 **youtube.com 새 탭으로 이탈하지 않고**, 우리 시스템 안의 상세 화면(`/dashboard/contents/[id]`)으로 **한번 더 들어가서** **임베드 플레이어(iframe)로 인앱 재생**한다. 영상 위에 우리 메타(제목·채널·요약·키워드·관련)를 얹어 MI 플랫폼답게.

David 결정: A안(인앱 상세 페이지 + 임베드).

범위: 유튜브 카드 라우팅 교정(외부→내부 상세) + `contents/[id]` 상세에 유튜브 임베드 브랜치 + **유튜브 해시태그(엔티티) 태깅** + **관련 기사 캐러셀**. SQL 없음(태깅은 코드+백필).

> David 추가 요청(2026-07-09): 유튜브에도 (1) **해시태그(엔티티)**를 달고, (2) 뉴스처럼 하단 **관련 기사 회전 캐러셀**을 노출. ⚠ 발견: content 상세엔 **관련기사 캐러셀·관련엔티티 칩이 이미 존재**(`FeedCarousel`+`getRelatedGrouped/getRelatedYoutube`) → 유튜브를 상세로 보내면 **자동 상속**. 단 **유튜브는 분류(matched_groups/keywords·content_entities)를 안 타서**(크롤러 `youtube_channel → 별도경로/미구현`) 해시태그·관련기사가 비어버림 → **유튜브 분류·엔티티 태깅이 선결**(2-4).

---

## 1. 현행 진단 (검증된 코드 사실)
- 유튜브 콘텐츠 = **`contents` 행**(`category='유튜브'`, `original_url`=watch URL). 별도 youtube 라우트 없음. 상세 = **`/dashboard/contents/[id]`**(존재).
- **영상 ID 확보 가능**: `src/lib/youtube.ts` `extractVideoId(original_url)`(youtube.com `?v=` / youtu.be path). ContentCard가 이미 썸네일 폴백에 사용.
- **현재 카드는 외부 링크**: `ContentCard`(콘텐츠 유튜브 그리드)는 `externalHref`(youtube.com 새 탭). `ContentListCard`는 `isYoutube`면 `<article>`(상세 링크 없음) + "원문" 외부.
- 상세 페이지(`contents/[id]`)엔 **유튜브 임베드 없음**(텍스트/본문 위주, `isReport` 분기만).

## 2. 구현

### 2-1. 유튜브 카드 → 인앱 상세 라우팅
- **`ContentListCard`**: `isYoutube`일 때도 다른 카드처럼 **`<Link href={`/dashboard/contents/${id}`}>`** 로(현재 `<article>` 특수분기 제거). 카드 내부 "원문" 외부링크는 유지 가능하나, 카드 클릭은 인앱 상세로.
- **`ContentCard`**(콘텐츠 유튜브 그리드·피드): 유튜브 항목의 클릭 타깃을 `externalHref`(youtube.com) → **`/dashboard/contents/${id}`**(내부). (id를 prop으로 받는지 확인 후 라우팅.)
- 기타 유튜브 노출 지점(YoutubeSection·홈 등)도 동일하게 내부 상세로. 외부 새 탭 제거.

### 2-2. 상세 페이지 유튜브 임베드 (`contents/[id]/page.tsx`)
- `category==='유튜브'` && `videoId = extractVideoId(content.original_url)` 있으면 **본문 최상단에 임베드 플레이어**:
  ```tsx
  <div className="aspect-video w-full overflow-hidden rounded-xl border border-border bg-black">
    <iframe
      src={`https://www.youtube-nocookie.com/embed/${videoId}`}
      title={content.title}
      allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
      allowFullScreen
      loading="lazy"
      className="h-full w-full"
    />
  </div>
  ```
  - **youtube-nocookie.com**(프라이버시 강화 모드) 사용.
- 임베드 아래 우리 메타: 제목·채널(sources.name/author)·발행일·요약(summary_ko)·매칭 키워드·관련 콘텐츠(기존 상세 구성 재사용).
- **폴백**: `videoId` 없거나 임베드 불가 대비 **"YouTube에서 보기"** 외부 링크(`original_url`) 항상 제공(임베드 차단 영상 대응).
- 리포트(`isReport`) 분기와 공존 — 유튜브 분기를 그 앞/옆에 추가.

### 2-4. 유튜브 해시태그·엔티티 태깅 (선결 — 백엔드)
- **현행 확인**: 유튜브 수집 경로가 뉴스와 달리 분류/엔티티 추출을 안 탈 가능성(크롤러 `youtube_channel → 별도경로/미구현`). → **유튜브 콘텐츠의 `matched_groups`·`matched_keywords`·`content_entities`가 비어 있는지 실측**(대표 유튜브 row 조회).
- **비어 있으면**: 뉴스와 **동일한 분류·엔티티 파이프라인을 유튜브 콘텐츠에도 적용**:
  - 분류(keyword_groups 매칭 → `matched_groups`/`matched_keywords`)를 유튜브 수집·처리 시 실행. 입력은 제목 + 채널명 + `summary_ko`(있으면). 
  - 엔티티 추출(`content_entities`)도 동일하게(뉴스 파이프라인 재사용).
  - **기존 유튜브 콘텐츠 백필**: 어드민 트리거 또는 크론에서 미분류 유튜브 row 재처리(sentiment/lgu-impact 백필과 같은 온디맨드 패턴).
- 재사용: 뉴스의 분류/엔티티 로직을 그대로 호출(신규 로직 최소화).

### 2-5. 카드·상세 해시태그 표시
- **유튜브 카드**(ContentCard 유튜브 그리드)에 뉴스처럼 **해시태그(matched_groups)** 노출 — 현재 유튜브 카드가 태그 미표시면 추가.
- **상세**: `contents/[id]`의 기존 **관련 엔티티 칩**·해시태그 렌더가 유튜브에도 적용됨(2-4로 데이터 채워지면 자동 표시).

### 2-6. 관련 기사 캐러셀 (대부분 자동)
- content 상세의 **기존 관련기사 캐러셀**(`FeedCarousel` + `getRelatedGrouped/getRelatedYoutube`, 뉴스/리서치/웹인사이트 유형별 가로 캐러셀)이 유튜브 상세에도 그대로 렌더됨 → **라우팅(2-1)만으로 대부분 충족**.
- 단 관련 매칭은 `matched_keywords`/엔티티 기반이라 **2-4(분류)가 돼야 의미 있게 채워짐**. 분류 후 유튜브 상세 하단에 관련 뉴스/리서치가 캐러셀로 노출.

### 2-3. CSP 확인 (임베드 허용)
- `next.config`·미들웨어·헤더에 **Content-Security-Policy `frame-src`** 가 있으면 **`https://www.youtube-nocookie.com`**(및 필요 시 `https://www.youtube.com`) 추가. 없으면 불필요.
- CSP가 iframe을 막으면 플레이어가 빈 화면이 되니 반드시 확인.

## 3. 회귀 가드
- 비유튜브 콘텐츠 상세 **불변**(유튜브 분기만 추가).
- 유튜브 카드 클릭 타깃만 외부→내부. "원문/YouTube에서 보기" 외부 링크는 폴백으로 유지(임베드 차단 영상·사용자 선택).
- `extractVideoId` 실패(잘못된 URL) 시 폴백 링크만 — 크래시 없음.
- 임베드는 `loading="lazy"` — 목록엔 임베드 없음(상세에서만), 성능 영향 최소.
- 프라이버시: youtube-nocookie + URL 파라미터에 개인정보 미포함.

## 4. 검증 (Sonnet)
- `npx tsc --noEmit` 0, `npx eslint` 0, `npm run build`.
- 유튜브 카드 클릭 → 새 탭 아님, `/dashboard/contents/[id]` 인앱 진입.
- 상세에서 임베드 플레이어 재생(youtube-nocookie), 전체화면 동작. CSP로 막히지 않음(실측).
- 임베드 차단 영상: "YouTube에서 보기" 폴백 노출.
- 비유튜브 상세 회귀 없음.

## 6. 참고
- 일부 영상은 게시자가 **임베드 비활성**(embedding disabled) → iframe이 "동영상 없음" 표시. 그 경우를 위해 폴백 링크 필수.
- 자동재생은 기본 끔(사용자 클릭 재생). 필요 시 `?autoplay=1`은 UX 논의 후.
