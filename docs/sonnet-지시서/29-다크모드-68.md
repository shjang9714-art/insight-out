## 전제 (이미 되어 있는 것)

`globals.css`에 `:root`(라이트)와 `.dark`(다크) OKLCH 토큰이 **완비**되어 있고, `@custom-variant dark (&:is(.dark *))`도 선언돼 있다. 즉 `.dark` 클래스가 `<html>`에 붙으면 토큰이 자동 전환된다. **남은 일은 (a) 클래스 토글 배선 + (b) 컴포넌트가 토큰을 쓰게 바꾸기**뿐이다.

## 1. ThemeProvider 배선

- 신규 `src/components/theme/ThemeProvider.tsx` (`'use client'`):
  ```tsx
  'use client'
  import { ThemeProvider as NextThemes } from 'next-themes'
  export function ThemeProvider({ children }: { children: React.ReactNode }) {
    return (
      <NextThemes attribute="class" defaultTheme="system" enableSystem disableTransitionOnChange>
        {children}
      </NextThemes>
    )
  }
  ```
- `src/app/layout.tsx`:
  - `<html lang="ko" ...>`에 **`suppressHydrationWarning`** 추가(next-themes 필수, FOUC/미스매치 방지).
  - `<body>` 내부를 `<ThemeProvider>{children}</ThemeProvider>`로 감싼다.
  - `attribute="class"` → `.dark` 클래스 전략(현재 CSS와 일치). `data-theme` 쓰지 말 것.

## 2. 테마 토글 — `src/components/theme/ThemeToggle.tsx` (`'use client'`)

- `useTheme()`(next-themes)로 `theme`/`setTheme` 사용. 마운트 전 렌더 가드(`mounted` state)로 hydration 미스매치 방지.
- lucide `Sun`/`Moon` 아이콘 토글 버튼. 클릭 시 `light`↔`dark` 토글(또는 system 포함 3-state는 선택). 헤더 버튼 톤은 기존 알림 버튼과 동일(`rounded-lg p-2 hover:bg-accent`).
- `DashboardHeader.tsx` 우측 영역(알림 버튼 옆)에 배치. 어드민 레이아웃 헤더에도 노출 권장.

## 3. 색상 토큰 스윕 (핵심 작업량)

현재 약 **41개 파일**에 라이트 전용 하드코딩 색상이 다수(`text-gray-400` 122회, `bg-white` 72회 등). 아래 **매핑 표**대로 일괄 치환 후 **파일별 육안 점검**. 무지성 전역 sed 금지 — 의미 맞는 토큰으로.

### 치환 매핑 (Tailwind 하드코딩 → 시맨틱 토큰)

| 하드코딩 | → 토큰 클래스 | 용도 |
|---|---|---|
| `bg-white` | `bg-background` (페이지) / `bg-card` (카드·패널·드롭다운) | 표면 |
| `bg-gray-50` | `bg-muted` / `bg-accent` | 옅은 표면·hover |
| `bg-gray-100` | `bg-muted` (hover는 `hover:bg-accent`) | hover/구분 |
| `bg-gray-200` | `bg-muted` / `bg-border` | 구분 |
| `text-gray-900` | `text-foreground` | 본문 강조 |
| `text-gray-800` / `-700` | `text-foreground` (약하면 `text-foreground/90`) | 본문 |
| `text-gray-600` / `-500` | `text-muted-foreground` | 보조 텍스트 |
| `text-gray-400` / `-300` | `text-muted-foreground` (더 옅게 `text-muted-foreground/70`) | 캡션·placeholder |
| `border-gray-50/100/200/300` | `border-border` | 모든 보더 |
| `divide-gray-*` | `divide-border` | 구분선 |
| `bg-black/50` 등 오버레이 | 유지(투명 오버레이는 OK) | 모달 |
| `brand-50/100/600/700` | **유지** | 브랜드 강조(양 테마 공통) |
| 카테고리 배지 색(`bg-purple-50 text-purple-700` 등 RecentFeed) | 유지하되 다크 대비 확인 — 필요 시 `dark:` 보강 | 배지 |

> 원칙: 페이지 최상위 배경=`bg-background`, 카드/패널/헤더/드롭다운=`bg-card`, 보조 텍스트=`text-muted-foreground`, 보더=`border-border`. hover 회색은 `hover:bg-accent`.

- 각 핵심 화면을 다크로 전환해 **가독성**(텍스트 대비), **보더 가시성**, **브랜드 핑크 위 텍스트 대비**, **배지 색** 확인.
