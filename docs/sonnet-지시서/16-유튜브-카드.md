## 0. 목표 (한 줄)
유튜브 페이지를 **mock → `youtube_videos` 실데이터**로 전환: 실제 썸네일·제목·채널명 카드 + 유튜브 외부 링크.

## 1. 데이터 (이미 존재)
- `youtube_videos`(`YoutubeVideoRow`): `video_id, title, channel_name, channel_id, thumbnail_url, published_at, view_count(보통 null), collected_at, ...`.
- `thumbnail_url` = `https://i.ytimg.com/vi/<videoId>/hqdefault.jpg`(수집 시 저장됨).
- RLS: `youtube_videos: 인증 사용자 조회` → 서버 client(쿠키) 로 조회 통과.
- **주의**: 유튜브는 서비스 태깅 대상이 아님 → **서비스별 필터는 v1 에서 제외**(전체 표시). (mock 의 `video.service`·뷰카운트 가짜값·그라데이션 썸네일은 버림)

## 2. 할 일

### 2.1 `src/app/dashboard/youtube/page.tsx` (mock → 실데이터, 서버 컴포넌트로 전환)
- `'use client'` 제거 → **서버 컴포넌트**. (`export const dynamic = 'force-dynamic'`, `metadata`)
- 서버 supabase client(쿠키, `contents/page.tsx` 패턴)로:
  ```ts
  const { data: videos } = await supabase
    .from('youtube_videos')
    .select('id, video_id, title, channel_name, thumbnail_url, published_at')
    .order('published_at', { ascending: false })
    .limit(60)
  ```
- 카드 그리드(반응형 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3` 등) 렌더, 각 카드:
  - **썸네일**: `<img src={thumbnail_url} alt={title} className="aspect-video w-full rounded-2xl object-cover" loading="lazy" />` (next/image 아닌 평범한 `<img>` — `next.config` 도메인 설정 불필요).
  - 제목(2줄 말줄임), 채널명, 발행일(KST).
  - 카드 전체를 **유튜브 외부 링크**로: `<a href={`https://www.youtube.com/watch?v=${video_id}`} target="_blank" rel="noopener noreferrer">`.
- **빈 상태**: 영상 없으면 "아직 수집된 유튜브 영상이 없습니다. (어드민에서 유튜브 채널 소스를 추가하세요)".
- 한국어 UI, AGENTS §9 토큰. mock(`YOUTUBE_VIDEOS`) import 제거.

### 2.2 `src/components/dashboard/YoutubeSection.tsx` (대시보드 위젯, 있으면)
- mock → `youtube_videos` 최근 `limit 6` 조회로 전환(서버 컴포넌트면 직접 조회, 아니면 props 로 받음). 동일 카드 스타일. 영상 없으면 섹션 숨김 또는 빈 상태.
