# 지시서 263 — 어드민 도움말 (정보 아이콘 + 서비스 연계 설명)

목표: 어드민의 각 기능에 **간단 설명 + 정보 아이콘(도움말)**을 붙인다. 도움말은 (1) 이 기능이 **무엇인지**, (2) **서비스(사용자) 화면과 어떻게 연계**되는지, (3) 어떻게 **관리·작성·운영**해야 하는지를 담는다. 설명이 없던 기능엔 한 줄 설명을, 상세는 정보 아이콘 팝오버로.

David 요청: 어드민 기능이 서비스 화면과 어떻게 연계되는지 설명 필요. 도움말 형태로.

범위: 재사용 `InfoHelp` 컴포넌트 + 어드민 섹션 헤더에 설명·아이콘. 도움말 문안(아래 제공). SQL 없음.

---

## 1. 구현

### 1-1. 재사용 컴포넌트 `InfoHelp`
- 아이콘(lucide `Info`/`HelpCircle`) 버튼 → 클릭/호버 시 **팝오버**(shadcn Popover/Tooltip)로 도움말 표시.
- props: `title?`, `children`(도움말 본문, 문단·리스트 허용). 접근성(aria-label "도움말").
- 어드민 톤(작은 회색 아이콘, 팝오버 max-w-xs~sm, 좌측/우측 자동 배치).

### 1-2. 배치
- 각 어드민 **섹션/카드 헤더 옆**(제목 오른쪽)에 `InfoHelp` + 필요 시 헤더 아래 **한 줄 설명**(muted).
- 대상 페이지: `/admin`(대시보드)·`/admin/insights`·`/admin/entities`·`/admin/briefings`·소스/키워드/키워드그룹/엔티티/뉴스레터 관리 등 어드민 컴포넌트 전반.
- 설명 없는 기능엔 **한 줄 설명 먼저**, 상세는 아이콘.

## 2. 도움말 문안 (기본 제공 — 그대로 사용, 이후 어드민/문서로 편집 가능)

각 항목: **[한 줄 설명] · 서비스 연계 · 운영 팁**.

- **인사이트 생성**(산업/헤드라인 카드): AI가 최근 기사에서 산업 인사이트 카드를 생성. → **AI 인사이트 탭의 "헤드라인 분석"**에 published로 노출. 운영: 기간 선택 후 생성, 근거 부족분은 draft로 남아 검토·승인 필요.
- **관심업체 카드 생성**(주요 기업): curated 회사별 최근 동향을 AI 카드로 생성. → **기업동향 > 주요 기업** 그룹별 카드·상세. 운영: 일 1회 자동+수동 트리거, 근거≥1이면 자동 published, 회사 목록은 큐레이션(아래) 관리.
- **논조 분석**(sentiment): 경쟁사 기사의 긍/중/부 논조 판정. → 내부 신호·정렬에 활용. 운영: 최근 미분석 기사 백필.
- **위기·기회 분석**(lgu_impact): 경쟁사 기사를 LG U+ 관점 위기/기회/관망으로 판정. → **경쟁사 동향(주간 리포트) 위기/기회 칩·타임라인**의 재료. 운영: 주기적 백필.
- **유튜브 태깅 백필**: 분류 없이 적재된 유튜브에 해시태그·엔티티 부여. → 유튜브 카드·상세의 **해시태그·관련 콘텐츠**. 운영: 신규는 자동, 기존은 버튼.
- **소스 관리**: 크롤 대상(뉴스/RSS/유튜브 채널) 등록·신뢰도(trust_tier). → 수집되는 **콘텐츠 전반**의 출처. 운영: 신뢰 소스는 tier 상향(게이트 완화).
- **키워드/키워드그룹 관리**: 매칭·태깅·관련도의 토대(include/exclude 패턴, search_seeds). → 콘텐츠 **해시태그·관련도·필터**, 크롤 키워드 수집. 운영: 노이즈는 exclude, 사업축은 그룹으로.
- **엔티티 관리**: 기업·기술·인물 정규화·병합, 경쟁사/그룹 지정. → **엔티티 칩·관계지도·경쟁사**. 운영: 중복 병합, 별칭 관리.
- **큐레이션 회사 관리**(curated_companies): 주요 기업·경쟁사 그룹·별칭 관리. → **주요 기업 7그룹·경쟁사 동향 5그룹**의 회사 목록. 운영: 회사 추가/그룹/별칭 편집(별칭이 기사 매칭 정확도 좌우).
- **프롬프트 관리**(llm_prompts): 생성 프롬프트를 코드 배포 없이 편집. → 회사 인사이트·주간 리포트 **생성 품질**. 운영: 톤·관점 조정, 한글 강제 유지.
- **모닝브리핑**: 매일 AI 브리핑 생성·승인·오디오(TTS). → **홈/브리핑** 노출. 운영: 생성→검토→공개, 오디오는 TTS 설정 필요.
- **번역/TTS 사용량**: 무료 한도 가드 모니터. 운영: 한도 근접 시 조정.

> 실제 화면에 존재하는 기능만 매칭해 붙이고, 목록에 없는 기능은 같은 형식(한 줄+연계+운영)으로 추가.
