## 작업 — `dashboard/ai-analysis/page.tsx` 위젯 추가 (서버 집계)

### 1. 집계(바운디드, SQL 없음)
- 기존 위젯 조회들과 병렬: `contents` published, `collected_at >= (오늘-13일 KST)`, select `matched_keywords`, limit 1000.
- JS: matched_keywords 펼쳐 **빈도 집계** → 상위 N(기본 30) 키워드(`{ name, count }`).
- 분류 join: 상위 키워드 이름으로 `keywords.select('name, is_competitor').in('name', names)` → `Set<경쟁사 이름>`(is_competitor=true). (대소문자: 매칭 안 되면 일반 처리, 무해.)
- 강조: 현재 사용자 `user_watchlist`(이미 93에서 조회 중이면 재사용) → `Set<업체명>`. 키워드명이 워치리스트 업체와 **대소문자 무시 일치 또는 포함**이면 강조.

### 2. 클라우드 렌더
- "키워드 맵" 섹션(아이콘 `Cloud` 또는 `Tags`). 범례: 경쟁사 / 관심업체 / 일반.
- 각 키워드: **글자 크기 ∝ 빈도**(예: 12~24px 정규화, `Math.round`), 색:
  - 워치리스트 매칭 → 브랜드 강조(`text-brand-600 font-semibold` + 미세 배경/ring) **우선**.
  - 경쟁사 → 빨강 계열(토큰).
  - 그 외 → 중립(`text-muted-foreground`).
- **클릭 → 검색 드릴**: `Link href={/dashboard/search?q=${encodeURIComponent(name)}}`. (타임라인은 후속.)
- 데이터 0이면 위젯 숨김/안내.

### 3. 배치/성능
- 14일·limit 1000 바운디드, `matched_keywords`만 select. 기존 page 쿼리들과 `Promise.all` 통합. keywords join 1회(in names).

## 회귀 / 주의
- DB·SQL 무변경. 대용량 시 집계 RPC 이관 후속(74/91 동일 메모).
