# 지시서 225 — 관심기업 마스터검색 + 엔티티 FK + 필터 교정

목표: 관심기업(watchlist)을 **자유텍스트 → 엔티티 연결**로 승격한다. (1) 기업 **마스터 검색·자동완성**(entities), (2) **수동 입력**(미매칭 허용), (3) **공유 설정 모달**(마이페이지 + 기업동향 인탭), (4) **콘텐츠 필터를 엔티티 기준으로 교정**(문자열 폴백).

David 결정: **A/C 조합** — entities(entity_type='company')를 마스터로, 없으면 수동 자유텍스트(entity_id null). DART 등 외부 임포트(B)는 미채택.

범위: `225-watchlist-entity-fk.sql`(수희) + 검색 API + 공유 모달 컴포넌트 + 마이페이지/기업동향 통합 + 필터 교정. 42703 graceful.

---

## 1. 현행 진단 (검증된 코드 사실)
- `user_watchlist(user_id, company text, ...)` — **자유텍스트**, 엔티티 연결 없음. unique(user_id, lower(company)).
- 관심기업 필터: `entities/page.tsx`(watchlist 뷰)·`AiInsightsView`·`lens.ts`가 `isWatched(name)` = 워치리스트 문자열 부분매칭. **부정확.**
- 마이페이지 `dashboard/mypage/page.tsx`가 워치리스트 add/remove(자유텍스트 입력).
- 225 SQL로 `entity_id` FK 추가 + 기존행 name/alias 매칭 백필.

## 2. 구현

### 2-1. 기업 검색 API (`/api/entities/search`)
- `GET ?q=&type=company` → `entities`(entity_type='company') `canonical_name ilike %q%` OR `entity_aliases.alias ilike %q%` → 상위 10건 `{ id, canonical_name }`(중복 제거). 인증 사용자 접근. 짧은 q(<1자) 빈 배열.

### 2-2. 공유 컴포넌트 `WatchlistSettingsModal`(신규)
- **검색 인풋**(디바운스 250ms) → `/api/entities/search` → **자동완성 드롭다운**(회사명). 선택 시 `user_watchlist` insert `{ company: canonical_name, entity_id }`.
- **수동 입력**: 결과에 없으면 "‘{입력값}’ 직접 추가" → insert `{ company: 입력값, entity_id: null }`(엔티티 생성은 admin 권한이라 미생성 — 문자열 폴백으로 동작).
- **현재 목록**: 워치리스트 칩/행 + 삭제. entity_id 있으면 연결 배지(작게).
- 저장 후 **리프레시**(router.refresh 또는 콜백) — 호출부가 갱신 반영.
- 본인 RLS(user_watchlist 본인 관리)로 동작. 중복(lower(company)) 시 무시/토스트.

### 2-3. 통합 — 마이페이지 + 기업동향 인탭
- **마이페이지**: 기존 워치리스트 입력 UI를 `WatchlistSettingsModal`(또는 인라인 패널)로 교체.
- **기업동향 관심기업 탭**(`entities/page.tsx` watchlist 뷰): 상단에 **"관심기업 설정" 버튼** → 같은 모달. 빈 상태(관심기업 0)에서도 이 버튼으로 바로 추가. (지금은 마이페이지로 링크만 → 인탭 설정으로 개선)

### 2-4. 필터 교정 (엔티티 기준, 문자열 폴백)
- 워치리스트 로드 시 `entity_id`도 함께 조회 → **watchedEntityIds**(non-null) + **watchedNames**(전체, 폴백).
- **콘텐츠/관심 매칭**:
  - 엔티티 링크 있는 콘텐츠는 `content_entities.entity_id ∈ watchedEntityIds`로 **정확 매칭**(우선).
  - entity_id 없는 워치항목·엔티티 미링크 콘텐츠는 기존 `isWatched(name)` **문자열 폴백**.
- v1 적용 범위: **기업동향 관심기업 탭**(company insight_cards 매칭은 topic 문자열 유지하되, 가능한 곳부터) + **콘텐츠 목록 '내 관심기업' 필터/렌즈**(content_entities 기준). `lens.ts` watch 렌즈에 entityIds 전달.
- **후속**: AiInsightsView·전 렌즈의 완전 엔티티화는 점진(이번엔 entity_id 우선·문자열 폴백까지).

## 3. 회귀 가드
- `company` 텍스트 유지 → 기존 표시·문자열 폴백 불변. entity_id는 **추가 신호**(있으면 정확, 없으면 기존과 동일).
- 225 SQL 미적용(entity_id 컬럼 없음, 42703) 시: 검색/추가는 company만 insert(entity_id 생략), 필터는 문자열 폴백 → **크래시 없이 기존 동작**. 코드 선배포 안전.
- 검색 API 빈 결과·짧은 q graceful.
- 수동 입력(entity_id null)도 정상 저장·문자열 매칭.
- RLS 본인 관리 유지.
