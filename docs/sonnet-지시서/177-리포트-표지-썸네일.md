## 0. 한 줄

리포트 **PDF의 1페이지(표지)를 클라이언트 pdf.js로 렌더 → 공개 버킷에 이미지로 저장 → `contents.thumbnail_url`에 세팅**하고, 콘텐츠 리스트 쿼리·카드에 `thumbnail_url`을 배선해 **리포트 카드에 표지가 보이게** 한다. PDF만(PPTX/DOCX 후속), 실패해도 업로드는 성공.

## 1. 현행 진단 (검증된 코드 사실)

- `contents.thumbnail_url` 컬럼 **존재**(`types.ts:151·188`). 카드 `ContentCard`는 `thumbnailUrl` 있으면 16:9 이미지 레이아웃 렌더(없으면 컴팩트/그라디언트).
- **그러나 콘텐츠 리스트 쿼리(`app/dashboard/contents/page.tsx`)가 `thumbnail_url`을 select 하지 않음** → 카드에 thumbnail 미전달 → 리포트는 항상 그라디언트. **배선 필요.**
- 업로드: `ReportUploadForm` → `/api/admin/upload`(service_role, `reports` 버킷 서명 업로드 URL 발급) → 클라 `uploadToSignedUrl('reports', …)` → `contents` insert(`file_path`) → PDF면 `/api/admin/contents/{id}/extract`(본문 추출) 호출.
- `reports` 버킷은 **비공개**(접근은 `report-url.ts`가 서명 URL 생성). 공개 URL 패턴은 `briefings` 버킷이 `getPublicUrl` 사용(공개).
- **pdfjs 미설치**.

## 2. DB / 인프라 핸드오프

- **SQL 없음**(thumbnail_url 컬럼 기존).
- **핸드오프 ①(수희/인프라): 공개 스토리지 버킷 `report-covers` 생성**(public read). 표지 이미지 전용. (없으면 표지 단계만 graceful 실패, 업로드·본문추출은 정상.)
- **핸드오프 ②(의존성): `pdfjs-dist` 추가**(`npm i pdfjs-dist`). 클라이언트 렌더용.

## 3. 구현

### 3-1. 표지 렌더 유틸 — `src/lib/contents/pdf-cover.ts` (신규, 클라)
- `renderPdfCover(file: File): Promise<Blob | null>`:
  - `pdfjs-dist` 동적 import, `workerSrc` 설정(cdnjs 또는 번들 워커).
  - 1페이지 로드 → 적정 스케일로 canvas 렌더(가로 ~480px 다운스케일) → `canvas.toBlob('image/webp'|'image/png', 0.8)`.
  - 예외 시 `null`(호출부 graceful).

### 3-2. 표지 업로드 경로 — `/api/admin/upload` 확장(또는 신규 `/api/admin/upload-cover`)
- 요청에 `kind:'cover'`(또는 별 라우트) → **`report-covers` 공개 버킷**의 서명 업로드 URL·storagePath 발급(파일명 `{contentId}.webp` 권장).
- service_role·admin 확인은 기존 로직 재사용.

### 3-3. `ReportUploadForm` — 표지 생성·업로드·세팅
콘텐츠 insert(contentId 확보) 이후, PDF일 때(본문 추출과 병행 가능):
1. `const coverBlob = await renderPdfCover(file)` (null이면 건너뜀).
2. cover 서명 URL 발급 → `uploadToSignedUrl('report-covers', path, coverBlob)`.
3. 공개 URL: `supabase.storage.from('report-covers').getPublicUrl(path)`.
4. `await supabase.from('contents').update({ thumbnail_url: publicUrl }).eq('id', contentId)`.
- **모든 단계 graceful**: 실패해도 업로드 성공 유지(본문 추출과 동일 톤). 표지 실패는 조용히 로그.
- 진행 표시(선택): "표지 생성 중" 미세 상태.

### 3-4. 콘텐츠 리스트 배선 — `app/dashboard/contents/page.tsx` + 카드
- select 에 **`thumbnail_url` 추가**(현재 미포함).
- `ContentListCard`/`ContentCard` 에 `thumbnailUrl={item.thumbnail_url}` 전달(카드는 이미 지원 — prop 배선만).
- 리포트 외 카테고리도 thumbnail_url 있으면 자연 표시(무해).

### 3-5. 표지 표시 톤(카드)
- 표지가 붙은 리포트 카드가 그리드에서 과하게 튀지 않게: 기존 16:9 썸네일 레이아웃 그대로 사용(별도 강조 X). 표지 없는 리포트는 기존 그라디언트/컴팩트 유지(혼재 자연스럽게).
