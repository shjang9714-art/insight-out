## 배경 (David)
사용자 피드는 발행순(`published_at`, 리포트만 `collected_at`)인데, **수집된 시간 순(collected_at)으로 보기**와 **일별로 묶어 보기**가 필요. 비파괴 — 기본 동작은 유지하고 토글로 추가.

## 작업 — `src/app/dashboard/contents/page.tsx`

### 1. 정렬 모드 (④) — URL 파라미터 `sort`
- `const sort = (searchParams.get('sort') ?? 'published') as 'published' | 'collected'`.
- `const sortByCollected = sort === 'collected' || isReportCategory` (리포트/AI보고서는 기존대로 항상 수집순).
- **쿼리 정렬**(288~290) 교체:
  ```ts
  q = sortByCollected
    ? q.order('collected_at', { ascending: false })
    : q.order('published_at', { ascending: false, nullsFirst: false })
  ```
- **날짜 필터 기준**(300~301): 정렬 기준과 일치시킴.
  ```ts
  const dateStart = getDateStart(date)
  if (dateStart) q = q.gte(sortByCollected ? 'collected_at' : 'published_at', dateStart)
  ```
- **JS 클러스터/최종 정렬**(337~356): `published_at` 기준을 `sortByCollected ? collected_at : published_at` 로(헬퍼 `basisTime(item)` 추출해 양쪽 적용).
- **displayDate**(91~95): `sortByCollected` 일 때 collected_at 표시. (시그니처에 인자 추가하거나 컴포넌트에서 분기.)

### 2. 정렬 토글 UI
- 기존 필터/뷰 토글 영역(카드/리스트 `contentView` 근처)에 **세그먼트 토글 "발행순 | 수집순"** 추가. 클릭 시 다른 필터처럼 `sort` 쿼리 갱신(router.push, 기존 파라미터 보존, page 1 리셋). 활성 스타일은 토큰/brand(#9).

### 3. 일별 묶음 보기 (⑥) — 로컬 토글 + 날짜 헤더
- 로컬 상태 `const [groupByDay, setGroupByDay] = useState(false)` (뷰 선호 → URL 불필요, contentView 와 동일 패턴).
- 토글 버튼 "일별로 보기"(뷰 토글 옆). 기본 off = 기존 평면 리스트.
- on 일 때: `clusteredItems` 를 **기준 날짜(KST)별 세그먼트**로 묶어 렌더.
  - 기준 날짜 = `sortByCollected ? item.collected_at : (displayDate 기준)`.
  - 헬퍼 `groupByKstDay(clusteredItems)` → `[{ key:'YYYY-MM-DD', label, items }]`. 이미 정렬돼 있으니 연속 그룹화.
  - 라벨: 오늘 / 어제 / 그 외 `M월 D일`(KST, `Asia/Seoul`).
  - 렌더: 각 세그먼트마다 **날짜 헤더**(작은 sticky 헤더, `text-sm font-semibold text-muted-foreground`) + 그 아래 기존 카드/리스트 렌더(현 `contentView` 유지). 즉 카드뷰·리스트뷰 둘 다에서 일별 헤더가 끼어듦.
- off 일 때 기존 렌더(588~640) 그대로.

### 4. 빈/로딩 상태
- 일별 보기에서도 빈 상태·더보기(`hasMore`)·무한로딩 동작 유지(그룹화는 누적 `items` 기준이라 페이지 증가 시 세그먼트 자연 확장).

## 회귀 / 주의
- DB 무변경. 기본값(sort=published, groupByDay=off)은 **현 동작과 동일**.
- `collected_at` 은 not null → 수집순/일별 날짜 누락 없음. `published_at` null 행은 발행순에서 기존대로 뒤(nullsFirst:false).
- 리포트/AI보고서는 발행순 선택해도 collected_at 유지(기존 지시서 70 규칙 보존).
- 클러스터(지시서 69) 대표 선정·접힘 동작 불변 — 정렬 기준만 basisTime 으로.
- 카드/리스트 토글, 카테고리·서비스·소스·관련도·날짜 필터 전부 기존대로 공존.
- `'use client'` 유지. UI 한국어(#1)·토큰 색(#9).
