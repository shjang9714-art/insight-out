## 0. 한 줄
"탭 이동에도 오디오 지속"은 **이미 된다**(전역 셸). 문제는 **카드를 닫으면 정지**하는 것 — 재생을 open/close와 분리해 **축소 상태(하단 미니 바)에서도 이어지게** 한다.

---

## 1. 착수 전 확인 (직접 확인 2026-07-22) — 계획이 바뀜

**원래 M-3 계획은 "전역 Context 신규(EnrichJobs 패턴)"였으나, 확인 결과 불필요.**

- `FloatingBriefingMini` 는 이미 `DashboardShell`(전역 셸)에 마운트돼 있다. App Router 레이아웃은 **라우트 이동 시 재실행되지 않으므로** 이 컴포넌트는 언마운트되지 않는다 → **탭 이동에도 오디오·상태 지속(이미 동작).**
- `new Audio()` 를 `audioRef` 로 관리, `preload='none'`(391) 등 재생 로직 완비.

**🔴 진짜 갭 — 카드를 닫으면 오디오가 멈춘다:**
```ts
// FloatingBriefingMini.tsx — 플레이어 닫힐 때 오디오 정지
useEffect(() => {
  if (!open && audioRef.current) { audioRef.current.pause(); setPlaying(false) }
}, [open])
```
- UI 는 우하단 **iPod nano 카드**(`open` 시 펼침). 재생하려면 카드를 펼쳐 둬야 하고, **닫으면 정지**한다.
- 프로토타입 §3 은 **재생 중이면 축소돼도(하단 미니 바) 지속** — 화면 가리지 않고 오디오만 흐름(출근길 유스케이스). **이게 빠져 있다.**

## 2. 구현

### 2.1 재생과 open/close 분리
- **`[open]` 의 "닫히면 정지"를 제거**한다. 카드를 닫아도 오디오는 계속 흐른다.
- 대신 **재생 중(`playing`)이면 축소 상태에서 "미니 바"** 를 보여준다. 정지 상태로 닫으면 기존처럼 접힌 진입 버튼만.

### 2.2 축소 미니 바 (재생 중 & 카드 닫힘)
- 위치: 하단, **하단 탭바(411) 위**(`bottom-[calc(4rem+…+safe-area)] md:bottom-6` — 미니 카드와 같은 기준, 411에서 이미 적용).
- 내용(작게): 브리핑 제목(1줄 말줄임) · **재생/일시정지 버튼** · 진행 바(얇게) · 펼치기(탭하면 카드 open) · 완전 정지·닫기(×).
- 데스크톱: 우하단 유지(현재 카드 위치). 모바일: 탭바 위 폭 맞춤 바 or 우하단 컴팩트 — **둘 중 프로토타입에 가까운 쪽**(하단 바)을 택하되 탭바와 안 겹치게.

### 2.3 완전 종료 경로
- 미니 바의 `×` 는 **오디오 정지 + 미니 바 숨김**(현재 카드 닫기와 별개 — 사용자가 명시적으로 끝냄).
- `ended`(재생 끝)면 자동으로 미니 바 숨김(기존 `ended` 핸들러가 `setPlaying(false)` 하므로 조건에 반영).

### 2.4 하지 말 것
- **오디오 생성·`preload='none'`(391)·`briefing` 조회 로직 무수정.** 재생 파이프라인 그대로.
- `DashboardShell` 마운트 위치 무변경(이미 전역).
- **전역 Context 새로 만들지 않는다**(§1 — 이미 전역 셸이라 불필요).
- 411 하단 탭바·`FloatingBriefingMini` 위치 기준(411) 무너뜨리지 않기.
- 데스크톱 우하단 카드 동작 회귀 금지.

## 3. 회귀 가드
1. 재생 시작 → **다른 탭으로 이동해도 오디오 지속**(이미 되던 것 — 회귀 금지).
2. **카드를 닫아도(축소) 오디오가 계속 재생**된다(이번 핵심).
3. 축소 시 **하단 미니 바**(제목·재생/일시정지·진행)가 하단 탭바 **위**에 뜬다.
4. 미니 바 탭 → 카드 펼침, 재생 상태 유지.
5. 미니 바 `×` → **오디오 정지 + 미니 바 사라짐.**
6. 재생 끝(`ended`) → 미니 바 자동 사라짐, 진행 0.
7. 하단 탭바·본문과 안 겹친다.
8. **데스크톱**: 우하단 카드 동작 기존과 동일(회귀 없음).
9. `preload='none'` 유지 — 재생 전 자동 다운로드 없음(391 회귀 금지).
