## 등록 절차
1. `/admin/sources` → 추가 → 유형 **오피니언**, 이름·`rss_url` 입력, **수집주기 10080분(7일)**, 활성.
2. "지금 수집" → 수집되면 유효 / 0건·에러면 🟡(피드 URL 점검) 또는 비활성.
3. 수집분은 **오피니언 카테고리**에 노출(영문은 번역 병기).
