# 화면 개편 마스터플랜 + 디자인 가이드 (웹 · 모바일 · 어드민)

**일자:** 2026-06-19 · **근거:** 페르소나 회의(9명) + 벤치마킹 갭(B1~B6)
**원칙(한 줄):** 홈은 *"오늘 알아야 할 한 가지 + 의미 + 다음 행동"*, 검색/질문을 1급 진입점, 워치리스트가 경험을 구동, 리스트→인사이트, 어드민은 매일 쓰는 3가지를 앞으로.

---

## 1. 웹(데스크톱) 화면별 개편 + 맞물린 기능

### 1.1 홈 — 가장 큰 변화
**레이아웃(위→아래):**
1. **"무엇이든 물어보기" 검색바**(상단 1급) — 지금은 기존 검색, 추후 생성형(B1) 연결.
2. **오늘의 요약 히어로** — 핵심 신호 3~5개(급상승 이슈·경쟁사 변화·논조 악화 선별) + 각 *시사점 한 줄* + *액션*(추적/보고서/공유).
3. **내 워치리스트 피드** — 담당 서비스·관심업체 기준.
4. **경쟁사 동향**(내 관점 태깅).
- 상단에 **개인화 토글**(전체 ↔ 내 서비스).

**맞물린 기능 점검:** 오늘의 요약 = 이슈(101)+논조(96)+급상승(104) 통합 집계 / 개인화 필터(user_services·watchlist) / 신호→액션 / 검색바(B1 전엔 기존).

### 1.2 AI 분석 (단일 스크롤, 111·113 유지)
- 각 섹션 **액션 활성**(보고서로·배틀카드 = 118 워크벤치 연결).
- **시계열 추이 미니차트**(B6) — 이슈/키워드 언급량·논조 추세.

### 1.3 이슈
- 보드(급상승·논조) → 상세(타임라인·엔티티·유사이슈). **"추적" = 알림 등록(B2).**

### 1.4 지식그래프
- ego(116·117) 유지, **검색 중심 진입**(엔티티 검색 → 중심).

### 1.5 전략보고서
- 워크벤치(118) → 뷰어. **"AI로 다듬기"**(키 확보 후).

### 1.6 엔티티 스마트 요약 (B3 — 신규 격상, 차별화 핵심)
- 엔티티 상세(102)를 *목록*에서 **요약 중심**으로: 최근 동향 요약 + **논조/언급량 추이** + 관련 이슈·문서. ("LG유플러스를 누르면 한 장 브리핑.")

## 2. 모바일 화면

- **단일 컬럼**, **오늘의 요약을 최상단**(데스크톱과 우선순위 동일, 더 압축).
- 뜨는 토픽·신호 = **가로 스크롤 carousel**.
- **하단 탭바**(홈 · 이슈 · 검색 · 보고서 · 마이) — 좌측 사이드바 대체. **검색을 중앙 1급**.
- 터치 타깃 ≥ 44px, 본문 ≥ 14px, 카드 정보 3요소 이내.
- **지식그래프는 모바일에서 간소화**(ego 노드 수 축소) 또는 목록 폴백 — 캔버스 그래프는 모바일 부담.
- 표·다열 위젯은 **세로 스택**으로 자동 폴백(이미 auto-fit 적용분 점검).

## 3. 어드민 개편

- **진입 = "오늘 할 일"**: 검토 대기 N · 오늘 수집 결과 · 실패/오류를 최상단 카드로.
- **매일 쓰는 3가지 상단 고정**: 콘텐츠 검토 / 이슈·인사이트 관리 / 크롤링 현황.
- **운영 신호등**(74 대시보드 확장): 수집·LLM·번역 사용량/한도 · **시드/데이터 점등 상태 가시화**(지금은 SQL로만 확인).
- **네비 그룹 정리 + 메뉴 검색**(15+ 메뉴).
- **콘텐츠 본문 편집**(body_original) · 컴포넌트 표준화(목록·필터·빈상태).

## 4. 디자인 가이드 — 시인성 · 가독성

> 스택: Tailwind v4(@theme) · shadcn(radix-nova) · 의미 토큰. 하드코딩 색 금지(AGENTS #9). 아래는 *원칙+권장값*.

### 4.1 타이포그래피
- 본문 **15~16px**, **line-height 1.6~1.7**(한글은 1.7 권장 — 자간·행간 넉넉히).
- 위계: h1 20 / h2 16~18 / h3 14~15. weight는 **400/500/600 세 단계만**.
- **최소 12px**(메타·캡션). 그 이하 금지.
- 강조는 **굵기·위치**로, 색 남발 금지. 숫자(KPI)는 tabular-nums.

### 4.2 색 · 대비
- 의미 색 **최소화**: 긍정 emerald / 부정 red / 중립 muted / **브랜드 brand-600은 CTA·핵심 강조에만**.
- 텍스트 대비 **WCAG AA**(본문 4.5:1, 큰 글씨 3:1) — `muted-foreground`가 너무 흐려 안 보이는 것 점검.
- **다크모드 양립** 필수(토큰 사용). 캔버스(그래프)는 라이트/다크 hex 분기.
- 배지: 한 카드에 **색 배지 2개 이내**(과하면 노이즈).

### 4.3 위계 · 여백
- **한 화면에 주인공 1개**(히어로). 나머지는 시각 비중 종속(크기·색·여백 차등).
- 섹션 간 **32~40px**, 카드 간 **16~24px**, 카드 패딩 **16~20px**.
- 경계 = **0.5px border-tertiary**, **그림자 지양**(flat). 라운드 카드 `rounded-lg/xl`.

### 4.4 밀도 · 스캔성
- 리스트 항목 = **제목 + 신호 배지 + 1줄 메타** 3요소 제한.
- 모든 섹션 **헤더 패턴 통일**: `아이콘 + 제목 + 목적 한 줄 + (액션)`.
- **빈 상태는 항상 "무엇을 하면 채워지는지"** 안내(휑한 화면 금지).

### 4.5 일관성(컴포넌트 표준)
- 논조/급상승/카테고리 **배지 색·모양 전 화면 통일**.
- 목록행·필터칩·빈상태·섹션헤더 **공통 컴포넌트화**(유지보수·일관성).

## 5. 그래서 무엇을 — 실행 순서 (제언)

| 순서 | 작업 | 비고 |
|---|---|---|
| 0 | **데이터 점등 검증**(수희 진단·SQL·백필) | **선행** — 빈 데이터에선 개편 효과 측정 불가 |
| 1 | **디자인 가이드 토큰화** — globals.css 타입·간격·배지 정리 | 전 화면 공통 기반 |
| 2 | **홈 "오늘의 요약" 히어로 + 개인화 토글** | 가장 큰 체감 |
| 3 | **엔티티 스마트 요약(B3)** + **워치리스트 알림(B2)** | LLM 약해도 가능·차별화 |
| 4 | **모바일 하단탭 + 오늘의 요약 우선** | 모바일 사용성 |
| 5 | **어드민 "오늘 할 일" + 운영 신호등** | 운영 효율 |
| 6 | (LLM 키 후) **생성형 검색(B1/B4)** · AI 다듬기 | 본격 차별화 |

> 즉, **데이터 점등(0) → 디자인 토큰화(1) → 홈 히어로(2)** 가 출발점. 그 뒤 B3/B2로 차별화, 모바일·어드민 정리, 마지막에 생성형 검색.
