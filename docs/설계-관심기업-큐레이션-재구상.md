## 1. 진단 (코드 확인)

### 1-1. 왜 추가해도 안 뜨나 / 바로 안 보이나
`generateCompanyInsightCards`(`lib/insight/generate.ts`) 사실:
- **cron(ai-refresh) 배치 전용 — 온디맨드 생성 없음.** 관심기업 추가해도 **다음 cron까지 카드 없음.** → 바로 안 보임(현재 답: **No**).
- **`minArticles=2` 게이트**: 최근 7일 내 그 회사명이 title/summary에 ilike 매칭되는 기사가 2건 미만이면 **스킵**(카드 안 생김).
- **`maxCompanies=15` 캡**: 워치리스트 인기순 top15만 생성. 니치 회사는 누락.
- **이름 ilike 매칭**: 워치리스트 회사명이 기사 표기와 다르면 매칭 실패.
- → 삼성전자는 기사 충분·매칭돼 카드 있음. 방금 추가한 회사는 위 4중 관문에 걸려 **안 뜸.**

### 1-2. 왜 영어로 나오나
`COMPANY_SYSTEM_PROMPT`가 한국어로 쓰였지만 **"반드시 한국어로 출력" 명시가 없음.** + 238로 **sambanova(Llama)·mistral**이 라우팅에 들어오며, 한국어 약한 provider가 implication을 **영어로 생성**(스크린샷의 "LG U+ B2B must view Samsung's..."). → 프롬프트에 **한국어 강제** + 한국어 강한 provider 우선 필요.

## 2. 재설계 — Part 5(큐레이션 칩) 채택 = 위 문제 근본 해결 (강력 추천)

David의 5번 제안이 1-1의 모든 관문을 없앤다:
- **주요기업 큐레이션 테이블**(`curated_companies`): LG U+ 관련 주요기업 20~40개 선제 등록(경쟁사·키어카운트·빅테크·반도체 등). 어드민 관리.
- **주기 생성(쌓기)**: 큐레이션 회사만 주 1회(또는 일 1회) cron으로 카드 생성·누적. 데이터가 **항상 존재**.
- **사용자 = 라벨칩 선택**: 자유 입력 대신 **우리가 제공하는 회사 칩 중 선택**(내 관심기업으로 담기). 선택 즉시 **이미 생성된 카드가 바로 보임**(온디맨드 생성·빈상태 없음).
- 효과: 즉시 노출 · 품질/커버리지 보장 · 비용 통제(고정 N개사만 생성) · 영어/누락 문제 소멸.
- (선택) 자유 입력 회사는 "요청" 형태로 받아 어드민이 큐레이션에 추가하는 흐름(하이브리드).

**내 의견: 채택 강력 추천.** 자유 워치리스트는 "즉시성·품질·비용"이 다 깨지는데, 큐레이션+칩은 셋 다 해결하고 MI 툴 성격(선별된 대상 심층 추적)에도 맞음.

## 4. 생성 프롬프트 — 한글 강제 + 어드민 편집

```
당신은 LG U+ B2B 시장 인텔리전스 분석가다. 주어진 한 기업 관련 최근 기사들을 종합해

**반드시 한국어로만 작성한다. 영어 문장·영어 단어 나열 금지(고유명사 제외).**
출력(JSON):
- card_headline: 읽고 싶게 만드는 에디토리얼 헤드라인(공백포함 24자 내외, 구체 수치·주체·변화폭, 사실 기반, 낚시·물음표 남용 금지).

```
