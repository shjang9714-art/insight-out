## 1. 기사 풀본문 채우기 (지시서 129) — `/admin/contents`

- [ ] "본문 보강" 버튼이 **"기사 풀본문 채우기"** 라벨로 보임 (강력 새로고침 Cmd+Shift+R)
- [ ] **기간 프리셋**(전체/7일/30일) 드롭다운 동작, 기본 최근 30일
- [ ] 한 번 클릭 → **자동 반복 드레인** + 진행률("누적 처리 N · 개선 M · 실패 K · 남은 R") 실시간 갱신
- [ ] 진행 중 **"중단"** 버튼으로 멈춤
- [ ] (야간) 새벽 4시 cron(`/api/cron/body-backfill`) 후 remaining 감소 — 다음 날 확인

## 2. 본문 상태 배지·필터·선택 채우기 (지시서 130) — `/admin/contents`

- [ ] 목록에 **"본문" 컬럼** 배지 표시 (SQL 전=처리됨/미시도, SQL 후=풀본문/스니펫/미시도)
- [ ] **"본문 상태" 필터**(전체/풀본문/스니펫/미시도) — 전 페이지 관통 (풀본문·스니펫은 130 SQL 후 활성)
- [ ] 행 다중선택 → **"선택 풀본문 채우기"** (50건/회, 실패건도 강제 재시도) → 완료 후 목록 갱신

## 3. 이슈 상세 = 증거 + AI 브리핑 (지시서 131) — `/dashboard/issues/[id]`

SQL 불필요(지금 바로):
- [ ] **신호 구성** 섹션(경쟁사동향·규제·투자M&A 등 건수) + 타임라인 행 **신호 배지**
- [ ] **논조 시계열 추세** 차트 + 개선/악화/유지 방향 라벨
- [ ] **근거 드릴다운** — facet 칩(카테고리/논조/신호) 클릭 → 목록 필터

131 SQL 후:
- [ ] 어드민 이슈 관리에서 이슈 **"AI 브리핑 생성"** 클릭 → 생성
- [ ] 이슈 상세 상단 **"AI 브리핑"** 섹션(현황/동인/논조/시사점 + 근거 칩) 표시

## 4. 렌즈 개인화 (지시서 132) — 이슈 / 기업 / AI인사이트

- [ ] **마이페이지**에서 담당 서비스 + 관심 기업(워치리스트) 설정
- [ ] 이슈/기업/AI인사이트 상단 **렌즈 스위처**(내 담당 / 경쟁사 워치 / 전체) 표시
- [ ] 렌즈 전환 → 세 화면 **즉시 재필터**(재로딩 없이) + **"내 관련" 배지**
- [ ] 세 화면 간 **선택 유지**(localStorage 공유)
- [ ] **`전체` 렌즈 = 기존과 동일**(회귀 0), 담당/워치 미설정 시 해당 칩 **비활성**

## 5. 인사이트 카드뉴스 (지시서 133) — `/dashboard/ai-analysis`

- [ ] 상단 **"카드뉴스 / 분석" 토글**, 기본 **카드뉴스**
- [ ] 카드뉴스 = **큰 글자 헤드라인** 1열 에디토리얼 카드(키커·시사점·근거 펼치기·보고서 보조링크)
- [ ] **"근거 N" 펼치기** 동작(키보드/aria 포함)
- [ ] **"분석" 토글 = 기존 그리드 그대로**(회귀 0)
- [ ] 토글 선택 **localStorage 영속**, 렌즈 전환과 함께 동작
