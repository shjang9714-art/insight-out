- **David ≠ Supabase 권한**. SQL 은 항상 수희가 실행. 코드 머지(PR)와 Supabase 반영은 **별개 경로**.
- **검증은 보고를 믿지 말고 재현**: SQL 은 `pip install --only-binary :all: pglast` 후 `pglast.parse_sql`. Mermaid 는 jsdom+mermaid 로 `mermaid.parse`. (둘 다 이번 세션에서 사용함)
- **샌드박스 한계**: 마운트가 파일 **삭제(unlink) 차단** → `git`/`rm` 이 샌드박스에서 실패할 수 있음(`.git/index.lock` 제거 불가). **커밋·푸시·삭제는 David 가 본인 터미널에서**.
- **파비콘 "안 바뀜"**: 거의 항상 (1) stale `.next`(→ `rm -rf .next && npm run build`) (2) 브라우저 파비콘 캐시(→ 시크릿 창). 파일은 멀쩡한 경우가 많음.
- **AskUserQuestion 응답이 비어 오는 경우** 잦음 → David 의 "그냥 가" 기조에 맞춰 합리적 기본값으로 진행하되, 진짜 분기(아키텍처 등)는 명시적으로 한 번 더 물어볼 것.
- **Next.js 16 (Turbopack)**: 훈련데이터와 다를 수 있음 — `node_modules/next/dist/docs/` 우선 참고 (AGENTS).
