## 작업 방식 (이 트랙 표준)
- **Opus = plan 모드, 계획 + 검증** 담당. 지시서(`docs/sonnet-지시서/NN.md`)로 작업 분해, 구현 결과 재현 검증.
- **Sonnet = 구현** 담당. tsc/build/lint 통과 후 보고 → Opus 검증 통과 시 커밋·푸시·`/api/version` 배포확인.
- **SQL 변경**은 `docs/sql-handoff/NN.sql` 로 분리해 먼저 푸시 → **수희가 Supabase에서 실행**(David는 Vercel 대시보드/Supabase 직접 적용 권한 없음 → 배포확인은 `/api/version`).
- 코드는 항상 "SQL 미적용/키 미설정 상태에서도 안 깨지게"(graceful degradation) 설계.
