## 2. 통합 스키마 (curated_companies + curated_groups)

### `curated_groups` — 그룹 정의(노출 방식 포함)
```
key text pk            -- telecom/aidc/cloud_ai/si_dx/security (+관심기업용 그룹)
label text             -- '통신 B2B 경쟁'
kind text              -- 'competitor' | 'watchlist'
display_mode text      -- 'always' | 'on_issue'
sort_order int
is_active boolean
```

### `curated_companies` — 회사(다중 그룹·별칭)
```
id uuid pk
name text unique       -- 대표 표기(예: 'SK텔레콤')
aliases text[]         -- ['SKT','SK Telecom'] — 기사 매칭·엔티티 연결용
groups text[]          -- ['telecom'] 또는 ['aidc','cloud_ai'] (다중)
is_competitor boolean
entity_id uuid null    -- entities 연결(있으면)
role text              -- 역할 메모
sort_order int
is_active boolean
```
- **기사 매칭 = name + aliases**(SKT/SK텔레콤 문제 해결).
- 회사 추가·그룹·별칭·노출방식 전부 **어드민 관리**.

## 3. 경쟁사 동향 탭 렌더 로직 (242/243/245 리팩터)
- 데이터원: `entities.competitor_group` → **`curated_companies`(is_competitor) + curated_groups**.
- 그룹 순서 = curated_groups.sort_order. 그룹별로 소속 회사(groups 배열 포함) 기사 매칭(name+aliases).
- **노출 방식 적용**:
  - `always` 그룹: 기사 없어도 그룹 박스 노출(빈 상태 안내).
  - `on_issue` 그룹: 최근 N일 관련 기사가 **임계치 이상일 때만** 그룹 노출(없으면 숨김). ④는 수주/제휴/대형, ⑤는 보안 이슈 키워드 가중.
- 위기/기회 칩(241 lgu_impact)·그룹박스·3×2 그리드(245)는 그대로 재사용.

## 4. 관심기업 큐레이션(7그룹)도 같은 테이블
- 앞서 받은 관심기업 7그룹(고객 포함)도 `curated_groups`(kind='watchlist')·`curated_companies`에 함께 시드.
- 관심기업 칩 = curated_companies(원하는 kind) → 사용자 선택 → 생성된 카드 노출.
- **경쟁사·관심기업 한 테이블**로 일원화(중복 회사는 groups·is_competitor로 구분).
