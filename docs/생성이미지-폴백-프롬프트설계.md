# 생성 이미지 폴백 풀 — 프롬프트 설계 (④)

목적: 원본에 이미지가 없는 콘텐츠에도 "빈 느낌 없는" 카드 커버를 주기 위해, **엔티티/키워드/카테고리별로 미리 생성해둔 이미지 풀**을 폴백으로 돌려 쓴다. David가 이 프롬프트로 이미지를 병렬 생성·저장하면, 후속 지시서(폴백 셀렉터)가 매칭해 사용한다.

## 0. 커버 폴백 체인 (우선순위)
1. **실제 이미지**(RSS 미디어 · 크롤 og:image · 업로드) → `thumbnail_url`
2. **og:image 재시도**(219, 수동/자동)
3. **생성 이미지 풀(④)** ← 이 문서
4. **BrandedCover**(211, 제목+카테고리 그라디언트) — 최종 안전망

## 1. 매칭 키 (이미지를 무엇에 붙일지)
콘텐츠 1건에 대해 위→아래 순으로 첫 매칭 키의 풀에서 1장 선택:
1. **엔티티**(워치리스트/EntityManager의 회사·기관, 예: `samsung`, `sk-hynix`, `lg-uplus`) — 가장 관련도 높음.
2. **키워드 그룹**(keyword_groups, 예: `ai`, `보안`, `통신`, `반도체`, `클라우드`, `경제`).
3. **카테고리**(`뉴스`·`웹인사이트`·`AI보고서`·`리포트`) — 최후 매칭.

각 키마다 **5~10장**의 변형을 두고, 콘텐츠 id 해시로 **결정적 회전**(같은 기사엔 항상 같은 이미지, 키 내에서 고르게 분산).

## 2. 저장·네이밍 규약 (David가 넣는 형태)
- 버킷: `topic-covers`(공개). 경로: `{keyType}/{keySlug}/{n}.webp` — 예: `entity/samsung/1.webp` … `entity/samsung/8.webp`, `group/ai/1.webp`, `category/뉴스/1.webp`.
- 규격: **16:9, 1200×675, webp**(카드 aspect-[16/9]와 일치), 200KB 내외 권장.
- slug 규칙: 영소문자·하이픈(엔티티/그룹 영문 slug), 카테고리는 한글 그대로.
- 셀렉터 지시서에서 이 규약으로 목록을 읽어 회전. (별도 DB 테이블 없이 스토리지 나열만으로 동작 가능; 필요 시 `topic_images` 인덱스 테이블은 후속 옵션.)

## 3. 스타일 가드레일 (전 이미지 공통 — 브랜드 일관성)
- **에디토리얼·추상**: 사진 같은 실사보다, 절제된 추상/기하/그라디언트 + 상징 오브젝트. 특정 실제 로고·인물·상표 금지.
- **텍스트 없음**(카드에서 제목이 위에 얹히므로 이미지에 글자 X).
- **브랜드 팔레트 우선**: 마젠타 포인트 `#DB0078`, 딥네이비/차콜 배경, 절제된 화이트/그레이. 카테고리별 보조색은 §4.
- **여백·구도**: 좌하/중앙 여백 확보(카드에서 제목·칩이 얹혀도 안 겹치게), 시선 집중 1포인트.
- **일관 톤**: 동일 조명·질감·채도로 "한 세트처럼". 다양성은 오브젝트·구도·색조에서만.
- 16:9, 고해상, 노이즈 최소.

## 4. 카테고리/도메인별 프롬프트 (복사용)
공통 접미사(모든 프롬프트 끝에 부착):
```
editorial abstract cover, no text, no logos, no real faces, 16:9, clean composition with empty space in lower-left, brand accent color magenta #DB0078 on deep navy/charcoal background, soft studio lighting, cohesive premium tech-media look, high resolution
```

- **AI/기술** (`group/ai`):
  `neural network motifs, flowing data filaments, translucent glass shapes, subtle circuit texture, calm futuristic —` + 공통접미사
- **보안** (`group/보안`):
  `abstract shield and lock geometry, layered secure vault motifs, encrypted grid, deep indigo with magenta highlight —` + 공통접미사
- **통신/네트워크** (`group/통신`):
  `signal waves, connected nodes over a stylized globe, fiber light streaks, telecom infrastructure abstracted —` + 공통접미사
- **반도체** (`group/반도체`):
  `macro abstract of silicon wafer patterns, chip lattice, metallic micro-architecture, cool tones with magenta accent —` + 공통접미사
- **클라우드/인프라** (`group/클라우드`):
  `floating cloud-server abstractions, stacked translucent layers, data centers as light blocks —` + 공통접미사
- **경제/시장** (`group/경제`):
  `abstract market rhythm, ascending light bars and curves, subtle grid, restrained gold+magenta on navy —` + 공통접미사
- **뉴스(일반)** (`category/뉴스`):
  `abstract broadcast/press motif, folded paper and light beams, dynamic diagonal composition —` + 공통접미사
- **리포트/AI보고서** (`category/리포트`, `category/AI보고서`):
  `abstract document/insight motif, layered charts as light, minimalist analytical geometry —` + 공통접미사

### 엔티티(회사) 프롬프트 패턴 (`entity/{slug}`)
로고·상표 없이 **업種 상징**으로:
```
abstract cover representing a {업종 예: telecom / semiconductor / consumer electronics} company, industry-symbolic geometry, no logo, no brand name — + 공통접미사
```
예) `lg-uplus` → telecom, `sk-hynix`/`samsung` → semiconductor/electronics. (엔티티별 5~8장, 색조/오브젝트만 변형.)

## 5. 변형(다양성) 축
같은 키에서 5~10장을 뽑을 때 아래만 바꿔 "세트감" 유지:
- 구도(대각/중앙/좌하 여백), 오브젝트 밀도(미니멀↔디테일), 색조(마젠타 비중), 질감(글래스/그레인/플랫), 조명 각도.

## 6. 다음 단계 (후속 지시서 예고)
이미지가 `topic-covers` 버킷에 위 규약대로 올라오면, **폴백 셀렉터 지시서**(예: 223)에서:
- 렌더 시 `thumbnail_url` 없으면 → 콘텐츠의 엔티티/키워드그룹/카테고리로 키 결정 → 해당 폴더 목록에서 id 해시로 1장 선택 → 카드에 표시(없으면 BrandedCover).
- 크롤 시점/백필로 `thumbnail_url`에 선주입할지, 렌더 시점 계산할지는 그때 결정(렌더 시점 계산이 저장 오염 없이 안전).
