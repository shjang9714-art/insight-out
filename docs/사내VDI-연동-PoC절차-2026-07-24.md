# 사내 VDI ↔ 인사이트 아웃 연동 PoC 절차서 (2026-07-24)

> 전제(확인됨): VDI 안에서 M365(Teams·SharePoint·Outlook·Copilot)·Power Automate 열림. **VDI Copilot이 이미 외부 뉴스 링크를 가져옴**(= MS 클라우드측 수집이 VDI 외부차단과 무관하게 작동).
> 핵심 원칙: **VDI에서 외부로 직접 나가지 않는다.** 인터넷 접근은 전부 MS 클라우드(Copilot Studio·PA 클라우드)가 대행하고, 결과는 M365에 착지시켜 VDI에서 열람.
> 담당: **[수희]** 토큰·시크릿 · **[David/관리자]** Copilot Studio·PA · **[Opus]** 이 절차서.

---

## 0. PoC 목표
VDI 사용자가 **VDI 안 M365 Copilot/Teams**에서 인사이트 아웃 데이터(콘텐츠·이슈·기업)를 질의·활용할 수 있음을 최소 구성으로 검증한다.

성패 기준: **VDI 안 Copilot/Teams 질의 → 인사이트 아웃 데이터가 답변에 나온다.**

---

## 1. 아키텍처 (한 줄)
```
[VDI]  Teams/Copilot(소비) ─┐
                            │ (M365, VDI 허용)
[MS 클라우드]  Copilot Studio 에이전트 ── MCP(streamable HTTP, Bearer) ──▶ 인사이트 아웃 /api/mcp
               Power Automate 클라우드 ──(선택) 데이터 이동 ──▶ SharePoint/Dataverse/Teams
[공개 인터넷]  insight-out-app.vercel.app
```
VDI는 외부에 안 나감. 인터넷 접근은 MS 클라우드가 대행.

---

## 2. 단계

### Phase A — 토큰·사전점검 (VDI 밖 / 관리자)
1. **[수희]** 읽기 전용 `mcp_token` 발급: `/api/admin/mcp-tokens`에서 **read 스코프만**(ops/reports/publish 제외), **만료** 설정(예: 90일).
2. **[수희]** 토큰을 **클라우드 시크릿**(Azure Key Vault 또는 Power Platform 환경변수)에 보관. 플로·에이전트 정의에 평문 금지. (VDI 안에서 토큰 다룰 일 없음.)
3. **[관리자, 외부 접근 환경에서]** MCP 핸드셰이크 사전점검 — Copilot Studio 붙이기 전, 외부 접근되는 환경(격리 외부창·개발 노트북·PA 테스트)에서 `/api/mcp`에 `initialize` → `tools/list` 확인. **streamable HTTP(POST)** 로 정상 응답하는지(SSE 아님).

### Phase B — Copilot Studio 에이전트에 MCP 연결 (MS 클라우드)
4. Copilot Studio에서 에이전트(신규 또는 기존)에 **MCP 도구로 `/api/mcp` 추가**. 각 도구(콘텐츠 검색·이슈·기업 조회)가 액션으로 자동 등록됨(GA 기능).
5. **인증**: 커넥션에 **API 키(헤더)** 방식으로 `Authorization: Bearer <read 토큰>` 주입.
6. **에이전트 지시문**: "LG U+ 기업사업 사내 인텔리전스 에이전트. 시장·경쟁사·이슈 근거는 인사이트 아웃 도구에서 가져와 답한다" 식 페르소나·근거 규칙.
7. **클라우드 테스트**: Copilot Studio 테스트 창에서 "경쟁사 ○○ 최근 이슈" 질의 → MCP 도구 호출·답변 확인.

### Phase C — VDI 소비 검증 (성패 지점)
8. 에이전트를 **Teams(채널/앱) 또는 M365 Copilot**에 게시.
9. **VDI 안 Teams/Copilot에서** 같은 질의 → 인사이트 아웃 데이터가 답변에 나오는지 **육안 확인**. ← 이게 PoC 성패.
   - VDI Copilot이 이미 외부 뉴스를 가져오므로, 같은 MS-클라우드 경로라 높은 확률로 성공.

### Phase D — (선택) Power Automate 데이터 이동
10. **PA 클라우드 플로**(VDI에서 작성해도 실행은 MS 클라우드): 스케줄 → 인사이트 아웃 호출 → 결과를 **SharePoint/Dataverse/Teams**로 적재.
    - ⚠️ PA는 REST/HTTP를 잘 다루고 **MCP JSON-RPC는 서툼**. PA로 옮길 거면 MCP를 억지로 부르기보다 (a) Copilot Studio 워크플로가 MCP 호출, 또는 (b) 인사이트 아웃에 **얇은 REST read 엔드포인트** 추가가 깔끔.
11. VDI에서 그 SharePoint/Teams 열람 확인.

---

## 3. 확인 포인트 · 리스크
- **전송 호환**: Copilot Studio는 SSE 미지원(2025-08~), **streamable HTTP만**. 인사이트 아웃은 `mcp-handler`라 지원 — Phase A-3에서 실측.
- **라이선스**: Copilot Studio 메시지 용량 · PA 프리미엄 커넥터(HTTP).
- **토큰**: read 전용·만료·클라우드 시크릿 보관. 유출 시 즉시 폐기(`revoked_at`).
- **egress IP 제한**: 인사이트 아웃은 현재 공개라 불필요. 추후 IP allowlist를 걸면 Copilot Studio egress IP 확인.
- **DLP**: Power Platform DLP 정책에서 이 커넥터·MCP 사용 범위 검토(사내 IT).
- **VDI는 소비만**: 모든 인터넷 접근은 MS 클라우드. VDI에서 직접 API/curl/PAD로 외부 호출 시도 금지(어차피 안 나감).

## 4. 인사이트 아웃 측 준비물 (요약)
- **필수 1개**: read 스코프 `mcp_token` 발급(기존 `/api/admin/mcp-tokens`). **신규 코드 없음.**
- **선택**: PA에서 REST로 당길 경우 얇은 read 엔드포인트(별도 지시서). MCP만 쓰면 불필요.
