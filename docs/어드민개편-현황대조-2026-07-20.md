
## 3. 🔴 최종안 §15 재배치 미이행

리포트 그룹에 아래 두 항목이 **독립 메뉴로 남아 있다.**

| 현재 위치 | 최종안 §15 지정 위치 |
|---|---|
| 리포트 > **프롬프트 콘솔** (`/admin/prompts`) | *AI 콘텐츠별 프롬프트 탭* 으로 흡수 |
| 리포트 > **AI 콘텐츠 보강** (`/admin/ai-jobs`) | *각 콘텐츠 관리 화면의 AI 작업* 으로 흡수 |

같은 성격으로 확인이 필요한 것:
- 콘텐츠 > **소스 관리**(`/admin/sources`) → §15는 *"콘텐츠 유형별 > 소스 관리"* (뉴스·웹인사이트 각 화면의 탭)
- 콘텐츠 > **수집 설정**(`/admin/crawl-settings`) → §15는 *"해당 콘텐츠 내부"*
- 콘텐츠 > **데이터 보강 재처리**(`/admin/enrich`) → §15는 *"각 콘텐츠 관리 또는 작업·오류 센터"*
- 통계분석 > **수집 분석**(`/admin/source-quality`) → §15의 *"소스 품질 → 통계분석 > 수집 분석"* 은 이행됨 ✅

**이 항목들은 탭 구조가 생겨야 흡수할 자리가 만들어진다.** 즉 §2(탭)와 §3(재배치)은 같은 작업이다.

## 5. ⚠️ 확인이 더 필요한 것 (추정 금지)

이 문서의 §2 표는 **`AdminTabShell`/`AdminTabs` import 여부로 판정**했다. 화면을 직접 열어본 것이 아니다.

- 각 화면이 실제로 몇 개 탭을 가졌는지, 최종안 탭 이름과 얼마나 맞는지는 **미확인**이다.
- `AdminContentManager`(2,230줄)는 카테고리 탭을 갖고 있으나 §8의 *기능* 탭(현황·소스관리·수집실행·본문수집·수집이력·통계)과는 다른 축이다. **둘을 혼동하지 말 것.**
- 다음 슬라이스 착수 전 대상 화면을 **직접 열어 탭 목록을 기록**할 것.

> 플래너는 오늘 성능 레인에서 **크기·상태를 확인하지 않아 5회 오진**했다(로드맵 §5). 같은 실수를 어드민 레인에서 반복하지 않는다.
