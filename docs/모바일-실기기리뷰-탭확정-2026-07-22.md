## 2. 🔴 탭 구성 확정 — 결정 근거

**레인 문서는 "기업 1급 승격을 제안"이라 적었으나, 확인 결과 이미 IA 문서가 확정한 사항이다.**

| 문서 | 시점 | L1(1급) 메뉴 |
|---|---|---|
| 마스터플랜 | 2026-06-19 | 홈·이슈·검색·보고서·**마이** |
| **사용자IA-재구성** | 2026-06-22 (갱신) | **홈·이슈·기업·기회·콘텐츠·보고서** + 검색 1급 |

→ **6-22 IA 가 6-19 마스터플랜을 갱신**했고, 거기서 **기업은 이미 L1**이다(§61 "기업 `/dashboard/entities` — 워치리스트·엔티티 한장 브리핑·관계 뷰"). 레인의 모바일 탭(홈·이슈·검색·기업·보고서)은 이 IA 와 정합한다.

### 2.1 모바일 5슬롯 매핑 (IA L1 6개 + 검색 → 하단 5탭)

| IA L1 | 모바일 배치 |
|---|---|
| 홈 | **탭 1** |
| 이슈 | **탭 2** |
| 검색 | **탭 3 (중앙 FAB)** — IA 에서 상시 1급 |
| 기업 | **탭 4** |
| 보고서 | **탭 5** |
| 기회 | → **이슈/보고서에 흡수**(IA §23: AI분석→보고서 흡수, 기회는 이슈의 렌즈) |
| 콘텐츠 | → **검색 안 필터**(IA §10·§70: "출처는 축이 아니라 원재료") |
| 마이 | → **우상단 아바타**(탭 아님) |

### 2.2 David 확정 필요
1. **5탭 = 홈·이슈·검색·기업·보고서** 로 확정하는가? (IA 근거로 타당)
2. **마이를 우상단 아바타**로 빼는 데 동의하는가? (5슬롯 확보 위해)
3. **기회·콘텐츠**를 위 매핑대로 흡수하는가, 별도 진입점이 필요한가?

→ 이 셋이 정해지면 **M-2(앱 셸·하단 탭바)를 지시서로 내린다.** 정해지기 전엔 M-2 착수 안 함(탭이 바뀌면 셸을 다시 짬).
