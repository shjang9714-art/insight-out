# 사용자 화면 IA 재구성 — 메뉴트리 · 제공 기능 · 기대효과

> 작성: Opus(Cowork) · 2026-06-22 · 근거: [IA 재설계 메모] · [이슈중심·엔티티 로드맵] · 화면개편 마스터플랜 · 현행 코드(`Sidebar.tsx`·dashboard 라우트)
> 목적: 출처중심 메뉴 → **마켓 인텔리전스 축**으로 재편하는 목표 IA를 확정 가능한 형태로 정리.

---

## 0. 한 줄 요약

**출처(뉴스·리포트·웹인사이트·유튜브)는 "축"이 아니라 "원재료(라이브러리)"다.** 진짜 축은 **이슈 · 기업 · 기회**(=인텔리전스)이고, 출처는 그 아래 "콘텐츠"로 접고 필터로 내린다. 결과물은 **보고서**로 모은다.

3계층 모델: **Raw(콘텐츠 수집) → Knowledge(이슈·기업·시그널·관계) → Output(인사이트·전략보고서)** + 홈 + 검색 1급.

---

## 1. 현행 → 목표 (한눈에)

| | 현행(출처 축) | 목표(인텔 축) |
|---|---|---|
| 상단 L1 | 뉴스 · 리서치 · 웹인사이트 · 유튜브 · AI분석 · 전략보고서 | **홈 · 이슈 · 기업 · 기회 · 콘텐츠 · 보고서** (+검색 1급) |
| 이슈/지식그래프 | 페이지는 있으나 **네비 진입점 없음=매몰** | **이슈=L1**, 지식그래프=기업/이슈 안의 "관계" 렌즈 |
| 출처 4종 | 각각 별도 메뉴 | **"콘텐츠" 하나로 접고 출처는 필터** |
| AI분석 | 별도 메뉴(죽은 `AnalysisTabs` 포함) | **보고서로 흡수**(인사이트+전략보고서) |
| 라벨 | '리서치'(확정명 '리포트'와 불일치) | '리포트'로 정정 |

## 2. 목표 메뉴트리

```
검색 ───────────────── (상단 상시 1급, 추천 질문 칩)

홈
이슈
기업
기회 ★신규축
콘텐츠 (라이브러리)
보고서

[좌측 개인 레일] 아카이빙 · 내 북마크 · 모닝브리핑(지난 브리핑) · 최근 본 항목
```

렌즈(별도 L1 아님, 허브 안의 뷰):
- **지식그래프** → 기업·이슈 안의 "관계" 탭
- **논조/시그널** → 이슈·기업 안의 지표
- **모닝브리핑** → 홈 카드 + 좌측 레일(현행 유지)
- **카드뉴스형 요약** → 표현 형식(홈/이슈/브리핑), 새 메뉴 아님

## 3. 메뉴별 제공 기능 · 기대효과

### 홈 `/dashboard`
- **제공 기능**: 오늘의 이슈·급상승 키워드(지시서 104) · 추천 질문 칩 레일(렌즈별: 경쟁사/규제/기회/내서비스) · 모닝브리핑 플레이어 카드 · 관심 기업 동향 요약.
- **기대효과**: 로그인 직후 "지금 무슨 일이 일어나는가"를 5초에 파악. 콜드스타트(뭘 봐야 할지 모름) 해소. 추천 질문이 탐색의 진입점이 됨.

### 이슈 `/dashboard/issues`
- **제공 기능**: 테마/내러티브 단위 타임라인 · `content_signals`(1,159건) 흡수 · 논조 분포 추이 · 유사 이슈/변화 추적(105) · 이슈→근거 콘텐츠 드릴다운.
- **기대효과**: 개별 기사 더미가 아니라 **"흐름"으로** 시장을 읽음. 무엇이 뜨겁고(부정 볼륨) 어디로 가는지(타임라인)가 보임. 전략보고서의 원천.

### 기업 `/dashboard/entities`
- **제공 기능**: 워치리스트(93) · 경쟁사 동향 카드+논조(96·97) · 엔티티 한장 브리핑(102) · **관계 뷰(지식그래프 112, react-force-graph)** · 기업별 이슈/시그널 묶음. (인물=의사결정자·업계 인물의 **공개·직업적 수준만**, 사생활 제외 — PIPA 준수)
- **기대효과**: "이 경쟁사 지금 어떤가"를 한 화면에. 워치리스트로 추적 자동화. 관계 뷰로 숨은 연결(파트너십·공급망) 발견.

### 기회 `/dashboard/opportunities` ★신규
- **제공 기능**: 사업공고·RFP·매출 신호(나라장터/조달청 공공데이터 등 **신규 소싱**) · `content_signals`에 "사업기회" 클래스 · 마감일·발주처·금액 필터.
- **기대효과**: **인텔리전스 → 영업 파이프라인 전환** = 최대 차별화. "동향만 보는 툴"에서 "돈 되는 단서를 주는 툴"로. (단, 신규 데이터 소싱 필요 = 후반 단계.)

### 콘텐츠 `/dashboard/contents` (+ 유튜브 흡수)
- **제공 기능**: 전 출처 통합 라이브러리 · **출처/카테고리/소스 facet 필터** · 본문(풀본문)·요약 · 검색 스코프 · 아카이빙/북마크 담기 · 소스 신뢰 배지(품질 레이어).
- **기대효과**: 출처 4개 메뉴를 1개로 접어 **네비 단순화**. 원하는 사람은 필터로 깊이 파고, 대부분은 이슈/기업을 통해 도달. 라이브러리 성격 명확.

### 보고서 `/dashboard/reports` (+ AI분석 흡수)
- **제공 기능**: AI 인사이트 카드 · **전략보고서 생성 워크벤치(조립기)** · 뷰어·PDF 내보내기 · AI로 다듬기(LLM) · 근거 콘텐츠 연결.
- **기대효과**: 분석의 **산출물(캡스톤)**을 한 곳에. 인텔을 의사결정 문서로 전환. 공유/발행 동선의 종착점.

### 검색 (상단 1급)
- **제공 기능**: 전역 검색 + facet · 추천 질문 칩(템플릿=지금 가능, 생성형 답변=LLM) · 결과→필터뷰 점프.
- **기대효과**: 메뉴를 모르는 사용자도 질문으로 진입. 발견성↑.

## 4. 단계별 전환 로드맵 (저비용 → 고비용)

| 단계 | 내용 | 의존성 |
|---|---|---|
| **1. 매몰 해소·라벨 정정** | 이슈·기업을 상단 L1으로 노출, '리서치'→'리포트', 죽은 `AnalysisTabs` 정리 | 없음(즉시) |
| **2. 출처 통합** | 뉴스/리포트/웹인사이트/유튜브 → "콘텐츠" 1개 + 출처 필터 | 없음(라우팅·필터) |
| **3. 허브 강화** | 이슈(시그널 흡수)·기업(관계 뷰 배선) 1급 허브로 완성 | 일부 LLM(논조·요약, **이미 점등**) |
| **4. 보고서 통합** | AI분석 → 보고서로 흡수, 인사이트+전략보고서 한 축 | 없음(이미 캡스톤 구현됨) |
| **5. 기회 신규축** | 공공데이터 소싱 + 사업기회 시그널 분류 | **신규 소싱·개발(큼)** |
| **6. 품질 레이어** | trust_tier+importance_score → 통합 품질점수(랭킹·필터·배지) | 중간 |

**원칙**: 1~2는 비용 거의 없고 체감 큰 정리 → 먼저. 3~4는 핵심 루프 완성(현재 거의 닫힘). 5(기회)는 가장 큰 차별화지만 신규 소싱이라 별도 트랙.

## 5. 확정 필요 (다음 판단)

1. **기회를 1급 축으로 확정**할지 — 확정 시 공공데이터 소싱 투자 시작. (권고: 슬롯은 예약, 구현은 3~4 이후)
2. **허브 네이밍** — `기업` vs `기업·인물` vs `엔티티`. (권고: 당분간 **기업**, 인물 적재 늘면 '기업·인물')
3. **C 재편 실행 시점** — 메모리 합의=캡스톤+온보딩 직전. 현재 캡스톤 거의 닫힘 → **1·2단계는 지금 착수해도 안전**.
4. **추천 질문 톤** — 차분한 칩 레일(권고) vs 절제된 모션.
