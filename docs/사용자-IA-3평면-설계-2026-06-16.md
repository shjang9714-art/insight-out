# 사용자 정보구조(IA) 3평면 설계 — 2026-06-16

> 정본 설계. David 확정 계위 기반. 변경 시 이 문서 우선. 구현은 단계별 지시서로 분리.

## 0. 한 줄
> ⚠️ **이건 사용자 네비 개편이 아니다.** 사용자 화면은 **카드 형태 유지**. 이 계위는 "각 카드가 무엇을 보여줄지"를 정의하는 **카드 콘텐츠 모델**이며, 실제 구현 액션은 이 구조가 요구하는 만큼 **어드민(운영자) 측 반영**이다.

사용자 카드를 **수집 / 생성 / 개인** 세 평면 + **개요·오늘**으로 가르는 콘텐츠 모델. 지금까지 평면 6타일(`CATEGORY_DEFS`)에 뒤섞여 있던 "수집 카테고리"와 "생성물(AI분석·전략보고서)"을 개념상 분리한다(지시서 75에서 미뤄둔 정리의 방향).

## 1. 확정 계위 (David)
```
전체 현황
├─ 오늘의 핵심 인사이트
├─ 외부 시그널            (수집)
│  ├─ 뉴스
│  ├─ 리서치 (Gartner / KRG)
│  ├─ 웹 인사이트
│  ├─ 뉴스레터            (수집 보류 — 자리만)
│  └─ 유튜브
├─ AI 분석               (생성)
│  ├─ 요약
│  ├─ 트렌드 감지
│  ├─ 경쟁사 분석
│  └─ 전략 시사점
├─ 전략 보고서           (생성)
│  ├─ AI보고서
│  ├─ 주간 브리프
│  └─ 임원 보고용 메모
└─ 아카이브              (개인)
   ├─ 저장한 콘텐츠
   ├─ 태그별 보기
   └─ 프로젝트별 보기
```

## 2. 세 평면 원칙 (MECE)
| 평면 | 의미 | 데이터 출처 | content_category? |
|---|---|---|---|
| **수집(외부 시그널)** | 외부에서 들어온 원본 | `contents`(뉴스/리포트/웹인사이트/유튜브), `youtube_videos` | ✅ enum 값 |
| **생성(AI 분석·전략 보고서)** | 시스템/LLM이 만든 산출물 | `content_signals`, `ai_reports`, `briefings` | ❌ enum 아님 — 별도 테이블/라우트 |
| **개인(아카이브)** | 사용자가 모은 것 | `archives`, `archive_items`, `bookmarks`, `content_keywords` | ❌ 뷰·필터 |

핵심: **생성물은 `content_category` enum에 넣지 않는다.** `AI분석`·`전략보고서`를 콘텐츠 카테고리 타일에서 빼는 것이 75 버그의 근본 해소.

## 3. 데이터 준비도 매핑
- **운영(그대로 가동)**: 뉴스·리서치·웹인사이트·유튜브(외부 시그널), 저장한 콘텐츠(아카이브).
- **부분(데이터 있음·UI 미완)**: 오늘의 핵심 인사이트(중요도·브리핑 인접), 요약(`summary_ko` 존재), 경쟁사 분석(`content_signals` 적재 중), AI보고서(`ai_reports` 테이블만), 태그별·프로젝트별(모델 완비, 화면 보강).
- **예정(신규)**: 전체 현황(사용자 대시보드), 트렌드 감지, 전략 시사점, 주간 브리프, 임원 메모.
- **수집 보류**: 뉴스레터(수집 폐기 상태 — 노드는 자리만, 부활은 별도 결정).

## 4. 어드민 반영 + 단계 로드맵
**사용자 화면은 카드 유지.** 아래는 이 카드 모델을 받치기 위한 어드민/백엔드 작업.

1. **생성물·수집 분리 정리(어드민, 저비용)** — 어드민 콘텐츠 관리 카테고리 탭에서 **생성물(AI분석·전략보고서) 제거**(contents에 없는 값 → 항상 빈 결과). 수집 카테고리(뉴스/리서치/웹인사이트/유튜브)만 탭으로. 75의 가드를 UI까지 마무리. → 지시서 78 후보.
2. **AI 분석 받침** — `content_signals`(이미 적재 중) 운영 뷰: 어드민 "AI·처리" 섹션(지시서 76)에 시그널 현황·LLM 이벤트 분석 관리. 사용자 'AI 분석' 카드(경쟁사·트렌드·전략 시사점)의 공급원.
3. **전략 보고서 받침** — `ai_reports` 생성 플로우 + 주간 브리프·임원 메모 타입(ai_report_type 확장 검토). 사용자 '전략 보고서' 카드 공급원.
4. **개요·오늘 받침** — '오늘의 핵심 인사이트' 카드는 editor pick·중요도·브리핑으로 공급(어드민 모닝브리핑·에디터픽 기존).

## 5. 결정 기록
- **사용자 화면 = 카드 유지.** 이 계위는 카드 콘텐츠 모델(무엇을 보여줄지), 네비 개편 아님. 실제 작업은 어드민 반영.
- 뉴스레터: **보류**(자리만·수집 부활 미정).
- 리서치: 카테고리 아님 → `리포트` 아래 **발행처(source: Gartner/KRG)**. 카드 라벨 "리서치".
- 생성물(AI분석/전략보고서): content_category 분리 — 어드민 콘텐츠 탭에서 제외, 별도 공급 경로.
