# 설계 — 전략보고서 재설계: 리서치 카드형 + AI프롬프트 HTML + 정기 발행(HITL)

## 배경/결정 (David)
현행 전략보고서(`ai_reports`)는 이슈/콘텐츠 통계를 **템플릿으로 markdown 조립** → 텍스트 리스트로 노출. 표지·요약·발행자 개념 없음, LLM 심층 생성 아님.

David 재설계 방향:
- **양식**: 리서치 콘텐츠 카드처럼 — **상단 이미지 + 제목 + 요약 + 날짜 + 발행자**.
- **본문**: AI 프롬프트 기반 **HTML(주로)** 생성. **주제·퀄리티·LLM 프롬프트가 매우 중요**.
- **운영**: 관리자 **human-in-the-loop 정기 발행물**. 표지 = **관리자 업로드 + AI 생성(나노바나나) 둘 다**. 본문 = **생성 위주·편집 최소(재생성)**. 발행 = **수동 먼저, 스케줄 후속**.

## 데이터 모델 (ai_reports 확장 — SQL 274)
추가 컬럼:
- `body_html text` — 본문(HTML, 주 렌더). 기존 `body_md` 는 폴백 유지.
- `summary text` — 카드 요약(2~3줄).
- `cover_image_url text` — 표지(업로드 또는 AI 생성 결과 URL).
- `publisher text default '인사이트 아웃'` — 발행자.
- `published_at timestamptz` — 발행일(카드 날짜). null=미발행.
- `topic text` — 주제(자유 문자열; 기존 `type` 는 분류 배지로 유지).
- status 확장: 기존 draft/generating/completed/failed + **published**(발행 완료·서비스 노출).

노출 규칙: **서비스(사용자) = `status='published'`(+ published_at) 카드만**. 어드민 = 전체.

## 프롬프트 (llm_prompts, key `strategy_report` — 어드민 편집)
- LLM이 **주제(+선택 소스: 이슈·콘텐츠 요약)**를 받아 **구조화된 한글 HTML 보고서**를 생성. 섹션(요약·배경·핵심분석·시사점·전망 등), 표/리스트 허용, 인라인 스타일 최소·시맨틱 태그 위주.
- **한글 강제**, 과장 금지·근거 기반, LG U+ B2B 관점. 프롬프트는 어드민에서 편집(퀄리티 핵심).
- 카드 `summary` 는 (a) 프롬프트가 함께 반환하거나 (b) 본문 첫 단락 추출.

## 생성 파이프라인
1. 어드민: 주제/타입 선택 + (선택) 소스 이슈·콘텐츠 지정 + (선택) 프롬프트 편집.
2. 소스 컨텍스트 수집(기존 이슈/콘텐츠 요약 재사용) → `llmComplete`(report 태스크, 무료 LLM 가능) → **HTML 초안** + summary → `body_html` 저장(status draft).
3. 어드민 검토 → 부족하면 **재생성**(프롬프트/주제 조정). 편집은 최소(원하면 원본 HTML 미세수정 옵션).
4. 표지: **업로드**(기존 `upload-cover.ts` 재사용, Supabase Storage) 또는 **AI 생성**(후속: 이미지 생성 엔드포인트 붙으면). 발행자·발행일 지정.
5. **발행**(status='published', published_at=now) → 서비스 카드 노출.

## 서비스 UI
- 리스트: **카드 그리드**(리서치/콘텐츠 카드 톤) — cover_image_url 상단, 제목, summary, published_at, publisher. published만.
- 상세: `body_html` **살균(sanitize) 후 렌더**(prose 스타일). body_html 없으면 body_md 폴백(ReportMarkdown).

## 보안
- HTML 본문은 **렌더 시 sanitize**(script/onN 제거) — 관리자 작성(HITL)이라도 방어적. 표지 업로드는 이미지 타입·크기 제한.

## 구현 분할(지시서)
- **274 (백엔드·모델·생성)**: SQL 274 적용 전제 graceful, LLM HTML 생성 + 프롬프트 로드 + 발행 상태.
- **275 (서비스 UI)**: 카드형 리스트 + HTML 상세(sanitize).
- **276 (어드민 HITL)**: 생성·재생성·표지(업로드/AI훅)·발행자/발행일·발행 워크플로우 + 프롬프트 관리 노출.
- **후속**: AI 표지 생성(나노바나나) 파이프라인, 스케줄 자동 초안.

## 회귀/그레이스풀
- 274 SQL 미적용(42703): 신규 컬럼 조회 스킵, 기존 body_md 흐름 유지.
- 무료 LLM 실패: 초안 실패 상태·재시도, 서비스엔 미노출.
