# AI Toolchain Map

Audit date: 2026-07-10  
Scope: user-facing and admin-adjacent AI, automation, rule-based, ranking, retrieval, crawling, media-processing, notification, and analytics tooling in the current Insight Out repository.

## 0. Executive Summary

- Insight Out currently uses a custom LLM router in `src/lib/llm/`, not the Vercel AI SDK or an OpenAI SDK. The router fans out to Gemini and OpenAI-compatible providers by raw `fetch`.
- RAG, embeddings, vector search, reranking, and RRM-like modules were not confirmed in code. Current retrieval is SQL, ILIKE search, keyword overlap, issue/entity linking, and Jaccard-style similarity.
- News crawling, RSS parsing, YouTube Atom feed ingestion, full-body extraction, translation, summarization, classification, recommendation scoring, briefing generation, newsletter dispatch, and TTS are implemented to different levels of maturity.
- OCR and STT are not implemented. Scanned PDF detection exists, but scanned PDFs are returned as needing OCR.
- YouTube transcript parsing is not implemented. YouTube summaries are generated from title/channel metadata only.
- Image generation is not implemented in runtime code. Generated-image prompt libraries exist in docs, while the product currently uses deterministic cover fallbacks and thumbnail extraction/copying.
- Search logging was not confirmed in code. Search is user-facing, but analytics for query value and failure modes are missing.
- Several operational controls exist under admin routes, but durable AI job logs, prompt-version management, raw item review, search logs, OCR queue, generated-image management, and recommendation rule management are incomplete or missing.
